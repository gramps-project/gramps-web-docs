    Configuración de Administración¶

    La página de Configuración > Administración es accesible a través del ícono de usuario en la barra de aplicaciones superior. Solo está disponible para usuarios con el rol de Propietario o Administrador y proporciona herramientas para gestionar la base de datos del árbol genealógico.

    La página está organizada en secciones colapsables. Haz clic en el encabezado de una sección para expandirla. Esta página enumera las secciones y enlaces a donde cada una de ellas está descrita.

    Datos¶

    • Cuotas de uso – uso actual en relación con los límites para personas y almacenamiento de medios
    • Importar datos – subir un archivo de árbol genealógico
    • Estado del archivo multimedia – objetos multimedia con sumas de verificación o archivos faltantes
    • Importar archivo multimedia – subir un archivo ZIP para completar archivos multimedia faltantes

    Índice de búsqueda¶

    • Gestionar índice de búsqueda – verificar el estado del índice y reconstruirlo

    Configuración del árbol¶

    • Nombre del Árbol Genealógico – renombrar la base de datos subyacente de Gramps
    • Información del Investigador – detalles de contacto del investigador principal, incrustados en las exportaciones

    Personalización¶

    • Colores del tema – color primario y de acento
    • Título de la aplicación – título mostrado en el navegador y en la barra de aplicaciones superior
    • Nota de la página de inicio – una nota mostrada en la página de inicio
    • Imagen de la página de inicio – una imagen mostrada en la página de inicio
    • Configuraciones de Exportación/Importación – copiar configuraciones del árbol como un archivo JSON

    Procesamiento del Árbol Genealógico¶

    • Verificar y Reparar Base de Datos – encontrar y corregir inconsistencias en la base de datos
    • Verificar los Datos – encontrar datos implausibles, como edades inusuales

    Etiquetas¶

    • Gestionar etiquetas – crear, renombrar, recolorear y eliminar etiquetas

    Copias de seguridad¶

    • Copias de seguridad almacenadas – copias de seguridad mantenidas en el servidor
    • Restaurar desde Copia de Seguridad – reemplazar el árbol con una copia de seguridad o un archivo XML de Gramps

    Zona de Peligro¶

    • Eliminar todos los objetos – limpiar el árbol o eliminar tipos de objetos específicos
