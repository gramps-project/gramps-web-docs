    データのインポート¶

    既存の家系図をGramps Webに取り込むには、別の系譜プログラム、オンラインサービス、またはGramps Desktopからエクスポートされたファイルをアップロードします。

    インポートは、ツリーの所有者と管理者が利用できる管理設定のデータセクションにあります（アプリバーのユーザーアイコン ▸ 管理）。ツリーがまだ空の状態のときは、ホームページの「始める」カードにある家系図のインポートボタンもそこに導きます。

    どのファイルを使用するか¶

    出所 ツリーをエクスポートする形式 ファイル拡張子
    別の系譜プログラムまたはオンラインサービス GEDCOM .ged
    Gramps Desktop Gramps XML .gramps
    GeneWeb GeneWeb .gw
    Pro-Gen Pro-Gen .def
    スプレッドシート Gramps CSV .csv
    アドレス帳 vCard .vcf

    GEDCOMは、ほぼすべての系譜プログラムやオンラインサービスがエクスポートできる共通の交換形式です。プログラムやウェブサイトで「エクスポート」または「ダウンロード」オプションを探し、複数の形式が提供されている場合はGEDCOMを選択してください。Gramps Wikiページの別の系譜プログラムからのインポートには、特定のプログラムに関する注意事項があります。

    Gramps Desktopを使用している場合は、GEDCOMではなくGramps XML（.gramps）を選択してください。これにより、すべてのGrampsデータが損失なく保持され、オンラインとオフラインのツリーは同じ識別子を保持するため、同期できます。以下のGramps Desktopからのインポートを参照してください。

    家系図ファイルのインポート¶

    1. 管理設定のデータセクションを開きます。
    2. 「家系図のインポート」の下で、ファイルを選択し、インポートをクリックします。
    3. ファイルが最初に解析され、「インポートの確認」ダイアログがオブジェクトの数（人、家族、イベント、場所など）を表示します。まだツリーには何も追加されていません。カウントが妥当に見えることを確認し、続行するにはインポートをクリックするか、何も変更せずに中止するにはキャンセルをクリックします。
    4. インポートはバックグラウンドで実行され、進行状況インジケーターが表示されます。データがインポートされると、検索インデックスが更新されます。大きなツリーの場合、これには時間がかかることがあります。

    インポートが完了したら、結果を確認します：ホームページの統計パネルに表示される人の数を古いプログラムの数と比較し、よく知っている家族を開いて、親、子供、日付、場所が期待通りに移行されたかを確認します。

    Warning

    通常のインポートは純粋に追加的です：常に新しいオブジェクトを作成し、既存のオブジェクトを更新または削除することはありません。同じGramps IDまたはハンドルの下にすでに存在するオブジェクトに対しても同様です。同じファイルを二度インポートすること、またはツリー内のデータと重複するファイルをインポートすることは、マージまたはスキップするのではなく、すべての一致するオブジェクトを重複させます。

    すでにインポートされたツリーに他の場所で行われた変更を取り込む必要がある場合は、バックアップからの復元を使用してください。これは、アップロードされたファイルに一致するようにツリーを置き換え、追加するのではありません。これにはGramps XMLファイルが必要です。

    ツリーに対して人の数に制限が設定されている場合（使用制限を参照）、それを超えるインポートは全体として拒否されます。

    GEDCOMファイル¶

    GEDCOM 5.5.1およびGEDCOM 7ファイルの両方をインポートできます。いくつか注意すべき点があります。

    文字エンコーディング¶

    GEDCOM 5.5.1ファイルは、そのヘッダーで文字エンコーディングを宣言します。UTF-8、UTF-16、ANSEL、およびWindows（ANSI）エンコーディングがサポートされています。インポート後にアクセントや他の特殊文字を含む名前が文字化けしている場合（例えば、MÃ¼llerではなくMüller）、ファイルは宣言されたものとは異なるエンコーディングでエクスポートされた可能性があります。古いプログラムから再度ファイルをエクスポートし、選択肢があればUTF-8を選んで、やり直してください。

    GEDCOM 7ファイルは常にUTF-8でエンコードされる必要があります。他のファイルは「無効なGEDCOMファイル」というエラーで拒否されます。

    プログラム固有のデータ¶

    多くのプログラムは、他のプログラムが理解できない独自の拡張をGEDCOMに追加します。Grampsはそのようなデータを静かに削除することはありません：解釈できない行は、「GEDCOMインポート」というタイプのノートに収集され、それに属する人、家族、または他のオブジェクトに添付されます。重要な情報が移行されなかったかどうかを確認するために、これらのノートを確認してください。

    メディアファイル¶

    GEDCOMファイルにはメディアファイル（写真やスキャンした文書など）への参照が含まれていますが、ファイル自体は含まれていません。インポート後、メディアオブジェクトはツリー内に存在しますが、そのファイルは欠落しており、メディアファイルの状態に表示されます。ファイルを追加するには、以下のメディアファイルのインポートを参照してください。

    Gramps Desktopからのインポート¶

    Gramps Desktopを使用している場合、次の手順でデータベースを準備し、すべてがスムーズに実行されるようにします。

    1. データベースをチェックして修復する
      • オプション：Gramps XMLにエクスポートしてデータベースのバックアップを作成します
      • データベースのチェックと修復ツールを実行します。これにより、Gramps Webで問題を引き起こす可能性のある内部の不整合が修正されます。
    2. メディアパスを相対パスに変換する
      • Grampsメディアマネージャーを使用して、すべてのメディアパスを絶対から相対に変換します。相対パスであっても、Grampsメディアディレクトリの外にあるメディアファイルは、Gramps Webと同期すると正しく機能しないことに注意してください。

    その後、ツリーをGramps XML（.gramps）にエクスポートし、上記の手順に従ってインポートし、次のセクションで説明するようにメディアファイルをアップロードします。同じツリーで作業を続けるには、Gramps Web Syncアドオンを使用してください。

    Gramps XMLパッケージのサポートがない理由¶

    Gramps XML（.gramps）はデータをインポートするための推奨形式ですが、Gramps XML パッケージ（.gpkg）はGramps Webではサポートされていません。これは、メディアファイルのインポートおよびエクスポートルーチンがウェブサーバーでの使用に適していないためです。

    メディアファイルのインポート¶

    家系図をインポートし、対応するメディアファイルをアップロードする必要がある場合は、管理設定のデータセクションでメディアファイルのインポートを使用します。これは、欠落しているメディアファイルを含むZIPファイルを期待します。ファイルは、次の2つの方法のいずれかでツリー内のメディアオブジェクトにマッチします：

    • チェックサムによるマッチング。 チェックサムを持つメディアオブジェクト（Gramps Desktopからインポートされたツリーの場合など）については、ZIPファイル内の名前やフォルダ構造に関係なく、一致するチェックサムを持つファイルが使用されます。これは、Grampsデータベース内のチェックサムが正しい場合にのみ機能します。チェックと修復ツールを実行することでこれが保証されます。
    • パスによるマッチング。 チェックサムを持たないメディアオブジェクト（GEDCOMインポート後に一般的）については、そのパスによってマッチングされます：ZIPファイルには、メディアオブジェクトに保存されている正確な相対パスの下にファイルが含まれている必要があります。

    GEDCOMファイルに保存されているパスが絶対パスである場合（例えば、C:\Users\...\photo.jpg）、パスによるマッチングは機能しません。この場合、最初にすべてをGramps Desktopにインポートし、インポートされたツリーと既存のメディアファイルを関連付けるためのオプションが多いため、Gramps Desktopからのインポートで説明されているようにGramps Webに移動することをお勧めします。

    よくある問題¶

    「サポートされていない形式」。 上記にリストされているファイル拡張子のみがインポートできます。プログラムまたはオンラインサービスがZIPアーカイブを提供した場合は、それを解凍し、内部の.gedファイルをアップロードしてください。

    すべてが二重に表示される。 同じファイルが二度インポートされました。インポートは決してマージしないため、やり直してください。

    特殊文字が文字化けしている。 文字エンコーディングを参照してください。

    写真が欠落している。 メディアファイルのインポートを参照してください。

    やり直す¶

    インポートが失敗した場合、または古いプログラムで何かを修正して再インポートしたい場合は、まず管理設定の危険ゾーンにあるすべてのオブジェクトを削除を使用してツリーを空にし、その後修正されたファイルをインポートします。これにより、インポート以降にGramps Webで行った変更も削除されることに注意してください。
