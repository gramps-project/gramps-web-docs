    Gramps 如何组织数据¶

    Gramps Web 将家谱存储为独立的对象——人、家庭、事件、地点、来源等等——而不是作为图表，这些对象彼此链接。一旦你了解这些对象是如何组合在一起的，输入数据就变得可预测：你想要链接的任何内容必须首先存在。

    Gramps Web 使用与 Gramps Desktop 相同的数据模型，因此本页上的所有内容适用于两者。

    基础构件¶

    对象 代表的内容 示例
    人 个人 你，你的祖母
    家庭 一对伴侣，他们的孩子，或两者 你的父母和他们的孩子
    事件 发生的事情，具有日期和地点 出生、婚姻、人口普查、移民
    地点 地理位置 一个村庄、一个教区、一个国家
    来源 文档或信息集合 一个教区登记册、一个人口普查、一部书
    引用 来源中的特定参考 教区登记册第12页，第3条
    存储库 存放来源的地方 一个档案馆、一个图书馆、一个网站
    注释 自由文本 转录、研究备注
    媒体对象 文件 一张照片、一个扫描的证书

    每种对象类型在 Gramps Web 中都有自己的列表，参见 列表。

    人与家庭¶

    父母和孩子并不是直接相互链接的，而是通过一个 家庭。一个家庭最多有两个伴侣和任意数量的孩子：

    • 你的父母和你通过你作为孩子的家庭相链接。
    • 你的兄弟姐妹是同一个家庭的其他孩子。
    • 你和你的配偶组成另一个家庭，你们是其中的伴侣，和你们的孩子一起。

    一个人可以在一个家庭中是孩子，而在多个家庭中是伴侣。每个孩子与每个父母之间都有关系，例如出生、收养或继子，而每个家庭都有关系类型，例如已婚或民事结合。

    这就是为什么“添加父母”到一个人意味着将该人作为孩子添加到一个家庭——这正是 树形图 为你在一步中完成的。

    事件¶

    出生、死亡或婚姻不是一个人的字段，而是一个 事件，具有类型、日期、地点和描述。人们通过 角色 与事件相链接：出生的人的角色是“主要”，而其他人可能作为见证人链接到同一事件。

    涉及一对伴侣的事件，例如婚姻，属于家庭而不是任何一方伴侣。一个事件也可以由几个人共享——例如，列出整个家庭的普查记录——而不是每个人都单独输入一次。

    共享对象：地点和来源¶

    地点、来源、引用、存储库、注释和媒体对象独立存在，任意数量的其他对象可以引用同一个对象。这有几个后果：

    • 一次创建，多次选择。 十个祖先出生的村庄是一个地点，在十个出生事件中被选择。如果你更正了它的名称或坐标，更正将适用于所有地方。
    • 在选择之前创建。 Gramps Web 中的表单选择已经存在的地点和来源。首先使用顶部应用栏中的 +（添加）按钮创建一个新地点或来源。
    • 地点是嵌套的。 一个地点可以被更大的地点包围——一个县包围一个村庄，国家包围县——因此你不必为每个村庄重复整个层次结构。
    • 来源和引用是分开的。 来源是整个教区登记册；引用是支持某个事实的特定条目，包括其页码、日期和你的信心。许多引用可以指向同一个来源。

    如果你不小心创建了相同的地点或来源两次，你可以 合并重复项。

    家庭树中的主人物¶

    主人物是家庭树图表的起点，也是报告的默认起点。有关如何设置它，请参见 首次登录。

    与 Gramps Desktop 不同

    在 Gramps Desktop 中，主人物存储在家谱数据库中，因此对于打开该数据库的每个人都是相同的。Gramps Web 不使用它。相反，主人物存储在你的浏览器中，每棵树单独存储：它不与其他用户共享，也不会随你在不同的浏览器或设备上使用。导入来自 Gramps Desktop 的树后，或者在另一台设备上使用 Gramps Web 时，你需要重新设置它。

    推荐的顺序¶

    手动输入新家庭时，这个顺序可以避免在表单之间来回跳转：

    1. 地点和来源。 创建你需要的地点，如果你记录来源，则创建你正在使用的来源。
    2. 人。 添加人及其出生和死亡日期和地点。在家庭树图表的编辑模式中，这是最快的，它会为你创建家庭——参见 开始新树 和 编辑家庭树。
    3. 进一步的事件。 打开一个家庭（例如从某个人的关系标签）以添加婚姻，并打开一个人的页面以添加其他事件。
    4. 引用。 在支持来源的个人、事件或其他对象的来源引用标签上，添加新的引用，选择来源，并输入页码。
    5. 注释和媒体。 附加转录、照片和扫描——参见 添加媒体文件。

    输入日期¶

    日期作为单独的年、月、日字段输入，也可以使用日期选择器填写。省略你不知道的部分：仅年份也是有效日期。

    与其猜测确切的日期，不如用日期的 类型 描述你实际知道的内容：

    你知道的内容 类型 示例
    确切的日期或其部分 常规 1850年3月12日，或仅1850年
    近似日期 大约 大约1850年
    限制 之前，之后 1900年之前
    日期位于某个时期内 范围 1850年至1855年之间
    某事持续了一段时间 跨度 从1850年到1855年
    仅某个时期的开始或结束 从，到 从1850年

    质量 字段记录你如何得出日期：“估计”表示经过推测的猜测，“计算”表示根据其他信息得出的日期，例如根据死亡时的年龄计算出的出生年份。

    大约和估计日期涵盖前后各50年

    当 Gramps 比较日期时，它将“关于”类型的日期——以及任何质量为“估计”的日期——视为一个范围，从给定日期前50年到后50年。例如，过滤出生在1840年至1860年之间的人时，也会找到“约1880年”出生的人，因为该日期被视为涵盖1830年至1930年。同样，“之前”和“之后”被视为前后各延伸50年。

    这可能会导致意外的结果，因此仅在无法缩小日期时使用“约”和“估计”。如果你知道更短的时间段，像“1878年至1882年之间”的范围会更精确。

    日历 字段允许你输入原始记录中使用的日历中的日期，例如儒略历，而不是自己进行转换。
