    私有记录¶

    树中的任何记录都可以标记为私有。结合用户角色，这决定了谁能看到什么。

    谁能看到什么¶

    Gramps Web 从不对公众开放：只有拥有账户的用户才能查看任何内容。在 Gramps 中，“公共”仅意味着“非私有”，即对每个登录用户可见。

    角色 公共记录 私有记录
    来宾 查看 –
    成员 查看 查看
    贡献者 查看，添加 查看，添加
    编辑者，所有者，管理员 查看，添加，编辑，删除 查看，添加，编辑，删除

    对于来宾，私有记录不存在：它们被排除在页面、列表、搜索结果、图表、报告、导出和 AI 助手的回答之外。这是在服务器读取数据库时强制执行的，而不是通过在应用程序中隐藏内容，因此来宾无法以其他方式访问私有数据。

    尚未获得批准的账户（在自我注册后）根本无法登录。

    因此，如果亲属或其他拥有来宾账户的人不应看到某些信息，请将其标记为私有。如果树的所有用户都可以看到所有内容，则将他们赋予成员角色（或更高角色），就无需将任何内容标记为私有。

    活人不会自动变为私有¶

    没有任何内容会自动变为私有——即使是仍然活着的人。活人的数据对来宾可见，直到您将其标记为私有。这同样适用于导入的树。

    要在 Gramps Web 中将可能仍然活着的人标记为私有：

    1. 在人员列表中，打开高级过滤器，并添加条件“可能活着的人”（将日期留空以表示今天）。应用过滤器。
    2. 点击 选择，勾选标题中的复选框，然后选择 全选。
    3. 选择 隐私 操作并将记录标记为私有。

    “可能活着”是根据个人及其亲属的日期进行估算的。没有任何可用日期的人被视为活着。检查结果，并记住，随着您添加数据，估算可能会改变。

    将某人标记为私有会隐藏该人，但不会隐藏他们的事件、笔记、媒体或家庭——见下文。Gramps Desktop 具有更多工具，可以一次设置许多相关记录的隐私，您可以与同步插件一起使用。

    后来去世的人也不会自动变为公共。您是否希望如此取决于您——许多研究人员更喜欢在一段时间内保持收集的信息私有。

    阅读锁图标¶

    可以查看私有数据的用户在私有项目旁边会看到一个锁。锁有两种类型：

    • 填充锁 – 记录本身是私有的。例如，在一个人的页面上，事件旁边的填充锁表示该事件是私有的，孩子旁边的填充锁表示该孩子是私有的。
    • 轮廓锁 – 只有链接是私有的，而不是它所指向的记录。例如，一个人指向事件的链接可以是私有的，而事件本身是公共的。该事件在该人的页面上被隐藏，但在其他地方仍然可见，例如在其他参与者的页面或事件列表中。

    如果记录及其链接都是私有的，则显示填充锁。

    同样的区分适用于儿童（孩子或孩子与家庭的链接）、关联、来源的存储库链接以及画廊中的媒体。名称、属性、地址和 URL 属于其记录，仅具有填充锁。

    将某些内容设为私有¶

    您需要编辑权限才能更改隐私。

    • 整个记录：打开其页面，进入编辑模式，然后点击工具栏中的锁按钮。
    • 记录的一部分 – 替代名称、属性、地址、URL、关联、子链接或存储库链接：打开该项的编辑对话框并打开 私有 开关。主名称没有开关，因为否则该人将显示为“私有”。
    • 来自某人或家庭页面的事件：事件的编辑对话框有一个隐私开关，适用于事件本身。如果事件与其他人共享，则在对所有人编辑后才能编辑，因为对他们来说是私有的。
    • 某人与事件的链接：在事件页面上，进入参与者的行的编辑模式。那里隐私开关仅适用于该参与者的链接，因此事件对其他参与者仍然可见。
    • 画廊中的媒体对象：在编辑模式下，点击瓷砖角落的锁。
    • 一次处理多个记录：在列表中选择它们并使用 隐私 操作，见列表。

    要检查列表中哪些记录是私有的，请在列表的列选择器中打开 隐私 列。

    注意事项¶

    • 将记录设为私有并不会使其链接的记录变为私有。如果某人是私有的，他们的事件、所属家庭和附加的笔记仍然可见，除非它们本身是私有的。使用高级过滤器或 隐私 列检查相关记录。
    • 将家庭或事件设为私有会隐藏它，但不会隐藏其中的人。
    • DNA 匹配和 Y-DNA 数据在其对话框中有自己的 私有 开关。
    • 由无法查看私有数据的用户制作的导出和媒体档案不包含任何私有记录或文件。
    • 隐私是 Gramps 的一项功能，因此在 Gramps Desktop 中标记为私有的记录在 Gramps Web 中也是私有的，反之亦然。
