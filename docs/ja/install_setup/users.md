# ユーザーシステム

Gramps Webは、インターネット上での公開アクセスを目的としておらず、認証されたユーザーのみがアクセスできるようになっています。ユーザーアカウントは、サイト所有者がコマンドラインまたはウェブインターフェースを介して作成するか、自己登録およびその後のサイト所有者による承認を通じて作成できます。

## ユーザー役割

現在定義されているユーザー役割は以下の通りです。

役割 | 役割ID | 権限
-----|---------|------------
ゲスト | 0 | 非プライベートオブジェクトの表示
メンバー | 1 | ゲスト + プライベートオブジェクトの表示
寄稿者* | 2 | メンバー + オブジェクトの追加
編集者 | 3 | 寄稿者 + オブジェクトの編集および削除
所有者 | 4 | 編集者 + ユーザーの管理
管理者 | 5 | 所有者 + マルチツリー設定での他のツリーの編集

レコードがプライベートかどうかはレコードごとに設定されます。詳細は[プライベートレコード](../user-guide/privacy.md)を参照してください。デフォルトでは、何もプライベートではなく、居住者でさえもプライベートではありません。

\* 「寄稿者」役割は現在部分的にしかサポートされていないことに注意してください。たとえば、家族オブジェクトは、家族メンバーの基盤となるGramps人物オブジェクトの変更を含むため、追加できません。可能な限り他の役割を使用することをお勧めします。

## ユーザーの管理

ユーザーを管理する方法は2つあります。

- ウェブインターフェースを使用して所有者権限で管理する
- サーバーのコマンドラインで管理する

ウェブアプリに最初にアクセスするために必要な所有者アカウントは、空のユーザーデータベースでGramps Webにアクセスしたときに自動的に起動されるオンボーディングウィザードで追加できます。

### コマンドラインでのユーザー管理

[Docker Compose](deployment.md)を使用する場合、基本コマンドは次のとおりです。

```bash
docker compose run grampsweb python3 -m gramps_webapi user COMMAND [ARGS]
```

`COMMAND`には`add`、`set-password`、または`delete`を指定できます。`[ARGS]`の`--help`を使用して、構文と可能な設定オプションを表示します。

`set-password NAME`は、既存のユーザーの新しいパスワードを設定します。古いパスワードは必要ありません。たとえば、誰もログインできなくなり、パスワードリセットのためのメールが設定されていない場合（Gramps Web API 3.26+）に使用します。パスワードは表示されずに2回入力を求められるため、シェルの履歴にパスワードが残ることはありません。すべてのユーザーのセッションは終了します。

### 自己登録ユーザーの承認

ユーザーが自己登録すると、即座にアクセスが許可されるわけではありません。新しいユーザー登録についてツリー所有者にメールが送信され、ユーザーにはメールアドレスを確認するためのリクエストが送信されます。メールアドレスを正常に確認すると、役割が`unconfirmed`から`disabled`に変更されます。ユーザーアカウントがこれらの2つの役割のいずれかにある間、ユーザーはログインできません。ツリー所有者はユーザーのリクエストを確認し、ユーザーに適切な役割を割り当てる必要があります。その後、ユーザーはログインできるようになります。
