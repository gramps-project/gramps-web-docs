# メディアファイルのインポート

家系図を[インポート](import.md)し、対応するメディアファイルをアップロードする必要がある場合は、家系図のインポートの下にある[インポートページ](import.md)の**メディアファイルのインポート**を使用してください。これは、欠落しているメディアファイルを含むZIPファイルを期待します。ツリーにメディアオブジェクトが含まれている場合にのみアップロードが可能です。ファイルは既存のメディアオブジェクトにマッチングされるため、家系図ファイルはそのメディアファイルを参照するだけなので、最初にインポートしてください。

ファイルは、次の2つの方法のいずれかでツリー内のメディアオブジェクトにマッチングされます：

- **チェックサムによるマッチング。** チェックサムを持つメディアオブジェクトの場合（Gramps Desktopからインポートされたツリーが該当）、一致するチェックサムを持つファイルが使用されます。ファイル名やZIPファイル内のフォルダ構造は無視されます。これは、Grampsデータベース内のチェックサムが正しい場合にのみ機能します。これを確認するためには、チェックと修復ツールを実行します。
- **パスまたはファイル名によるマッチング。** チェックサムを持たないメディアオブジェクト（GEDCOMインポート後によく見られる）は、メディアオブジェクトに保存された相対パスによってマッチングされます。ZIP内にそのパスを持つファイルがない場合、ファイル名のみでマッチングされ、大文字と小文字は無視されます（Gramps Web API 3.26以降）。これは、`C:\Users\...\Family\grandpa.jpg`のような他のプログラムからの絶対パスにも機能しますので、すべてのファイルをZIPファイルに入れるだけで済みます。ファイル名は、ZIPファイル内およびまだファイルを持たないメディアオブジェクトの中で一意である場合にのみ使用されます。

アップロード後、結果にはファイルが見つかったメディアオブジェクトの数が表示され、ZIPファイルにファイルがなかったものがGramps IDと保存されたパスとともにリストされます。このリストを使用して欠落しているファイルを見つけ、これらのファイルだけを含む別のZIPファイルをアップロードしてください。すでにサーバーにあるファイルには影響しません。

異なるフォルダ内に同じファイル名のメディアオブジェクトが複数ある場合、ファイル名によるマッチングは機能しません。ZIPファイル内の保存されたパスからフォルダ構造を再作成するか、すべてを最初にGramps Desktopにインポートしてください。Gramps Desktopには、インポートされたツリーと既存のメディアファイルを関連付けるためのより多くのオプションがあります。その後、[Gramps Desktopからの移行](import.md#coming-from-gramps-desktop)で説明されているようにGramps Webに移動してください。

## メディアファイルのステータス

[管理設定](settings.md)の**データ**セクションには、次の情報が表示されます：

- ツリー内のメディアオブジェクトの総数と、チェックサムが欠落しているものがあるかどうか
- サーバーから関連ファイルが欠落しているメディアオブジェクトの数

緑のチェックマークは、すべてが正常であることを示します。問題が検出された場合、影響を受けたオブジェクトへのリンクが表示されます。欠落しているチェックサムは、メディア参照は含まれているが実際のファイルは含まれていないGEDCOMのような形式からデータがインポートされた場合に一般的に発生します。欠落しているファイルは、上記の方法でアップロードできます。
