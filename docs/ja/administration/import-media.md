# メディアファイルのインポート

ファミリーツリーを[インポート](import.md)し、対応するメディアファイルをアップロードする必要がある場合は、[管理設定](settings.md)のデータセクションで**メディアファイルのインポート**を使用してください。これは、欠落しているメディアファイルを含むZIPファイルを期待します。ファイルは、次の2つの方法のいずれかでツリー内のメディアオブジェクトにマッチングされます：

- **チェックサムによるマッチング。** チェックサムを持つメディアオブジェクトの場合（Gramps Desktopからインポートされたツリーに該当します）、マッチングするチェックサムを持つファイルが使用されます。ファイル名やZIPファイル内のフォルダ構造は関係ありません。これは、Grampsデータベース内のチェックサムが正しい場合にのみ機能します。これを確認するために、チェックと修復ツールを実行することが推奨されます。
- **パスによるマッチング。** チェックサムを持たないメディアオブジェクト（GEDCOMインポート後に典型的です）は、そのパスによってマッチングされます：ZIPファイルには、メディアオブジェクトに保存されている相対パスと正確に一致するファイルが含まれている必要があります。

GEDCOMファイルに保存されているパスが絶対パスである場合（例えば `C:\Users\...\photo.jpg`）、パスによるマッチングは機能しません。この場合、最初にすべてをGramps Desktopにインポートし、既存のメディアファイルをインポートされたツリーに関連付けるためのオプションが多くあるため、その後[Gramps Desktopからの移行](import.md#coming-from-gramps-desktop)に記載されているようにGramps Webに移動することをお勧めします。
