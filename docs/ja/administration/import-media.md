# メディアファイルのインポート

家系図を[インポートした](import.md)場合、対応するメディアファイルをアップロードする必要がある場合は、[管理設定](settings.md)のデータセクションで**メディアファイルのインポート**を使用してください。これは、欠落しているメディアファイルを含むZIPファイルを期待します。ファイルは、次の2つの方法のいずれかでツリー内のメディアオブジェクトにマッチングされます：

- **チェックサムによるマッチング。** チェックサムを持つメディアオブジェクトの場合（Gramps Desktopからインポートされたツリーが該当します）、一致するチェックサムを持つファイルが使用されます。ファイル名やZIPファイル内のフォルダ構造は関係ありません。これは、Grampsデータベース内のチェックサムが正しい場合にのみ機能します。これを確認するためには、チェックと修復ツールを実行する必要があります。
- **パスによるマッチング。** チェックサムを持たないメディアオブジェクト（GEDCOMインポート後に典型的です）は、そのパスによってマッチングされます：ZIPファイルには、メディアオブジェクトに保存されている相対パスと正確に一致するファイルが含まれている必要があります。

GEDCOMファイルに保存されているパスが絶対パス（例：`C:\Users\...\photo.jpg`）の場合、パスによるマッチングは機能しません。この場合、最初にすべてをGramps Desktopにインポートし、既存のメディアファイルをインポートされたツリーに関連付けるためのオプションが多くあるため、その後[Gramps Desktopからの移行](import.md#coming-from-gramps-desktop)に記載されているようにGramps Webに移動することをお勧めします。

## メディアファイルのステータス

[管理設定](settings.md)の**データ**セクションには、次の情報が表示されます：

- ツリー内のメディアオブジェクトの総数と、チェックサムが欠落しているものがあるかどうか
- サーバーから関連ファイルが欠落しているメディアオブジェクトの数

緑のチェックマークは、すべてが正常であることを示します。問題が検出された場合、影響を受けたオブジェクトへのリンクが表示されます。欠落しているチェックサムは、メディア参照は含まれているが実際のファイルは含まれていないGEDCOMのような形式からデータがインポートされた場合に通常発生します。欠落しているファイルは、上記のようにアップロードできます。
