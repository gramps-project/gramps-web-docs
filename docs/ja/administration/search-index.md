# 検索インデックス

**検索インデックス** セクションは、[管理設定](settings.md) の状態を示し、フルテキスト検索インデックスを再構築することができます。

## 検索インデックスの管理

Gramps Web は、データが変更されるたびに自動的に更新されるフルテキスト検索インデックスを維持します。ステータスインジケーターは、現在インデックスされているオブジェクトの数と総オブジェクト数を示します。

**検索インデックスの更新** をクリックすると、フル再構築がトリガーされます。タスクがバックグラウンドで実行されている間、進行状況インジケーターが表示されます。これはめったに必要ありません。

ツリーにまだ検索インデックスがない場合、たとえばインデックス形式が変更されたサーバーのアップグレード後など、Gramps Web はツリーが初めて開かれるときにバックグラウンドでインデックスを構築します。構築中は、セクションに「検索インデックスが構築中です。」と表示され、カウントの代わりに表示され、**検索インデックスの更新** は無効になり、検索結果が不完全な場合があります。構築は [通知](../user-guide/notifications.md) に「検索インデックスの更新」タスクとして表示されます。
