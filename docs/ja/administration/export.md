# データのエクスポート

エクスポートページでは、家系図データをさまざまな形式でダウンロードしたり、すべてのメディアファイルのアーカイブを取得したりできます。

## Gramps XMLとして家系図をエクスポートする

家系図データのコピーを取得するには、Gramps Webのエクスポートページを開き、Gramps XML形式を選択します。「エクスポート」をクリックすると、ファイルが生成され、準備が整い次第ダウンロードが開始されます。

Gramps Webユーザーにプライベートレコードを表示する権限がない場合、エクスポートにはプライベートレコードが含まれないことに注意してください。

## 家系図のバックアップ

ツリーの完全なバックアップ（設定やユーザーを含む）については、[バックアップと復元](backups.md)を参照してください。Gramps XMLエクスポートは家系図データのバックアップとして機能し、[バックアップからの復元](backups.md#restore-from-backup)を介して復元できます。

## 他の系譜プログラムのユーザーと家系図を共有する

Gramps XMLとして系譜データを共有することができない場合は、GEDCOMファイルをエクスポートすることもできます。これはGramps Webツリーのバックアップとしては適していないことに注意してください。

## メディアファイルのバックアップ

メディアファイルをバックアップするには、エクスポートページでメディアファイルのZIPアーカイブを作成してダウンロードできます。

特に大きなツリーの場合、これはサーバーにとって高コストな操作になる可能性があり、絶対に必要な場合にのみ行うべきです。このため、作成できるメディアアーカイブの数は制限されています（デフォルトでは1時間に1つ）。制限に達すると、エラーメッセージが表示されます。

メディアファイルを定期的にバックアップするためのより良いオプションは、[Gramps Web Syncアドオン](sync.md)を使用し（これはバックアップソリューションではありません）、ローカルコンピュータ上で増分バックアップを作成することです。

いずれの場合でも、Gramps Webユーザーにプライベートレコードを表示する権限がない場合、エクスポートにはプライベートメディアオブジェクトのファイルが含まれません。

## 別のGramps Webインスタンスに移動する

Gramps Webは特定のプロバイダーにロックされることはなく、データを失うことなく、サーバーに直接アクセスすることなく、別のGramps Webインスタンスに移動できます。

完全な移行を実現するには、次の手順に従ってください（ツリー所有者権限があると仮定します）：

1. エクスポートページに移動し、ツリーをGramps XML（`.gramps`）ファイルとしてエクスポートします。[Syncアドオン](sync.md)を使用している場合は、Grampsデスクトップでもエクスポートを生成できます。
2. エクスポートページで、メディアアーカイブを生成してダウンロードします。[Syncアドオン](sync.md)を使用している場合は、ローカルのGrampsメディアフォルダーをZIPすることもできます。
3. 設定 > 管理 > ユーザー管理に移動し、「ユーザー詳細をエクスポート」ボタンをクリックします。JSONファイルがダウンロードされます。
4. 新しいGramps Webインスタンスで、インポートページを開きます。ステップ1でエクスポートした`.gramps`ファイルをインポートします。
5. 新しいGramps Webインスタンスのインポートページで、メディアアーカイブ（ZIP）をアップロードします。
6. 新しいGramps Webインスタンスの設定 > 管理 > ユーザー管理に移動します。「ユーザーアカウントをインポート」ボタンをクリックし、ステップ3でダウンロードしたJSONファイルをアップロードします。

ユーザーアカウントは移行されますが、すべてのユーザーは「パスワードを忘れた」リンクを使用して新しいパスワードを設定する必要があることに注意してください。パスワードは暗号化された形式で保存されており、エクスポートできません。
