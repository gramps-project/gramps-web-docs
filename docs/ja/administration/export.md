## 家系図をバックアップする

ツリーの所有者は、[バックアップ](settings.md#backups)セクションの管理設定で、ツリーの設定やユーザーを含む完全なバックアップを作成、ダウンロード、復元できます。

また、家系図データのみのバックアップを作成するには、Gramps Webのエクスポートページを開き、Gramps XML形式を選択します。

「エクスポート」をクリックすると、ファイルが生成され、準備が整い次第ダウンロードが開始されます。

Gramps Webユーザーがプライベートレコードを表示する権限を持っていない場合、エクスポートは完全なバックアップにはならないことに注意してください。プライベートレコードは含まれません。

このGramps XMLファイルは、[バックアップから復元](settings.md#restore-from-backup)を通じて、ツリーをこの正確な状態に復元するために後で使用できます。

## 他の系譜プログラムのユーザーと家系図を共有する

Gramps XMLとして系譜データを共有することができない場合、GEDCOMファイルをエクスポートすることもできます。これはGramps Webツリーのバックアップには適していないことに注意してください。

## メディアファイルをバックアップする

メディアファイルをバックアップするには、エクスポートページで全メディアファイルのZIPアーカイブを作成してダウンロードできます。

特に大きなツリーの場合、これはサーバーにとって高コストな操作になる可能性があるため、絶対に必要な場合にのみ行うべきです。このため、作成できるメディアアーカイブの数は制限されています（デフォルトでは1時間に1つ）。制限に達すると、エラーメッセージが表示されます。

メディアファイルを定期的にバックアップするためのより良いオプションは、[Gramps Web Syncアドオン](sync.md)を使用し（これはバックアップソリューションではありません）、ローカルコンピュータに増分バックアップを作成することです。

いずれの場合も、Gramps Webユーザーがプライベートレコードを表示する権限を持っていない場合、エクスポートにはプライベートメディアオブジェクトのファイルが含まれません。

## 別のGramps Webインスタンスに移動する

Gramps Webは特定のプロバイダーにロックされることはなく、データを失うことなく、サーバーに直接アクセスすることなく、別のGramps Webインスタンスに移動できます。

完全な移行を実現するためには、以下の手順に従ってください（ツリー所有者の権限があると仮定します）：

1. エクスポートページに移動し、ツリーをGramps XML（`.gramps`）ファイルとしてエクスポートします。[Syncアドオン](sync.md)を使用している場合は、Grampsデスクトップでもエクスポートを生成できます。
2. エクスポートページで、メディアアーカイブを生成してダウンロードします。[Syncアドオン](sync.md)を使用している場合は、ローカルのGrampsメディアフォルダーをZIPすることもできます。
3. 設定 > 管理 > ユーザー管理に移動し、「ユーザー詳細をエクスポート」ボタンをクリックします。JSONファイルがダウンロードされます。
4. 新しいGramps Webインスタンスで、インポートページを開きます。ステップ1でエクスポートした`.gramps`ファイルをインポートします。
5. 新しいGramps Webインスタンスのインポートページで、メディアアーカイブ（ZIP）をアップロードします。
6. 新しいGramps Webインスタンスの設定 > 管理 > ユーザー管理に移動します。「ユーザーアカウントをインポート」ボタンをクリックし、ステップ3でダウンロードしたJSONファイルをアップロードします。

ユーザーアカウントは移行されますが、すべてのユーザーは「パスワードを忘れた」リンクを使用して新しいパスワードを設定する必要があることに注意してください。パスワードは暗号化された形式で保存されており、エクスポートできません。
