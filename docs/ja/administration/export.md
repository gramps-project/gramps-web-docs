# データのエクスポート

エクスポートページでは、家系図データをさまざまな形式でダウンロードしたり、すべてのメディアファイルのアーカイブを取得したりできます。

## Gramps XMLとして家系図をエクスポート

家系図データのコピーを取得するには、Gramps Webのエクスポートページを開き、Gramps XML形式を選択します。**生成**をクリックしてファイルを作成し、準備ができたら**ダウンロード**をクリックします。大きな家系図の場合、ファイルの生成には時間がかかることがあります。その間にページを離れて、後で[通知](../user-guide/notifications.md)からファイルをダウンロードすることができます。

Gramps Webユーザーがプライベートレコードを表示する権限を持っていない場合、エクスポートにはプライベートレコードが含まれないことに注意してください。

## 家系図のバックアップ

家系図の完全なバックアップ（設定やユーザーを含む）については、[バックアップと復元](backups.md)を参照してください。Gramps XMLエクスポートは、家系図データのバックアップとして機能し、[バックアップからの復元](backups.md#restore-from-backup)を介して復元できます。

## 他の系譜プログラムのユーザーと家系図を共有

Gramps XMLとして系譜データを共有することができない場合、GEDCOMファイルをエクスポートすることもできます。これはGramps Webの家系図のバックアップとしては適していないことに注意してください。

## メディアファイルのバックアップ

メディアファイルをバックアップするには、エクスポートページでメディアファイルのZIPアーカイブを作成してダウンロードできます。

特に大きな家系図の場合、これはサーバーにとって高コストな操作になる可能性があるため、絶対に必要な場合にのみ行うべきです。このため、作成できるメディアアーカイブの数は制限されています（デフォルトでは1時間に1つ）。制限に達すると、エラーメッセージが表示されます。

メディアファイルを定期的にバックアップするためのより良いオプションは、[Gramps Web Syncアドオン](sync.md)を使用し（これ自体はバックアップソリューションではありません）、ローカルコンピュータに増分バックアップを作成することです。

いずれの場合も、Gramps Webユーザーがプライベートレコードを表示する権限を持っていない場合、エクスポートにはプライベートメディアオブジェクトのファイルが含まれません。

## 別のGramps Webインスタンスに移動

Gramps Webは特定のプロバイダーにロックされることはなく、データを失うことなく、サーバーに直接アクセスすることなく、別のGramps Webインスタンスに移動できます。

完全な移行を実現するには、次の手順に従ってください（ツリーオーナー権限があると仮定します）：

1. エクスポートページに移動し、家系図をGramps XML（`.gramps`）ファイルとしてエクスポートします。[Syncアドオン](sync.md)を使用している場合、Grampsデスクトップでもエクスポートを生成できます。
2. エクスポートページで、メディアアーカイブを生成してダウンロードします。[Syncアドオン](sync.md)を使用している場合、ローカルのGrampsメディアフォルダをZIPすることもできます。
3. 設定 > 管理 > ユーザー管理に移動し、「ユーザー詳細をエクスポート」ボタンをクリックします。JSONファイルがダウンロードされます。
4. 新しいGramps Webインスタンスで、[インポートページ](import.md)を開きます。ステップ1でエクスポートした`.gramps`ファイルをインポートします。
5. 新しいGramps Webインスタンスのインポートページで、[メディアファイルをインポート](import-media.md)の下にメディアアーカイブ（ZIP）をアップロードします。
6. 新しいGramps Webインスタンスの設定 > 管理 > ユーザー管理に移動します。「ユーザーアカウントをインポート」ボタンをクリックし、ステップ3でダウンロードしたJSONファイルをアップロードします。

ユーザーアカウントは移行されますが、すべてのユーザーは「パスワードを忘れた」リンクを使用して新しいパスワードを設定する必要があることに注意してください。パスワードは暗号化された形式で保存されており、エクスポートすることはできません。
