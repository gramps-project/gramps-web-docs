# バックアップと復元

ツリーの所有者は、[管理設定](settings.md)の**バックアップ**セクションで、ツリーのバックアップを作成、ダウンロード、および復元できます。

バックアップには、プライベートレコードを含む家系図データ、ツリー設定、およびツリーのユーザーが含まれます。メディアファイルは含まれていません。詳細は[メディアファイルのバックアップ](export.md#back-up-your-media-files)を参照してください。

## 保存されたバックアップ

サーバー管理者がバックアップディレクトリ（`BACKUP_DIR`、[サーバー設定](../install_setup/configuration.md)を参照）を設定している場合、バックアップはサーバーに保存できます。そうでない場合、このセクションにはバックアップの保存が設定されていないという通知が表示され、アップロードされたファイルからの復元のみが可能です。

**バックアップを作成...**をクリックしてバックアップを作成します。バックアップはバックグラウンドタスクとして作成され、その後、保存されたバックアップのリストに日付、人数、サイズと共に表示されます。サーバーは最新のバックアップ（デフォルトでは5つ）しか保持せず、古いものは自動的に削除されます。また、1日に作成できるバックアップの数にも制限があります。

保存されたバックアップごとに、次の操作ができます：

- **ダウンロード**：例えば、他の場所にコピーを保持するために、`.tar`ファイルとしてダウンロードします。
- **復元**：以下に説明するように復元します。
- **削除**：確認後に削除します。

サーバー上で実行されているGramps Webのバージョンよりも新しいバージョンで作成されたバックアップは、警告アイコンでマークされ、復元できません。

## バックアップからの復元

保存されたバックアップまたはアップロードされたファイルからツリーを復元します。保存されたバックアップから復元するには、その隣にある復元ボタンをクリックします。ファイルから復元するには、Gramps Webバックアップ（`.tar`）またはGramps XMLファイル（`.gramps`）を選択し、**復元**をクリックします。

!!! danger
    データの復元は破壊的な置き換えであり、マージではありません。バックアップに存在しない既存のオブジェクトは削除されます。

Gramps Webバックアップの場合、バックアップがいつ作成されたか、どのツリーに対して、どのバージョンであるかを示すダイアログが表示され、復元する部分を選択できます：

- **データ** – 家系図のオブジェクト
- **ツーリー設定** – テーマカラー、アプリタイトル、ホームページのノートなど、管理ページの設定
- **ユーザー** – ツリーのユーザー

**プレビュー**をクリックすると、復元によって何が変更されるかを確認できます。Gramps XMLファイルはデータのみを含むため、そのようなファイルの場合、プレビューはすぐに開始されます。セッションが十分に新しくない場合は、再認証を求められます。プレビューはバックグラウンドタスクとして実行され、完了すると、オブジェクトタイプごとの変更を要約したダイアログが開きます（人々、家族、イベント、場所、引用、ソース、リポジトリ、メディアオブジェクト、ノート、タグ）、およびツリー設定とユーザーが選択されている場合：

- **追加** – バックアップに存在するが現在のツリーに存在しないオブジェクト
- **更新** – 両方に存在するが異なるオブジェクト
- **削除** – 現在のツリーに存在せずバックアップにないオブジェクト
- **変更なし** – 両方で同一のオブジェクト

削除されるオブジェクトがある場合、ダイアログはその数を警告します。要約を確認し、変更を適用するには**復元**をクリックするか、キャンセルするには**キャンセル**をクリックします。

復元後、バックアップから追加されたユーザーがリストされます。彼らにはランダムなパスワードが付与されるため、サインインする前にパスワードをリセットする必要があります。サーバー上に既に存在するユーザーは変更されません。サーバー上にファイルが欠けているメディアオブジェクトもリストされます。これらは[メディアファイルのインポート](import-media.md)を介してアップロードしてください。

!!! note
    データの復元はオブジェクトデータとメディア参照のみを復元します。バイナリメディアファイル自体とツリーのメタデータ（デフォルトの人物、ブックマーク、名前グループ）は影響を受けません。

!!! tip
    これを使用して、悪いインポートや不要な一括編集の後に、ツリーを既知の良好なバックアップにロールバックします。

## Gramps XMLをバックアップとして

バックアップの保存が利用できない場合、または家系図データのコピーを保持したいだけの場合は、ツリーをGramps XMLとして[エクスポート](export.md)します。そのようなファイルは、[バックアップからの復元](#restore-from-backup)を介して復元することもできます。

Gramps Webユーザーがプライベートレコードを表示する権限を持っていない場合、エクスポートは完全なバックアップにはなりません。なぜなら、プライベートレコードは含まれないからです。
