# データのインポート

既存の家系図をGramps Webに取り込むには、他の系譜プログラムからエクスポートされたファイル、オンラインサービスからのファイル、またはGramps Desktopからのファイルをアップロードします。

インポートは、[管理設定](settings.md)の**データ**セクションにあります（アプリバーのユーザーアイコン ▸ 管理）。これは、ツリーの所有者と管理者が利用できます。ツリーがまだ空の状態のときは、ホームページの「始める」カードにある**家系図のインポート**ボタンもそこに導きます。

## どのファイルを使用するか

| 出所 | 家系図をエクスポートする形式 | ファイル拡張子 |
|---|---|---|
| 他の系譜プログラムまたはオンラインサービス | GEDCOM | `.ged` |
| Gramps Desktop | Gramps XML | `.gramps` |
| GeneWeb | GeneWeb | `.gw` |
| Pro-Gen | Pro-Gen | `.def` |
| スプレッドシート | Gramps CSV | `.csv` |
| アドレス帳 | vCard | `.vcf` |

GEDCOMは、ほぼすべての系譜プログラムとオンラインサービスがエクスポートできる共通の交換形式です。プログラムやウェブサイトで「エクスポート」または「ダウンロード」オプションを探し、複数の形式が提供されている場合はGEDCOMを選択してください。Gramps Wikiのページ[他の系譜プログラムからのインポート](https://www.gramps-project.org/wiki/index.php/Import_from_another_genealogy_program)には、特定のプログラムに関するメモがあります。

Gramps Desktopを使用している場合は、GEDCOMではなくGramps XML（`.gramps`）を選択してください。これにより、すべてのGrampsデータが損失なく保持され、オンラインとオフラインのツリーが同じ識別子を維持できるため、[同期](sync.md)が可能です。以下の[Gramps Desktopからのインポート](#coming-from-gramps-desktop)を参照してください。

## 家系図ファイルのインポート

1. 管理設定の**データ**セクションを開きます。
2. 「家系図のインポート」の下で、ファイルを選択し、**インポート**をクリックします。
3. 最初にファイルが解析され、「インポートの確認」ダイアログがオブジェクトの数（人、家族、イベント、場所など）を表示します。まだツリーには何も追加されていません。カウントが妥当に見えるか確認し、続行するには**インポート**をクリックし、何も変更せずに中止するには**キャンセル**をクリックします。
4. インポートはバックグラウンドで実行され、進行状況インジケーターが表示されます。データがインポートされると、検索インデックスが更新されます。大きなツリーの場合、これには時間がかかることがあります。インポートが失敗した場合は、その理由が表示されます。

インポートが完了したら、結果を確認してください：ホームページの**統計**パネルに表示されている人数と古いプログラムの人数を比較し、よく知っている家族を開いて、親、子供、日付、場所が期待通りに移行されたか確認してください。

!!! warning
    通常のインポートは純粋に追加的です：常に新しいオブジェクトを作成し、既存のオブジェクトを更新または削除することはありません。同じGramps IDまたはハンドルの下にすでに存在するオブジェクトに対しても同様です。同じファイルを二度インポートすること、またはツリーに既に存在するデータと重複するファイルをインポートすると、マージやスキップするのではなく、すべての一致するオブジェクトが重複します。

    すでにインポートされたツリーに他の場所で行われた変更を取り込む必要がある場合は、[バックアップからの復元](settings.md#restore-from-backup)を使用してください。これにより、アップロードされたファイルに合わせてツリーが置き換えられ、追加されることはありません。これにはGramps XMLファイルまたはGramps Webバックアップが必要です。

ツリーに設定された人数の制限（[使用制限](settings.md#usage-quotas)を参照）を超えるインポートは、全体として拒否されます。

## GEDCOMファイル

GEDCOM 5.5.1およびGEDCOM 7ファイルの両方をインポートできます。いくつか注意すべき点があります。

### 文字エンコーディング

GEDCOM 5.5.1ファイルは、そのヘッダーで文字エンコーディングを宣言します。UTF-8、UTF-16、ANSEL、およびWindows（ANSI）エンコーディングがサポートされています。インポート後にアクセントやその他の特殊文字を含む名前が文字化けしている場合（例えば、`MÃ¼ller`ではなく`Müller`）、ファイルは宣言されたものとは異なるエンコーディングでエクスポートされた可能性があります。古いプログラムから再度ファイルをエクスポートし、選択肢があればUTF-8を選んで、[やり直してください](#starting-over)。

GEDCOM 7ファイルは常にUTF-8でエンコードされている必要があります。他のファイルは「無効なGEDCOMファイル」というエラーで拒否されます。

### プログラム固有のデータ

多くのプログラムは、他のプログラムが理解できない独自の拡張をGEDCOMに追加します。Grampsはそのようなデータを静かに削除することはありません：解釈できない行は、「GEDCOMインポート」タイプのノートに収集され、関連する人、家族、または他のオブジェクトに添付されます。重要な情報が移行されなかったかどうかを確認するために、これらのノートを確認してください。

### メディアファイル

GEDCOMファイルにはメディアファイル（写真やスキャンした文書など）への参照が含まれていますが、ファイル自体は含まれていません。インポート後、メディアオブジェクトはツリーに存在しますが、そのファイルは欠落しており、[メディアファイルの状態](settings.md#media-file-status)に表示されます。ファイルを追加するには、[メディアファイルのインポート](import-media.md)を参照してください。

## Gramps Desktopからのインポート

Gramps Desktopを使用している場合、次の手順でデータベースを準備し、すべてがスムーズに動作するようにします。

1. データベースをチェックして修復する
    - オプション：Gramps XMLにエクスポートしてデータベースのバックアップを作成します。
    - [データベースのチェックと修復ツール](https://gramps-project.org/wiki/index.php/Gramps_5.2_Wiki_Manual_-_Tools#Check_and_Repair_Database)を実行します。これにより、Gramps Webで問題を引き起こす可能性のある内部の不整合が修正されます。
2. メディアパスを相対パスに変換する
    - Grampsメディアマネージャーを使用して、[すべてのメディアパスを絶対パスから相対パスに変換します](https://gramps-project.org/wiki/index.php/Gramps_5.2_Wiki_Manual_-_Tools#Convert_paths_from_relative_to_absolute)。相対パスを使用しても、Grampsメディアディレクトリの外にあるメディアファイルは、Gramps Webと同期すると正しく機能しないことに注意してください。

その後、ツリーをGramps XML（`.gramps`）にエクスポートし、上記の手順でインポートし、[メディアファイルをアップロード](import-media.md)します。同じツリーでコンピュータとウェブの両方で作業を続けるには、[Gramps Web Syncアドオン](sync.md)を使用してください。

### Gramps XMLパッケージのサポートがない理由は？

Gramps XML（`.gramps`）はデータをインポートするための推奨形式ですが、Gramps XML *パッケージ*（`.gpkg`）はGramps Webではサポートされていません。これは、メディアファイルのインポートおよびエクスポートルーチンがウェブサーバーでの使用に適していないためです。

## 一般的な問題

**「サポートされていない形式」。** [上記](#which-file-to-use)にリストされているファイル拡張子のみがインポート可能です。プログラムやオンラインサービスからZIPアーカイブを受け取った場合は、それを解凍し、中の`.ged`ファイルをアップロードしてください。

**すべてが二重に表示される。** 同じファイルが二度インポートされました。インポートは決してマージしないため、[やり直してください](#starting-over)。

**特殊文字が文字化けしている。** [文字エンコーディング](#character-encoding)を参照してください。

**写真が欠落している。** [メディアファイルのインポート](import-media.md)を参照してください。

### やり直す

インポートが失敗した場合や、古いプログラムで何かを修正して再インポートしたい場合は、まず[すべてのオブジェクトを削除](settings.md#delete-all-objects)を使用してツリーを空にし、その後修正されたファイルをインポートしてください。これにより、インポート以降にGramps Webで行った変更も削除されることに注意してください。
