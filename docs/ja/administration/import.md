# データのインポート

既存の家系図をGramps Webに取り込むには、他の系譜プログラムからエクスポートされたファイル、オンラインサービスからのファイル、またはGramps Desktopからのファイルをアップロードします。

インポートには独自のページがあり、ツリーの所有者と管理者が利用できます。**管理設定**の**データ**セクションにある**家系図のインポート**をクリックして開きます（アプリバーのユーザーアイコン ▸ 管理）。ツリーがまだ空の間は、ホームページの「始める」カード、家系図内、リスト内の**家系図のインポート**ボタンもそこに導きます。

## どのファイルを使用するか

| 出所 | ツリーをエクスポートする形式 | ファイル拡張子 |
|---|---|---|
| 他の系譜プログラムまたはオンラインサービス | GEDCOM | `.ged` |
| Gramps Desktop | Gramps XML | `.gramps` |
| GeneWeb | GeneWeb | `.gw` |
| Pro-Gen | Pro-Gen | `.def` |
| スプレッドシート | Gramps CSV | `.csv` |
| アドレス帳 | vCard | `.vcf` |

GEDCOMは、ほとんどすべての系譜プログラムとオンラインサービスがエクスポートできる一般的な交換形式です。プログラムやウェブサイトで「エクスポート」または「ダウンロード」オプションを探し、複数の形式が提供されている場合はGEDCOMを選択してください。Gramps Wikiのページ[他の系譜プログラムからのインポート](https://www.gramps-project.org/wiki/index.php/Import_from_another_genealogy_program)には、特定のプログラムに関する注意事項があります。

Gramps Desktopを使用している場合は、GEDCOMではなくGramps XML（`.gramps`）を選択してください。これにより、すべてのGrampsデータが損失なく保持され、オンラインとオフラインのツリーは同じ識別子を保持するため、[同期](sync.md)が可能です。以下の[Gramps Desktopからのインポート](#coming-from-gramps-desktop)を参照してください。

## 家系図ファイルのインポート

1. 上記の手順でインポートページを開きます。
2. 「家系図のインポート」の下で、ファイルを選択し、**インポート**をクリックします。アップロードの進行状況が表示されます。
3. 最初にファイルが読み込まれ、「インポートの確認」ダイアログが、含まれているオブジェクトの数（人、家族、イベント、場所など）と、インポーターの[レポート](#the-import-report)がある場合はそれを表示します。まだツリーには何も追加されていません。カウントが妥当に見えることを確認し、続行するには**インポート**をクリックし、何も変更せずに中止するには**キャンセル**をクリックします。ツリーにすでに人が含まれている場合、ダイアログは同じデータを再度インポートすると重複が発生することを警告します。
4. インポートはバックグラウンドで実行され、進行状況インジケーターが表示されます。データがインポートされると、検索インデックスが更新されます。大きなツリーの場合、これには時間がかかることがあります。インポートが失敗した場合は、その理由が表示されます。
5. ツリーにまだホームパーソンがいない場合は、選択するように求められます。

インポートが完了したら、結果を確認してください：ホームページの**統計**パネルに表示される人数と、古いプログラムの人数を比較し、よく知っている家族を開いて、親、子供、日付、場所が期待通りに移行されているかを確認します。ファイルが写真や他のメディアファイルを参照している場合は、次に[メディアファイルのインポート](import-media.md)を行います。

!!! warning
    通常のインポートは純粋に追加的です：常に新しいオブジェクトを作成し、既存のオブジェクトを更新または削除することはありません。すでにツリーに同じGramps IDまたはハンドルの下に存在するオブジェクトに対しても同様です。同じファイルを二度インポートすること、またはツリー内のデータと重複するファイルをインポートすることは、マージやスキップを行うのではなく、すべての一致するオブジェクトを重複させます。

    すでにインポートされたツリーに対して他の場所で行われた変更を持ち込む必要がある場合は、[バックアップからの復元](backups.md#restore-from-backup)を使用してください。これは、アップロードされたファイルに一致するようにツリーを置き換えるものであり、追加するものではありません。これにはGramps XMLファイルまたはGramps Webバックアップが必要です。

## インポートレポート

インポーターは、完全にインポートできなかったものを報告します。たとえば、理解できなかったGEDCOM行、ファイルから欠落しているレコードへの参照、または古いファイル形式などです。レポートは**レポート**の下に表示され、確認ダイアログとインポート後の両方に表示されます。確認する前に読むことをお勧めします。そうしないと、ツリー内で後で気づく問題を説明していることがよくあります。

すべてのメッセージが問題であるわけではありません。多くのGEDCOMファイルには、報告されるが保持されるプログラム固有のデータが含まれています。詳細は[プログラム固有のデータ](#program-specific-data)を参照してください。レポートの隣にあるボタンを使用して、レポートをコピーしたり、テキストファイルとしてダウンロードしたりできます。たとえば、[フォーラム](../help/help.md)で助けを求めるために使用します。

## 使用制限

サーバー管理者は、あなたのツリーに対する制限を設定できます（[サーバー設定](../install_setup/configuration.md)を参照）。**データ**セクションの上部には、これらの制限に対する現在の使用状況が表示されます：

- **人** – ツリー内の人オブジェクトの数と設定された最大数（無制限の場合は∞）
- **メディアストレージ** – アップロードされたメディアファイルの合計サイズと設定されたストレージクォータ（無制限の場合は∞）

人数の制限を超えるインポートは、全体として拒否されます。

## GEDCOMファイル

GEDCOM 5.5.1およびGEDCOM 7ファイルの両方をインポートできます。いくつか注意すべき点があります。

### 文字エンコーディング

GEDCOM 5.5.1ファイルは、そのヘッダーで文字エンコーディングを宣言します。UTF-8、UTF-16、ANSEL、およびWindows（ANSI）エンコーディングがサポートされています。インポート後にアクセントや他の特殊文字を含む名前が乱れて表示される場合（たとえば、`MÃ¼ller`ではなく`Müller`）、ファイルは宣言されているエンコーディングとは異なるエンコーディングでエクスポートされた可能性があります。古いプログラムからファイルを再度エクスポートし、選択肢があればUTF-8を選んで、[やり直してください](#starting-over)。

GEDCOM 7ファイルは常にUTF-8でエンコードされている必要があります。他のファイルは「無効なGEDCOMファイル」というエラーで拒否されます。

### プログラム固有のデータ

多くのプログラムは、他のプログラムが理解できない独自の拡張をGEDCOMに追加します。Grampsはそのようなデータを静かに削除することはありません。解釈できない行は、「GEDCOMインポート」というタイプのノートに収集され、関連する人、家族、または他のオブジェクトに添付されます。これらのノートを確認して、重要な情報が移行されていないかどうかを確認してください。

### メディアファイル

GEDCOMファイルにはメディアファイル（写真やスキャンした文書など）への参照が含まれていますが、ファイル自体は含まれていません。インポート後、メディアオブジェクトはツリー内に存在しますが、そのファイルは欠落しており、[メディアファイルの状態](import-media.md#media-file-status)の下に表示されます。ファイルを追加するには、[メディアファイルのインポート](import-media.md)を参照してください。

## Gramps Desktopからのインポート

Gramps Desktopを使用している場合、次の手順でデータベースを準備し、すべてがスムーズに実行されるようにします。

1. データベースをチェックして修復する
    - オプション：Gramps XMLにエクスポートしてデータベースのバックアップを作成します
    - [データベースのチェックと修復ツール](https://gramps-project.org/wiki/index.php/Gramps_5.2_Wiki_Manual_-_Tools#Check_and_Repair_Database)を実行します。これにより、Gramps Webで問題を引き起こす可能性のある内部の不整合が修正されます。
2. メディアパスを相対パスに変換する
    - Grampsメディアマネージャーを使用して、[すべてのメディアパスを絶対から相対に変換します](https://gramps-project.org/wiki/index.php/Gramps_5.2_Wiki_Manual_-_Tools#Convert_paths_from_relative_to_absolute)。相対パスであっても、Grampsメディアディレクトリの外にあるメディアファイルは、Gramps Webと同期すると正しく機能しないことに注意してください。

その後、ツリーをGramps XML（`.gramps`）にエクスポートし、上記の手順に従ってインポートし、[メディアファイルをアップロード](import-media.md)します。コンピュータとウェブで同じツリーに取り組み続けるには、[Gramps Web Syncアドオン](sync.md)を使用してください。

### なぜGramps XMLパッケージのサポートがないのか？

Gramps XML（`.gramps`）はデータをインポートするための推奨形式ですが、Gramps XML *パッケージ*（`.gpkg`）はGramps Webではサポートされていません。これは、メディアファイルのインポートおよびエクスポートルーチンがウェブサーバーでの使用に適していないためです。

## 一般的な問題

**「サポートされていない形式」。** [上記](#which-file-to-use)にリストされているファイル拡張子のみがインポートできます。プログラムやオンラインサービスがZIPアーカイブを提供した場合は、それを解凍し、内部の`.ged`ファイルをアップロードしてください。

**すべてが二重に表示される。** 同じファイルが二度インポートされました。インポートは決してマージされないため、[やり直してください](#starting-over)。

**特殊文字が乱れている。** [文字エンコーディング](#character-encoding)を参照してください。

**写真が欠落している。** [メディアファイルのインポート](import-media.md)を参照してください。

### やり直す

インポートが失敗した場合や、古いプログラムで何かを修正して再インポートしたい場合は、まず[すべてのオブジェクトを削除](#delete-all-objects)してツリーを空にし、その後修正されたファイルをインポートします。これにより、インポート以降にGramps Webで行った変更も削除されることに注意してください。

### すべてのオブジェクトを削除

!!! danger
    オブジェクトの削除は**元に戻せません**。進む前に[バックアップ](backups.md)を作成してください。

**すべてのオブジェクトを削除**は、[管理設定](settings.md)の**危険ゾーン**セクションにあります。**削除**をクリックすると、以下の選択肢から削除するオブジェクトを選ぶダイアログが開きます：

- **すべてのオブジェクト** – ツリーを完全にクリアします
- **特定のオブジェクトタイプ** – たとえば、イベントのみまたはメディアオブジェクトのみ

アクションを確認するために再認証（再ログイン）を求められます。削除はバックグラウンドタスクとして実行され、進行状況インジケーターが表示されます。

!!! warning
    オブジェクトタイプのサブセットのみを削除する（すべてのオブジェクトを一度に削除するのではなく）と、大きなツリーの場合、サーバーがオブジェクト間のすべての関係をチェックして更新する必要があるため、非常に長い時間がかかることがあります。
