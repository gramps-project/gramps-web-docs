# データのインポート

既存の家系図を、他の系譜プログラム、オンラインサービス、または Gramps Desktop からエクスポートされたファイルをアップロードすることで Gramps Web に取り込むことができます。

インポートは、[管理設定](settings.md) の **データ** セクションにあり（アプリバーのユーザーアイコン ▸ 管理）、ツリーの所有者と管理者が利用できます。ツリーがまだ空の状態では、ホームページの「始める」カードにある **家系図のインポート** ボタンもそこに導きます。

## どのファイルを使用するか

| 出所 | ツリーをエクスポートする形式 | ファイル拡張子 |
|---|---|---|
| 他の系譜プログラムまたはオンラインサービス | GEDCOM | `.ged` |
| Gramps Desktop | Gramps XML | `.gramps` |
| GeneWeb | GeneWeb | `.gw` |
| Pro-Gen | Pro-Gen | `.def` |
| スプレッドシート | Gramps CSV | `.csv` |
| アドレス帳 | vCard | `.vcf` |

GEDCOM は、ほぼすべての系譜プログラムとオンラインサービスがエクスポートできる一般的な交換形式です。プログラムやウェブサイトで「エクスポート」または「ダウンロード」オプションを探し、複数の形式が提示された場合は GEDCOM を選択してください。Gramps Wiki ページの [他の系譜プログラムからのインポート](https://www.gramps-project.org/wiki/index.php/Import_from_another_genealogy_program) には、特定のプログラムに関する注意事項があります。

Gramps Desktop を使用している場合は、GEDCOM ではなく Gramps XML (`.gramps`) を選択してください。これにより、すべての Gramps データが損失なく保持され、オンラインとオフラインのツリーが同じ識別子を維持するため、[同期](sync.md)が可能になります。以下の [Gramps Desktop からのインポート](#coming-from-gramps-desktop) を参照してください。

## 家系図ファイルのインポート

1. 管理設定の **データ** セクションを開きます。
2. 「家系図のインポート」の下で、ファイルを選択し、**インポート** をクリックします。
3. ファイルが最初に解析され、「インポートの確認」ダイアログがオブジェクトの数（人、家族、イベント、場所など）を表示します。まだツリーには何も追加されていません。カウントが妥当に見えることを確認し、続行するには **インポート** をクリックし、何も変更せずに中止するには **キャンセル** をクリックします。
4. インポートはバックグラウンドで実行され、進行状況インジケーターが表示されます。データがインポートされると、検索インデックスが更新されます。大きなツリーの場合、これには時間がかかることがあります。インポートが失敗した場合は、その理由が表示されます。

インポートが完了したら、結果を確認してください：ホームページの **統計** パネルに表示される人の数と古いプログラムの数を比較し、よく知っている家族を開いて、親、子供、日付、場所が期待通りに移行されたかを確認します。

!!! warning
    通常のインポートは純粋に追加的です：常に新しいオブジェクトを作成し、既存のものを更新または削除することはありません。すでに同じ Gramps ID またはハンドルの下にツリーに存在するオブジェクトについても同様です。同じファイルを二度インポートすることや、ツリー内のデータと重複するファイルをインポートすると、マージやスキップするのではなく、すべての一致するオブジェクトが重複します。

    すでにインポートされたツリーに対して他の場所で行った変更を取り込む必要がある場合は、[バックアップからの復元](backups.md#restore-from-backup)を使用してください。これは、アップロードされたファイルに一致するようにツリーを置き換えるもので、追加するのではありません。これには Gramps XML ファイルまたは Gramps Web バックアップが必要です。

## 使用制限

サーバー管理者は、ツリーに対する制限を設定できます（[サーバー設定](../install_setup/configuration.md)を参照）。**データ** セクションの上部には、これらの制限に対する現在の使用状況が表示されます：

- **人** – ツリー内の人物オブジェクトの数と設定された最大数（無制限の場合は ∞）
- **メディアストレージ** – アップロードされたメディアファイルの合計サイズと設定されたストレージクォータ（無制限の場合は ∞）

人の数の制限を超えるインポートは、全体として拒否されます。

## GEDCOM ファイル

GEDCOM 5.5.1 と GEDCOM 7 のファイルの両方をインポートできます。いくつか注意すべき点があります。

### 文字エンコーディング

GEDCOM 5.5.1 ファイルは、そのヘッダーで文字エンコーディングを宣言します。UTF-8、UTF-16、ANSEL、および Windows (ANSI) エンコーディングがサポートされています。インポート後にアクセントやその他の特殊文字を含む名前が文字化けしている場合（例えば `MÃ¼ller` の代わりに `Müller`）、ファイルは宣言されているものとは異なるエンコーディングでエクスポートされた可能性があります。古いプログラムからファイルを再度エクスポートし、選択肢があれば UTF-8 を選んで、[やり直してください](#starting-over)。

GEDCOM 7 ファイルは常に UTF-8 でエンコードされなければなりません。他のファイルは「無効な GEDCOM ファイル」というエラーで拒否されます。

### プログラム固有のデータ

多くのプログラムは、他のプログラムが理解できない独自の拡張を GEDCOM に追加します。Gramps はそのようなデータを黙って削除することはありません：解釈できない行は、「GEDCOM インポート」というタイプのノートに収集され、関連する人物、家族、または他のオブジェクトに添付されます。重要な情報が移行されなかったかどうかを確認するために、これらのノートを確認してください。

### メディアファイル

GEDCOM ファイルにはメディアファイル（写真やスキャンした文書など）への参照が含まれていますが、ファイル自体は含まれていません。インポート後、メディアオブジェクトはツリー内に存在しますが、そのファイルは欠落しており、[メディアファイルの状態](import-media.md#media-file-status)に表示されます。ファイルを追加するには、[メディアファイルのインポート](import-media.md)を参照してください。

## Gramps Desktop からのインポート

Gramps Desktop を使用している場合、次の手順でデータベースを準備し、すべてがスムーズに実行されるようにします。

1. データベースをチェックして修復する
    - オプション：Gramps XML にエクスポートしてデータベースバックアップを作成する
    - [データベースのチェックと修復ツール](https://gramps-project.org/wiki/index.php/Gramps_5.2_Wiki_Manual_-_Tools#Check_and_Repair_Database)を実行します。これにより、Gramps Web で問題を引き起こす可能性のある内部の不整合が修正されます。
2. メディアパスを相対パスに変換する
    - Gramps メディアマネージャーを使用して、[すべてのメディアパスを絶対パスから相対パスに変換します](https://gramps-project.org/wiki/index.php/Gramps_5.2_Wiki_Manual_-_Tools#Convert_paths_from_relative_to_absolute)。相対パスであっても、Gramps メディアディレクトリの外にあるメディアファイルは、Gramps Web と同期すると正しく機能しないことに注意してください。

その後、ツリーを Gramps XML (`.gramps`) にエクスポートし、上記の手順に従ってインポートし、[メディアファイルをアップロード](import-media.md)します。コンピュータとウェブの両方で同じツリーに作業を続けるには、[Gramps Web Sync アドオン](sync.md)を使用してください。

### なぜ Gramps XML パッケージのサポートがないのか？

Gramps XML (`.gramps`) はデータをインポートするための推奨形式ですが、Gramps XML *パッケージ* (`.gpkg`) は Gramps Web ではサポートされていません。これは、メディアファイルのインポートおよびエクスポートルーチンがウェブサーバーでの使用に適していないためです。

## よくある問題

**「サポートされていない形式」。** [上記](#which-file-to-use)にリストされているファイル拡張子のみがインポート可能です。プログラムやオンラインサービスから ZIP アーカイブを受け取った場合は、それを解凍し、中の `.ged` ファイルをアップロードしてください。

**すべてが二重に表示される。** 同じファイルが二度インポートされました。インポートは決してマージしないため、[やり直してください](#starting-over)。

**特殊文字が文字化けしている。** [文字エンコーディング](#character-encoding)を参照してください。

**写真が欠落している。** [メディアファイルのインポート](import-media.md)を参照してください。

### やり直す

インポートが失敗した場合や、古いプログラムで何かを修正して再インポートしたい場合は、まず [すべてのオブジェクトを削除](#delete-all-objects)してツリーを空にし、その後修正されたファイルをインポートしてください。これにより、インポート以降に Gramps Web で行った変更も削除されることに注意してください。

### すべてのオブジェクトを削除

!!! danger
    オブジェクトを削除することは **元に戻せません**。進む前に [バックアップ](backups.md)を作成してください。

**すべてのオブジェクトを削除** は、[管理設定](settings.md) の **危険ゾーン** セクションにあります。**削除** をクリックすると、削除するオプションを選択できるダイアログが開きます：

- **すべてのオブジェクト** – ツリーを完全にクリアします
- **特定のオブジェクトタイプ** – 例えば、イベントのみまたはメディアオブジェクトのみ

アクションを確認するために再認証（再ログイン）を求められます。削除はバックグラウンドタスクとして実行され、進行状況インジケーターが表示されます。

!!! warning
    オブジェクトタイプのサブセットのみを削除する（すべてのオブジェクトを一度に削除するのではなく）場合、大きなツリーでは非常に長い時間がかかることがあります。サーバーはオブジェクト間のすべての関係をチェックして更新する必要があるためです。
