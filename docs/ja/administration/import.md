# データのインポート

既存の家系図をGramps Webに取り込むには、他の系譜プログラム、オンラインサービス、またはGramps Desktopからエクスポートされたファイルをアップロードします。

インポートは、[管理設定](settings.md)の**データ**セクションにあります（アプリバーのユーザーアイコン ▸ 管理）。これは、ツリーの所有者と管理者が利用できます。ツリーがまだ空の状態のときは、ホームページの「始める」カードにある**家系図をインポート**ボタンからもアクセスできます。

## どのファイルを使用するか

| 出所 | 家系図をエクスポートする形式 | ファイル拡張子 |
|---|---|---|
| 他の系譜プログラムまたはオンラインサービス | GEDCOM | `.ged` |
| Gramps Desktop | Gramps XML | `.gramps` |
| GeneWeb | GeneWeb | `.gw` |
| Pro-Gen | Pro-Gen | `.def` |
| スプレッドシート | Gramps CSV | `.csv` |
| アドレス帳 | vCard | `.vcf` |

GEDCOMは、ほぼすべての系譜プログラムおよびオンラインサービスがエクスポートできる共通の交換形式です。プログラムやウェブサイトで「エクスポート」または「ダウンロード」オプションを探し、複数の形式が提供されている場合はGEDCOMを選択してください。Gramps Wikiページの[他の系譜プログラムからのインポート](https://www.gramps-project.org/wiki/index.php/Import_from_another_genealogy_program)には、特定のプログラムに関する注意事項があります。

Gramps Desktopを使用している場合は、GEDCOMではなくGramps XML（`.gramps`）を選択してください。これにより、すべてのGrampsデータが損失なく保持され、オンラインとオフラインのツリーが同じ識別子を維持できるため、[同期](sync.md)が可能です。以下の[Gramps Desktopからのインポート](#coming-from-gramps-desktop)を参照してください。

## 家系図ファイルのインポート

1. 管理設定の**データ**セクションを開きます。
2. 「家系図をインポート」の下で、ファイルを選択し、**インポート**をクリックします。
3. 最初にファイルが解析され、「インポートの確認」ダイアログが表示され、含まれているオブジェクトの数（人、家族、イベント、場所など）が示されます。まだツリーには何も追加されていません。カウントが妥当に見えることを確認し、続行するには**インポート**をクリックし、何も変更せずに中止するには**キャンセル**をクリックします。
4. インポートはバックグラウンドで実行され、進行状況インジケーターが表示されます。データがインポートされると、検索インデックスが更新されます。大きなツリーの場合、これには時間がかかることがあります。インポートが失敗した場合は、その理由が表示されます。

インポートが完了したら、結果を確認してください：ホームページの**統計**パネルに表示される人数と古いプログラムに表示される人数を比較し、よく知っている家族を開いて、親、子供、日付、場所が期待通りに移行されているかを確認します。

!!! warning
    通常のインポートは純粋に追加的です：常に新しいオブジェクトを作成し、既存のオブジェクトを更新または削除することはありません。たとえ同じGramps IDまたはハンドルの下に既に存在するオブジェクトであってもです。同じファイルを二度インポートすることや、ツリー内のデータと重複するファイルをインポートすると、マージやスキップするのではなく、すべての一致するオブジェクトが重複します。

    すでにインポートされたツリーに対して他の場所で行われた変更を取り込む必要がある場合は、[バックアップからの復元](settings.md#restore-from-backup)を使用してください。これは、アップロードされたファイルに一致するようにツリーを置き換え、追加するのではありません。これにはGramps XMLファイルまたはGramps Webバックアップが必要です。

ツリーに対して人数の制限が設定されている場合（[使用制限](settings.md#usage-quotas)を参照）、それを超えるインポートは全体として拒否されます。

## GEDCOMファイル

GEDCOM 5.5.1およびGEDCOM 7ファイルの両方をインポートできます。いくつか注意すべき点があります。

### 文字エンコーディング

GEDCOM 5.5.1ファイルは、そのヘッダーで文字エンコーディングを宣言します。UTF-8、UTF-16、ANSEL、およびWindows（ANSI）エンコーディングがサポートされています。インポート後にアクセントや他の特殊文字を含む名前が文字化けしている場合（例えば、`MÃ¼ller`の代わりに`Müller`）、ファイルは宣言されたものとは異なるエンコーディングでエクスポートされた可能性があります。古いプログラムから再度ファイルをエクスポートし、選択肢があればUTF-8を選んで、[やり直してください](#starting-over)。

GEDCOM 7ファイルは常にUTF-8でエンコードされている必要があります。他のファイルは「無効なGEDCOMファイル」というエラーで拒否されます。

### プログラム固有のデータ

多くのプログラムは、他のプログラムが理解できない独自の拡張をGEDCOMに追加します。Grampsはそのようなデータを静かに削除することはありません：解釈できない行は、「GEDCOMインポート」タイプのノートに収集され、該当する人物、家族、または他のオブジェクトに添付されます。重要な情報が移行されていないかどうか、これらのノートを確認してください。

### メディアファイル

GEDCOMファイルにはメディアファイル（写真やスキャンした文書など）への参照が含まれていますが、ファイル自体は含まれていません。インポート後、メディアオブジェクトはツリー内に存在しますが、そのファイルは欠落しており、これは[メディアファイルの状態](settings.md#media-file-status)に表示されます。ファイルを追加するには、以下の[メディアファイルのインポート](#import-media-files)を参照してください。

## Gramps Desktopからのインポート

Gramps Desktopを使用している場合、次の手順でデータベースを準備し、すべてがスムーズに動作するようにします。

1. データベースをチェックして修復する
    - オプション：Gramps XMLにエクスポートしてデータベースのバックアップを作成します。
    - [データベースのチェックと修復ツール](https://gramps-project.org/wiki/index.php/Gramps_5.2_Wiki_Manual_-_Tools#Check_and_Repair_Database)を実行します。これにより、Gramps Webで問題を引き起こす可能性のある内部の不整合が修正されます。
2. メディアパスを相対パスに変換する
    - Grampsメディアマネージャーを使用して、[すべてのメディアパスを絶対パスから相対パスに変換します](https://gramps-project.org/wiki/index.php/Gramps_5.2_Wiki_Manual_-_Tools#Convert_paths_from_relative_to_absolute)。相対パスを使用しても、Grampsメディアディレクトリの外にあるメディアファイルは、Gramps Webと同期すると正しく機能しないことに注意してください。

その後、ツリーをGramps XML（`.gramps`）にエクスポートし、上記の手順に従ってインポートし、次のセクションで説明するようにメディアファイルをアップロードします。コンピュータとウェブの両方で同じツリーに作業を続けるには、[Gramps Web Syncアドオン](sync.md)を使用してください。

### なぜGramps XMLパッケージはサポートされていないのか？

Gramps XML（`.gramps`）はデータをインポートするための推奨形式ですが、Gramps XML *パッケージ*（`.gpkg`）はGramps Webではサポートされていません。これは、メディアファイルのインポートおよびエクスポートルーチンがウェブサーバーでの使用に適していないためです。

## メディアファイルのインポート

家系図をインポートし、対応するメディアファイルをアップロードする必要がある場合は、管理設定のデータセクションで**メディアファイルをインポート**を使用します。これは、欠落しているメディアファイルを含むZIPファイルを期待します。ファイルは、次の2つの方法のいずれかでツリー内のメディアオブジェクトに一致します。

- **チェックサムによる一致。** チェックサムを持つメディアオブジェクト（Gramps Desktopからインポートされたツリーの場合）については、一致するチェックサムを持つファイルが使用されます。ファイル名やZIPファイル内のフォルダ構造に関係なく、これが適用されます。これは、Grampsデータベース内のチェックサムが正しい場合にのみ機能します。これは、チェックと修復ツールを実行することで保証されます。
- **パスによる一致。** チェックサムを持たないメディアオブジェクト（GEDCOMインポート後に典型的）については、そのパスによって一致します：ZIPファイルには、メディアオブジェクトに保存されている相対パスと正確に一致するファイルが含まれている必要があります。

GEDCOMファイルに保存されているパスが絶対パスである場合（例えば、`C:\Users\...\photo.jpg`）、パスによる一致は機能しません。この場合、最初にすべてをGramps Desktopにインポートし、既存のメディアファイルをインポートされたツリーに関連付けるためのオプションが多いため、その後[Gramps Desktopからのインポート](#coming-from-gramps-desktop)で説明されているようにGramps Webに移行することをお勧めします。

## よくある問題

**「サポートされていない形式」。** [上記](#which-file-to-use)にリストされているファイル拡張子のみがインポートできます。プログラムやオンラインサービスがZIPアーカイブを提供した場合は、それを解凍して内部の`.ged`ファイルをアップロードしてください。

**すべてが二重に表示される。** 同じファイルが二度インポートされました。インポートは決してマージされないため、[やり直してください](#starting-over)。

**特殊文字が文字化けしている。** [文字エンコーディング](#character-encoding)を参照してください。

**写真が欠落している。** [メディアファイルのインポート](#import-media-files)を参照してください。

### やり直す

インポートが失敗した場合や、古いプログラムで何かを修正して再インポートしたい場合は、まず管理設定の危険ゾーンにある[すべてのオブジェクトを削除](settings.md#delete-all-objects)を使用してツリーを空にし、その後修正されたファイルをインポートしてください。これにより、インポート以降にGramps Webで行った変更も削除されることに注意してください。
