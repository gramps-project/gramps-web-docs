# データの確認と検証

**ファミリーツリー処理**セクションの[管理設定](settings.md)には、ファミリーツリーをチェックするための2つのツールがあります：データベース内の技術的な問題をチェックするものと、信じがたいデータをチェックするものです。

## データベースのチェックと修復

このツールは、Grampsデータベースの内部の不整合をチェックし、修正できるものを修正します – Gramps Desktopの[データベースのチェックと修復ツール](https://www.gramps-project.org/wiki/index.php/Gramps_5.2_Wiki_Manual_-_Tools#Check_and_Repair_Database)に類似しています。

**チェックと修復**をクリックし、進行状況インジケーターが完了するのを待ちます。結果はボタンの下に表示されます：

- エラーが見つからなかった場合、確認メッセージが表示されます。
- エラーが見つかった場合、適用された修正の概要が表示されます。

予期しないエラーや、オブジェクト間の関係が欠如しているなどのデータベースの不整合によって引き起こされる可能性のある動作に遭遇した場合は、このツールを実行してください。

## データの検証

[データベースのチェックと修復](#check-and-repair-database)が*技術的*な不整合を探すのに対し、このツールは*信じがたい*データを探します – Gramps Desktopの[データの検証ツール](https://gramps-project.org/wiki/index.php/Gramps_5.0_Wiki_Manual_-_Tools#Verify_the_Data)に類似しています。これは不可能ではないが、再確認する価値があるほどありそうにない事柄を報告します。例えば、12歳の母親や130歳まで生きた人などです。

**オプション**の下で、テストが使用する閾値を調整できます – 最大年齢、結婚または子供を持つための最小および最大年齢、最大子供数など – また、欠落または不正確な日付を推定するかどうか、31日の2月のような無効な日付を報告するかどうかを設定できます。

**データの検証**をクリックして開始します。チェックはバックグラウンドタスクとして実行され、その後、**データ検証結果**の下に結果がリストされます。このツールによって何も変更されることはありません：見つかったものを報告するだけです。

!!! note
    発見はエラーの証明ではありません。長寿や大きな年齢差は実際に存在するため、結果は修正すべき項目のリストではなく、確認すべき項目のリストとして扱ってください。
