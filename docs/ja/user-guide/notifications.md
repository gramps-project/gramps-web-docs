# 通知

アプリバーの上部にあるベルをクリックすると通知が開きます。ベルのバッジには未読の通知の数が表示されます。メニューには実行中のタスクと最新の通知がリストされており、**すべて表示**をクリックすると完全な通知ログが開きます。小さな画面では、ベルをクリックすると直接ログが開きます。

通知は以下に関するものです：

- **他のユーザーによる変更。** 他のユーザーがGramps Webを使用している間にツリーを変更すると、誰が何を変更したかを示す通知が表示されます。例えば、「人物を編集」や「12の変更」といった内容です。それをクリックすると、[改訂履歴](revisions.md)で変更を開くことができます。Gramps Webのユーザーがいない変更（Gramps Desktopを使用して共有データベースに直接行った変更など）は、名前なしで表示されます。これは改訂履歴を表示できるユーザー（メンバー以上）のみが利用可能です。
- **バックグラウンドタスク** – インポートやエクスポート、レポートの生成、OCRテキスト認識、データベースのアップグレード、多くのオブジェクトの削除や編集、検索インデックスの再構築など – それらの状態（例：保留中、開始、進行中）を表示し、完了または失敗した際に通知します。
- **エラー** – セッション中に発生したエラー（APIリクエストの失敗、バックグラウンドタスクのエラー、保存の失敗、またはブラウザレベルのエラー）です。

完了したエクスポートやメディアアーカイブは、その通知からダウンロードできます。また、[エクスポートページ](../administration/export.md)を離れた後でもダウンロード可能です。

一部の通知には、失敗したタスクのエラーメッセージなどの構造化された詳細が含まれています。そのようなエントリを通知ログでクリックすると、エラーデータの内訳と**JSONをコピー**ボタンが表示されるダイアログが開きます。これはバグを報告する際に便利で、JSONにはサーバーからの正確なエラー情報が含まれています。

通知ログで**すべてクリア**を使用して、すべての通知を消去します。

インポート、復元、すべてのオブジェクトの削除、または検索インデックスの再構築など、ツリー全体を変更するタスクは同時に実行できません。別のタスクが実行中のときに新しいタスクを開始すると、別のタスクがすでにこのツリーで実行中であるというメッセージが表示され、実行中のタスクがその進行状況とともに表示されます。

!!! note
    通知はメモリにのみ保存され、ページを再読み込みするとクリアされます。Gramps Webは開いている間のみ他のユーザーによる変更をチェックするため、あなたが離れている間に行われた変更は報告されません。これらについては[改訂履歴](revisions.md)を参照してください。
