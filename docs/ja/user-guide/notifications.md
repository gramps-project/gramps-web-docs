# 通知

**通知**はベルアイコンを持つサイドバー項目です。エラーが発生したり、バックグラウンドタスクが実行中の場合、未読通知の数がバッジに表示されます。それをクリックすると通知ログが開きます。

通知ログは二つの目的を持っています：

- セッション中に発生したエラーの記録です – APIリクエストの失敗、バックグラウンドタスクのエラー、保存の失敗、またはブラウザレベルのエラー。
- 長時間実行されるバックグラウンドタスクの進行状況を追跡します – インポートやエクスポート、レポートの生成、OCRテキスト認識、データベースのアップグレード、検索/セマンティックインデックスの再構築など – それらの状態（例：保留中、開始、進行中）を示し、完了または失敗した際に通知します。

各エントリには短いメッセージ、ソース（ネットワーク、タスク、保存、またはブラウザ）、およびタイムスタンプが表示されます。完了したタスクは「タスク完了」または「タスク失敗」と表示されます。

一部の通知には、失敗したタスクのエラーメッセージなどの構造化された詳細が含まれています。そのようなエントリをクリックすると、エラーデータの内訳と**JSONをコピー**ボタンを含むダイアログが開きます。これはバグを報告する際に便利で、JSONにはサーバーからの正確なエラー情報が含まれています。

**すべてクリア**を使用して、すべての通知を消去します。

インポート、復元、すべてのオブジェクトの削除、または検索インデックスの再構築など、全体のツリーを変更するタスクは同時に実行できません。別のタスクが実行中のときに新しいタスクを開始すると、別のタスクがこのツリーで既に実行中であるというメッセージが表示され、実行中のタスクがその進行状況と共に表示されます。

!!! note
    通知はメモリにのみ保存され、ページをリロードするとクリアされます。
