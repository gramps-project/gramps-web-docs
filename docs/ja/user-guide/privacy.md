# プライベートレコード

ツリー内の任意のレコードはプライベートとしてマークできます。[ユーザーロール](../install_setup/users.md#user-roles)と共に、これにより誰が何を見られるかが決まります。

## 誰が何を見られるか

Gramps Webは決して一般公開されることはありません：アカウントを持つユーザーのみが何かを見ることができます。Grampsにおける「公開」とは単に「プライベートでない」ことを意味し、つまりツリーにログインしているすべてのユーザーに見えるということです。

| ロール | 公開レコード | プライベートレコード |
|---|---|---|
| ゲスト | 表示 | – |
| メンバー | 表示 | 表示 |
| 貢献者 | 表示、追加 | 表示、追加 |
| 編集者、オーナー、管理者 | 表示、追加、編集、削除 | 表示、追加、編集、削除 |

ゲストにとって、プライベートレコードは存在しません：ページ、リスト、検索結果、チャート、レポート、エクスポート、AIアシスタントの回答から除外されます。これはサーバーがデータベースを読み取る際に強制されており、アプリ内で物を隠すことによってではないため、ゲストは他の方法でプライベートデータにアクセスすることもできません。

まだ承認されていないアカウント（[自己登録](registration.md)後）は、全くログインできません。

したがって、親族やゲストアカウントを持つ他の人が特定の情報を見てはいけない場合は、それをプライベートとしてマークしてください。ツリーのすべてのユーザーがすべてを見ることができる場合は、メンバーのロール（またはそれ以上）を与え、何もプライベートとしてマークする必要はありません。

## 生存者は自動的にプライベートではない

何も自動的にプライベートにはなりません - 生存者でさえもです。生存者のデータは、プライベートとしてマークするまでゲストに見える状態です。これはインポートされたツリーにも適用されます。

Gramps Webでおそらく生存している人々をプライベートにするには：

1. 人々のリストで、[詳細フィルター](lists.md#advanced-filter)を開き、「おそらく生存している人々」という条件を追加します（今日の日付は空白のままにします）。フィルターを適用します。
2. **選択**をクリックし、ヘッダーのチェックボックスをオンにして、**すべて選択**を選びます。
3. **プライバシー**アクションを選択し、レコードをプライベートとしてマークします。

「おそらく生存している」は、その人とその親族の生年月日から推定されます。使用可能な日付がない人は生存していると見なされます。結果を確認し、データを追加するにつれて推定が変わる可能性があることを考慮してください。

人をプライベートとしてマークすると、その人は隠されますが、イベント、ノート、メディア、または家族は隠されません - 下記を参照してください。Gramps Desktopには、関連する多くのレコードのプライバシーを一度に設定するためのより多くのツールがあり、[Syncアドオン](../administration/sync.md)と共に使用できます。

後に亡くなる人も自動的に公開されることはありません。それを望むかどうかはあなた次第です - 多くの研究者は収集した情報をしばらくプライベートに保つことを好みます。

## ロックアイコンの読み方

プライベートデータを表示できるユーザーは、プライベートアイテムの横にロックが表示されます。2種類あります：

- **塗りつぶされたロック** - レコード自体がプライベートです。例えば、人物のページでは、イベントの横に塗りつぶされたロックがある場合、そのイベントはプライベートであり、子供の横にある場合はその子供がプライベートであることを意味します。
- **アウトラインロック** - プライベートなのは*リンク*だけで、リンク先のレコードではありません。例えば、人物のイベントへのリンクがプライベートであっても、イベント自体は公開されていることがあります。この場合、その人物のページからはイベントが隠されますが、他の参加者のページやイベントリストなど、他の場所ではまだ見える状態です。

レコードとそのリンクの両方がプライベートな場合、塗りつぶされたロックが表示されます。

この区別は、子供（子供または家族への子供のリンク）、関連、ソースのリポジトリリンク、ギャラリー内のメディアにも適用されます。名前、属性、住所、URLはそれぞれのレコードに属し、塗りつぶされたロックのみを持ちます。

## 何かをプライベートにする

プライバシーを変更するには編集権限が必要です。

- **全体のレコード**: ページを開き、編集モードに入り、ツールバーのロックボタンをクリックします。
- **レコードの一部** - 別名、属性、住所、URL、関連、子供のリンク、またはリポジトリリンク: そのアイテムの編集ダイアログを開き、**プライベート**スイッチをオンにします。主な名前にはスイッチがありません。そうしないと、その人は「プライベート」として表示されます。
- **人物または家族のページからのイベント**: イベントの編集ダイアログには、そのイベント自体のプライバシースイッチがあります。イベントが他の人と共有されている場合、**すべての人のために編集**の後でのみ編集可能になります。なぜなら、すべての人にとってプライベートだからです。
- **イベントへの人物のリンク**: イベントページで、参加者の行を編集モードで開きます。そこにあるプライバシースイッチは、その参加者のリンクにのみ適用されるため、他の参加者にはイベントが見えるままです。
- **ギャラリー内のメディアオブジェクト**: 編集モードで、タイルの隅にあるロックをクリックします。
- **複数のレコードを一度に**: リストでそれらを選択し、**プライバシー**アクションを使用します。詳細は[リスト](lists.md#tags-and-privacy)を参照してください。

リスト内のどのレコードがプライベートであるかを確認するには、リストの列ピッカーで**プライバシー**列をオンにします。

## 考慮すべきこと

- レコードをプライベートにしても、それがリンクしているレコードはプライベートにはなりません。人がプライベートであれば、その人のイベント、所属する家族、およびそれに付随するノートは、プライベートでない限りまだ見える状態です。関連するレコードを確認するには、詳細フィルターまたは**プライバシー**列を使用してください。
- 家族やイベントをプライベートにすると、それは隠されますが、その中の人々は隠されません。
- [DNAマッチとY-DNAデータ](dna-matches.md#private-matches)には、それぞれのダイアログに独自の**プライベート**スイッチがあります。
- プライベートデータを表示できないユーザーによって作成されたエクスポートやメディアアーカイブには、プライベートレコードやファイルは含まれません。
- プライバシーはGrampsの機能であり、Gramps DesktopでプライベートとしてマークされたレコードはGramps Webでもプライベートであり、その逆も同様です。
