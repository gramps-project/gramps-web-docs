# Gramps Webを使用したY-DNA分析

!!! note "注意"
    この機能は、Gramps Web APIバージョン3.3.0以降およびGramps Webフロントエンドバージョン25.9.0以降を必要とします。

Gramps WebのY-DNAビューは、生のY染色体単一ヌクレオチド多型（SNP）データを使用して、個人の最も可能性の高いY-DNAハプログループを特定し、推定される祖先を人間のY染色体ツリーに表示します。

## Y-DNA SNPデータの取得と保存方法

Y-DNA SNPデータを取得するには、遺伝子検査サービスを通じてY-DNAテストを実施する必要があります。結果は、各変異を文字列（例：`R-BY44535`）で識別し、変異が存在するかどうかを示す`+`または`-`記号を持つ変異のセットとして表されます。Gramps Webは、すべてのテストされたSNPの文字列を`SNP1+, SNP2-, SNP3+,...`の形式で、カスタムタイプ`Y-DNA`の人物属性に保存することを期待しています（大文字と小文字が区別されます）。この属性をGramps WebまたはGramps Desktopで手動で作成するか、Gramps WebのY-DNAビューに移動して青い「追加」ボタンをクリックし、データを追加する人物を選択してSNP文字列を貼り付けることができます。いずれにせよ、データはGrampsデータベースの人物属性として保存されます。

さまざまなテストサービスからSNPデータを取得する方法についての指示は、[以下を参照](#instructions-for-obtaining-snp-data-from-testing-services)してください。

## 仕組み

人物がSNPデータを含む`Y-DNA`属性を持つと、Gramps Webはオープンソースの[yclade](https://github.com/DavidMStraub/yclade) Pythonライブラリを使用して、その人物の人間のY染色体ツリー上での最も可能性の高い位置を特定します。このツリーは、何万ものY-DNAテストに基づいて[YFull](https://www.yfull.com/)プロジェクトによって作成されました。Gramps WebはYFullツリーのローカルコピーを使用しているため、データは第三者に送信されることはありません。

ツリーは根から葉に向かって移動し、各ノードでそのノードに関連付けられたSNPが、その人物の陽性および陰性のテストSNPと比較され、適切な枝がたどられます。

最終的な結果は、ツリーの根（[Y染色体の「アダム」](https://en.wikipedia.org/wiki/Y-chromosomal_Adam)）から、人物のSNPデータと一致する最も派生したクレードまでの一連のクレードです。各クレードには、そのクレードに属するYFullデータベース内のサンプルの年齢に基づいた推定年齢があります。

Y染色体は父から子に受け継がれるため、この連続は人物の父系の祖先の抜粋に対応します。

## 結果の解釈方法

最も重要な情報は、ページの上部に表示される人物の最も可能性の高いハプログループです。この名前は、そのハプログループに属するテストされたサンプルの出身国などの詳細情報を含む[YFull](https://www.yfull.com/)ウェブサイトの対応ページにリンクされています。

Gramps Webに表示される父系祖先ツリーでは、テストされた人物の真上にあるボックスが、その人物のハプログループに属するすべてのテストされたサンプルの最も最近の共通祖先（MRCA）です。この祖先に示されている日付は、彼の推定されたおおよその誕生日です。彼の上にいる祖先は、このハプログループを定義する変異が最初に現れた祖先です。

Y染色体の変異率が遅いため、MRCAは数百年前のものである可能性があります。稀なハプログループ（すなわち、これまでにテストされた人が少ないハプログループ）では、数千年前であることもあります。

MRCAとテストされた人物の間には、あなたのツリーに文書化されている限りの父系の系譜が示されています：父、その父、そしてその先、最も古いものから順に。最も古い文書化された祖先の上にある点線は、文書化されていない世代を示し、その数の推定値が付いています。生物学的な父親のみが追跡され、養父や継父である場合はY染色体を受け継いでいないため、ラインはそこで停止します。ライン内の人物をクリックすると、その人物のページが開きます。

各クレードボックスのアイコンをクリックすると、そのクレードがYFullウェブサイトで開きます。

## プライベートY-DNAデータ

Y-DNAデータの追加および編集用のダイアログには、**プライベート**スイッチがあります。プライベートY-DNAデータは、プライベートレコードを表示できないユーザーからは隠されます。詳細は[プライベートレコード](privacy.md)を参照してください。

## テストサービスからSNPデータを取得するための指示

### [YSEQ](https://www.yseq.net/)

「マイアカウント」にログインしたら、「マイ結果 / アレルの表示」に移動し、ページの下部に移動します。「アレルリストコンパクト」というテキストフィールドは、Gramps Web専用に追加されており、`Y-DNA`属性に貼り付けるのにちょうど適した形式になっています。
