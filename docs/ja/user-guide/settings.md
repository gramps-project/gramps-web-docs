# ユーザー設定

ユーザー設定は、アプリの上部バーにあるユーザーアイコンからアクセスでき、次に**ユーザー設定**を選択します。ページは折りたたみ可能なセクションに整理されています。変更は、特に記載がない限り、即座に反映されます。

!!! note
    ユーザー設定の変更は、自分のアカウントにのみ影響します。すべてのユーザーに影響を与える設定は、[管理設定](../administration/settings.md)で管理されています。

## アカウント

プロフィール情報、資格情報、およびアカウントのセキュリティをカバーします。

### ユーザー情報

あなたの**ユーザー名**と現在の**ユーザー役割**（例：ゲスト、メンバー、エディター）を表示します。これらは読み取り専用です。

### メールアドレスの変更

新しいメールアドレスを入力し、**送信**をクリックして、アカウントに関連付けられたアドレスを更新します。メールアドレスは、パスワードのリセットや（設定されている場合）通知に使用されます。

### パスワードの変更

現在のパスワードと新しいパスワードを入力し、次に**送信**をクリックします。現在のパスワードを忘れた場合は、ログインページの**パスワードを忘れた**リンクを使用してください。

### リンクされたサインイン方法

サーバーがシングルサインオンを提供している場合（[OIDC認証](../install_setup/oidc.md)を参照）、Googleや組織のログインなどのプロバイダーからアカウントをGramps Webアカウントにリンクできます。その後、そのプロバイダーでサインインし、既存のアカウントにアクセスできます。役割や編集内容も保持されます。このセクションは、シングルサインオンが有効で、サーバーがリンクをサポートしている場合（Gramps Web API 3.24以降）のみ表示されます。

アカウントをリンクするには、**リンクする**をクリックし、プロバイダーの名前を選択し、プロバイダーでサインインすると、設定に戻されます。最近サインインしていない場合は、最初に再度サインインするよう求められます。

プロバイダーアカウントは、1つのGramps Webアカウントにのみリンクできます。「このサインインは別のアカウントに既にリンクされています」と表示された場合、それは他の場所にリンクされているためです。たとえば、そのプロバイダーで最初にサインインしたときに作成されたアカウントにリンクされています。管理者がその別のアカウントを削除すると、その後あなたのアカウントにリンクできるようになります。

アカウントのリンクを解除するには、**リンク解除**をクリックします。最後のリンクされたサインイン方法である場合、後でサインインできるようにパスワードを入力する必要があります。シングルサインオンを通じてアカウントが作成され、パスワードを設定していない場合は、最初にログインページの**パスワードを忘れた**を使用して設定してください（これにはサーバーがメールを送信する必要があります）。サーバーがプロバイダーを通じてのみサインインを許可している場合、最後のリンクされたアカウントはリンク解除できません。

## 外観

デバイスに保存された表示設定を制御します。

### 言語

Gramps Webインターフェースの言語を選択します。言語設定はブラウザのローカルストレージに保存され、現在のデバイスにのみ適用されます。

### テーマ

次のいずれかを選択します：

- **システム** – オペレーティングシステムの明るい/暗い設定に従う（デフォルト）
- **ライト** – 常にライトテーマを使用
- **ダーク** – 常にダークテーマを使用

テーマ設定はブラウザのローカルストレージに保存されます。

### 家系図の設定

#### デフォルトの家系図ビュー

[家系図](tree.md)ページに移動したときにデフォルトで開くチャートタイプを設定します。オプションは、祖先ツリー、子孫ツリー、砂時計グラフ、関係グラフ、ファンチャートです。

この設定はブラウザのローカルストレージに保存されます。

## 開発者ツール

### APIトークン

現在のセッショントークンをクリップボードにコピーします。このトークンは、REST APIに対して直接認証するために使用できます。たとえば、Gramps Webインスタンスの`/api/swagger-ui`で提供されるインタラクティブなSwagger UIで使用できます。

**Swaggerを起動**をクリックすると、新しいタブでSwagger UIが開き、セッションがすでに利用可能です。

!!! note
    セッショントークンは短命です。Swaggerで使用する前にすぐにコピーしてください。期限切れになる可能性があります。
