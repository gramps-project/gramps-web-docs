Gramps Webでは、Gramps Desktopと同様に、写真の中で人をタグ付けすることができ、人物とメディアオブジェクトをリンクします。これは自動顔検出によって簡素化されています。

画像の領域は、人物だけでなく、家族、イベント、場所、ソース、または引用にもリンクできます。たとえば、写真の中の建物やスキャンしたページの引用などです。オブジェクトは、同じ人物の複数の写真があるアルバムページなど、同じ画像内に複数の領域を持つことができます。

## 領域をリンクする

画像の領域をオブジェクトにリンクするには、次の手順に従います。

- メディアオブジェクトの詳細ビューを開きます。たとえば、全画面プレビューで「詳細を表示」をクリックします。
- 右下隅にある青い編集ボタンをクリックします。このボタンが表示されない場合は、ユーザーに編集権限がありません。
- 画像の上に、検出された顔に対応する点線の境界を持つボックスが表示されます。ボックスをクリックして選択します。
- 代わりに自分で領域を描くには、<svg style="width:24px;height:24px;top:6px;position:relative;opacity:0.6;" viewBox="0 0 24 24">
    <path fill="currentColor" d="M13,17H17V13H19V17H23V19H19V23H17V19H13V17M11,17V19H9V17H11M7,17V19H5V17H7M19,9V11H17V9H19M19,5V7H17V5H19M15,5V7H13V5H15M11,5V7H9V5H11M7,5V7H5V5H7M7,13V15H5V13H7M7,9V11H5V9H7Z" />
</svg>
ボタンをクリックして、画像上に矩形をドラッグします。描画はタッチスクリーンでも機能します。
- 「リンク」ボタンをクリックして、既存の人物、家族、イベント、場所、ソース、または引用を選択します。

リンクされた領域は、実線の境界とリンクされたオブジェクトの名前とそのタイプのアイコンを持つラベルで表示されます。画像の全画面ビューで、リンクされた領域をクリックすると、リンクされたオブジェクトが開きます。

## 領域を編集する

編集モードでは、リンクされた領域をクリックして選択します。次に、以下の操作ができます。

- **移動**するにはドラッグするか、四隅のハンドルを使って**サイズ変更**します。変更はマウスボタンを放すか、指を離すと保存されます。
- 「リンク」ボタンを使用して**別のオブジェクト**にリンクします。
- 確認後、<svg style="width:24px;height:24px;top:6px;position:relative;opacity:0.6;" viewBox="0 0 24 24">
    <path fill="currentColor" d="M19,4H15.5L14.5,3H9.5L8.5,4H5V6H19M6,19A2,2 0 0,0 8,21H16A2,2 0 0,0 18,19V7H6V19Z" />
</svg>
ボタンで**削除**します。これにより、オブジェクトと画像の間のリンクが削除されますが、オブジェクト自体は削除されません。

Escapeキーを押すか、「選択をクリア」ボタンをクリックして、選択をクリアし、描画モードを終了します。

領域はキーボードでも使用できます：Tabキーを押して領域間を移動し、EnterまたはSpaceキーを押して編集モードで1つを選択するか、全画面ビューでリンクされたオブジェクトを開きます。
