# リスト

Gramps Webのすべてのオブジェクトタイプにはリストビューがあります：人々、家族、イベント、場所、ソース、引用、リポジトリ、ノート、メディアです。これらはすべて同じ方法で動作し、ソート、フィルタリング、および一括編集のための同じツールを共有しています。

## ソートとページング

列ヘッダーをクリックすると、その列でソートされます。もう一度クリックすると、順序が逆になります。ソートはサーバーによって行われるため、表示しているページだけでなく、リスト全体に適用されます。

長いリストはページに分割されます。下部のページネーションコントロールを使用して、ページ間を移動します。

狭い画面では、テーブルは自動的にコンパクトなレイアウトに切り替わるため、リストビューは電話でも使用可能です。

## 列の選択

リストの上にあるギアアイコンをクリックして、**列**ダイアログを開きます。列をチェックまたはチェックを外して表示または非表示にします。**リセット**は、そのリストのデフォルトの選択を復元します。

少なくとも1つの列は表示されている必要があるため、最後の列はチェックを外すことができません。

列の選択はオブジェクトタイプおよび家系図ごとに記憶されます。これはブラウザに保存されるため、他のユーザーには表示されませんが、別のブラウザやデバイスには引き継がれません。

## フィルタリング

**フィルタ**ボタンをクリックしてフィルターパネルを開きます。フィルタリングには3つの方法があり、組み合わせることができます：

- **既製のフィルタ**は、オブジェクトタイプに依存する折りたたみ可能なセクションにあります。たとえば、人々の場合、出生年、死亡年、さまざまな人物のプロパティ、関連の数、タグ、およびオブジェクトがプライベートかパブリックかでフィルタリングできます。
- **高度なフィルタ** – 既製のフィルタでは表現できない条件を構築するためのビルダーで、[以下](#advanced-filter)に説明されています。
- **GQL** – [Gramps Query Language](gql.md)のクエリ用のテキストフィールドです。クエリを入力し、Enterキーを押すか、**適用**をクリックします。クエリが無効な場合、フィールドの枠が赤くなります。クエリは他のフィルタの上に適用されます。

アクティブなフィルタはリストの上にチップとして表示されます。チップのクリアボタンをクリックして単一のフィルタを削除するか、**すべてのフィルタをクリア**を使用して一度にすべてを削除します。

### 高度なフィルタ

フィルターパネルの下部にある**高度なフィルタ**をクリックして条件ビルダーを開きます。その条件は、Gramps Desktopで知られているフィルタルールです。たとえば、「&lt;名前&gt;を持つ人々」や「&lt;人物&gt;の祖先」などです。

- **条件を追加**をクリックしてルールを選択します。ルールはカテゴリにグループ化されており、名前や説明で検索できます。
- ルールのパラメータを入力します。各パラメータには、日付フィールド、タグセレクタ、または人物や場所のオブジェクトセレクタなど、対応する入力があります。
- グループの条件がどのように組み合わされるかを選択します：**すべての条件**、**いずれかの条件**、または – それらの隣のメニューを介して – **正確に1つの条件**。
- **グループを追加**をクリックして、別のグループ内に条件のグループを追加します。これには独自の組み合わせ方法があります。
- 条件またはグループの**否定**を選択して反転させます。

**適用**をクリックしてリストをフィルタリングします。

ビルダーを開いたときにアクティブな既製のフィルタは、条件として表示されます。構築したフィルタが既製のフィルタで表現できる場合、適用後にそれらと一緒に表示されます。そうでない場合は、単一の**高度なフィルタ**チップとして表示され、フィルターパネルにはビルダーを再度開くための**編集**ボタンが提供されます。

!!! note
    Gramps Desktopに保存されたカスタムフィルタを参照するルールはビルダーでは利用できません。ルールはGramps Web API 3.24以降であなたの言語で表示されます。

## オブジェクトの選択と一括操作

編集権限を持つユーザーは、フィルターボタンの隣に**選択**ボタンを見ます。これをクリックすると選択モードに入り、各行にチェックボックスが追加されます。

選択したいオブジェクトにチェックを入れると、選択されたオブジェクトの数を示すツールバーが表示され、**アクション**ドロップダウンと**適用**ボタンが表示されます。

テーブルヘッダーのチェックボックスは、現在のページのすべてのオブジェクトを選択します。現在のフィルタに一致するオブジェクトがさらにある場合、ツールバーは**すべて選択 (N)**を提供し、すべてのページにわたるN個の一致するオブジェクトを選択します。行のチェックを外したり、ページやフィルタを変更したり、選択モードを終了したりすると、この選択は終了します。

### 削除

1つ以上のオブジェクトを選択し、**削除**を選択して**適用**をクリックします。確認ダイアログが表示され、アクションを元に戻すことができないことを警告します。

10個以上のオブジェクトを削除する場合は、バックグラウンドタスクとして実行されます。その進捗は**適用**ボタンの隣と[通知](notifications.md)に表示され、完了するとリストが再読み込みされます。

!!! tip
    削除は他の変更と同様に[改訂履歴](revisions.md)に記録されるため、誤って一括削除した場合は、対応するトランザクションを元に戻すことで復元できます。

### マージ

**正確に2つの**オブジェクトを選択し、**マージ**を選択して**適用**をクリックします。どちらのオブジェクトがマージされたオブジェクトの主データを提供するかを尋ねるダイアログが表示されます。主として保持したいオブジェクトをクリックします。もう一方のオブジェクトのデータがそれにマージされ、参照が更新されます。

マージは人々、家族、イベント、場所、ソース、および引用に対して利用可能です。リポジトリ、ノート、およびメディアオブジェクトには利用できません。

メディアビューでは、選択はギャラリーとリストレイアウトの両方で機能します：選択モードでは、タイルや行をクリックするとトグルされます。メディアに対しては**削除**のみが利用可能なアクションです。

有効な選択なしにアクションを選択した場合（たとえば、1つのオブジェクトだけが選択された状態でのマージなど）、必要なことを説明するダイアログが表示されます。
