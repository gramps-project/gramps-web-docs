# リスト

Gramps Webのすべてのオブジェクトタイプにはリストビューがあります：人々、家族、イベント、場所、ソース、引用、リポジトリ、ノート、メディア。それらはすべて同じように機能し、ソート、フィルタリング、および一括編集のための同じツールを共有しています。

## ソートとページング

列ヘッダーをクリックすると、その列でソートされます。再度クリックすると、順序が逆になります。ソートはサーバーによって行われるため、表示しているページだけでなく、リスト全体に適用されます。

長いリストはページに分割されます。下部のページネーションコントロールを使用して、ページ間を移動します。

狭い画面では、テーブルは自動的にコンパクトレイアウトに切り替わるため、リストビューは電話でも使用可能です。

## 列の選択

リストの上部にあるツールバーの右端にあるギアアイコンをクリックして、**列**ダイアログを開きます。列をチェックまたはチェック解除して、表示または非表示にします。**リセット**は、そのリストのデフォルトの選択を復元します。

少なくとも1つの列は表示されている必要があるため、最後の列はチェックを外すことができません。

列の選択はオブジェクトタイプごとおよび家系図ごとに記憶されます。ブラウザに保存されるため、他のユーザーには表示されませんが、異なるブラウザやデバイスには引き継がれません。

## フィルタリング

**フィルタ**ボタンをクリックしてフィルタパネルを開きます。フィルタリングには3つの方法があり、組み合わせることができます：

- オブジェクトタイプに依存する折りたたみ可能なセクションにある**既製のフィルタ**。たとえば、人々の場合、名前、生年、死亡年、さまざまな人のプロパティ、関連の数、タグ、およびオブジェクトがプライベートかパブリックかでフィルタリングできます。家族は父、母、または子供の名前でフィルタリングでき、ソースは著者で、場所とリポジトリはそのタイプでフィルタリングできます。
- **高度なフィルタ** – 既製のフィルタでは表現できない条件ビルダー、[以下](#advanced-filter)に説明されています。
- **GOQL** – [Gramps Object Query Language](goql.md)の式用のテキストフィールドで、構文ハイライトがあります。式を入力してEnterを押すか、**適用**をクリックします。式が無効な場合、フィールドはエラーとしてマークされます。式は他のフィルタの上に適用されます。

アクティブなフィルタはツールバーの下の行にチップとして表示されます。チップのクリアボタンをクリックして単一のフィルタを削除するか、**すべてのフィルタをクリア**を使用して一度にすべてを削除します。

### 高度なフィルタ

フィルタパネルの下部にある**高度なフィルタ**をクリックして条件ビルダーを開きます。その条件は、Gramps Desktopで知られているフィルタルール、たとえば「&lt;name&gt;の人々」や「&lt;person&gt;の祖先」などです。

- **条件を追加**をクリックしてルールを選択します。ルールはカテゴリにグループ化されており、名前や説明で検索できます。
- ルールのパラメータを入力します。各パラメータには一致する入力があります。たとえば、日付フィールド、タグセレクタ、または人や場所のオブジェクトセレクタです。
- グループの条件がどのように組み合わされるかを選択します：**すべての条件**、**任意の条件**、またはそれらの隣のメニューを介して**正確に1つの条件**。
- **グループを追加**をクリックして、別のグループ内に条件のグループを追加し、それを組み合わせる方法を持たせます。
- 条件またはグループに**Not**を選択して反転させます。

**適用**をクリックしてリストをフィルタリングします。

ビルダーを開くときにアクティブな既製のフィルタとGOQL式が条件として表示されます。GOQL式は独自の条件として追加することもでき、たとえば**任意の条件**で複数の式を組み合わせることができます。作成したフィルタが既製のフィルタで表現できる場合、適用後にそれらと一緒に表示されます。そうでない場合は、単一の**高度なフィルタ**チップとして表示され、フィルタパネルにはビルダーを再度開くための**編集**ボタンが提供されます。

!!! note
    Gramps Desktopに保存されたカスタムフィルタを参照するルールは、ビルダーでは利用できません。ルールは、Gramps Web API 3.24以降ではあなたの言語で表示されます。

## オブジェクトの選択と一括操作

編集権限を持つユーザーは、フィルタボタンの隣に**選択**ボタンを見ることができます。これをクリックすると選択モードに入り、各行にチェックボックスが追加されます。

選択したいオブジェクトにチェックを入れると、選択された数を示すツールバーが表示され、**アクション**ドロップダウンと**適用**ボタンが表示されます。

テーブルヘッダーのチェックボックスをクリックすると、現在のページのすべてのオブジェクトが選択されます。現在のフィルタに一致するオブジェクトがさらにある場合、ツールバーは**すべて選択 (N)**を提供し、すべてのページにわたってNの一致するオブジェクトを選択します。行のチェックを外したり、ページやフィルタを変更したり、選択モードを終了すると、この選択が終了します。

### 削除

1つ以上のオブジェクトを選択し、**削除**を選択して**適用**をクリックします。確認ダイアログが表示され、アクションを確認するように求められ、アクションは元に戻せないことを警告します。

10個以上のオブジェクトを削除する場合は、バックグラウンドタスクとして実行されます。その進行状況は**適用**ボタンの隣と[通知](notifications.md)に表示され、完了するとリストが再読み込みされます。

!!! tip
    削除は、他の変更と同様に[改訂履歴](revisions.md)に記録されるため、誤って一括削除した場合は、対応するトランザクションを元に戻すことで復元できます。

### マージ

**正確に2つ**のオブジェクトを選択し、**マージ**を選択して**適用**をクリックします。ダイアログが表示され、どちらのオブジェクトがマージされたオブジェクトの主要データを提供するかを尋ねます。保持したい方をクリックします。もう一方のオブジェクトのデータが統合され、参照が更新されます。

マージは人々、家族、イベント、場所、ソース、および引用に対して利用可能です。リポジトリ、ノート、およびメディアオブジェクトには利用できません。

メディアビューでは、選択はギャラリーとリストレイアウトの両方で機能します：選択モードでは、タイルや行をクリックすると切り替わります。メディアに対しては**削除**のみが利用可能なアクションです。

有効な選択なしにアクションを選択した場合（たとえば、1つのオブジェクトのみが選択された状態でのマージなど）、ダイアログが必要な条件を説明します。
