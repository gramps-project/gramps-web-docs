# リスト

Gramps Webのすべてのオブジェクトタイプにはリストビューがあります：人々、家族、イベント、場所、ソース、引用、リポジトリ、ノート、メディア。それらはすべて同じ方法で機能し、並べ替え、フィルタリング、および一括編集のための同じツールを共有しています。

## 並べ替えとページング

列ヘッダーをクリックすると、その列で並べ替えが行われます。再度クリックすると、順序が逆転します。並べ替えはサーバーによって行われるため、表示しているページだけでなく、リスト全体に適用されます。

長いリストはページに分割されます。下部のページネーションコントロールを使用して、ページ間を移動します。

狭い画面では、テーブルは自動的にコンパクトなレイアウトに切り替わるため、リストビューは電話でも使用可能です。

## 列の選択

リストの上部にあるツールバーの右端にあるギアアイコンをクリックして、**列**ダイアログを開きます。列をチェックまたはチェック解除して表示または非表示にします。**リセット**は、そのリストのデフォルトの選択を復元します。

少なくとも1つの列は表示されている必要があるため、最後の列はチェック解除できません。

デフォルトの列に加えて、すべてのリストには**タグ**列があり、プライベートレコードを表示できるユーザーには、各プライベートオブジェクトのロックを表示する**プライバシー**列があります。以前にリストの列選択を変更した場合、**タグ**のような新しい列は自動的に追加されません。ダイアログでチェックしてください。

列の選択はオブジェクトタイプごとおよび家系図ごとに記憶されます。ブラウザに保存されるため、他のユーザーには表示されませんが、異なるブラウザやデバイスには引き継がれません。

## フィルタリング

**フィルター**ボタンをクリックしてフィルターパネルを開きます。フィルタリングには3つの方法があり、組み合わせることができます：

- オブジェクトタイプに依存する折りたたみ可能なセクションにある**既製のフィルター**。たとえば、人々の場合、名前、生年、死亡年、さまざまな人物のプロパティ、関連の数、タグ、およびオブジェクトがプライベートかパブリックかでフィルタリングできます。家族は父、母、または子供の名前でフィルタリングでき、ソースは著者で、場所とリポジトリはそのタイプでフィルタリングできます。
- **高度なフィルター** – 既製のフィルターでは表現できない条件を構築するためのビルダーで、[以下](#advanced-filter)に説明されています。
- **GOQL** – [Grampsオブジェクトクエリ言語](goql.md)の式用のテキストフィールドで、構文ハイライトがあります。式を入力し、Enterを押すか、**適用**をクリックします。式が無効な場合、フィールドはエラーとしてマークされます。式は他のフィルターの上に適用されます。

アクティブなフィルターはツールバーの下の行にチップとして表示されます。チップのクリアボタンをクリックして単一のフィルターを削除するか、**すべてのフィルターをクリア**を使用して一度にすべてを削除します。

### 高度なフィルター

フィルターパネルの下部にある**高度なフィルター**をクリックして条件ビルダーを開きます。その条件は、Gramps Desktopで知られているフィルタールール、たとえば「&lt;name&gt;を持つ人々」や「&lt;person&gt;の祖先」などです。

- **条件を追加**をクリックしてルールを選択します。ルールはカテゴリにグループ化されており、名前や説明で検索できます。
- ルールのパラメータを入力します。各パラメータには、日付フィールド、タグセレクター、または人物や場所のオブジェクトセレクターなど、対応する入力があります。
- グループの条件の組み合わせ方法を選択します：**すべての条件**、**いずれかの条件**、または – それらの隣のメニューを介して – **正確に1つの条件**。
- **グループを追加**をクリックして、別のグループ内に条件のグループを追加し、それらを組み合わせる方法を設定します。
- 条件またはグループの**否定**を選択して反転させます。

**適用**をクリックしてリストをフィルタリングします。

ビルダーを開いたときにアクティブな既製のフィルターとGOQL式は、条件として表示されます。GOQL式は独自の条件として追加することもでき、たとえば**いずれかの条件**で複数の式を組み合わせることができます。構築したフィルターが既製のフィルターで表現できる場合、適用後にそれらと一緒に表示されます。そうでない場合は、単一の**高度なフィルター**チップとして表示され、フィルターパネルにはビルダーを再度開くための**編集**ボタンが表示されます。

!!! note
    Gramps Desktopに保存されたカスタムフィルターを参照するルールは、ビルダーでは利用できません。ルールは、Gramps Web API 3.24以降であなたの言語で表示されます。

#### 保存されたフィルター

構築したフィルターを再利用するには、条件ビルダーで**保存**をクリックし、名前を付けます。既存の名前で保存すると、そのフィルターが置き換えられます。**保存されたフィルター**は、ビルダーで現在のオブジェクトタイプの保存されたフィルターをリストします。1つを選択するとビルダーに読み込まれ、**適用**をクリックする前に変更できます。

保存されたフィルターは、ブラウザに、家系図およびオブジェクトタイプごとに保存されるため、他のユーザーや他のデバイスでは利用できません。

保存されたフィルターは、ツリーが変更されると機能しなくなる場合があります。たとえば、削除された人物を参照している場合（そのオブジェクトセレクターは「見つかりません」と表示されます）。そのようなフィルターは、条件が修正されるまで適用または保存できません。

## オブジェクトの選択と一括操作

編集権限のあるユーザーは、フィルターボタンの隣に**選択**ボタンを見ます。それをクリックすると選択モードに入り、各行にチェックボックスが追加されます。

選択したいオブジェクトにチェックを入れると、選択された数とともに**アクション**ドロップダウンおよび**適用**ボタンを表示するツールバーが表示されます。

テーブルヘッダーのチェックボックスは、現在のページのすべてのオブジェクトを選択します。現在のフィルターに一致するオブジェクトがさらにある場合、ツールバーは**すべて選択（N）**を提供し、すべてのページにわたってNの一致するオブジェクトを選択します。行のチェックを外したり、ページやフィルターを変更したり、選択モードを終了すると、この選択は終了します。

### 削除

1つ以上のオブジェクトを選択し、**削除**を選択して**適用**をクリックします。確認ダイアログが表示され、アクションを確認するように求められ、元に戻すことができないことを警告します。

10個以上のオブジェクトを削除する場合は、バックグラウンドタスクとして実行されます。その進行状況は**適用**ボタンの横と[通知](notifications.md)に表示され、完了するとリストが再読み込みされます。

!!! tip
    削除は、他の変更と同様に[改訂履歴](revisions.md)に記録されるため、誤って一括削除した場合は、対応するトランザクションを元に戻すことで復元できます。

### タグとプライバシー

**タグを追加**、**タグを削除**、および**プライバシー**のアクションは、選択したすべてのオブジェクトを一度に変更します（Gramps Web API 3.26以降が必要）：

- **タグを追加**は、既存のタグまたはダイアログで作成した新しいタグを追加します。
- **タグを削除**は、選択したオブジェクトからそのタグを削除します。
- **プライバシー**は、選択したオブジェクトをプライベートまたはパブリックとしてマークします。これはオブジェクト自体のみを変更し、その部分やリンクされているレコードには影響しません – [プライベートレコード](privacy.md)を参照してください。

削除と同様に、10個以上のオブジェクトを編集する場合は、バックグラウンドタスクとして実行されます。変更は[改訂履歴](revisions.md)に1つのトランザクションとして記録されるため、一緒に元に戻すことができます。

### マージ

**正確に2つの**オブジェクトを選択し、**マージ**を選択して**適用**をクリックします。ダイアログが表示され、どちらのオブジェクトがマージされたオブジェクトの主要データを提供するかを尋ねます。保持したいものをクリックします。もう一方のオブジェクトのデータがそれにマージされ、参照が更新されます。

マージは、人々、家族、イベント、場所、ソース、および引用に利用可能です。リポジトリ、ノート、およびメディアオブジェクトには利用できません。

メディアビューでは、選択はギャラリーとリストレイアウトの両方で機能します：選択モードでは、タイルや行をクリックすると切り替わります。メディアオブジェクトはマージできません。

有効な選択なしでアクションを選択した場合 – たとえば、1つのオブジェクトのみが選択された状態でのマージ – ダイアログが必要な条件を説明します。
