# DNAマッチの取り扱い

DNAマッチは、2人の個体間で一致するDNAのセグメントであり、マーカー、いわゆるSNP（単一ヌクレオチド多型の略称、発音は「スニップ」）の存在によって特定されます。

このデータを取得するには、DNAセグメントマッチデータを表示できるマッチングデータベースにアップロードされたDNAテストへのアクセスが必要です（例：MyHeritage、Gedmatch、FamilytreeDNA）。Gramps Webはマッチングを自ら行うことはなく、アップロードしたデータにのみアクセスします。

## DNAマッチデータの入力

DNAマッチデータを入力するには、[編集権限](../install_setup/users.md)が必要です。データはGrampsデータベースのノートとして保存されます。メインメニューからアクセスできるDNAビューは、このデータを正しい形式で入力するための便利な方法を提供します。

新しいマッチを入力するには、右下の+ボタンをクリックします。開くダイアログで、2人の個体を選択します。「最初の人」と「2番目の人」は異なる扱いを受けることに注意してください：マッチは最初の人から2番目の人への関連として保存されます。DNAマッチビューと染色体ブラウザでは、最初の人のみが選択可能です。通常、最初の人はあなたがアクセスできるDNAテストを持つ人であり、2番目の人はより遠い親戚です。

2番目の人がデータベースに存在しない場合は、ユーザーインターフェースの右上隅にある「人物を作成」ボタンを使用して最初に作成する必要があります。人物を作成したら、DNAマッチビューに戻り、新しく作成した人物を選択できます。

次に、生データをテキストフィールドに貼り付けます。データは、通常、染色体番号、マッチの開始位置と終了位置、マッチ内のSNPの数、およびセンチモルガン（cM）単位でのマッチの長さを含む、カンマまたはタブ区切りのマッチのテーブルである必要があります。また、マッチデータを含むファイルをテキストフィールドにドラッグアンドドロップすることもできます。

そのようなテーブルの最小例は次のとおりです：

```csv
Chromosome,Start Location,End Location,Centimorgans,SNPs
6,6358001,18115715,19.6,7424
7,150135758,154205894,10.9,2816
```

形式が有効であれば、テキストフィールドの下にプレビューがテーブルとして表示されます。

最後に、「保存」ボタンをクリックして、マッチをデータベースに保存します。

## DNAマッチデータの表示

DNAマッチビューには、データベース内の関連するDNAマッチを持つ各人物を選択できるドロップダウンがあります。人物が選択されると、そのマッチがテーブルにリストされます：マッチの名前、選択された人物との関係、共有DNAの合計長さ（センチモルガンcM）、共有セグメントの数、およびこれらのセグメントの中で最も大きいものの長さ。

すでにツリーに配置されているマッチについては、関係列にツリーに記録された関係が表示されます（Grampsデータベースから自動的に決定されます）。ツリー内で選択された人物と関連していないマッチについては、共有DNAから推定された関係が「≈」でマークされて表示されます。

マッチをクリックすると、そのページが開き、共有DNAの概要、[関係の推定](#relationship-estimate)、ツリー内の関係のチャート、およびセグメントのリストが表示されます。各セグメントは、父系または母系のどちらにあるかが示されます。側面は手動で入力することもできます（生データの「Side」という列に父系の場合は`P`、母系の場合は`M`を提供する）し、最近の共通の祖先から自動的に決定することもできます。セグメントの隣にあるダウンロードボタンは、それらをマッチダイアログが受け入れる形式のCSVファイルとして保存します。

## 関係の推定

共有DNAは特定の関係の証明ではありません：2人の親戚が共有するDNAの量は大きく異なり、異なる関係が重なり合います。したがって、Gramps Webは、共有セグメントの数と長さから計算された確率を伴う可能性のある関係の範囲を表示します（Gramps Web API 3.26以降が必要です）。

関係はその*度数*によってグループ化されます：

- **親または子**および**全兄弟**はそれぞれ独自に表示されます。
- **2度の親戚**には、異母兄弟、祖父母および孫、叔父、叔母、姪、甥が含まれます。
- **3度の親戚**には、いとこ、曾祖父母、曾おば、曾おじ、異母おば、異母おじが含まれます。
- 各さらなる度数は、約1世代離れています。例えば、いとこの一度の除去は4度、二度のいとこは5度です。9度以上は「9+」としてグループ化されます。

同じ度数の関係は、平均してほぼ同じ量のDNAを共有するため、DNAだけでは区別できません。人々の年齢を使用して区別してください – 60歳の2度の親戚の30歳は、祖父母よりもむしろ姪である可能性が高いです。

この推定は、近い親戚に対して最も信頼性があります。遠い関係の場合、マッチは少数のセグメントしか共有せず、確率は複数の度数に分散します。

### DNAに対するツリーの確認

マッチがツリーに配置されている場合、Gramps Webは共有DNAがそこに記録された関係に適合するかどうかを確認します。その関係に対してDNAが非常にあり得ない場合、マッチテーブルに警告アイコンが表示され、マッチページに警告が表示されます。括弧内の数値（例：「1 : 500」）は、記録された関係に対するDNAの可能性と、最も可能性の高い関係に対するDNAの可能性を比較します。

警告は、より注意深く見る理由であり、エラーの証明ではありません。一般的な原因は次のとおりです：

- ツリー内の間違い（例：親の誤り）
- 親の誤認（例：未知の養子縁組や異なる生物学的父親）
- 不完全なマッチデータ（例：テストサービスから高い閾値を超えるセグメントのみがコピーされた場合）
- 複数の系統を通じた関係（例：母親と父親の両方を通じて関連する人々（「系譜の崩壊」）は、予想以上に多くのDNAを共有します）。

養子縁組などの出生によらない関係は、チェックされません。

## マッチの編集

マッチを編集するには、そのページを開き、編集ボタンをクリックするか、`e`を押します。生データを変更することはできますが、マッチに関連付けられた個体を変更することはできません – 個体を変更したい場合は、マッチを削除して新しいものを作成する必要があります。

## プライベートマッチ

マッチの追加および編集のダイアログには、**プライベート**スイッチがあります。プライベートマッチは、そのセグメントを含め、プライベートレコードを表示できないユーザーから隠されます。プライベートマッチは、他のすべての人に対してロックでマークされます。プライバシーについての詳細は、[プライベートレコード](privacy.md)を参照してください。

## Gramps Desktopでのマッチデータの取り扱い

DNAマッチデータは、Grampsデータベースのノートとして保存されます。この形式は、[DNAセグメントマップアドオン](https://gramps-project.org/wiki/index.php/Addon:DNASegmentMapGramplet)と互換性があります。Gramps Desktop用のアドオンです。そのWikiページには、データを取得する方法、解釈する方法、およびGrampsにデータを入力する方法についての詳細が含まれています。

!!! info
    Gramps Web API v2.8.0は、より広範な生DNAマッチデータを受け入れるためのいくつかの変更を導入しましたが、これはまだGramps Desktopアドオンでは利用できません。Gramps Desktopアドオンは、将来的に同じ形式をサポートするように更新される予定です。
