# Grampsがデータを整理する方法

Gramps Webは、家系図をチャートとしてではなく、互いにリンクされた別々のオブジェクト（人、家族、イベント、場所、ソースなど）として保存します。これらのオブジェクトがどのように組み合わさるかを理解すると、データの入力が予測可能になります：リンクしたいものは最初に存在している必要があります。

Gramps WebはGramps Desktopと同じデータモデルを使用しているため、このページのすべての内容は両方に適用されます。

## 基本要素

| オブジェクト | 表すもの | 例 |
|---|---|---|
| 人 | 個人 | あなた、あなたの祖母 |
| 家族 | カップル、その子供、またはその両方 | あなたの両親とその子供たち |
| イベント | 発生した事象、日付と場所を伴う | 出生、結婚、国勢調査、移民 |
| 場所 | 地理的な位置 | 村、教区、国 |
| ソース | 情報の文書またはコレクション | 教区登録簿、国勢調査、書籍 |
| 引用 | ソース内の特定の参照 | 教区登録簿のページ12、エントリー3 |
| リポジトリ | ソースが保管されている場所 | アーカイブ、図書館、ウェブサイト |
| ノート | 自由なテキスト | 転写、研究のメモ |
| メディアオブジェクト | ファイル | 写真、スキャンした証明書 |

すべてのオブジェクトタイプにはGramps Web内に独自のリストがあります。詳細は[リスト](lists.md)を参照してください。

## 人と家族

親と子供は直接リンクされているのではなく、**家族**を通じてリンクされています。家族は最大2人のパートナーと任意の数の子供を持つことができます：

- あなたの両親とあなたは、あなたが子供である家族を通じてリンクされています。
- あなたの兄弟姉妹は同じ家族の他の子供です。
- あなたとあなたの配偶者は別の家族を形成し、あなたがパートナーであり、子供たちと共に存在します。

1人の人は1つの家族の子供であり、複数の家族のパートナーでもあります。各子供はそれぞれの親に対して出生、養子縁組、または継子などの関係を持ち、各家族には結婚や市民連合などの関係タイプがあります。

このため、「親を追加する」ということは、その人を家族の子供として追加することを意味します。これは[ツリーチャート](tree-edit.md)が1ステップで行います。

## イベント

出生、死亡、または結婚は人のフィールドではなく、それ自体が**イベント**であり、タイプ、日付、場所、説明を持ちます。人々は**役割**を持ってイベントにリンクされています：出生の役割を持つ人は「主要」として、他の誰かは同じイベントに証人としてリンクされることがあります。

結婚などのカップルに関するイベントは、どちらのパートナーではなく家族に属します。イベントは複数の人によって共有されることもあります。たとえば、世帯全体をリストした国勢調査記録などです。

## 共有オブジェクト：場所とソース

場所、ソース、引用、リポジトリ、ノート、メディアオブジェクトはそれ自体で存在し、任意の数の他のオブジェクトが同じものを参照できます。これにはいくつかの結果があります：

- **一度作成し、何度も選択する。** あなたの祖先の10人が生まれた村は1つの場所であり、10の出生イベントで選択されます。名前や座標を修正すると、その修正はすべての場所に適用されます。
- **選択する前に作成する。** Gramps Webのフォームは、すでに存在する場所やソースを選択します。最初に**+**（追加）ボタンを使用して新しい場所やソースを作成します。
- **場所はネストされています。** 場所はより大きな場所に囲まれることがあります。たとえば、村は郡に、郡は国に囲まれるため、すべての村に対して階層全体を繰り返す必要はありません。
- **ソースと引用は別々です。** ソースは教区登録簿全体であり、引用は事実を支持する特定のエントリーで、そのページ、日付、あなたの信頼度を含みます。多くの引用が同じソースを指すことができます。

誤って同じ場所やソースを2回作成した場合は、[重複をマージする](lists.md#merge)ことができます。

## オブジェクトのページを編集する

ソース、リポジトリ、またはメディアオブジェクトのページで、編集モードでタイトルをクリックして変更します（メディアオブジェクトの場合は、その説明）。Enterを押すか、✓をクリックするか、他の場所をクリックして保存します。Escapeを押すか、✕をクリックしてキャンセルします。

オブジェクトのページのほとんどのリストは、あなたが与えた順序を保持します。たとえば、イベント、名前、属性、住所、引用、または家族の子供たちです。編集モードでは、行を選択し、上下ボタンで移動するか、ドラッグして新しい位置に移動します：マウスを使う場合は、行を押して移動し、タッチスクリーンでは、行を押し続けて持ち上げます。ドラッグ中にEscapeを押すとキャンセルされます。ギャラリー内のメディアも同様に再配置できます。詳細は[プロフィール写真](media.md#profile-pictures)を参照してください。

## ホームパーソン

ホームパーソンは、家系図が始まる人物であり、レポートのデフォルトの出発点です。設定方法については[初回ログイン](first-login.md)を参照してください。

!!! note "Gramps Desktopとは異なる"
    Gramps Desktopでは、ホームパーソンは家系図データベースに保存されるため、そのデータベースを開くすべての人にとって同じです。Gramps Webはこれを使用していません。代わりに、ホームパーソンはブラウザに保存され、各ツリーごとに別々です：他のユーザーと共有されず、別のブラウザやデバイスに移動することはありません。Gramps Desktopからツリーをインポートした後や、別のデバイスでGramps Webを使用する際には、再設定が必要です。

## 推奨される順序

新しい家族を手動で入力する際、この順序はフォーム間を行き来することを避けます：

1. **場所とソース。** 必要な場所を作成し、ソースを記録する場合は、作業中のソースを作成します。
2. **人。** 出生および死亡の日付と場所を持つ人を追加します。これは、家系図チャートの編集モードで最も早く行えます。これにより、家族が自動的に作成されます。詳細は[新しいツリーを開始する](start-tree.md)および[家系図の編集](tree-edit.md)を参照してください。
3. **さらなるイベント。** 家族を開いて（たとえば、人物の関係タブから）結婚を追加し、人物のページを開いて他のイベントを追加します。
4. **引用。** ソースが支持する人物、イベント、または他のオブジェクトのソース引用タブで新しい引用を追加し、ソースを選択してページを入力します。
5. **ノートとメディア。** 転写、写真、スキャンを添付します。詳細は[メディアファイルを追加](media.md)を参照してください。

## 日付の入力

日付は年、月、日を別々のフィールドとして入力され、日付ピッカーを使用しても入力できます。知らない部分は省略してください：年だけでも有効な日付です。
正確な日を推測する代わりに、フィールドの上にあるチップを使用して日付のタイプを選択することで、実際に知っていることを説明します。チップの下に選択されたタイプのヒントが表示されます：

| あなたが知っていること | タイプ | 例 |
|---|---|---|
| 正確な日付、またはその一部 | 通常 | 1850年3月12日、または1850年だけ |
| おおよその日付 | 約 | 約1850年 |
| 制限 | 前、後 | 1900年以前 |
| 日付が期間内のどこかにある | 範囲 | 1850年から1855年の間（「最も早い」と「最も遅い」フィールド） |
| 何かが期間にわたって続いた | スパン | 1850年から1855年まで |

スパンの場合、2つの日付（「から」と「まで」のいずれか）を空白のままにすることができるため、「1850年から」または「1855年まで」は1つの日付だけのスパンになります。

**品質**および**カレンダー**フィールドは**その他のオプション**の下にあり、日付がそれらのいずれかを使用する場合に自動的に開きます。品質は、日付に到達する方法を記録します：推測による「推定」、他の情報から導き出された日付（たとえば、死亡時の年齢から計算された出生年）による「計算済み」です。

!!! warning "約および推定日付は前後50年をカバーします"
    Grampsが日付を比較する際、「約」というタイプの日付と「推定」という品質のある日付は、与えられた日付の50年前から50年後までの範囲として扱われます。たとえば、1840年から1860年の間に生まれた人々のリストをフィルタリングすると、「約1880年」に生まれた人も見つかります。この日付は1830年から1930年をカバーすると見なされます。同様に、「前」と「後」は、日付の50年前または50年後までをカバーすると見なされます。

    これは驚くべき結果をもたらす可能性があるため、日付を絞り込めない場合にのみ「約」や「推定」を使用してください。より短い期間がわかっている場合は、「1878年から1882年の間」のような範囲がより正確です。

カレンダーを使用すると、元の記録で使用されたカレンダー（ユリウス暦など）で日付を入力でき、自分で変換する必要はありません。
