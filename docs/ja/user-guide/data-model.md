# Grampsがデータを整理する方法

Gramps Webは、家系図をチャートとしてではなく、個々のオブジェクト – 人、家族、イベント、場所、ソースなど – として保存し、それらが互いにリンクされています。これらのオブジェクトがどのように組み合わさるかを理解すれば、データの入力は予測可能になります：リンクしたいものは最初に存在している必要があります。

Gramps WebはGramps Desktopと同じデータモデルを使用しているため、このページのすべての内容は両方に適用されます。

## 基本要素

| オブジェクト | 表すもの | 例 |
|---|---|---|
| 人 | 個人 | あなた、あなたの祖母 |
| 家族 | カップル、彼らの子供、またはその両方 | あなたの両親と彼らの子供 |
| イベント | 発生した事象、日付と場所を伴う | 誕生、結婚、国勢調査、移民 |
| 場所 | 地理的な位置 | 村、教区、国 |
| ソース | 情報の文書またはコレクション | 教区の登録簿、国勢調査、書籍 |
| 引用 | ソース内の特定の参照 | 教区の登録簿のページ12、エントリー3 |
| リポジトリ | ソースが保管されている場所 | アーカイブ、図書館、ウェブサイト |
| ノート | 自由なテキスト | 転写、研究のメモ |
| メディアオブジェクト | ファイル | 写真、スキャンした証明書 |

すべてのオブジェクトタイプはGramps Web内に独自のリストを持っています。詳細は[リスト](lists.md)を参照してください。

## 人と家族

親と子供は直接リンクされているのではなく、**家族**を通じてリンクされています。家族は最大2人のパートナーと任意の数の子供を持つことができます：

- あなたの両親とあなたは、あなたが子供である家族を通じてリンクされています。
- あなたの兄弟姉妹は同じ家族の他の子供です。
- あなたとあなたの配偶者は別の家族を形成し、あなたはその家族のパートナーであり、子供たちと共に存在します。

1人の人は1つの家族の子供であり、複数の家族のパートナーであることができます。各子供はそれぞれの親に対して、出生、養子、または継子などの関係を持ち、各家族には結婚や市民連合などの関係タイプがあります。

これが、「親を追加する」ということが、人物を家族に子供として追加することを意味する理由です – これは[ツリーチャート](tree-edit.md)があなたのために1ステップで行います。

## イベント

誕生、死亡、または結婚は人のフィールドではなく、独自の**イベント**であり、タイプ、日付、場所、説明を持ちます。人々は**役割**を持ってイベントにリンクされています：誕生の人は「主役」という役割を持ち、他の誰かが同じイベントに証人としてリンクされることがあります。

カップルに関するイベント（結婚など）は、どちらのパートナーにも属さず、家族に属します。イベントは複数の人によって共有されることもあります – たとえば、世帯全体をリストした国勢調査の記録などです – 人ごとに1回入力されるのではなく。

これは編集に影響します。イベント自体 – そのタイプ、日付、場所、説明 – は、リンクされているすべての人にとって同じであるため、1人のページから共有イベントを編集すると、すべての人に対して変更されます。そのため、編集ダイアログでは他の参加者が最初にリストされ、フィールドは**全員のために編集**を選択した後にのみ編集可能になります。イベントへの1人のリンクに属するもの – 役割、引用、ノート、そしてその人にのみ適用される属性 – は、イベントのページの**参加者**タブで編集されます。そこで参加者を追加または削除することもできます。たとえば、代父母の役割や「印で署名された」というノートは、洗礼に対する代父母のリンクに属し、洗礼自体には属しません。

## 共有オブジェクト：場所とソース

場所、ソース、引用、リポジトリ、ノート、メディアオブジェクトはそれぞれ独立して存在し、他の任意の数のオブジェクトが同じものを参照できます。これにはいくつかの結果があります：

- **一度作成し、何度も選択する。** あなたの10人の先祖が生まれた村は1つの場所であり、10の出生イベントで選択されます。名前や座標を修正すると、その修正はすべての場所に適用されます。
- **選択する前に作成する。** Gramps Webのフォームは、すでに存在する場所やソースを選択します。最初に**+**（追加）ボタンを使用して新しい場所またはソースを作成してください。
- **場所はネストされています。** 場所はより大きな場所に含まれることがあります – 村は郡に、郡は国に – そのため、すべての村のために全階層を繰り返す必要はありません。
- **ソースと引用は別々です。** ソースは教区登録簿全体であり、引用は事実を支持する特定のエントリーで、そのページ、日付、あなたの信頼度を含みます。多くの引用が同じソースを指すことができます。

もし誤って同じ場所やソースを2回作成してしまった場合は、[重複をマージする](lists.md#merge)ことができます。

## オブジェクトのページを編集する

ソース、リポジトリ、またはメディアオブジェクトのページでは、編集モードでタイトルをクリックして変更します（メディアオブジェクトの場合は、その説明）。Enterを押すか、✓をクリックするか、他の場所をクリックして保存します；Escapeを押すか、✕をクリックしてキャンセルします。

オブジェクトのページのほとんどのリストは、あなたが与えた順序を保持します。たとえば、イベント、名前、属性、住所、引用、または家族の子供などです。編集モードでは、行を選択し、上下ボタンで移動するか、ドラッグして新しい位置に移動します：マウスを使って行を押し、移動させます；タッチスクリーンでは、行を押し続けて持ち上げます。ドラッグ中にEscapeを押すとキャンセルされます。ギャラリー内のメディアも同様に再配置できます。詳細は[プロフィール写真](media.md#profile-pictures)を参照してください。

## ホームパーソン

ホームパーソンは、家系図が始まる人物であり、レポートのデフォルトの出発点です。設定方法については[初回ログイン](first-login.md)を参照してください。

!!! note "Gramps Desktopとは異なる"
    Gramps Desktopでは、ホームパーソンは家系図データベースに保存されるため、そのデータベースを開くすべての人にとって同じです。Gramps Webではこれを使用しません。代わりに、ホームパーソンはあなたのブラウザに保存され、各ツリーごとに別々です：他のユーザーと共有されず、別のブラウザやデバイスに移動することはありません。Gramps Desktopからツリーをインポートした後や、別のデバイスでGramps Webを使用する場合は、再度設定する必要があります。

## 推奨される順序

新しい家族を手動で入力する際、この順序はフォーム間を行き来することを避けます：

1. **場所とソース。** 必要な場所を作成し、ソースを記録する場合は、作業中のソースを作成します。
2. **人々。** 生年月日と死亡日、場所を持つ人々を追加します。これは、家系図チャートの編集モードで最も早く行えます。家族を自動的に作成します – [新しいツリーを開始](start-tree.md)と[家系図の編集](tree-edit.md)を参照してください。
3. **さらなるイベント。** 家族を開いて（たとえば、人物の関係タブから）結婚を追加し、人物のページを開いて他のイベントを追加します。
4. **引用。** ソースがサポートする人物、イベント、または他のオブジェクトのソース引用タブで、新しい引用を追加し、ソースを選択してページを入力します。
5. **ノートとメディア。** 転写、写真、スキャンを添付します – [メディアファイルを追加](media.md)を参照してください。

## 日付の入力

日付は、年、月、日を別々のフィールドとして入力され、日付ピッカーを使用しても入力できます。知らない部分は省略してください：年だけでも有効な日付です。
正確な日を推測する代わりに、フィールドの上にあるチップを使って日付のタイプを選択することで、実際に知っていることを説明します。チップの下にあるヒントが選択したタイプを説明します：

| 知っていること | タイプ | 例 |
|---|---|---|
| 正確な日付、またはその一部 | 通常 | 1850年3月12日、または1850年だけ |
| おおよその日付 | 約 | 約1850年 |
| 限界 | 前、後 | 1900年以前 |
| 日付が期間内のどこかにある | 範囲 | 1850年から1855年の間（「最も早い」と「最も遅い」フィールド） |
| 何かが期間にわたって続いた | スパン | 1850年から1855年まで |

スパンの場合、2つの日付のいずれか（「から」と「まで」）は空白のままにすることができるため、「1850年から」または「1855年まで」は1つの日付だけのスパンになります。

**品質**および**カレンダー**フィールドは**詳細オプション**の下にあり、日付がそれらのいずれかを使用する場合は自動的に開きます。品質は、日付に到達する方法を記録します：「推定」は推測によるもので、「計算」は他の情報から導き出された日付、たとえば死亡時の年齢から計算された出生年などです。

!!! warning "約と推定の日付は前後50年をカバーします"
    Grampsが日付を比較する際、「約」というタイプの日付 – および品質が「推定」の日付 – は、指定された日付の50年前から50年後までの範囲として扱います。たとえば、1840年から1860年の間に生まれた人々をPeopleリストでフィルタリングすると、「約1880年」に生まれた人も見つかります。なぜなら、その日付は1830年から1930年までカバーされると見なされるからです。同様に、「前」と「後」は、日付の50年前または50年後までの範囲を持つと見なされます。

    これは驚くべき結果をもたらす可能性があるため、「約」と「推定」は日付を絞り込むことができない場合にのみ使用してください。より短い期間がわかっている場合は、「1878年から1882年の間」のような範囲がより正確です。

カレンダーを使用すると、元の記録で使用されたカレンダー（たとえば、ユリウス暦）で日付を入力でき、あなた自身で変換する必要はありません。
