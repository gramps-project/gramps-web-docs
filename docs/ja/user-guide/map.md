# マップ

マップページは、家系図内のすべての場所を地理的マップ上のインタラクティブなマーカーとして表示します。サイドバーからアクセスできます。

## 場所マーカー

GPS座標がGrampsデータベースに保存されている場所のみがマップに表示されます。座標のない場所は静かに省略されます。GPS座標は、場所の詳細ページで設定できます（場所を編集し、緯度と経度のフィールドに入力します）。

!!! tip
    マップに多くの場所が表示されていない場合は、場所の詳細ページを開いて、緯度と経度が設定されているか確認してください。場所の編集ビューから直接座標を追加または修正できます。

座標のある各場所はマーカーとして表示されます。マーカーをクリックすると、場所の名前と関連するイベントや人物を示すサマリーカードが開きます。カード内の場所の名前をクリックすると、完全な場所の詳細ページが開きます。

## 検索

マップの左上隅にある検索ボックスは、入力するにつれて検索を行い、結果を3つの見出しの下にグループ化します：

- **場所** – あなたの家系図にある場所。1つを選択すると、マップがその場所にパンし、マーカーがハイライトされます。
- **人物** – あなたの家系図にある人物。1つを選択すると、[以下](#following-a-person-across-the-map)で説明されている人物ビューにマップが切り替わります。
- **外部** – [OpenStreetMap](https://www.openstreetmap.org/)からの世界中の場所。1つを選択すると、その場所にマップがパンし、ズームされます。家系図の場所をフィルタリングしたり変更したりすることはありません。

外部の結果は、場所に座標を追加する際にも便利です：ここで場所を調べて、緯度と経度を入力する前にその位置を確認できます。

## マップ上での人物の追跡

人物を選択すると – マップの検索ボックスから、または人物の詳細ページの**マップで開く**ボタンを使用して – その人物のイベントに関連する場所が時系列で線で結ばれて表示されます。各線に沿った小さな矢印は移動の方向を示しており、マップ上で人物の生涯を出生から死亡まで追跡できます。

場所の詳細ページにも**マップで開く**ボタンがあり、その場所を中心にマップが開きます。

## タイムスライダー

ページの下部にあるタイムスライダーは、関連するイベントの年に基づいて表示される場所マーカーをフィルタリングします：

- ハンドルをドラッグして年を選択します。
- 選択した時間ウィンドウ内にあるイベントにリンクされた場所のみが表示されます。
- これを使用して、特定の歴史的な時点であなたの先祖が住んでいた場所を追跡します。

## マップレイヤー

レイヤースイッチャーボタン（スタックされたレイヤーのアイコン、左下）を使用して、2つのベースマップの間で選択できます：

### ベースマップ

デフォルトのレイヤーで、[OpenFreeMap](https://openfreemap.org)（ライトモード用のリバティスタイル、ダークモード用のダークスタイル）によって提供されます。これは、場所を特定するのに適した現代的な汎用マップです。

### 歴史的マップ

ベースマップを[OpenHistoricalMap](https://www.openhistoricalmap.org)（OHM）に切り替えます。これは、異なる時点での世界をマッピングするコミュニティ主導のプロジェクトです – OpenStreetMapの歴史的な対比と考えてください。

歴史的マップレイヤーがアクティブなとき、タイムスライダーはマップタイル自体もフィルタリングします：OHMは選択した年に表示されたマップをレンダリングするため、歴史的な境界、場所名、特徴が現代のものの代わりに表示されます。これにより、先祖の位置と現代の地理的および政治的文脈を1つのビューで見ることができます。

!!! note
    OpenHistoricalMapのカバレッジは地域や時代によって異なります。貢献が少ない地域や時代では、限られた歴史的詳細が表示されることがあります。欠落または不正確な歴史データに気付いた場合は、[OpenHistoricalMapに貢献することを検討してください](https://www.openhistoricalmap.org) – 誰でも編集できるオープンなコミュニティプロジェクトです。

## カスタムマップオーバーレイ

組み込みのベースレイヤーに加えて、Grampsに**メディア**オブジェクトとして保存された任意のスキャンされた歴史的マップ画像を、ライブマップ上に位置付けられたカスタムオーバーレイに変えることができます。これは、古い都市計画、教区マップ、または現代または歴史的な地理と直接比較したい不動産マップのスキャンに便利です。

### 画像の地理参照

1. スキャンされたマップ画像のメディアオブジェクトを開き、編集モードに切り替えます。
2. "マップ"タブを開き、**座標を編集**をクリックします。これにより、画像とマップが並んで表示される地理参照ダイアログが開きます。
3. **マップ上のポイントを選択**をクリックし、画像のポイントが対応するマップ上の位置をクリックします。ポイントが選択されると、画像が初めてマップ上に配置されます。
4. **スケール**スライダーを使用して画像のサイズを変更し、**不透明度**スライダーを使用して位置決め中にベースマップを透かして見ることができます。
5. **画像を整列**をクリックし、マップ上で再度クリックして、ピン留めされたポイントが正確に一致するように画像を移動します。
6. 画像が基盤となる地理に一致するまで、スケール、不透明度、整列のステップを繰り返し、その後保存します。

裏側では、これにより画像のコーナー座標がメディアオブジェクトの`map:bounds`属性に保存されます。

### マップページでのオーバーレイの表示

このように地理参照されたメディアオブジェクトは、自動的にマップページでトグル可能なレイヤーとして利用可能になります。レイヤースイッチャー（スタックされたレイヤーのアイコン、左下）を開いて、ベースマップとは独立して各オーバーレイを表示または非表示にします。オーバーレイはメディアオブジェクトのタイトルでリストされます。
