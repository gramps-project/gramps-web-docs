# マップ

マップページは、家系図内のすべての場所を地理的な地図上にインタラクティブなマーカーとして表示します。サイドバーからアクセスできます。

## 場所のマーカー

GPS座標がGrampsデータベースに保存されている場所のみが地図に表示されます。座標のない場所は静かに省略されます。GPS座標は、場所の詳細ページで設定できます（場所を編集し、緯度と経度のフィールドに入力します）。

!!! tip
    多くの場所が地図に表示されていない場合は、場所の詳細ページを開いて緯度と経度が設定されているか確認してください。場所の編集ビューから直接座標を追加または修正できます。

座標のある各場所はマーカーとして表示されます。マーカーをクリックすると、その場所の名前と関連するイベントや人物を示すサマリーカードが開きます。カード内の場所の名前をクリックすると、完全な場所の詳細ページが開きます。

## 検索

地図の左上隅にある検索ボックスを使用すると、名前で世界の任意の場所にジャンプできます。これはツリーの場所をフィルタリングするものではなく、単に地図を検索した場所にパンおよびズームします。

## 時間スライダー

ページの下部にある時間スライダーは、関連するイベントの年に基づいて表示される場所のマーカーをフィルタリングします：

- ハンドルをドラッグして年を選択します。
- 選択した時間ウィンドウ内にあるイベントにリンクされた場所のみが表示されます。
- これを使用して、特定の歴史的な時点での先祖の居住地を追跡できます。

## マップレイヤー

レイヤースイッチャーボタン（スタックされたレイヤーのアイコン、左下）を使用すると、2つのベースマップの間で選択できます：

### ベースマップ

デフォルトのレイヤーで、[OpenFreeMap](https://openfreemap.org)（ライトモード用のLibertyスタイル、ダークモード用のダークスタイル）によって提供されています。これは、場所を特定するのに適した現代的な汎用地図です。

### 歴史的マップ

ベースマップを[OpenHistoricalMap](https://www.openhistoricalmap.org)（OHM）に切り替えます。これは、異なる時点での世界をマッピングするコミュニティ主導のプロジェクトで、OpenStreetMapの歴史的な対応物と考えてください。

歴史的マップレイヤーがアクティブな場合、時間スライダーは地図タイル自体もフィルタリングします：OHMは選択した年に見られた地図をレンダリングするため、歴史的な境界、場所の名前、および特徴が現代のものの代わりに表示されます。これにより、先祖の居住地と現代の地理的および政治的文脈を一つのビューで見ることができます。

!!! note
    OpenHistoricalMapのカバレッジは地域や時代によって異なります。貢献が少ない地域や時代では、歴史的な詳細が限られている場合があります。欠落しているまたは不正確な歴史データに気付いた場合は、[OpenHistoricalMapに貢献する](https://www.openhistoricalmap.org)ことを検討してください。これは誰でも編集できるオープンなコミュニティプロジェクトです。

## カスタムマップオーバーレイ

組み込みのベースレイヤーに加えて、Grampsに**メディア**オブジェクトとして保存されている任意のスキャンされた歴史的地図画像を、ライブマップ上に配置されたカスタムオーバーレイに変えることができます。これは、古い都市計画、教区地図、または現代または歴史的地理と直接比較したい不動産地図のスキャンに便利です。

### 画像の地理参照

1. スキャンされた地図画像のメディアオブジェクトを開き、編集モードに切り替えます。
2. 「マップ」タブを開き、**座標を編集**をクリックします。これにより、画像と地図が並んだ地理参照ダイアログが開きます。
3. **地図上のポイントを選択**をクリックし、画像のポイントが対応する地図上の位置をクリックします。ポイントが選択されると、画像は初めて地図に配置されます。
4. **スケール**スライダーを使用して画像のサイズを変更し、**不透明度**スライダーを使用して位置決め中にベースマップを透かして見ることができます。
5. **画像を整列**をクリックし、再度地図をクリックして、ピン留めされたポイントが正確に一致するように画像を移動させます。
6. 画像が基盤となる地理に一致するまで、スケール、不透明度、整列のステップを繰り返し、保存します。

裏では、これにより画像のコーナー座標がメディアオブジェクトの`map:bounds`属性に保存されます。

### マップページでのオーバーレイの表示

この方法で地理参照されたメディアオブジェクトは、自動的にマップページで切り替え可能なレイヤーとして利用できるようになります。レイヤースイッチャー（スタックされたレイヤーのアイコン、左下）を開いて、ベースマップとは独立して各オーバーレイを表示または非表示にできます。オーバーレイはメディアオブジェクトのタイトルでリスト表示されます。
