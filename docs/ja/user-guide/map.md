# 地図

地図ページは、家系図内のすべての場所を地理的地図上のインタラクティブなマーカーとして表示します。サイドバーからアクセスできます。

## 場所のマーカー

GPS座標がGrampsデータベースに保存されている場所のみが地図に表示されます。座標がない場所は静かに省略されます。GPS座標は場所の詳細ページで設定できます（場所を編集し、緯度と経度のフィールドに入力します）。

!!! tip
    地図に多くの場所が表示されていない場合は、場所の詳細ページを開いて緯度と経度が設定されているか確認してください。場所の編集ビューから直接座標を追加または修正できます。

座標のある各場所はマーカーとして表示されます。マーカーをクリックすると、場所の名前とその関連イベントや人物を示すサマリーカードが開きます。カード内の場所の名前をクリックすると、フルの場所詳細ページが開きます。

## 検索

地図の左上隅にある検索ボックスは、入力する際に検索を行い、結果を3つの見出しの下にグループ化します：

- **場所** – あなたの家系図にある場所。1つを選択すると、地図がその場所にパンし、マーカーがハイライトされます。
- **人物** – あなたの家系図にある人物。1つを選択すると、地図が[以下](#following-a-person-across-the-map)に説明されている人物ビューに切り替わります。
- **外部** – 世界中の[OpenStreetMap](https://www.openstreetmap.org/)からの場所。1つを選択すると、単に地図がその場所にパンし、ズームインします。家系図の場所をフィルタリングしたり変更したりすることはありません。

外部の結果は、場所に座標を追加する際にも便利です：ここで場所を調べて、緯度と経度を入力する前にその位置を確認できます。

## 地図上での人物の追跡

人物を選択すると – 地図の検索ボックスから、または人物の詳細ページの**地図で開く**ボタンを使用して – その人物のイベントに関連する場所が、時系列順に線で結ばれて表示されます。各線に沿った小さな矢印は移動の方向を示しているため、地図上で人物の生涯を出生から死亡まで追跡できます。

場所の詳細ページにも**地図で開く**ボタンがあり、その場所を中心に地図を開きます。

## 時間スライダー

ページの下部にある時間スライダーは、関連するイベントの年に基づいて表示される場所のマーカーをフィルタリングします：

- ハンドルをドラッグして年を選択します。
- 選択した時間ウィンドウ内にあるイベントにリンクされた場所のみが表示されます。
- これを使用して、特定の歴史的な時点で先祖が住んでいた場所を追跡します。

## 地図レイヤー

レイヤースイッチャーボタン（スタックされたレイヤーアイコン、左下）を使用すると、2つのベースマップの間で選択できます。その下には、「あなたの地図」として自分の地図レイヤーがリストされており（[カスタムマップオーバーレイ](#custom-map-overlays)と[場所のマップファイル](#map-files-of-places)を参照）、外部の[Wikidata建物](#wikidata-buildings)レイヤーが表示され、これらはオンオフ切り替え可能です。

両方のベースマップのラベルは、Gramps Webで選択した言語で表示され、地図データにその言語の名前がある場合はその言語で、そうでない場合は現地名で表示されます。

### ベースマップ

デフォルトのレイヤーで、[OpenFreeMap](https://openfreemap.org)（ライトモード用のリバティスタイル、ダークモード用のダークスタイル）によって提供されています。これは、場所を特定するのに適した現代的な汎用地図です。

### 歴史的地図

ベースマップを[OpenHistoricalMap](https://www.openhistoricalmap.org)（OHM）に切り替えます。これは、異なる時点での世界をマッピングするコミュニティ主導のプロジェクトで、OpenStreetMapの歴史的な対応物と考えることができます。

歴史的地図レイヤーがアクティブなとき、時間スライダーは地図タイル自体もフィルタリングします：OHMは選択した年に見えた地図をレンダリングするため、歴史的な境界、場所名、特徴が現代のものの代わりに表示されます。これにより、先祖の位置と現代の地理的および政治的文脈を1つのビューで確認できます。

!!! note
    OpenHistoricalMapのカバレッジは地域や時代によって異なります。貢献が少ない地域や時代では、歴史的な詳細が限られている場合があります。欠落または不正確な歴史データに気付いた場合は、[OpenHistoricalMapに貢献する](https://www.openhistoricalmap.org)ことを検討してください – 誰でも編集できるオープンなコミュニティプロジェクトです。

## カスタムマップオーバーレイ

組み込みのベースレイヤーに加えて、スキャンした歴史的地図画像をGrampsに**メディア**オブジェクトとして保存し、ライブマップ上にカスタムオーバーレイとして配置することができます。これは、古い都市計画、教区地図、またはプロパティマップのスキャンを現代または歴史的な地理と直接比較したい場合に便利です。

### 画像の地理参照

1. スキャンした地図画像のメディアオブジェクトを開き、編集モードに切り替えます。
2. 「地図」タブを開き、**座標を編集**をクリックします。これにより、画像と地図が並んで表示される地理参照ダイアログが開きます。
3. **地図上のポイントを選択**をクリックし、画像のポイントが対応する地図上の位置をクリックします。ポイントが選択されると、画像は初めて地図上に配置されます。
4. **スケール**スライダーを使用して画像のサイズを変更し、**不透明度**スライダーを使用して配置中にベースマップを透かして見ることができます。
5. **画像を整列**をクリックし、再度地図をクリックして、ピン留めされたポイントが正確に一致するように画像を移動します。
6. 画像が基盤となる地理に一致するまで、スケール、不透明度、整列のステップを繰り返し、保存します。

裏では、これにより画像のコーナー座標がメディアオブジェクトの`map:bounds`属性に保存されます。

### 地図ページでのオーバーレイの表示

この方法で地理参照されたメディアオブジェクトは、自動的に地図ページでトグル可能なレイヤーとして利用可能になります。レイヤースイッチャー（スタックされたレイヤーアイコン、左下）を開いて、ベースマップとは独立して各オーバーレイを表示または非表示にできます。オーバーレイはメディアオブジェクトのタイトルでリストされます。

## 場所のマップファイル

場所には、メディアオブジェクトとしてマップファイルを添付できます – 例えば、教区、地区、または不動産の境界、またはルートなどです。サポートされているファイル形式はKML（`.kml`）、GeoJSON（`.geojson`）、およびGPX（`.gpx`）です。

地図上で場所を選択すると、そのマップファイルが地図の上に描画され、ファイルに保存されている色が使用されます。座標のない場所でもこれが機能します：その場合、地図はファイルがカバーするエリアにズームインします。場所が選択されている間、そのファイルは「あなたの地図」の下にレイヤースイッチャーにリストされ、各ファイルをオフにすることができます。

場所にマップファイルを追加するには、他の[メディアファイル](media.md)と同様に、その場所のギャラリーに追加します。

## Wikidata建物

「Wikidata建物」レイヤーは、[Wikidata](https://www.wikidata.org/)に記録された建物を表示します。教会、農場、町の家などが含まれます。デフォルトではオフになっており、レイヤースイッチャーの「外部」でオンにできます。地図が十分にズームインされているときのみ、建物が表示されます。時間スライダーがアクティブな場合、選択した時点で存在した建物のみが表示されます。

建物をクリックすると、Wikidataからその詳細（建設または解体された時期、住所、居住者、所有者など）を確認できます。

### 建物を場所として保存

オブジェクトを追加できるユーザーは、建物の詳細に**場所として保存**ボタンを表示します。これをクリックすると、新しい場所のフォームが開き、建物の名前があなたの言語で事前入力され、場所の種類（農場の場合は`Farm`、それ以外は`Building`）、座標、およびWikidataアイテムへのリンクが含まれます。フォームを完成させ、例えば囲む場所を選択し、保存します。

あなたの家系図内に建物と同じ場所にある場所がある場合、ボタンは**保存された場所を開く**と表示され、その場所が表示されます。

!!! info
    サーバー管理者は、[フロントエンド設定](../install_setup/frontend-config.md)の`mapWikidata`オプションを使用してWikidata建物レイヤーを削除できます。
