# タグ

タグは、Grampsデータベース内の任意のオブジェクト（人、家族、イベント、場所、ソース、引用、リポジトリ、ノート、メディア）に適用できるラベルです。これらはオブジェクトをグループ化したりフィルタリングしたりするのに便利です。タグはGrampsファミリーツリーデータベースに保存され、すべてのユーザーで共有されます。また、Gramps Desktopで作成されたタグとも完全に互換性があります。

## タグの管理

タグは、**管理設定**の[タグ](../administration/settings.md#tags)セクションから管理されます。このセクションは、オーナーまたは管理者の役割を持つユーザーのみが利用できます。ここでは、すべての既存のタグが表示され、次の操作が可能です。

- **新しいタグを作成**するには、**新しいタグ**ボタンを使用します
- 編集（鉛筆）アイコンを使用してタグの**名前を変更**します
- カラーピッカーを使用してタグの**色を変更**します
- 削除アイコンを使用してタグを**削除**します

!!! note
    タグを削除すると、それが適用されていたすべてのオブジェクトから削除されます。

## オブジェクトへのタグの適用

タグは、編集モードの詳細ページでオブジェクトに適用したり、削除したりできます。複数のオブジェクトに一度にタグを付けるには、リストでそれらを選択し、**タグを追加**または**タグを削除**アクションを使用します。詳細は[リスト](lists.md#tags-and-privacy)を参照してください。

タグはリストの**タグ**列や、検索結果、ブックマーク、履歴に表示されます。リストに列が表示されない場合は、列ピッカーで有効にしてください。

## タグによるフィルタリング

すべての[オブジェクトリストページ](lists.md)（人、家族、イベント、場所、ソース、引用、リポジトリ、ノート、メディア）にはタグフィルターが含まれています。これを使用して、特定のタグが適用されたオブジェクトのみを表示します。

## 特殊なタグ

Gramps Webには特別な意味を持つ2つのタグがあります：

- **`Blog`** – `Blog`タグが付けられたソースはブログ投稿として扱われ、[ブログ](blog.md)ビューに表示されます
- **`ToDo`** – `ToDo`タグが付けられたノートは研究タスクとして扱われ、[タスク](tasks.md)ビューに表示されます

これらのタグは、ブログまたはタスク機能を初めて使用したときに自動的に作成されます。名前を変更したり削除したりすると、対応する機能が破損します。
