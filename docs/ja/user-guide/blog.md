# 組み込みブログの使用

ブログは、家族の歴史研究に関するストーリーを提示するためのものです。

Grampsデータベースでは、ブログ投稿はソースとして表され、ブログのテキストを含むノートが添付されており、オプションでブログ投稿の画像用のメディアファイルが含まれます。Gramps Webは、`Blog`タグを持つすべてのソースをブログ記事として扱います。

## ブログ投稿の追加

投稿を書く最も簡単な方法は、Gramps Webの専用**新しいブログ投稿**フォームを使用することです。これは、ブログページの青い**+**ボタンから、またはアプリの上部バーの**追加**メニュー（プラスアイコン）から**ブログ投稿**を選択して開くことができます。

フォームには以下のフィールドがあります：

- **タイトル** – 投稿のタイトル（必須）
- **著者** – 誰が書いたか
- **内容** – 投稿自体のリッチテキストエディタ
- **メディア** – 1つ以上のメディアオブジェクト。最初のものはテキストの上に表示されるプレビュー画像になります。すべてのメディアはテキストの下にギャラリーとして表示されます。
- **タグ** と **プライベート**スイッチ（他のオブジェクトと同様）

フォームを保存すると、基礎となるソース、ノート、および`Blog`タグが作成されます。詳細は[以下](#relation-between-blog-and-sources)を参照してください。

### 手動での投稿の追加

基礎となるオブジェクトを自分で構築することで、投稿を作成することもできます。これはGramps Desktopで行う唯一の方法であり（[Gramps Webと同期](../administration/sync.md)されています）、手順は両方のアプリケーションで同じです：

- 新しいソースを追加します。ソースのタイトルはブログ投稿のタイトルになり、ソースの著者は投稿の著者になります。
- オプションで、ソースをGramps Webブログに対応するリポジトリに関連付けます。
- ソースに新しいノートを追加します。ブログ投稿を書き、そのテキストをノートにコピーします。
- オプションで、ソースに1つ以上のメディアファイルを追加します。最初のメディアファイルは、テキストの上に表示される投稿のプレビュー画像として使用されます。すべてのメディアファイルはテキストの下にギャラリーとして表示されます。
- ソースに`Blog`ラベルを追加します（存在しない場合は作成します）。

## ブログとソースの関係

ブログ投稿は単なるソースであるため、すべてのブログ記事はソースのリストにも表示され、検索結果にもソースとして表示されます。ソースビューには「ブログに表示」ボタンがあり、それをクリックするとそのブログ投稿のブログビューに移動します。ブログ投稿のURLには、対応するソースのGramps IDも含まれているため、`yourdomain.com/blog/S0123`の記事は`yourdomain.com/source/S0123`のソースに対応します。

すべてのブログ投稿の下部には「詳細」ボタンがあり、それをクリックするとソースビューに移動します。
