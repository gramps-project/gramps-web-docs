新しいメディアファイル（画像、音声ファイル、動画ファイル、またはその他のファイル）を追加する方法は2つあり、既存のメディアファイルは新しいオブジェクトが作成される際にリンクできます。

## 新しいスタンドアロンメディアファイルを追加する

スタンドアロンメディアファイルを追加するには、アプリの上部バーの + アイコンをクリックし、「メディアオブジェクト」を選択します。

「ファイルを選択」をクリックして、コンピュータからファイルを選択します。モバイルデバイスでは、このボタンをクリックすると、デバイスのカメラで直接写真を撮るオプションが表示されます。

オプションとして、

- 「タイトル」の下にメディアファイルの説明を入力する
- 日付を入力する
- メディアファイルをプライベートに設定する（これにより、十分な権限を持つユーザーのみが表示できるようになります）

「追加」をクリックしてファイルをアップロードし、メディアオブジェクトを作成します。

## 新しいメディアファイルを追加し、別のオブジェクトにリンクする

Grampsでは、次のオブジェクトタイプにメディアオブジェクトを添付できます：人、家族、イベント、場所、ソース、および引用。

任意のオブジェクトの詳細ビューで、右下の青い編集ボタンをクリックします（表示されない場合は、ユーザーに編集権限がありません）。「ギャラリー」タブをクリックし、青い + ボタンをクリックします。

前のセクションで説明したのと同じフィールドを提供するダイアログが開きます。「保存」をクリックしてファイルをアップロードし、新しいメディアオブジェクトを追加し、表示されているオブジェクトにリンクします。

## プロフィール画像

人物のギャラリーの最初の画像がプロフィール画像として使用されます。編集モードでは、「プロフィール画像」バッジが付けられます。別の画像を使用するには、ギャラリーのサムネイルの矢印ボタンを使って最初の位置に移動します。

人物にメディアがまだない場合、編集モードでは **プロフィール画像を追加** プレースホルダーが表示されます。これをクリックして新しいメディアファイルをアップロードするか、既存のものを選択します。

## オブジェクト作成時に既存のメディアファイルをリンクする

新しい人物、家族、イベント、場所、ソース、または引用を作成すると、フォームに「メディア」セクションがあります。そこでは、1つ以上の既存のメディアオブジェクトを選択でき、保存すると新しいオブジェクトにリンクされます。

人物とその誕生および死亡イベントを同時に作成する場合、選択したメディアオブジェクトは人物のみにリンクされ、イベントにはリンクされません。

## メディアの閲覧

メディアビューは、メディアオブジェクトをサムネイルのギャラリーまたはリストとして表示します。選択はブラウザに記憶されます。他の [リストビュー](lists.md) と同様に、日付でのソート、フィルタリング、メディアの一括選択および削除が可能です。

ギャラリーのタイルをクリックすると、メディアがライトボックスで開きます。矢印キー、スワイプ、または矢印ボタンを使って、フィルタリングおよびソートされた結果をページをまたいで移動できます。ライトボックスの **詳細** ボタンをクリックすると、メディアオブジェクトのページが開きます。リストレイアウトの行をクリックすると、メディアオブジェクトのページが直接開きます。

動画はサムネイルと再生ボタンで表示されます。音声および動画ファイルは、メディアオブジェクトのページ、ライトボックス、[ブログ投稿](blog.md)、およびノートに埋め込まれた状態で再生できます。

## テキスト認識 (OCR)

サーバー管理者がOCRサポートを有効にしている場合、メディアオブジェクトの詳細ビューの画像の下に「テキスト認識」ボタンが表示されます。

「テキスト認識」をクリックし、画像に表示されているテキストの言語を選択してから、「実行」をクリックします。画像は [Tesseract OCR](https://github.com/tesseract-ocr/tesseract) で処理され、認識されたテキストが下に表示されます。

ユーザーに編集権限がある場合、「ノートとして保存」をクリックして、認識されたテキストを含む新しいノート（タイプ「トランスクリプト」）を作成し、メディアオブジェクトにリンクします。

!!! tip
    OCRの精度は画像の品質と選択した言語に大きく依存します。結果が間違っているように見える場合は、異なる言語を試してみてください。たとえば、歴史的なドイツの文書は、通常のドイツ語ではなくフラクタール変種が必要なことがよくあります。
