# 検索

検索ページは、アプリバーの虫眼鏡アイコンをクリックするか、`s` [キーボードショートカット](shortcuts.md)を押すことでアクセスできます。

## フルテキスト検索

検索フィールドに任意のクエリを入力し、Enterを押す（または検索ボタンをクリック）します。Gramps Webは、すべてのオブジェクトタイプ（人、家族、イベント、場所、ソース、引用、リポジトリ、ノート、メディア）を検索し、関連性に基づいて結果を返します。

結果には、オブジェクトタイプ、名前、および簡単な要約が表示されます。任意の結果をクリックすると、対応する詳細ページが開きます。

末尾に`*`を使用するとワイルドカードとして機能します。たとえば、`Mey*`は「Meyer」、「Meyers」、「Meyerhofer」などに一致します。

## オブジェクトタイプによるフィルタリング

検索フィールドの下には、各オブジェクトタイプ（人、家族、イベント、場所など）のトグルボタンがあり、結果を1つまたは複数の特定のタイプに絞り込むことができます。デフォルトではすべてのタイプが検索されます。1つ以上のトグルを有効にすると、結果はそのタイプのみに制限されます。

## セマンティック検索

!!! warning "非推奨"
    セマンティック検索は非推奨であり、Gramps Web API 3.25で削除される予定です。上記のフルテキスト検索には影響しません。

サーバー管理者が[セマンティック（AI駆動）検索](../install_setup/chat.md#semantic-search-deprecated)を有効にしている場合、検索ページの右上隅に2つのオプションを持つモードトグルが表示されます：

- **検索** – 標準のフルテキスト検索（デフォルト）
- **セマンティック** – クエリの意味を理解するAI駆動の検索で、正確な単語の一致ではなく意味に基づいています

セマンティック検索は、「19世紀のバイエルンの農夫」のような自然言語のクエリに便利です。セマンティック検索インデックスが構築されている必要があります。インデックスの構築または更新方法については、[管理設定](../administration/settings.md)を参照してください。
