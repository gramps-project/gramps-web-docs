# 検索

検索ページは、アプリバーの虫眼鏡アイコンをクリックするか、`s` [キーボードショートカット](shortcuts.md)を押すことでアクセスできます。

## フルテキスト検索

検索フィールドにクエリを入力します。結果は、2文字目以降の入力に応じて表示されます。1文字の検索を行うには、Enterを押します。Gramps Webは、すべてのオブジェクトタイプ（人、家族、イベント、場所、ソース、引用、リポジトリ、ノート、メディア）を横断して検索し、関連性に基づいて一致する結果を返します。検索をクリアするには、フィールド内のクリアボタンをクリックするか、Escapeを押します。

各結果は、オブジェクトタイプ、その名前、および詳細（例えば、人の生年月日や死亡日、家族の結婚、ソースの著者、ノートの最初の行など）を示します。任意の結果をクリックすると、対応する詳細ページが開きます。

## 検索構文

- **すべての単語が一致する必要があります。** `Müller Berlin`は、両方の単語を含むオブジェクトを見つけます。
- **`or`**は、いずれかの単語を含むオブジェクトを見つけます。例えば、`Meyer or Maier`。`and`も単語の間に入力できますが、違いはありません。
- `or`は、隣接する単語に適用されます：`Meyer or Maier Berlin`は「(Meyer or Maier) and Berlin」を意味します。括弧はサポートされていません。
- **引用符**はフレーズを一致させます。つまり、この順序の単語：`"Johann Georg"`。
- **ワイルドカード：**末尾の`*`は任意の終わりに一致します。例えば、`Mey*`は「Meyer」、「Meyers」、「Meyerhofer」などに一致します。フレーズにも適用されます：`"Johann Georg"*`。
- **最後の単語が補完されます。**クエリが文字または数字で終わる場合、`*`で終わるかのように検索されるため、`Anna Smi`はすでに「Anna Smith」を見つけます。最後の単語を正確に検索するには、クエリをスペースで終わらせるか、単語を引用符で囲みます。これは、オブジェクトセレクタの検索ボックスや[マップ](map.md#search)にも適用されます。
- `or`と`and`は大文字小文字を区別せずに認識されます。これらの単語自体を検索するには、引用符で囲みます。
- 単語を除外することはできません。「not」はありません。

## 検索で見つかるもの

- アクセントは一致する必要はありません。「Müller」は「Muller」も見つけ、「muller」は「Müller」を見つけます。
- 家族やイベントは、その人々の名前によっても見つけられます。例えば、「Müller」はMüllerという名前のすべての人の家族やイベントを見つけます。これらの結果は、直接の一致の下にランク付けされます。
- 標準タイプは、インターフェース言語の名前で見つけられます。例えば、「Taufe」はドイツ語インターフェースの洗礼を見つけます。
- アンダースコアは単語を区切るため、「microfilm」は`scanned_microfilm.png`という名前のメディアファイルを見つけます。
- プライベートレコードを表示できないユーザーは、プライベートメンバーの名前を通じて家族などのオブジェクトを見つけることはできません。

## オブジェクトタイプによるフィルタリング

検索フィールドの下には、各オブジェクトタイプ（人、家族、イベント、場所など）のトグルボタンがあり、結果を1つまたは複数の特定のタイプに絞り込むことができます。デフォルトではすべてのタイプが検索されます。1つまたは複数のトグルを有効にすると、結果はそのタイプのみに制限されます。
