# 検索

検索ページは、アプリバーの虫眼鏡アイコンをクリックするか、`s` [キーボードショートカット](shortcuts.md)を押すことでアクセスできます。

## フルテキスト検索

検索フィールドに任意のクエリを入力し、Enterを押す（または検索ボタンをクリック）します。Gramps Webは、すべてのオブジェクトタイプ（人、家族、イベント、場所、ソース、引用、リポジトリ、ノート、メディア）を検索し、関連性に基づいて一致する結果を返します。

結果にはオブジェクトタイプ、名前、および簡単な要約が表示されます。任意の結果をクリックすると、対応する詳細ページが開きます。

## 検索構文

- **すべての単語が一致する必要があります。** `Müller Berlin`は、両方の単語を含むオブジェクトを見つけます。
- **`or`**は、いずれかの単語を含むオブジェクトを見つけます。例：`Meyer or Maier`。`and`も単語の間に入力できますが、違いはありません。
- `or`は、その隣にある単語に適用されます：`Meyer or Maier Berlin`は「(Meyer or Maier) and Berlin」を意味します。括弧はサポートされていません。
- **引用符**はフレーズを一致させます。つまり、この順序の単語：`"Johann Georg"`。
- **ワイルドカード：**末尾の`*`は任意の終了に一致します。例：`Mey*`は「Meyer」、「Meyers」、「Meyerhofer」などに一致します。これはフレーズにも適用されます：`"Johann Georg"*`。
- `or`と`and`は大文字小文字を区別せずに認識されます。これらの単語自体を検索するには、引用符で囲んでください。
- 単語を除外することはできません。「not」はありません。

## 検索が見つけるもの

- アクセントは一致する必要はありません。「Müller」は「Muller」も見つけ、「muller」は「Müller」も見つけます。
- 家族やイベントは、その人の名前でも見つけられます。例：「Müller」はMüllerという名前のすべての人の家族やイベントを見つけます。これらの結果は、直接の一致の下にランク付けされます。
- 標準タイプは、インターフェース言語での名前で見つけられます。例：「Taufe」はドイツ語インターフェースでの洗礼を見つけます。
- アンダースコアは単語を区切るので、「microfilm」は`scanned_microfilm.png`という名前のメディアファイルを見つけます。
- プライベートレコードを表示できないユーザーは、プライベートメンバーの名前を通じて家族などのプライベート情報からオブジェクトを見つけることはできません。

## オブジェクトタイプによるフィルタリング

検索フィールドの下には、各オブジェクトタイプ（人、家族、イベント、場所など）のトグルボタンがあり、結果を1つまたは複数の特定のタイプに絞り込むことができます。デフォルトではすべてのタイプが検索されます。1つ以上のトグルを有効にすると、結果はそのタイプのみに制限されます。
