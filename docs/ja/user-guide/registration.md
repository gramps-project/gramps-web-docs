シングルツリーインストールでは、誰でもGramps Webインスタンスで新しいアカウントを登録できますが、ログインに使用できるようにするには、サイトの所有者によって手動で有効にする必要があります。

マルチツリーインストールでは、ユーザーはサインアップするためにツリーIDも必要です。実際には、これはツリー所有者によって共有された登録リンクを使用してサインアップできることを意味します。

## 1. 登録フォームを見つける

Gramps Webのホームページのログインフォームには、通常「新しいアカウントを登録」というリンクがあります。

このリンクがない場合、サーバーでの登録が無効になっているか、Gramps Webのマルチツリーインストールである可能性があります。いずれの場合も、アカウントを作成するか、登録リンクを送信できるツリー所有者に連絡してください。

サーバーが外部アカウント（Google、Microsoft、または組織のシングルサインオンなど）でのサインインをサポートしている場合、登録ページでもこれらのオプションが提供されます。これを選択すると、パスワードなしで、下記のメール確認なしにアカウントが作成されます。サーバーが自動的に役割を割り当てない限り、アカウントはツリー所有者によって有効にされる必要があります（ステップ4）。

ツリー所有者は、設定/管理の下で登録リンクを見つけてコピーできます。

## 2. 登録フォームを送信する

登録フォームには、ユーザー名、パスワード、メールアドレス、フルネームの4つの必須フィールドがあります。4つのフィールドがすべて入力されたら、「送信」をクリックして登録プロセスを開始します。

## 3. メールアドレスを確認する

フォームが送信された後、提供されたメールアドレスに自動メールが送信され、メール確認リンクが含まれています。それをクリックすると確認ページが開きます。

確認メールが届かない場合（スパムフォルダも確認した場合）、Gramps Webサーバー管理者によってメールが正しく設定されていない可能性があります。

## 4. アカウントを有効にする

メールアドレスが確認された後、ツリー所有者はメール通知を受け取り、「設定」ページの「ユーザー管理」セクションに移動して新しいユーザーアカウントを有効にできます（アプリの上部バーのユーザーアイコンからアクセス可能）し、ユーザーの役割を「無効」から[他の役割](../install_setup/users.md)に変更します。

新しいユーザーは、自分のアカウントが有効になったという自動通知を受け取らないため、管理者が個人的に通知することをお勧めします。
