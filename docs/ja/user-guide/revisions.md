# 改訂履歴

改訂履歴ビューは、家系図に対して行われたすべての編集を表示します。

リストビューは、「トランザクション」によってグループ化された編集を表示します。トランザクションは、Grampsオブジェクトに対する1つ以上の追加、削除、または変更のグループです。たとえば、父親と母親として2人の既存の人物を持つ新しい家族を追加すると、1つの追加された家族オブジェクトと2つの変更された人物オブジェクトを含むトランザクションが生成されます（なぜなら、それらは新しい家族オブジェクトへのリンクを含んでいるからです）。

トランザクションをクリックすると、トランザクションの詳細ビューが開きます。そこには、Grampsオブジェクトによる個々の追加、削除、更新のリストが含まれています。

個々の変更を選択すると、Grampsオブジェクトの生のJSON表現のビューが開き、追加と削除がそれぞれ緑と赤で強調表示されます。差分の上にあるボタンをクリックすると、そのオブジェクトのページに直接移動します。

## 単一オブジェクトの改訂

特定の人物、家族、イベント、またはその他のオブジェクトの履歴を確認するには、そのページを開き、**改訂**タブに切り替えます。そこには、そのオブジェクトに対して行われたすべての変更が新しいものから順にリストされており、変更の種類（追加、更新、または削除）、それを行ったユーザー、そしてその日時が表示されます。エントリをクリックすると、それに属するトランザクションが開き、差分を確認したり、元に戻したりできます。

**もっと表示**をクリックすると、古いエントリが読み込まれます。非常に長い履歴を持つオブジェクトの場合、最新の改訂のみが表示されます。改訂履歴が記録される前に最後に変更されたオブジェクトについては、タブには最後の変更の時間のみが表示されます。

!!! note
    改訂タブはメンバー以上に表示され、Gramps Web APIバージョン3.22以降が必要です。

## 改訂の元に戻す

トランザクション詳細ページでは、**元に戻す**ボタンを使用してそのトランザクションを逆転させることができます。これをクリックすると、元に戻すことがクリーンに実行できるかどうかがチェックされます。

**クリーンな元に戻し** – トランザクションの影響を受けたオブジェクトのいずれも、その後に変更されていない場合、元に戻すことがリスクなしに進行できます。確認ダイアログが表示され、**元に戻す**をクリックするとトランザクションが逆転します。

**強制が必要** – 影響を受けたオブジェクトの1つ以上が後のトランザクションによって変更されている場合、クリーンな元に戻しは不可能です。ダイアログは、元に戻すことを強制するとデータの不整合が生じる可能性があることを警告します。なぜなら、問題のオブジェクトに依存する後の変更は、そのまま保持されるからです。キャンセルするか、**強制的に元に戻す**をクリックして進めることができます。

いずれの場合も、元に戻しはバックグラウンドタスクとして実行され、進行状況インジケーターが表示されます。
