# AIアシスタントの使用

Gramps Webの**アシスタント**ビュー（インストールで有効になっている場合）は、家系図に関する質問に答えるAIアシスタントへのアクセスを提供します。

!!! warning
    他のAIアシスタントと同様に、回答が間違っている可能性があります。回答に含まれるリンクを使用して、それに基づく記録を確認してください。

## 仕組み

アシスタントは、事前にあなたの家系図を知りません。質問に答えるために、大規模な言語モデルが必要な記録を検索します。これは、あなたが自分で行うのと同じように行われます：

- [全文検索](search.md)を使用して家系図を検索します。
- 名前、日付、場所、子供の数などの基準で人々、イベント、家族をフィルタリングします。
- 人の祖先、子孫、その他の親戚を見つけ、その関係を示します。
- 人々、家族、イベント、場所、ノートの完全な記録を読み取ります。

その後、見つけた記録に基づいて回答し、それらへのリンクを提供します。作業中は、使用しているツールが表示されるので、進行状況を追うことができます。時間がかかる質問はバックグラウンドで実行されるため、他のページに移動して戻ってくることができます。

アシスタントは、あなたの家系図からのみ回答し、言語モデルの一般的な知識からは回答しません。よく知られた人物についても同様です。家系図に記録がない場合は、その旨を伝え、見つけた関連情報（例えばノートに記載されている情報）を示します。あなたが見ることを許可されているものだけを表示します：プライベートな記録へのリンクは、表示できないユーザーにはプレーンテキストとして表示されます。

フォローアップの質問は、同じ会話内の以前の質問のコンテキストを保持するため、「彼はいつ亡くなりましたか？」と人について尋ねることができます。

## 何を尋ねることができるか

- **人に関する事実**: 「メアリー・スミスはいつ生まれましたか？」または「ジョン・ドーの子供の名前は何ですか？」
- **親戚**: 「ジェーン・スミスの祖父母は誰ですか？」または「ヨハン・マイヤーの子孫でアメリカに移住したのは誰ですか？」
- **基準による検索**: 「1850年以降にロンドンで生まれたのは誰ですか？」、「1920年から1950年の間の結婚をリストアップしてください」または「5人以上の子供がいるカップルはどれですか？」
- **場所**: 「パリでどのイベントがありましたか？」または「デンマークで生まれたのは誰ですか？」 – より大きな場所内の場所も含まれます。
- **ノート**: 「マイヤー家の農場についてノートには何が書かれていますか？」

「最も一般的なファーストネームは何ですか？」のように、全体の家系図を一度に必要とする質問は、アシスタントが一度の検索で見ることができる記録の数が限られているため、あまりうまく機能しません。

## 画像について尋ねる

サーバー管理者がそれを有効にしている場合、プロンプトには画像を添付するボタンがあります。また、画像を貼り付けたり、画像ファイルをプロンプトにドロップしたりすることもできます。最大4つの画像を質問に添付できます。たとえば、教会の記録のスキャンを添付して「このエントリーに記載されているのは誰で、私の家系図にいますか？」と尋ねることができます。

画像は、添付された質問と一緒にのみ送信されます。フォローアップの質問は、アシスタントがそれについて言ったことを参照できますが、画像自体には言及できないため、必要に応じて再度添付してください。あなたの家系図にAIの使用制限がある場合、各画像は追加の質問と同じようにカウントされます。

## アシスタントに家系図を変更させる

サーバー管理者がそれを有効にしている場合、編集者、所有者、管理者はアシスタントに家系図を変更するように依頼できます。たとえば、「ヨハン・マイヤーのために1802年5月3日にセント・メアリーで洗礼を追加してください」または「アンナ・スミスの生年を修正してください、1871年であるべきです」といった具合です。

アシスタントは自分から何も変更することはありません。アシスタントは、追加、編集、削除する各記録をリストした**提案された変更**カードで回答します。古い値は取り消し線で示され、新しい値は強調表示されます。**適用**をクリックするまで、何も起こりません。その後、変更は一度の操作で行われ、他の編集と同様に元に戻すことができます。表示されるメッセージまたは[改訂履歴](revisions.md)から元に戻すことができます。

提案を適用する前に慎重に確認してください – 特にアシスタントが正しい人物を選んだこと、そして新しい記録（場所やソースなど）が、わずかに異なる名前であなたの家系図に既に存在しないことを確認してください。提案が完全に正しくない場合は、何を変更するかを伝え、アシスタントが再度提案します。

提案が適用された後は、同じ会話内の古い提案は適用できなくなります。これは、提案が以前の家系図のために行われたためです。同様のことが、影響を受ける記録の一つがその間に変更された場合にも起こります。

## 質問をするためのヒント

- **人の名前を指定する。** アシスタントはあなたが誰であるか、またはあなたの家族の人物が誰であるかを知りませんので、「私の祖母」ではなく「アンナ・スミス（1950年生まれ）の祖母」について尋ねてください。Gramps IDを使用することもできます。例えば、「I0042の子供たち」。
- **一般的な名前の場合は具体的に。** 「1850年にボストンで生まれたジョン・スミスはいつ結婚しましたか？」は「ジョン・スミスはいつ結婚しましたか？」よりも良いです。
- **自分の言語を使用する。** 自分の言語で質問し、同じ言語で回答を受け取ることができます。
- **異なる方法で再度尋ねる。** 回答が不完全に見える場合は、興味のある場所や期間を指定して再度尋ねてください。

!!! tip
    うまくいったことやうまくいかなかったことについて、コミュニティと経験を共有してください。
