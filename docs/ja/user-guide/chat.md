# AIアシスタントの使用

!!! info
    AIアシスタントは、Gramps Web APIバージョン2.5.0以上およびGramps Webバージョン24.10.0以上を必要とします。Gramps Web APIバージョン3.6.0では、よりインテリジェントな対話のためのツール呼び出し機能が導入されました。



Gramps Webの**アシスタント**ビュー（インストールに利用可能な場合、古いバージョンでは「チャット」と表示されます）では、家系図に関する質問に答えるAIアシスタントにアクセスできます。

!!! warning
    これはまだ新しく進化中の機能であるため、質問の種類によってはうまく機能するものとそうでないものがあります。また、他のAIアシスタントと同様に、事実に基づかない回答をすることがあるため、必ず二重チェックを行ってください。

## 仕組み

アシスタントがどのような質問に答えられるかを理解するためには、以下の仕組みを理解することが役立ちます：

1. ユーザーが質問をします。
2. アシスタントは、専門のツールを使用してデータベースに直接クエリを実行します：家系図を[全文検索](search.md)で検索し、特定の基準で人々/イベント/家族/場所をフィルタリングし、個人間の関係を計算し、ノートを含む完全な記録を参照します。
3. 大規模な言語モデルが、見つかった記録に基づいて回答を作成します。
4. 回答が表示され、その基にした記録へのリンクが提供されます。

Gramps Web APIバージョン3.24より古いサーバーでは、アシスタントは意味検索にも依存していましたが、これは段階的に廃止されています。

アシスタントが作業している間、現在使用しているツール（例：人を検索中、関係を調べている）を示すインジケーターが表示されるため、回答を構築する過程を追うことができます。長時間かかる質問はバックグラウンドタスクとして処理されるため、他のページに移動して戻ってくることができ、進捗は[通知](notifications.md)にも反映されます。回答は、読みやすさを考慮してMarkdown（リスト、強調、リンクなど）でフォーマットされています。

## 何を尋ねることができるか

Gramps Web APIバージョン3.6.0で導入されたツール呼び出し機能により、AIアシスタントはより複雑な質問に対応できるようになりました：

- **家族関係**: "ジェーン・スミスの祖父母は誰ですか？" または "ジョン・ドーはメアリー・ジョンソンとどのように関連していますか？"
- **フィルタリング検索**: "1850年以降にロンドンで生まれたすべての人を見せてください" または "パリで発生したイベントはどれですか？"
- **日付ベースのクエリ**: "1900年以前に亡くなったのは誰ですか？" または "1920年から1950年の間に行われた結婚をリストしてください"
- **場所情報**: "フランスにはどんな場所がありますか？" または "セント・メアリー教会について教えてください"
- **一般的な質問**: "ジョン・ドーの子供の名前は何ですか？" または "メアリー・スミスはいつ生まれましたか？"

## 質問をするためのヒント

AIアシスタントから最良の結果を得るために：

- **具体的に**: 曖昧さを避けるために、できるだけ詳細に質問を構成してください。例えば、「1850年にボストンで生まれたジョン・スミスはいつ結婚しましたか？」は「ジョン・スミスはいつ結婚しましたか？」よりも良いです。
- **適切な名前を使用**: 関連する場合は、特定の名前、場所、日付を言及してください。
- **一度に一つのことを尋ねる**: 複雑な質問をより簡単な部分に分けて、より良い結果を得てください。
- **自分の言語を使用**: 大規模な言語モデルは多言語対応しているため、自分の言語で質問し、同じ言語で回答を受け取ることができます。

!!! tip
    うまくいったことやうまくいかなかったことについて、コミュニティと経験を共有してください。
