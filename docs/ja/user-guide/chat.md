# AIアシスタントの使用

!!! info
    AIアシスタントは、Gramps Web APIバージョン2.5.0以上およびGramps Webバージョン24.10.0以上を必要とします。Gramps Web APIバージョン3.6.0では、よりインテリジェントなインタラクションのためのツール呼び出し機能が導入されました。



Gramps Webの**アシスタント**ビュー（インストールに利用可能な場合、古いバージョンでは「チャット」と表示されます）では、家系図に関する質問に答えるAIアシスタントにアクセスできます。

!!! warning
    これはまだ新しい進化中の機能であるため、質問の種類によってはうまく機能するものとそうでないものがあります。また、他のAIアシスタントと同様に、事実に基づかない回答をすることがあるため、必ず二重チェックしてください。

## 仕組み

アシスタントがどのような質問に答えられるかを理解するためには、以下のようにその仕組みを理解することが役立ちます：

1. ユーザーが質問をします。
2. アシスタントは、専門のツールを使用してデータベースに直接クエリを実行します：フルテキスト検索を使用してツリーを検索し、特定の基準で人々/イベント/家族/場所をフィルタリングし、個人間の関係を計算し、完全な記録を調べます（そのノートを含む）。
3. 大規模な言語モデルが見つけた記録に基づいて回答を形成します。
4. 回答が表示され、基にした記録へのリンクが含まれます。

アシスタントは、一般的な知識の言語モデルからではなく、あなたのツリーからのみ回答します – 有名な人についても同様です。ツリーに何かが記録されていない場合、それを明示し、見つけた関連情報（例えばノート内の情報）を言及します。見ることが許可されていないオブジェクトへのリンクはプレーンテキストとして表示されます。

フォローアップの質問は、同じ会話内の以前の質問のコンテキストを保持するため、「彼はいつ亡くなりましたか？」と人について尋ねた後に聞くことができます。

アシスタントが作業している間、現在使用しているツール（例：人を検索中、関係を調べ中）を示すインジケーターが表示されるため、回答を構築している様子を追うことができます。長時間かかる質問はバックグラウンドタスクとして処理されるため、ナビゲートして戻ってくることができ、進捗は[通知](notifications.md)にも反映されます。回答はMarkdown（リスト、強調、リンクなど）でフォーマットされ、読みやすくなっています。

## 何を尋ねることができるか

Gramps Web APIバージョン3.6.0で導入されたツール呼び出し機能により、AIアシスタントはより複雑な質問にも対応できるようになりました：

- **家族関係**: "ジェーン・スミスの祖父母は誰ですか？" または "ジョン・ドーはメアリー・ジョンソンとどのように関係していますか？"
- **フィルタリングされた検索**: "1850年以降にロンドンで生まれたすべての人を見せてください" または "パリで起こったイベントは何ですか？"
- **日付ベースのクエリ**: "1900年以前に亡くなった人は誰ですか？" または "1920年から1950年の間に行われた結婚をリストしてください"
- **場所情報**: "フランスにはどんな場所がありますか？" または "セント・メアリー教会について教えてください"
- **一般的な質問**: "ジョン・ドーの子供の名前は何ですか？" または "メアリー・スミスはいつ生まれましたか？"

## 質問の仕方のヒント

AIアシスタントから最良の結果を得るためには：

- **具体的に**: 曖昧さを避けるために、できるだけ詳細に質問を構成してください。例えば、「1850年にボストンで生まれたジョン・スミスはいつ結婚しましたか？」は「ジョン・スミスはいつ結婚しましたか？」よりも良いです。
- **固有名詞を使用**: 関連する場合は、特定の名前、場所、日付を言及してください。
- **一度に一つのことを尋ねる**: 複雑な質問をより簡単な部分に分けて、より良い結果を得てください。
- **自分の言語を使用**: 大規模な言語モデルは多言語対応しているため、自分の言語で質問をし、同じ言語で回答を受け取ることができます。

!!! tip
    うまくいったことやうまくいかなかったことについて、コミュニティと経験を共有してください。
