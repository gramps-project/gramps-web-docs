# 組み込みのタスク管理を使用する

Gramps Webには、組み込みの系譜タスク管理ツールが含まれています。これは、研究者がタスクを計画し、優先順位を付けるだけでなく、タスクを文書化することを可能にするためのものです。このため、タスクはGrampsデータベース内のソースとして表現されます。タスクが完了した後、関連するコンテンツは研究プロセスを文書化するソースとして機能します。

## タスクの基本

タスクには以下のプロパティがあります：

- ステータス。これは「オープン」、「進行中」、「ブロック」、「完了」のいずれかです。
- 優先順位。これは「低」、「中」、「高」のいずれかです。
- タグ。ラベルは基盤となるソースの通常のGrampsタグです。（すべてのタスクには、タスクとして識別するために`ToDo`ラベルが追加されていますが、このラベルは混乱を避けるためにタスクリストでは非表示です。）
- タイトル。タスクリストに表示されます。
- 説明。問題の説明を記述するために使用できるリッチテキストフィールドですが、進捗状況を文書化することもできます。
- メディア。タスクに添付されたメディアファイル。

## タスクを作成する

タスクは通常のGrampsオブジェクトであるため、他のオブジェクト（人物やイベントなど）を編集または作成できるユーザーグループによって編集または作成できます。

タスクを作成するには、タスクリストページの+ボタンをクリックします。少なくともタイトルを入力し、オプションで優先順位、説明、添付ファイル、およびタグを入力します。作成時のステータスは常に「オープン」です。

## タスクリスト

デフォルトでは、タスクリストはステータスでソートされており、完了したタスクは最後に表示され、各ステータス内では優先順位が高いものから順に表示されます。フィルターバーのソートメニューでは、優先順位、タイトル、または最終変更（最新のものが最初）でソートすることもできます。

タスクをクリックすると、それが開きます。編集権限を持つユーザーは、タスクのステータスアイコンをクリックして、リスト内で直接ステータスを変更することもできます。たとえば、完了としてマークすることができます。

リストの上にある**フィルター**ボタンは、タイトル、ステータス、優先順位、またはタグでタスクをフィルタリングします。これは[GOQL](goql.md)式または[高度なフィルター](lists.md#advanced-filter)を使用して行います。複数のステータスや優先順位を選択すると、それらのいずれかを持つタスクが表示されます。たとえば、すべてのオープンおよびブロックされたタスクです。

## タスクを編集する

タスクページには、他のGrampsオブジェクトのような「編集モード」はありません：

- タイトルをクリックして編集します。Enterを押すか、✓をクリックするか、他の場所をクリックして保存します。キャンセルするにはEscapeを押すか、✕をクリックします。
- ステータスと優先順位の変更は即座に適用されます。
- 説明や添付ファイルを編集するには、セクションの見出しの横にある編集ボタンをクリックします。説明はその下の「保存」ボタンで保存されます。添付ファイルの編集は**完了**で終了します。
- ロックボタンは、タスクがプライベートかどうかを設定します。タスクの説明は同じプライバシーを持ちます。

編集権限のないユーザーは、ステータスと優先順位をテキストとして表示し、コンテンツのないセクションは非表示になります。

タイトルの下に、編集者はさらに2つのボタンを見ます：**ソースを編集**は、タスクを表すソースを開き、他のノート、引用、および属性を編集できます。**削除**は、確認後にタスクを削除し、タスクリストに戻ります。表示されるメッセージには、タスクを復元するための元に戻すボタンがあります。

## タスクプロパティの一括変更

編集権限を持つユーザーは、タスクリストの各行にチェックボックスを見ます。タスクを選択し、リストの上にある**優先順位を設定**または**ステータスを設定**を使用して、選択したすべてのタスクを一度に変更します。

## Gramps Desktopのタスク

Gramps Webを介してタスクを追加すると、ソースとノートには`ToDo`タグが付与されるため、タスクはデスクトップの[To Do Notes Gramplet](https://gramps-project.org/wiki/index.php/Addon:ToDoNotesGramplet)や[To Do Report](https://gramps-project.org/wiki/index.php/Addon:ToDoReport)に表示されます。

Gramps Desktopでタスクを追加または編集するには、以下のガイドラインを使用します。

- タグ`ToDo`を持つソースを追加し、タスクタイトルをタイトルとして設定します。
- オプションで、タグ`ToDo`を持つソースにノートを追加し、「To Do」とタイプし、説明をテキストとして追加します。
- 属性「ステータス」を追加し、「オープン」、「進行中」、「ブロック」、「完了」のいずれかに設定します。
- 属性「優先順位」を追加し、低は9、中は5、高は1に設定します（これらの直感に反する値はiCalendar仕様から取られています）。
