Gramps Webに初めてログインすると、ユーザーがフロントエンドの言語と[ホームパーソン](https://www.gramps-project.org/wiki/index.php/Gramps_Glossary#home_person)を選択する必要がある「ユーザー設定」とラベル付けされた設定フォームが表示されます。ホームパーソンの選択は、ウェブサイトのホームページからも変更できます。

Gramps Webウェブサイトのユーザーのホームパーソンは、サイトの所有者がデスクトップ版Grampsで選択した人物と同じである必要はありません。これは個人設定であり、Gramps Webのすべてのユーザーにとって異なる場合があります。ホームパーソンは家系図の初期表示に使用され、ほとんどのレポートの出発点となります。一般的な選択肢は、ユーザーが自分自身をホームパーソンとして選択することです。他のメンバーと共同作業を行う場合、これらのユーザーは共通の祖先をホームパーソンとして設定したいかもしれません。これにより、遠い関係の共通の参照点が確保されます。

ホームパーソンとして人物を選択するには、テキストフィールドに名または姓を入力し始めると、一致する候補のドロップダウンリストが表示されます。

ツリーがまだ空の場合、選択できる人物はいません。この場合、ホームページには編集者が最初のステップを進めるための**始める**カードが表示されます：最初に人物を追加する（または家系図ファイルをインポートする）、次に家族を追加して人々を接続します。空のツリーで最初に作成した人物は、自動的にあなたのホームパーソンになります。

言語とホームパーソンの設定はブラウザのローカルストレージに保存されるため、特定のデバイスで持続します。
