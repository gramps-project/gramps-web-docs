Gramps Webに初めてログインすると、ユーザーがフロントエンドの言語と[ホームペルソン](https://www.gramps-project.org/wiki/index.php/Gramps_Glossary#home_person)を選択する必要がある設定フォーム（ユーザー設定とラベル付けされている）が表示されます。ホームペルソンの選択は、ウェブサイトのホームページからも変更できます。

Gramps Webウェブサイトのユーザーのホームペルソンは、サイトの所有者がGramps for Desktopsで選択した人物と同じである必要はありません。これは個々の設定であり、Gramps Webのすべてのユーザーにとって異なる場合があります。ホームペルソンは家系図の初期表示に使用され、ほとんどのレポートの出発点となります。一般的な選択肢は、ユーザーが自分自身をホームペルソンとして選択することです。他のメンバーと共同作業を行う場合、これらのユーザーは共通の祖先をホームペルソンとして設定したいと考えるかもしれません。これにより、遠い関係のための共通の参照点が確保されます。

ホームペルソンとして人物を選択するには、テキストフィールドに名または姓を入力し始めると、一致する項目のドロップダウンリストが表示されます。

ツリーがまだ空の場合、選択できる人物はいません。この場合、ホームページには編集者が最初のステップを案内する**開始する**カードが表示されます：最初に人物を追加する（または家系図ファイルをインポートする）、次に家族を追加して人々を接続します。空のツリーで最初に作成した人物は、自動的にあなたのホームペルソンになります。ステップバイステップの手順については、[新しいツリーを開始する](start-tree.md)を参照してください。

言語とホームペルソンの設定はブラウザのローカルストレージに保存されるため、特定のデバイスで持続します。ホームペルソンは各ツリーごとに別々に保存されます。
