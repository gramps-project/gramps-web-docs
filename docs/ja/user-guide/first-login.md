Gramps Webに初めてログインすると、ユーザーがフロントエンドの言語と[ホーム人物](https://www.gramps-project.org/wiki/index.php/Gramps_Glossary#home_person)を選択する必要がある設定フォーム（ユーザー設定と表示されます）が表示されます。ホーム人物の選択は、ウェブサイトのホームページからも変更できます。

Gramps Webウェブサイトのユーザーのホーム人物は、サイトの所有者がGramps for Desktopsで選択した人物と同じである必要はありません。これは個人の設定であり、Gramps Webの各ユーザーごとに異なることができます。ホーム人物は家系図の初期表示に使用され、ほとんどのレポートの出発点となります。一般的な選択肢は、ユーザーが自分自身をホーム人物として選択することです。他のメンバーと共同作業を行う場合、これらのユーザーは共通の祖先をホーム人物として設定したいと考えるかもしれません。これにより、遠い関係のための共通の参照点が確保されます。

人物をホーム人物として選択するには、テキストフィールドに名または姓を入力し始めると、一致する候補のドロップダウンリストが表示されます。

ツリーがまだ空の場合、選択できる人物はいません。この場合、ホームページには編集者が最初のステップを進めるための**始める**カードが表示されます。最初に人物を追加する（または家系図ファイルをインポートする）ことから始め、その後、家族を追加して人々をつなげます。空のツリーで最初に作成した人物は、自動的にあなたのホーム人物になります。ステップバイステップの手順については、[新しいツリーを開始する](start-tree.md)を参照してください。

言語とホーム人物の設定は、ブラウザのローカルストレージに保存されるため、特定のデバイスで持続します。
