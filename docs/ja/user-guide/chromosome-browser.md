# クロモソームブラウザ

クロモソームブラウザは、個人のDNAマッチを視覚化するためのツールです。これは、染色体上に他の人と共有されているDNAセグメントを色付きのバーとして表示します。

DNAビューの「クロモソームブラウザ」タブの下にあります。

各染色体について、上部の（淡い青色の）バーは父親から受け継いだコピーを表し、下部の（淡い赤色の）バーは母親から受け継いだものを表します。共有されているセグメントは、これらの上に色付きのバーとして表示されます。どちらの側（父方または母方）が不明なセグメントは、2つの間の別のトラックに表示されます。複数のマッチのセグメントが重なる場合、それぞれのセグメントが見えるように、別の細いレーンで描画されます。

凡例のマッチの名前をクリックすると、その人の共有セグメントのみが表示されます。

## 共通の祖先によるグルーピング

凡例の上で、セグメントを**マッチ**で色分けするか、**共通の祖先**で色分けするかを切り替えることができます。共通の祖先を使用すると、選択した人と同じ最も最近の共通の祖先から子孫であるマッチが同じ色と凡例の行を共有します。これにより、どの染色体の部分がどの祖先のカップルから受け継がれたかを一目で確認できます。同じ側のグループの他のマッチと重なるセグメントは、おそらく同じ祖先から来ているため、新しい未知のマッチを特定するのに役立ちます。

グループは、最も近い関係から順に並べられています。共通の祖先が知られていないマッチは「不明」としてグループ化されます。複数の系統で関連しているマッチは、最も近い系統でグループ化されます。

## チャートの保存

チャートを保存するには、人物セレクタの隣にあるダウンロードボタンをクリックします。白い背景と凡例を含むSVGファイルがダウンロードされ、各マッチの総共有センチモルガンが含まれます。凡例でマッチまたはグループが選択されている場合、そのマッチまたはグループのみが含まれます。
