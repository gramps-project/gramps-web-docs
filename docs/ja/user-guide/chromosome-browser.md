# クロモソームブラウザ

クロモソームブラウザは、個人のDNAマッチを視覚化するためのツールです。これは、染色体上の他の人と共有されているDNAセグメントを色付きのバーとして表示します。

DNAビューの「クロモソームブラウザ」タブの下にあります。

各染色体について、上部（薄い青）のバーは父親から受け継いだコピーを表し、下部（薄い赤）のバーは母親から受け継いだコピーを表します。共有セグメントは、これらの上に色付きのバーとして表示されます。側面（父系または母系）が不明な場合、セグメントは両方のバーにまたがり、ハッチマークで表示されます。

凡例のマッチ名をクリックすると、その人の共有セグメントのみが表示されます。

チャートを保存するには、人物セレクターの隣にあるダウンロードボタンをクリックします。これにより、白い背景と凡例を含むSVGファイルがダウンロードされ、各マッチの合計共有センチモルガンが含まれます。凡例でマッチが選択されている場合、そのマッチのみが含まれます。
