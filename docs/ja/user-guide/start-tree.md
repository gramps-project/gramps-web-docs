# 新しいツリーを開始する

このページでは、空の家系図における最初のステップ、つまり自分自身を追加し、両親を追加し、家系図チャートでその結果を見る方法を説明します。所要時間は約15分です。

他の系譜プログラムやGramps Desktopに既に家系図がある場合は、手動で再入力する必要はありません。代わりに[データのインポート](../administration/import.md)を参照してください。

!!! note
    人を追加するには、エディターロール以上が必要です。ツリーの所有者は常にこのロールを持っています。すべてのロールについては[ユーザーシステム](../install_setup/users.md)を参照してください。

## 1. 場所を作成する

Grampsでは、場所は一度作成され、その後、そこで発生したすべてのイベントに選択されます。たとえば、同じ町での兄弟姉妹の誕生などです。したがって、誰かの出生地として選択する前に、その場所が存在している必要があります。

あなたが生まれた場所を作成するには：

1. アプリバーの上部にある**+**（追加）ボタンをクリックし、**場所**を選択します。
2. 場所の**名前**を入力し、オプションでその**タイプ**（市や村など）を入力します。
3. オプションで、**地図上で選択**をクリックして座標を設定し、その場所が[地図](map.md)に表示されるようにします。
4. **追加**をクリックします。

両親の出生地も同様に作成します。まだ場所がわからない場合は、スキップして後で追加できます。

## 2. 自分を追加する

ホームページに戻ります。ツリーが空の間は、**開始する**カードが表示されます。**新しい人**をクリックして、新しい人のフォームを開きます：

- **名前** – あなたの名と姓
- **性別**
- **誕生日** – 下記の[日付の入力](#entering-dates)を参照
- **出生地** – **既存の場所を選択**をクリックし、作成した場所を検索します

死亡のフィールドは空のままにして、**追加**をクリックします。新しい人のページが開きます。

空のツリーで最初に作成された人は、自動的にあなたの**ホームパーソン**になります：家系図チャートが始まる人です。ホームページでいつでも別のホームパーソンを選択できます。

### 日付の入力

日付は年、月、日を別々のフィールドに入力します。年だけがわかっている場合は、年だけを入力します。不確かな日付の場合は、正確な日を推測するのではなく、日付のタイプを変更します。たとえば、「約」や「以前」などです。

## 3. 両親を追加する

1. サイドバーで**家系図**をクリックします。チャートにはあなたがホームパーソンとして表示されます。
2. 右下隅の鉛筆ボタンをクリックして編集モードをオンにします。
3. あなたのカードの小さな**+**ボタンをクリックします。**家族メンバーを追加**ダイアログが開きます。
4. **父**の横にある**+**アイコンをクリックして新しい人を作成し、前と同様にフォームに記入して保存します。あなたの父がチャートに表示され、すでにあなたにリンクされています。
5. **母**についても同様に繰り返します。

各関係の横にある**リンク**アイコンは、新しい人を作成するのではなく、すでにツリーに存在する人を接続します。

同様に、チャート内の任意のカードの**+**をクリックして、その人の両親、子供、または配偶者を追加します。各変更は即座に保存されます。編集モードを終了するには、アプリバーの上部にある閉じるボタンをクリックします。

## 4. 結果を見る

チャートには、あなたとあなたの両親が表示されます。ページ上部のタブで他のチャートタイプを試してみてください。たとえば、ファンチャートなどです。任意の人のカードをクリックして、その人を中心にチャートを表示します。すべてのチャートとオプションについては[家系図](tree.md)を参照してください。

## 次のステップ

- **詳細を追加する。** 人のページを開きます。たとえば、チャートツールバーの**人物詳細**ボタンを使用して、さらなるイベント、ノート、ソースなどを追加します。チャート内で直接行えることについては[ツリー表示での編集](tree-edit.md)を参照してください。
- **写真や文書を追加する。** [メディアファイルを追加](media.md)を参照してください。
- **家族を招待する。** 親族はあなたのツリーに独自のアカウントが必要です。詳細は[ユーザーの管理](../administration/users.md)と[登録](registration.md)を参照してください。
