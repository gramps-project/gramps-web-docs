# Приложение Gramps Web DigitalOcean в 1 клик

Вместо [самостоятельной установки Gramps Web](deployment.md) вы также можете воспользоваться [приложением Gramps Web DigitalOcean в 1 клик](https://marketplace.digitalocean.com/apps/gramps-web?refcode=b1d13ebe86ac&action=deploy). Digital Ocean размещает демонстрационную версию Gramps Web.

<a href="https://www.digitalocean.com/?refcode=b1d13ebe86ac&utm_campaign=Referral_Invite&utm_medium=Referral_Program&utm_source=badge"><img src="https://web-platforms.sfo2.cdn.digitaloceanspaces.com/WWW/Badge%202.svg" alt="Реферальный значок DigitalOcean" /></a>

В рамках процедуры настройки вам потребуется зарегистрировать учётную запись в DigitalOcean и выбрать платный тариф для используемого «дроплета» (виртуальной машины).

Можно утверждать, что на данный момент это самый простой способ развернуть собственный экземпляр Gramps Web на собственном хостинге с защитой SSL без использования собственного оборудования.

!!! info
    Обратите внимание, что за услуги хостинга вы будете платить DigitalOcean. Проект Gramps с открытым исходным кодом не предоставляет платную поддержку.

## Шаг 1: Создайте учётную запись DigitalOcean

Создайте учётную запись на сайте [DigitalOcean](https://www.digitalocean.com/), если у вас её ещё нет.

## Шаг 2: Создайте дроплет

- Перейдите в [приложение Gramps Web в 1 клик](https://marketplace.digitalocean.com/apps/gramps-web?refcode=b1d13ebe86ac&action=deploy) и нажмите «Create Gramps Web Droplet».
- Выберите тариф как минимум с 2 ГБ оперативной памяти.
- Настройте аутентификацию для своего дроплета
- Нажмите «Create Droplet»

## Шаг 3: Настройте доменное имя

Вам потребуется доменное имя (или поддомен). Если у вас есть домен, направьте его на IP-адрес своего дроплета. В противном случае вы можете воспользоваться бесплатным сервисом, например [DuckDNS](https://www.duckdns.org/).

## Шаг 4: Войдите в свой дроплет

Подключитесь к своему дроплету по SSH. Вы должны увидеть сообщение «Welcome to the Gramps Web DigitalOcean 1-click app setup!». Если это не так, подождите несколько минут и попробуйте снова (установка ещё не завершена).

Скрипт настройки запросит у вас доменное имя (например, `mygrampswebinstance.duckdns.org`) и адрес электронной почты (необходим для сертификата Let's Encrypt). При необходимости он также запросит настройки SMTP, которые Gramps Web использует для отправки электронных писем, например для сброса паролей; оставьте поле SMTP-хоста пустым, чтобы пропустить этот шаг.

После этого дождитесь завершения настройки в фоновом режиме

## Шаг 5: Запустите Gramps Web

Теперь ваш экземпляр Gramps Web должен быть доступен в корне вашего домена с действительным сертификатом SSL, и вы должны увидеть помощник первоначального запуска.

## Последующее изменение конфигурации

Скрипт настройки сохраняет базовый URL и параметры электронной почты в файле `/root/letsencrypt.env` в виде [параметров конфигурации](configuration.md) с префиксом `GRAMPSWEB_`, например:

```
GRAMPSWEB_EMAIL_HOST=smtp.example.com
GRAMPSWEB_EMAIL_PORT=587
GRAMPSWEB_EMAIL_USE_STARTTLS=true
```

Чтобы добавить или изменить параметры, отредактируйте этот файл на дроплете и примените изменения с помощью команды

```bash
cd /opt/grampsweb && docker compose up -d
```
