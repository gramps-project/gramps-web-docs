# Настройки администрирования

Страница **Настройки > Администрирование** доступна через иконку пользователя в верхней панели приложения. Она доступна только пользователям с ролью Владелец или Администратор и предоставляет инструменты для управления базой данных семейного дерева.

Страница организована в сворачиваемые секции. Нажмите на заголовок секции, чтобы развернуть ее. Эта страница перечисляет секции и ссылки на описание каждой из них.

## Данные

- [Квоты использования](import.md#usage-quotas){#usage-quotas} – текущее использование относительно лимитов для хранения людей и медиа
- [Импорт данных](import.md){#import-data} – загрузить файл семейного дерева
- [Статус медиафайлов](import-media.md#media-file-status){#media-file-status} – медиаобъекты с отсутствующими контрольными суммами или файлами
- [Импорт медиаархива](import-media.md){#import-media-archive} – загрузить ZIP-файл для заполнения отсутствующих медиафайлов
