# Настройки администрирования

Страница **Настройки > Администрирование** доступна через значок пользователя в верхней панели приложения. Она доступна только пользователям с ролью Владелец или Администратор и предоставляет инструменты для управления базой данных семейного дерева.

Страница организована в сворачиваемые секции. Нажмите на заголовок секции, чтобы развернуть её.

## Данные

Охватывает квоты использования, импорт данных и управление медиафайлами.

### Квоты использования

В верхней части секции отображается текущее использование относительно любых настроенных лимитов:

- **Люди** – количество объектов людей в дереве по сравнению с настроенным максимумом (∞ если неограниченно)
- **Хранение медиа** – общий размер загруженных медиафайлов по сравнению с настроенной квотой хранения (∞ если неограниченно)

Квоты устанавливаются администратором сервера; см. [Конфигурация сервера](../install_setup/configuration.md) для получения подробной информации.

### Импорт данных

Секция импорта позволяет загружать файл семейного дерева или медиаархив. См. [Импорт данных](import.md) для получения полных инструкций.

### Статус медиафайлов

Эта секция показывает:

- Общее количество медиаобъектов в дереве и наличие у них контрольной суммы
- Количество медиаобъектов, связанные файлы которых отсутствуют на сервере

Зеленая галочка указывает на то, что всё в порядке. Если обнаружены проблемы, отображаются ссылки на затронутые объекты. Отсутствие контрольных сумм обычно происходит, когда данные были импортированы из формата, такого как GEDCOM, который включает ссылки на медиа, но не сами файлы. Отсутствующие файлы можно загрузить через функцию импорта медиаархива.

### Импорт медиаархива

Позволяет загружать ZIP-файл медиафайлов для заполнения отсутствующих файлов. См. [Импорт данных](import.md) для получения полных инструкций.

## Индекс поиска

### Управление индексом поиска

Gramps Web поддерживает полнотекстовый индекс поиска, который обычно обновляется автоматически при изменении данных. Индикатор статуса показывает, сколько объектов в настоящее время индексировано по сравнению с общим количеством объектов.

Нажмите **Обновить индекс поиска**, чтобы инициировать полное перестроение. Индикатор прогресса отображается во время выполнения задачи в фоновом режиме. Это обычно необходимо только после обновления сервера.

### Индекс семантического поиска

!!! warning "Устарело"
    Семантический поиск устарел и будет удалён в Gramps Web API 3.25 вместе с этой секцией. Чат с ИИ не нуждается в этом, так как Gramps Web API 3.24.

Если на сервере включен [семантический (с поддержкой ИИ) поиск](../install_setup/chat.md#semantic-search-deprecated), появляется дополнительная секция с двумя действиями:

- **Регенерировать индекс семантического поиска** – перестраивает весь семантический индекс с нуля. Это требует значительных вычислительных ресурсов и может занять много времени.
- **Обновить индекс семантического поиска** – выполняет инкрементальное обновление, добавляя только объекты, которые ещё не индексированы. Быстрее, чем полное перестроение.

## Настройки дерева

### Название семейного дерева

!!! note
    Переименование дерева работает только в [настройке с несколькими деревьями](../install_setup/multi-tree.md) или когда `TREE_ID` явно установлен в [конфигурации сервера](../install_setup/configuration.md). В стандартной установке с одним деревом без установленного `TREE_ID` это вызовет ошибку.

Это позволяет изменить имя базового семейного дерева Gramps. Введите новое имя и нажмите **Переименовать**, чтобы применить.

!!! tip
    Если вы хотите изменить только имя, отображаемое в панели приложения, не переименовывая базу данных, используйте настройку [Название приложения](#app-title).

### Информация о исследователе

Установите имя, адрес и контактные данные основного исследователя. Эта информация встраивается в экспорты (например, файлы GEDCOM).

## Настройка

### Цвета темы

Установите пользовательский **основной цвет** и **акцентный цвет** для интерфейса Gramps Web. Эти цвета применяются ко всем пользователям этого дерева и вступают в силу немедленно после сохранения.

Используйте выбор цветов, чтобы выбрать цвета, затем нажмите **Сохранить**. Нажмите **Сбросить**, чтобы вернуться к значениям по умолчанию.

### Название приложения

Установите пользовательское название для приложения. Если установлено, это переопределяет название семейного дерева в заголовке браузера и в верхней панели приложения.

Введите название и нажмите **Сохранить**. Оставьте пустым, чтобы использовать значение по умолчанию (название семейного дерева).

### Заметка на главной странице

Выберите объект Gramps **Заметка**, который будет отображаться на главной странице панели управления. Содержимое заметки отображается под основными колонками панели управления и видно всем пользователям, имеющим доступ к дереву.

Используйте селектор объектов, чтобы найти и выбрать заметку, затем сохраните. Нажмите **Удалить**, чтобы очистить текущую заметку на главной странице.

### Изображение на главной странице

Выберите объект Gramps **Медиа**, который будет отображаться как изображение на главной странице панели управления. В сочетании с заметкой на главной странице изображение отображается рядом с текстом заметки. Без заметки отображается только изображение.

Используйте селектор объектов, чтобы найти и выбрать медиаобъект, затем сохраните. Нажмите **Удалить**, чтобы очистить текущее изображение на главной странице.

### Настройки экспорта/импорта

Настройки на уровне дерева (название приложения, цвета темы, заметка/изображение на главной странице и т. д.) могут быть экспортированы в виде JSON-файла для резервного копирования или копирования в другой экземпляр Gramps Web.

- Нажмите **Экспортировать настройки**, чтобы скачать текущие настройки в виде JSON-файла.
- Нажмите **Импортировать настройки дерева**, чтобы загрузить ранее экспортированный JSON-файл и применить настройки.

## Обработка семейного дерева

### Проверка и восстановление базы данных

Этот инструмент проверяет базу данных Gramps на внутренние несоответствия и исправляет те, которые может – аналогично инструменту [Проверка и восстановление базы данных](https://www.gramps-project.org/wiki/index.php/Gramps_5.2_Wiki_Manual_-_Tools#Check_and_Repair_Database) в Gramps Desktop.

Нажмите **Проверить и восстановить** и дождитесь завершения индикатора прогресса. Результат отображается под кнопкой:

- Если ошибки не найдены, отображается сообщение о подтверждении.
- Если ошибки найдены, отображается сводка применённых исправлений.

Запустите этот инструмент, если вы столкнулись с неожиданными ошибками или поведением, которые могут быть вызваны несоответствиями в базе данных, такими как отсутствующие связи между объектами.

### Проверка данных

В то время как [Проверка и восстановление базы данных](#check-and-repair-database) ищет *технические* несоответствия, этот инструмент ищет *неправдоподобные* данные – аналогично инструменту [Проверка данных](https://gramps-project.org/wiki/index.php/Gramps_5.0_Wiki_Manual_-_Tools#Verify_the_Data) в Gramps Desktop. Он сообщает о вещах, которые не невозможны, но достаточно маловероятны, чтобы на них стоило обратить внимание, таких как мать в возрасте 12 лет или человек, доживший до 130 лет.

В разделе **Опции** вы можете настроить пороги, используемые тестами – максимальный возраст, минимальный и максимальный возраст для вступления в брак или для рождения детей, максимальное количество детей и так далее – а также указать, следует ли оценивать отсутствующие или неточные даты и сообщать о недействительных датах, таких как 31 февраля.

Нажмите **Проверить данные**, чтобы начать. Проверка выполняется как фоновая задача, а результаты затем перечисляются в разделе **Результаты проверки данных**. Этот инструмент ничего не изменяет: он только сообщает о том, что находит.

!!! note
    Результат не является доказательством ошибки. Долгая жизнь и большие возрастные разрывы действительно имеют место, поэтому рассматривайте результаты как список вещей для проверки, а не как список вещей для исправления.

## Теги

### Управление тегами

Создавайте, переименовывайте, изменяйте цвет и удаляйте [теги](../user-guide/tags.md) для семейного дерева. Теги хранятся в базе данных Gramps, общие для всех пользователей, и полностью совместимы с Gramps Desktop.

Нажмите **Новый тег**, чтобы создать тег. Используйте элементы управления рядом с существующим тегом, чтобы переименовать его (значок карандаша), изменить его цвет (выбор цвета) или удалить его (значок удаления).

!!! note
    Удаление тега удаляет его из всех объектов, к которым он был применён.

См. [Теги](../user-guide/tags.md) для получения информации о том, как теги используются во всем Gramps Web, включая специальные теги `Blog` и `ToDo`.

## Резервные копии

Резервная копия содержит данные семейного дерева, включая частные записи, настройки дерева и пользователей дерева. Медиафайлы не включены; см. [Резервное копирование ваших медиафайлов](export.md#back-up-your-media-files).

### Храненные резервные копии

Если администратор сервера установил каталог резервного копирования (`BACKUP_DIR`, см. [Конфигурация сервера](../install_setup/configuration.md)), резервные копии могут храниться на сервере. В противном случае в секции отображается уведомление о том, что хранение резервных копий не настроено, и доступно только восстановление из загруженного файла.

Нажмите **Создать резервную копию...**, чтобы создать резервную копию. Она создается как фоновая задача и затем появляется в списке хранимых резервных копий с датой, количеством людей и размером. Сервер хранит только самые новые резервные копии (пять по умолчанию) и автоматически удаляет более старые. Количество резервных копий, которые можно создать за день, также ограничено.

Для каждой хранимой резервной копии вы можете:

- **Скачать** её в виде файла `.tar`, например, чтобы сохранить копию в другом месте.
- **Восстановить** её, как описано ниже.
- **Удалить** её после подтверждения.

Резервная копия, созданная с помощью более новой версии Gramps Web, чем та, что работает на сервере, помечается значком предупреждения и не может быть восстановлена.

### Восстановление из резервной копии

Восстанавливает дерево из хранимой резервной копии или из загруженного файла. Чтобы восстановить хранимую резервную копию, нажмите кнопку восстановления рядом с ней. Чтобы восстановить из файла, выберите резервную копию Gramps Web (`.tar`) или файл Gramps XML (`.gramps`) и нажмите **Восстановить**.

!!! danger
    Восстановление данных является разрушительной заменой, а не слиянием. Любой существующий объект, отсутствующий в резервной копии, будет удалён.

Для резервной копии Gramps Web появляется диалог, в котором показывается, когда была сделана резервная копия, для какого дерева и с какой версией, и позволяет выбрать, какие части восстановить:

- **Данные** – объекты семейного дерева
- **Настройки дерева** – настройки этой страницы, такие как цвета темы, название приложения и заметка на главной странице
- **Пользователи** – пользователи дерева

Нажмите **Предварительный просмотр**, чтобы увидеть, что изменится при восстановлении. Файл Gramps XML содержит только данные, поэтому для такого файла предварительный просмотр начинается сразу. Вам будет предложено повторно аутентифицироваться, если ваша сессия недостаточно свежа. Предварительный просмотр выполняется как фоновая задача и, по завершении, открывает диалог, обобщающий изменения по типу объекта (люди, семьи, события, места, цитаты, источники, репозитории, медиаобъекты, заметки, теги), а также для настроек дерева и пользователей, если они выбраны:

- **Добавить** – объекты, присутствующие в резервной копии, но отсутствующие в текущем дереве
- **Обновить** – объекты, присутствующие в обоих, которые отличаются
- **Удалить** – объекты в текущем дереве, отсутствующие в резервной копии
- **Без изменений** – объекты, идентичные в обоих

Если какие-либо объекты будут удалены, диалог предупреждает, сколько. Просмотрите сводку, затем нажмите **Восстановить**, чтобы применить изменения, или **Отмена**, чтобы прервать.

После восстановления пользователи, добавленные из резервной копии, перечисляются. Им присваивается случайный пароль, поэтому им необходимо сбросить свой пароль, прежде чем они смогут войти. Пользователи, которые уже существуют на сервере, никогда не изменяются. Также перечисляются медиаобъекты, файлы которых отсутствуют на сервере; загрузите их через [Импорт медиаархива](#import-media-archive).

!!! note
    Восстановление данных восстанавливает только данные объектов и ссылки на медиа. Сами бинарные медиафайлы и метаданные дерева (по умолчанию, закладки, группы имен) не затрагиваются.

!!! tip
    Используйте это, чтобы откатить дерево к известной хорошей резервной копии, например, после неудачного импорта или нежелательного массового редактирования.

## Опасная зона

!!! danger
    Действия в Опасной зоне являются **необратимыми**. Сделайте [резервную копию](#backups) перед продолжением.

### Удалить все объекты

Удаляет объекты из семейного дерева. Нажатие на **Удалить** открывает диалог, в котором вы можете выбрать, что удалить:

- **Все объекты** – полностью очищает дерево
- **Определенные типы объектов** – например, только события или только медиаобъекты

Вам будет предложено повторно аутентифицироваться (войти снова), чтобы подтвердить действие. Удаление выполняется как фоновая задача, и отображается индикатор прогресса.

!!! warning
    Удаление только подмножества типов объектов (вместо всех объектов сразу) может занять очень много времени для больших деревьев, так как сервер должен проверить и обновить все связи между объектами.

!!! tip
    Используйте это, чтобы начать с чистого листа перед импортом нового дерева или чтобы удалить конкретные типы объектов, которые были импортированы неправильно.
