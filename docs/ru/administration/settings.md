# Настройки администрирования

Страница **Настройки > Администрирование** доступна через иконку пользователя в верхней панели приложения. Она доступна только пользователям с ролью Владельца или Администратора и предоставляет инструменты для управления базой данных семейного дерева.

Страница организована в сворачиваемые разделы. Нажмите заголовок раздела, чтобы развернуть его.

## Данные

Охватывает квоты использования, импорт данных и управление медиафайлами.

### Квоты использования

В верхней части раздела отображается текущее использование относительно любых настроенных лимитов:

- **Люди** – количество объектов людей в дереве по сравнению с установленным максимумом (∞ если неограничено)
- **Хранение медиа** – общий размер загруженных медиафайлов по сравнению с установленной квотой хранения (∞ если неограничено)

Квоты устанавливаются администратором сервера; см. [Конфигурация сервера](../install_setup/configuration.md) для получения подробной информации.

### Импорт данных

Раздел импорта позволяет загружать файл семейного дерева или медиаархив. См. [Импорт данных](import.md) для получения полных инструкций.

### Статус медиафайлов

В этом разделе отображается:

- Общее количество медиаобъектов в дереве и есть ли среди них объекты без контрольной суммы
- Количество медиаобъектов, файл которых отсутствует на сервере

Зеленая галочка указывает на то, что все в порядке. Если обнаружены проблемы, отображаются ссылки на затронутые объекты. Отсутствующие контрольные суммы обычно возникают, когда данные были импортированы из формата, такого как GEDCOM, который включает ссылки на медиа, но не сами файлы. Отсутствующие файлы можно загрузить через функцию импорта медиаархива.

### Импорт медиаархива

Позволяет загружать ZIP-файл медиафайлов для заполнения отсутствующих файлов. См. [Импорт данных](import.md) для получения полных инструкций.

## Индекс поиска

### Управление индексом поиска

Gramps Web поддерживает полнотекстовый индекс поиска, который обычно обновляется автоматически при изменении данных. Индикатор статуса показывает, сколько объектов в настоящее время индексируется по сравнению с общим количеством объектов.

Нажмите **Обновить индекс поиска**, чтобы инициировать полное перестроение. Индикатор прогресса отображается, пока задача выполняется в фоновом режиме. Это редко требуется.

Если у дерева еще нет индекса поиска, например, после обновления сервера, которое изменило формат индекса, Gramps Web создает его в фоновом режиме в первый раз, когда дерево открывается. Пока он создается, раздел показывает "Индекс поиска создается." вместо количеств, **Обновить индекс поиска** отключен, и результаты поиска могут быть неполными. Создание отображается в [Уведомлениях](../user-guide/notifications.md) как задача "Обновить индекс поиска".

## Настройки дерева

### Название семейного дерева

!!! note
    Переименование дерева работает только в [настройке с несколькими деревьями](../install_setup/multi-tree.md) или когда `TREE_ID` явно установлен в [конфигурации сервера](../install_setup/configuration.md). В стандартной установке с одним деревом без установленного `TREE_ID` это вызовет ошибку.

Это позволяет изменить название базовой базы данных семейного дерева Gramps. Введите новое имя и нажмите **Переименовать**, чтобы применить.

!!! tip
    Если вы хотите изменить только имя, отображаемое в панели приложения, не переименовывая базу данных, используйте вместо этого настройку [Название приложения](#app-title).

### Информация о исследователе

Установите имя, адрес и контактные данные основного исследователя. Эта информация встраивается в экспорты (например, файлы GEDCOM).

## Настройка

### Цвета темы

Установите пользовательский **основной цвет** и **акцентный цвет** для интерфейса Gramps Web. Эти цвета применяются ко всем пользователям этого дерева и вступают в силу немедленно после сохранения.

Используйте выбор цветов, чтобы выбрать цвета, затем нажмите **Сохранить**. Нажмите **Сбросить**, чтобы вернуться к значениям по умолчанию.

### Название приложения

Установите пользовательское название для приложения. Если установлено, это переопределяет название семейного дерева в строке заголовка браузера и в верхней панели приложения.

Введите название и нажмите **Сохранить**. Оставьте пустым, чтобы использовать значение по умолчанию (название семейного дерева).

### Заметка на главной странице

Выберите объект **Заметка** Gramps для отображения на главной странице панели управления. Содержимое заметки отображается под основными колонками панели управления и видно всем пользователям, имеющим доступ к дереву.

Используйте селектор объектов, чтобы найти и выбрать заметку, затем сохраните. Нажмите **Удалить**, чтобы очистить текущую заметку на главной странице.

### Изображение на главной странице

Выберите объект **Медиа** Gramps для отображения в качестве изображения на главной странице панели управления. В сочетании с заметкой на главной странице изображение отображается рядом с текстом заметки. Без заметки отображается только изображение.

Используйте селектор объектов, чтобы найти и выбрать медиаобъект, затем сохраните. Нажмите **Удалить**, чтобы очистить текущее изображение на главной странице.

### Настройки экспорта/импорта

Настройки на уровне дерева (название приложения, цвета темы, заметка/изображение на главной странице и т. д.) могут быть экспортированы в виде JSON-файла для резервного копирования или копирования в другой экземпляр Gramps Web.

- Нажмите **Экспортировать настройки**, чтобы скачать текущие настройки в виде JSON-файла.
- Нажмите **Импортировать настройки дерева**, чтобы загрузить ранее экспортированный JSON-файл и применить настройки.

## Обработка семейного дерева

### Проверка и восстановление базы данных

Этот инструмент проверяет базу данных Gramps на внутренние несоответствия и исправляет те, которые может – аналогично инструменту [Проверка и восстановление базы данных](https://www.gramps-project.org/wiki/index.php/Gramps_5.2_Wiki_Manual_-_Tools#Check_and_Repair_Database) в Gramps Desktop.

Нажмите **Проверить и восстановить** и дождитесь завершения индикатора прогресса. Результат отображается под кнопкой:

- Если ошибок не найдено, отображается сообщение подтверждения.
- Если ошибки найдены, отображается сводка примененных исправлений.

Запустите этот инструмент, если вы столкнулись с неожиданными ошибками или поведением, которые могут быть вызваны несоответствиями в базе данных, такими как отсутствующие отношения между объектами.

### Проверка данных

В то время как [Проверка и восстановление базы данных](#check-and-repair-database) ищет *технические* несоответствия, этот инструмент ищет *неправдоподобные* данные – аналогично инструменту [Проверка данных](https://gramps-project.org/wiki/index.php/Gramps_5.0_Wiki_Manual_-_Tools#Verify_the_Data) в Gramps Desktop. Он сообщает о вещах, которые не невозможны, но достаточно маловероятны, чтобы на них стоило обратить внимание, таких как мать в возрасте 12 лет или человек, доживший до 130 лет.

В разделе **Опции** вы можете настроить пороги, которые используют тесты – максимальный возраст, минимальный и максимальный возраст для вступления в брак или для рождения детей, максимальное количество детей и так далее – а также решать, следует ли оценивать отсутствующие или неточные даты и следует ли сообщать о недействительных датах, таких как 31 февраля.

Нажмите **Проверить данные**, чтобы начать. Проверка выполняется как фоновая задача, а результаты затем перечисляются в разделе **Результаты проверки данных**. Этот инструмент ничего не изменяет: он только сообщает о том, что находит.

!!! note
    Находка не является доказательством ошибки. Долгая жизнь и большие возрастные разрывы действительно случаются, поэтому рассматривайте результаты как список вещей для проверки, а не как список вещей для исправления.

## Теги

### Управление тегами

Создавайте, переименовывайте, изменяйте цвет и удаляйте [теги](../user-guide/tags.md) для семейного дерева. Теги хранятся в базе данных Gramps, общие для всех пользователей и полностью совместимы с Gramps Desktop.

Нажмите **Новый тег**, чтобы создать тег. Используйте элементы управления рядом с существующим тегом, чтобы переименовать его (значок карандаша), изменить его цвет (выбор цвета) или удалить его (значок удаления).

!!! note
    Удаление тега удаляет его из всех объектов, к которым он был применен.

См. [Теги](../user-guide/tags.md) для получения информации о том, как теги используются во всем Gramps Web, включая специальные теги `Blog` и `ToDo`.

## Резервные копии

Резервная копия содержит данные семейного дерева, включая частные записи, настройки дерева и пользователей дерева. Медиафайлы не включены; см. [Резервное копирование ваших медиафайлов](export.md#back-up-your-media-files).

### Хранение резервных копий

Если администратор сервера настроил директорию резервного копирования (`BACKUP_DIR`, см. [Конфигурация сервера](../install_setup/configuration.md)), резервные копии могут храниться на сервере. В противном случае раздел показывает уведомление о том, что хранение резервных копий не настроено, и доступно только восстановление из загруженного файла.

Нажмите **Создать резервную копию...**, чтобы создать резервную копию. Она создается как фоновая задача и затем появляется в списке хранящихся резервных копий с датой, количеством людей и размером. Сервер хранит только самые новые резервные копии (пять по умолчанию) и автоматически удаляет более старые. Количество резервных копий, которые можно создать за день, также ограничено.

Для каждой хранящейся резервной копии вы можете:

- **Скачать** ее в виде файла `.tar`, например, чтобы сохранить копию в другом месте.
- **Восстановить** ее, как описано ниже.
- **Удалить** ее после подтверждения.

Резервная копия, созданная с помощью более новой версии Gramps Web, чем та, что работает на сервере, помечается значком предупреждения и не может быть восстановлена.

### Восстановление из резервной копии

Восстанавливает дерево из хранящейся резервной копии или из загруженного файла. Чтобы восстановить хранящуюся резервную копию, нажмите кнопку восстановления рядом с ней. Чтобы восстановить из файла, выберите резервную копию Gramps Web (`.tar`) или файл Gramps XML (`.gramps`) и нажмите **Восстановить**.

!!! danger
    Восстановление данных является разрушительной заменой, а не слиянием. Любой существующий объект, отсутствующий в резервной копии, будет удален.

Для резервной копии Gramps Web диалог показывает, когда была сделана резервная копия, для какого дерева и с какой версией, и позволяет выбрать, какие части восстановить:

- **Данные** – объекты семейного дерева
- **Настройки дерева** – настройки этой страницы, такие как цвета темы, название приложения и заметка на главной странице
- **Пользователи** – пользователи дерева

Нажмите **Предварительный просмотр**, чтобы увидеть, что изменится при восстановлении. Файл Gramps XML содержит только данные, поэтому для такого файла предварительный просмотр начинается сразу. Вам будет предложено повторно пройти аутентификацию, если ваша сессия недостаточно свежа. Предварительный просмотр выполняется как фоновая задача, и, как только он завершится, открывается диалог с резюме изменений по типу объекта (люди, семьи, события, места, цитаты, источники, репозитории, медиаобъекты, заметки, теги), а также для настроек дерева и пользователей, если они выбраны:

- **Добавить** – объекты, присутствующие в резервной копии, но отсутствующие в текущем дереве
- **Обновить** – объекты, присутствующие в обоих, которые отличаются
- **Удалить** – объекты в текущем дереве, отсутствующие в резервной копии
- **Без изменений** – объекты, идентичные в обоих

Если какие-либо объекты будут удалены, диалог предупреждает, сколько. Просмотрите сводку, затем нажмите **Восстановить**, чтобы применить изменения, или **Отмена**, чтобы прервать.

После восстановления пользователи, добавленные из резервной копии, перечисляются. Им назначается случайный пароль, поэтому им нужно сбросить свой пароль, прежде чем они смогут войти в систему. Пользователи, которые уже существуют на сервере, никогда не изменяются. Также перечисляются медиаобъекты, файлы которых отсутствуют на сервере; загрузите их через [Импорт медиаархива](#import-media-archive).

!!! note
    Восстановление данных восстанавливает только данные объектов и ссылки на медиа. Бинарные медиафайлы сами по себе и метаданные дерева (стандартный человек, закладки, группы имен) не затрагиваются.

!!! tip
    Используйте это, чтобы откатить дерево к известной хорошей резервной копии, например, после неудачного импорта или нежелательного массового редактирования.

## Зона опасности

!!! danger
    Действия в Зоне опасности являются **необратимыми**. Сделайте [резервную копию](#backups) перед продолжением.

### Удалить все объекты

Удаляет объекты из семейного дерева. Нажатие **Удалить** открывает диалог, где вы можете выбрать, чтобы удалить:

- **Все объекты** – полностью очищает дерево
- **Определенные типы объектов** – например, только события или только медиаобъекты

Вам будет предложено повторно пройти аутентификацию (войти снова), чтобы подтвердить действие. Удаление выполняется как фоновая задача, и отображается индикатор прогресса.

!!! warning
    Удаление только подмножества типов объектов (вместо всех объектов сразу) может занять очень много времени для больших деревьев, так как сервер должен проверить и обновить все отношения между объектами.

!!! tip
    Используйте это, чтобы начать с чистого листа перед импортом нового дерева или для удаления конкретных типов объектов, которые были импортированы неправильно.
