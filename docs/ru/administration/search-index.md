# Индекс поиска

Раздел **Индекс поиска** в [Настройках администрирования](settings.md) показывает состояние полнотекстового индекса поиска и позволяет вам восстановить его.

## Управление индексом поиска

Gramps Web поддерживает полнотекстовый индекс поиска, который обычно обновляется автоматически при изменении данных. Индикатор состояния показывает, сколько объектов в настоящее время проиндексировано по сравнению с общим количеством объектов.

Нажмите **Обновить индекс поиска**, чтобы инициировать полное восстановление. Индикатор прогресса отображается, пока задача выполняется в фоновом режиме. Это редко требуется.

Если у дерева еще нет индекса поиска, например, после обновления сервера, которое изменило формат индекса, Gramps Web создает его в фоновом режиме при первом открытии дерева. Пока он создается, в разделе отображается "Индекс поиска создается." вместо подсчетов, **Обновить индекс поиска** отключен, и результаты поиска могут быть неполными. Создание отображается в [Уведомлениях](../user-guide/notifications.md) как задача "Обновить индекс поиска".
