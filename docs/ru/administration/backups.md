# Резервное копирование и восстановление

Владельцы дерева могут создавать, загружать и восстанавливать резервные копии дерева в разделе **Резервные копии** настроек [Администрирования](settings.md).

Резервная копия содержит данные о семейном дереве, включая приватные записи, настройки дерева и пользователей дерева. Медиафайлы не включены; см. [Резервное копирование ваших медиафайлов](export.md#back-up-your-media-files).

## Хранимые резервные копии

Если администратор сервера настроил директорию для резервных копий (`BACKUP_DIR`, см. [Конфигурация сервера](../install_setup/configuration.md)), резервные копии могут храниться на сервере. В противном случае в разделе отображается уведомление о том, что хранение резервных копий не настроено, и доступно только восстановление из загруженного файла.

Нажмите **Создать резервную копию...**, чтобы создать резервную копию. Она создается как фоновая задача и затем появляется в списке хранимых резервных копий с указанием даты, количества людей и размера. Сервер хранит только самые новые резервные копии (по умолчанию пять) и автоматически удаляет более старые. Также ограничено количество резервных копий, которые могут быть созданы за день.

Для каждой хранимой резервной копии вы можете:

- **Скачать** ее в виде файла `.tar`, например, чтобы сохранить копию в другом месте.
- **Восстановить** ее, как описано ниже.
- **Удалить** ее после подтверждения.

Резервная копия, созданная с помощью более новой версии Gramps Web, чем та, что работает на сервере, помечается значком предупреждения и не может быть восстановлена.

## Восстановление из резервной копии

Восстанавливает дерево из хранимой резервной копии или из загруженного файла. Чтобы восстановить хранимую резервную копию, нажмите кнопку восстановления рядом с ней. Чтобы восстановить из файла, выберите резервную копию Gramps Web (`.tar`) или файл Gramps XML (`.gramps`) и нажмите **Восстановить**.

!!! danger
    Восстановление данных является разрушительной заменой, а не слиянием. Любой существующий объект, отсутствующий в резервной копии, будет удален.

Для резервной копии Gramps Web появляется диалог, в котором указывается, когда была сделана резервная копия, для какого дерева и с какой версией, и позволяет выбрать, какие части восстановить:

- **Данные** – объекты семейного дерева
- **Настройки дерева** – настройки страницы Администрирования, такие как цвета темы, название приложения и заметка на главной странице
- **Пользователи** – пользователи дерева

Нажмите **Предварительный просмотр**, чтобы увидеть, что изменится после восстановления. Файл Gramps XML содержит только данные, поэтому для такого файла предварительный просмотр начинается сразу. Вам будет предложено повторно аутентифицироваться, если ваша сессия недостаточно свежа. Предварительный просмотр выполняется как фоновая задача и, по завершении, открывает диалог, подводящий итоги изменений по типу объекта (люди, семьи, события, места, цитаты, источники, репозитории, медиаобъекты, заметки, теги), а также для настроек дерева и пользователей, если они выбраны:

- **Добавить** – объекты, присутствующие в резервной копии, но отсутствующие в текущем дереве
- **Обновить** – объекты, присутствующие в обоих, но отличающиеся
- **Удалить** – объекты в текущем дереве, отсутствующие в резервной копии
- **Без изменений** – объекты, идентичные в обоих

Если какие-либо объекты будут удалены, диалог предупреждает, сколько. Просмотрите сводку, затем нажмите **Восстановить**, чтобы применить изменения, или **Отмена**, чтобы прервать.

После восстановления пользователи, добавленные из резервной копии, будут перечислены. Им будет выдан случайный пароль, поэтому им необходимо сбросить свой пароль, прежде чем они смогут войти в систему. Пользователи, которые уже существуют на сервере, никогда не изменяются. Медиаобъекты, файлы которых отсутствуют на сервере, также будут перечислены; загрузите их через [Импорт медиафайлов](import-media.md).

!!! note
    Восстановление данных восстанавливает только данные объектов и ссылки на медиа. Сами бинарные медиафайлы и метаданные дерева (по умолчанию, человек, закладки, группы имен) не затрагиваются.

!!! tip
    Используйте это, чтобы откатить дерево к известной хорошей резервной копии, например, после неудачного импорта или нежелательного массового редактирования.

## Gramps XML как резервная копия

Если хранение резервных копий недоступно или вы хотите просто сохранить копию данных семейного дерева, [экспортируйте](export.md) дерево в формате Gramps XML. Такой файл также может быть восстановлен через [Восстановление из резервной копии](#restore-from-backup).

Обратите внимание, что если у вашего пользователя Gramps Web нет разрешения на просмотр приватных записей, экспорт не будет полным резервным копированием, так как он не будет содержать никаких приватных записей.
