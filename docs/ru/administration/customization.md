# Настройка дерева

Владельцы деревьев и администраторы могут адаптировать название и внешний вид дерева, а также его домашнюю страницу для всех пользователей. Эти настройки находятся в разделах **Настройки дерева** и **Настройка** в [Настройках администрирования](settings.md).

## Название семейного дерева

!!! note
    Переименование дерева работает только в [настройке с несколькими деревьями](../install_setup/multi-tree.md) или когда `TREE_ID` явно установлен в [конфигурации сервера](../install_setup/configuration.md). В стандартной установке с одним деревом без установленного `TREE_ID` это вызовет ошибку.

Это позволяет изменить название базовой базы данных семейного дерева Gramps. Введите новое название и нажмите **Переименовать**, чтобы применить изменения.

!!! tip
    Если вы хотите изменить только название, отображаемое в панели приложения, не переименовывая базу данных, используйте настройку [Заголовок приложения](#app-title).

## Информация о исследователе

Установите имя, адрес и контактные данные основного исследователя. Эта информация встраивается в экспорты (например, файлы GEDCOM).

## Цвета темы

Установите пользовательский **основной цвет** и **акцентный цвет** для веб-интерфейса Gramps. Эти цвета применяются ко всем пользователям этого дерева и вступают в силу сразу после сохранения.

Используйте выбор цветов, чтобы выбрать цвета, затем нажмите **Сохранить**. Нажмите **Сбросить**, чтобы вернуть значения по умолчанию.

## Заголовок приложения

Установите пользовательский заголовок для приложения. Если установлен, он заменяет название семейного дерева в строке заголовка браузера и в верхней панели приложения.

Введите заголовок и нажмите **Сохранить**. Оставьте пустым, чтобы использовать значение по умолчанию (название семейного дерева).

## Заметка на домашней странице

Выберите объект **Заметка** Gramps для отображения на домашней странице панели управления. Содержимое заметки отображается под основными колонками панели управления и видно всем пользователям, имеющим доступ к дереву.

Используйте селектор объектов, чтобы найти и выбрать заметку, затем сохраните. Нажмите **Удалить**, чтобы очистить текущую заметку на домашней странице.

## Изображение на домашней странице

Выберите объект **Медиа** Gramps для отображения в качестве изображения на домашней странице панели управления. В сочетании с заметкой на домашней странице изображение появляется рядом с текстом заметки. Без заметки отображается только изображение.

Используйте селектор объектов, чтобы найти и выбрать медиа-объект, затем сохраните. Нажмите **Удалить**, чтобы очистить текущее изображение на домашней странице.

## Настройки экспорта/импорта

Настройки на уровне дерева (заголовок приложения, цвета темы, заметка/изображение на домашней странице и т.д.) могут быть экспортированы в файл JSON для резервного копирования или для копирования в другой экземпляр Gramps Web.

- Нажмите **Экспортировать настройки**, чтобы скачать текущие настройки в виде файла JSON.
- Нажмите **Импортировать настройки дерева**, чтобы загрузить ранее экспортированный файл JSON и применить настройки.
