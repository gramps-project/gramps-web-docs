# Импорт медиафайлов

Если вы [импортировали семейное дерево](import.md) и вам нужно загрузить соответствующие медиафайлы, используйте **Импорт медиафайлов** на [странице импорта](import.md), ниже импорта семейного дерева. Ожидается ZIP-файл, содержащий недостающие медиафайлы. Загрузка возможна только после того, как дерево содержит медиаобъекты, поскольку файлы сопоставляются с существующими медиаобъектами – файл семейного дерева только ссылается на свои медиафайлы, поэтому сначала импортируйте его.

Файлы сопоставляются с медиаобъектами в вашем дереве одним из двух способов:

- **По контрольной сумме.** Для медиаобъектов, у которых есть контрольная сумма – как это происходит для деревьев, импортированных из Gramps Desktop – используется файл с совпадающей контрольной суммой, независимо от его имени или структуры папок в ZIP-файле. Это работает только в том случае, если контрольные суммы в базе данных Gramps правильные, что гарантирует запуск инструмента проверки и восстановления.
- **По пути или имени файла.** Медиаобъекты без контрольной суммы – как это обычно бывает после импорта GEDCOM – сопоставляются по относительному пути, хранящемуся в медиаобъекте. Если ни один файл в ZIP не имеет этого пути, они сопоставляются только по имени файла, игнорируя регистр (с версии Gramps Web API 3.26). Это также работает для абсолютных путей из других программ, таких как `C:\Users\...\Family\grandpa.jpg`, так что вы можете просто поместить все файлы в ZIP-файл. Имя файла используется только в том случае, если оно уникально, как в ZIP-файле, так и среди медиаобъектов, которые все еще не имеют файла.

После загрузки результат показывает, для скольких медиаобъектов был найден файл, и перечисляет те, для которых в ZIP-файле не было файла, с их Gramps ID и сохраненным путем. Используйте этот список, чтобы найти недостающие файлы, затем загрузите другой ZIP-файл только с ними – файлы, которые уже находятся на сервере, не затрагиваются.

Если несколько медиаобъектов имеют одинаковое имя файла в разных папках, сопоставление по имени файла не работает для них. Либо воссоздайте структуру папок из сохраненных путей в ZIP-файле, либо сначала импортируйте все в Gramps Desktop, который имеет больше возможностей для связывания существующих медиафайлов с импортированным деревом, а затем переходите к Gramps Web, как описано в [Переходе из Gramps Desktop](import.md#coming-from-gramps-desktop).

## Статус медиафайлов

Раздел **Данные** в [Настройках администрирования](settings.md) показывает:

- Общее количество медиаобъектов в дереве и есть ли среди них те, у которых отсутствует контрольная сумма
- Количество медиаобъектов, для которых связанный файл отсутствует на сервере

Зеленая галочка указывает на то, что все в порядке. Если обнаружены проблемы, отображаются ссылки на затронутые объекты. Отсутствующие контрольные суммы обычно возникают, когда данные были импортированы из формата, такого как GEDCOM, который включает ссылки на медиа, но не сами файлы. Недостающие файлы можно загрузить, как описано выше.
