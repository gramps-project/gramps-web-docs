# Импорт медиафайлов

Если вы [импортировали семейное дерево](import.md) и вам нужно загрузить соответствующие медиафайлы, используйте **Импорт медиафайлов** в разделе Данные настроек [Администрации](settings.md). Ожидается ZIP-файл, содержащий недостающие медиафайлы. Файлы сопоставляются с медиаобъектами в вашем дереве одним из двух способов:

- **По контрольной сумме.** Для медиаобъектов, у которых есть контрольная сумма – как это происходит для деревьев, импортированных из Gramps Desktop – используется файл с совпадающей контрольной суммой, независимо от его имени или структуры папок в ZIP-файле. Это работает только в том случае, если контрольные суммы в базе данных Gramps корректны, что обеспечивает запуск инструмента проверки и восстановления.
- **По пути.** Медиаобъекты без контрольной суммы – как это обычно бывает после импорта GEDCOM – сопоставляются по их пути: ZIP-файл должен содержать файл точно по относительному пути, хранящемуся в медиаобъекте.

Если пути, хранящиеся в вашем файле GEDCOM, являются абсолютными (например, `C:\Users\...\photo.jpg`), сопоставление по пути не будет работать. В этом случае рекомендуется сначала импортировать все в Gramps Desktop, который имеет больше возможностей для связывания существующих медиафайлов с импортированным деревом, а затем перейти к Gramps Web, как описано в [Переходе из Gramps Desktop](import.md#coming-from-gramps-desktop).

## Статус медиафайлов

Раздел **Данные** настроек [Администрации](settings.md) показывает:

- Общее количество медиаобъектов в дереве и есть ли среди них недостающие контрольные суммы
- Количество медиаобъектов, связанные файлы которых отсутствуют на сервере

Зеленая галочка указывает на то, что все в порядке. Если обнаружены проблемы, отображаются ссылки на затронутые объекты. Недостающие контрольные суммы обычно возникают, когда данные были импортированы из формата, такого как GEDCOM, который включает ссылки на медиафайлы, но не сами файлы. Недостающие файлы можно загрузить, как описано выше.
