# Импорт медиафайлов

Если вы [импортировали семейное дерево](import.md) и необходимо загрузить соответствующие медиафайлы, используйте **Импорт медиафайлов** в разделе Данные настроек [Администрирования](settings.md). Ожидается, что это будет ZIP-файл, содержащий недостающие медиафайлы. Файлы сопоставляются с медиаобъектами в вашем дереве одним из двух способов:

- **По контрольной сумме.** Для медиаобъектов, у которых есть контрольная сумма – как это происходит для деревьев, импортированных из Gramps Desktop – используется файл с совпадающей контрольной суммой, независимо от его имени или структуры папок в ZIP-файле. Это работает только в том случае, если контрольные суммы в базе данных Gramps корректны, что обеспечивает запуск инструмента проверки и восстановления.
- **По пути.** Медиаобъекты без контрольной суммы – как это обычно бывает после импорта GEDCOM – сопоставляются по их пути: ZIP-файл должен содержать файл точно по относительному пути, хранящемуся в медиаобъекте.

Если пути, хранящиеся в вашем файле GEDCOM, абсолютные (например, `C:\Users\...\photo.jpg`), сопоставление по пути не будет работать. В этом случае рекомендуется сначала импортировать все в Gramps Desktop, который имеет больше возможностей для связывания существующих медиафайлов с импортированным деревом, а затем перейти к Gramps Web, как описано в [Переходе из Gramps Desktop](import.md#coming-from-gramps-desktop).
