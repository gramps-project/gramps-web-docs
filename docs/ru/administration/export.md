# Экспорт данных

Страница экспорта позволяет вам скачать данные семейного дерева в различных форматах, а также архив всех медиафайлов.

## Экспорт семейного дерева в формате Gramps XML

Чтобы получить копию данных семейного дерева, откройте страницу экспорта в Gramps Web и выберите формат Gramps XML. Нажатие на "экспорт" сгенерирует файл и начнет загрузку, как только он будет готов.

Обратите внимание, что если у вашего пользователя Gramps Web нет разрешения на просмотр частных записей, экспорт не будет содержать никаких частных записей.

## Резервное копирование вашего семейного дерева

Для полного резервного копирования дерева – включая его настройки и пользователей – смотрите [Резервное копирование и восстановление](backups.md). Экспорт в формате Gramps XML может служить резервной копией только данных семейного дерева и может быть восстановлен через [Восстановление из резервной копии](backups.md#restore-from-backup).

## Поделитесь своим семейным деревом с пользователями других генеалогических программ

Когда обмен генеалогическими данными в формате Gramps XML невозможен, вы также можете экспортировать файл GEDCOM. Обратите внимание, что это не подходит в качестве резервной копии вашего дерева Gramps Web.

## Резервное копирование ваших медиафайлов

Чтобы сделать резервную копию ваших медиафайлов, вы можете создать и скачать ZIP-архив всех медиафайлов на странице экспорта.

Обратите внимание, что, особенно для больших деревьев, это может быть затратной операцией для сервера и должно выполняться только в случае крайней необходимости. По этой причине количество медиаархивов, которые можно создать, ограничено (по умолчанию – один в час). Если вы достигнете лимита, появится сообщение об ошибке.

Лучший вариант для регулярного резервного копирования ваших медиафайлов – использовать [дополнение Gramps Web Sync](sync.md) (которое само по себе не является решением для резервного копирования) и создавать инкрементные резервные копии на вашем локальном компьютере.

В обоих случаях, если у вашего пользователя Gramps Web нет разрешения на просмотр частных записей, экспорт не будет содержать файлы частных медиаобъектов.

## Перемещение в другую инстанцию Gramps Web

Gramps Web не привязывает вас к конкретному провайдеру, и вы всегда можете перейти на другую инстанцию Gramps Web, не теряя никаких данных и не имея прямого доступа к серверам.

Чтобы осуществить полную миграцию, выполните следующие шаги (при условии, что у вас есть права владельца дерева):

1. Перейдите на страницу экспорта и экспортируйте ваше дерево в файл Gramps XML (`.gramps`). Если вы используете [дополнение Sync](sync.md), вы также можете сгенерировать экспорт в настольной версии Gramps.
2. На странице экспорта создайте и скачайте архив медиафайлов. Если вы используете [дополнение Sync](sync.md), вы также можете просто ZIP-овать вашу локальную папку медиафайлов Gramps.
3. Перейдите в Настройки > Администрирование > Управление пользователями и нажмите кнопку "Экспортировать данные пользователей". Это загрузит файл JSON.
4. В новой инстанции Gramps Web откройте страницу импорта. Импортируйте файл `.gramps`, экспортированный на шаге 1.
5. На странице импорта новой инстанции Gramps Web загрузите архив медиафайлов (ZIP).
6. Перейдите в Настройки > Администрирование > Управление пользователями новой инстанции Gramps Web. Нажмите кнопку "Импортировать учетные записи пользователей" и загрузите файл JSON, загруженный на шаге 3.

Обратите внимание, что, хотя ваши учетные записи пользователей будут мигрированы, всем вашим пользователям необходимо будет установить новые пароли, используя ссылку "забыли пароль", так как пароли хранятся в зашифрованном виде и не могут быть экспортированы.
