# Управление пользователями

Интерфейс управления пользователями доступен через **Настройки > Управление пользователями** (иконка пользователя в верхней панели приложения). Он доступен только пользователям с ролью Владелец или Администратор.

## Роли пользователей

Смотрите [Система пользователей](../install_setup/users.md) для полного описания доступных ролей пользователей и их прав.

## Просмотр и фильтрация пользователей

Страница управления пользователями отображает таблицу всех зарегистрированных учетных записей пользователей с следующими столбцами:

- **Имя пользователя** – имя для входа
- **Полное имя** – отображаемое имя
- **E-mail** – адрес электронной почты пользователя
- **Роль** – назначенная роль (Гость, Участник, Контрибьютор, Редактор, Владелец или Администратор)
- **Источник учетной записи** – либо "Пароль" (локальная учетная запись), либо имя внешнего поставщика удостоверений (например, при использовании OIDC)

Используйте поле поиска и выпадающий список ролей в верхней части таблицы для фильтрации списка. Нажмите кнопку сброса фильтров, чтобы сбросить все фильтры.

## Редактирование пользователя

Нажмите на иконку редактирования (карандаш) в любой строке, чтобы открыть диалог редактирования. Вы можете изменить:

- Полное имя
- Адрес электронной почты
- Роль

Это основной способ **включить нового саморегистрированного пользователя**: измените его роль с *отключено* на любую активную роль (например, Участник или Редактор).

Адреса электронной почты не обязательно должны быть уникальными (с версии Gramps Web API 3.22), поэтому несколько учетных записей могут использовать один и тот же адрес.

Отключение пользователя или изменение его пароля завершает все его сессии в течение 15 минут.

!!! примечание
    Владельцы не могут редактировать, изменять пароль или удалять пользователей с более высокой ролью, таких как администратор сайта. Пользователи с одинаковой ролью, такие как два владельца дерева, могут управлять друг другом.

## Добавление пользователя вручную

Нажмите на иконку **добавить пользователя** (person-add) над таблицей, чтобы создать новую учетную запись пользователя напрямую без необходимости саморегистрации. Заполните имя пользователя, полное имя, адрес электронной почты, пароль и роль в диалоговом окне и нажмите **Сохранить**.

## Удаление пользователя

Нажмите на иконку удаления (мусор) в любой строке и подтвердите диалог. Это действие нельзя отменить.

!!! примечание
    Чтобы предотвратить ситуацию, когда дерево останется без кого-либо, кто может его администрировать, вы не можете понизить свою роль ниже Владельца или удалить свою учетную запись, если вы единственный Владелец или Администратор дерева. Сначала повысите другую учетную запись до Владельца. Администратор все еще может изменить или удалить последнего владельца дерева другого пользователя, так как он может назначить нового.

## Экспорт и импорт учетных записей пользователей

Эти кнопки полезны при [миграции на другую инстанцию Gramps Web](export.md).

- **Экспорт деталей пользователей** (иконка загрузки) – загружает JSON-файл, содержащий все учетные записи пользователей (без паролей, так как пароли хранятся в зашифрованном виде).
- **Импорт учетных записей пользователей** (иконка добавления группы) – загружает ранее экспортированный JSON-файл для массового создания учетных записей пользователей. Все импортированные пользователи должны будут установить новый пароль через ссылку "Забыли пароль", так как пароли не могут быть перенесены.

## Ссылка на регистрацию (только для многодеревьев)

В многодеревьевом режиме ссылка на регистрацию для новых пользователей отображается в верхней части страницы управления пользователями. Вы можете скопировать эту ссылку и поделиться ею с людьми, которых хотите пригласить зарегистрировать учетную запись на вашем дереве.

!!! примечание
    В однодеревьевом режиме есть общая ссылка "Зарегистрироваться" на странице входа; ссылка на регистрацию для каждого дерева нужна только в многодеревьевых установках.

## Разрешения на чат с ИИ

Если чат с ИИ был включен на сервере, выпадающий список в верхней части страницы позволяет вам контролировать, какие роли пользователей могут использовать функцию чата:

- Все (включая гостей)
- Участники и выше
- Контрибьюторы и выше
- Редакторы и выше
- Только владельцы и администраторы
- Никто (отключить чат для всех пользователей)
