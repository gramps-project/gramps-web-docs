# Поиск

Страница поиска доступна по нажатию на значок увеличительного стекла в верхней панели приложения или по нажатию клавиши `s` [горячей клавиши](shortcuts.md).

## Полнотекстовый поиск

Введите любой запрос в поле поиска и нажмите Enter (или нажмите кнопку поиска). Gramps Web ищет по всем типам объектов – людям, семьям, событиям, местам, источникам, цитатам, репозиториям, заметкам и медиа – и возвращает соответствующие результаты, отсортированные по релевантности.

Результаты показывают тип объекта, имя и краткое резюме. Нажмите на любой результат, чтобы открыть соответствующую страницу с деталями.

## Синтаксис поиска

- **Все слова должны совпадать.** `Müller Berlin` находит объекты, содержащие оба слова.
- **`or`** находит объекты, содержащие любое из слов, например, `Meyer or Maier`. `and` также можно вводить между словами, но это не имеет значения.
- `or` применяется к словам, непосредственно соседствующим с ним: `Meyer or Maier Berlin` означает "(Meyer или Maier) и Berlin". Скобки не поддерживаются.
- **Кавычки** соответствуют фразе, т.е. словам в этом порядке: `"Johann Georg"`.
- **Подстановочный знак:** завершающий `*` соответствует любому окончанию, например, `Mey*` соответствует "Meyer", "Meyers", "Meyerhofer" и т.д. Это также работает для фраз: `"Johann Georg"*`.
- `or` и `and` распознаются в любом регистре. Чтобы искать одно из этих слов, поместите его в кавычки.
- Слова не могут быть исключены; нет "not".

## Что находит поиск

- Акценты не обязательно должны совпадать: "Müller" также находит "Muller", а "muller" находит "Müller".
- Семьи и события также находятся по именам их людей, например, "Müller" находит семьи и события всех, кого зовут Müller. Эти результаты располагаются ниже прямых совпадений.
- Стандартные типы находятся по их названиям на вашем интерфейсном языке, например, "Taufe" находит крещения в немецком интерфейсе.
- Подчеркивания разделяют слова, поэтому "microfilm" находит медиафайл с именем `scanned_microfilm.png`.
- Пользователи, которые не могут просматривать частные записи, не находят объекты через частную информацию, такую как семья по имени частного члена.

## Фильтрация по типу объекта

Под полем поиска кнопки-переключатели для каждого типа объекта (Люди, Семьи, События, Места и т.д.) позволяют вам сузить результаты до одного или нескольких конкретных типов. По умолчанию ищутся все типы. Активирование одной или нескольких кнопок ограничивает результаты только этими типами.
