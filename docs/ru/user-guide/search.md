# Поиск

Страница поиска доступна по нажатию на иконку увеличительного стекла в верхней панели приложения или нажатием клавиши `s` [горячей клавиши](shortcuts.md).

## Полнотекстовый поиск

Введите любой запрос в поле поиска и нажмите Enter (или нажмите кнопку поиска). Gramps Web осуществляет поиск по всем типам объектов – людям, семьям, событиям, местам, источникам, цитатам, репозиториям, заметкам и медиа – и возвращает соответствующие результаты, отсортированные по релевантности.

Результаты показывают тип объекта, имя и краткое резюме. Нажмите на любой результат, чтобы открыть соответствующую страницу с деталями.

Знак `*` может использоваться как подстановочный знак, например, `Mey*` соответствует "Meyer", "Meyers", "Meyerhofer" и т.д.

## Фильтрация по типу объекта

Под полем поиска находятся кнопки-переключатели для каждого типа объекта (Люди, Семьи, События, Места и т.д.), которые позволяют вам сузить результаты до одного или нескольких конкретных типов. По умолчанию ищутся все типы. Активируя один или несколько переключателей, вы ограничиваете результаты только этими типами.

## Семантический поиск

!!! warning "Устарело"
    Семантический поиск устарел и будет удален в Gramps Web API 3.25. Полнотекстовый поиск, описанный выше, не затрагивается.

Если администратор сервера включил [семантический (на основе ИИ) поиск](../install_setup/chat.md#semantic-search-deprecated), в правом верхнем углу страницы поиска появляется переключатель режима с двумя вариантами:

- **Поиск** – стандартный полнотекстовый поиск (по умолчанию)
- **Семантический** – поиск на основе ИИ, который понимает смысл вашего запроса, а не просто сопоставляет точные слова

Семантический поиск полезен для запросов на естественном языке, таких как "фермер в Баварии в 19 веке". Он требует, чтобы индекс семантического поиска был заполнен; см. [Настройки администрирования](../administration/settings.md) для получения информации о том, как создать или обновить индекс.
