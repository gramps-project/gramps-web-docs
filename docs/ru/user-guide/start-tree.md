# Начало нового дерева

Эта страница проведет вас через первые шаги в пустом семейном дереве: добавление себя, добавление ваших родителей и просмотр результата на диаграмме семейного дерева. Это займет около 15 минут.

Если у вас уже есть семейное дерево в другой генеалогической программе или в Gramps Desktop, вам не нужно вводить его снова вручную – смотрите [Импорт данных](../administration/import.md).

!!! note
    Добавление людей требует роли Редактора или выше. Владелец дерева всегда имеет эту роль. См. [Система пользователей](../install_setup/users.md) для всех ролей.

## 1. Создайте место

В Gramps место создается один раз, а затем выбирается для каждого события, которое там произошло – например, для рождений нескольких братьев и сестер в одном городе. Вот почему место должно существовать, прежде чем вы сможете выбрать его как место рождения кого-то.

Чтобы создать место, где вы родились:

1. Нажмите кнопку **+** (Добавить) в верхней панели приложения и выберите **Место**.
2. Введите **Название** места и, при желании, его **Тип** (например, город или деревня).
3. При желании, нажмите **Выбрать на карте**, чтобы установить его координаты, чтобы место появилось на [карте](map.md).
4. Нажмите **Добавить**.

Создайте места рождения ваших родителей таким же образом. Если вы еще не знаете место, пропустите его – вы можете добавить его позже.

## 2. Добавьте себя

Вернитесь на главную страницу. Пока дерево пустое, оно показывает карточку **Начать**. Нажмите **Новый человек**, чтобы открыть форму для нового человека:

- **Имя** – ваше имя и фамилия
- **Пол**
- **Дата рождения** – смотрите [Ввод дат](#entering-dates) ниже
- **Место рождения** – нажмите **Выбрать существующее место** и найдите место, которое вы создали

Оставьте поля для даты смерти пустыми и нажмите **Добавить**. Откроется страница нового человека.

Первый созданный человек в пустом дереве автоматически становится вашим **Домашним человеком**: человеком, с которого начинается диаграмма семейного дерева. Вы можете выбрать другого Домашнего человека в любое время на главной странице.

### Ввод дат

Дата вводится как отдельные поля для года, месяца и дня. Если вы знаете только год, заполните только год. Для неопределенных дат измените тип даты – например, на "примерно" или "до" – вместо того, чтобы угадывать точный день.

## 3. Добавьте своих родителей

1. Нажмите **Семейное дерево** в боковой панели. Диаграмма показывает вас как Домашнего человека.
2. Нажмите кнопку с карандашом в правом нижнем углу, чтобы включить режим редактирования.
3. Нажмите маленькую кнопку **+** на вашей карточке. Откроется диалог **Добавить члена семьи**.
4. Рядом с **Отец** нажмите значок **+**, чтобы создать нового человека, заполните форму как раньше и сохраните. Ваш отец появится на диаграмме, уже связанный с вами.
5. Повторите с **Матерью**.

Значок **ссылки** рядом с каждой связью соединяет человека, который уже существует в вашем дереве, вместо создания нового.

Таким же образом нажмите **+** на любой карточке в диаграмме, чтобы добавить родителей, детей или супруга этого человека. Каждое изменение сохраняется немедленно. Чтобы выйти из режима редактирования, нажмите кнопку закрытия в верхней панели приложения.

## 4. Посмотрите результат

Теперь диаграмма показывает вас с вашими родителями. Попробуйте другие типы диаграмм на вкладках в верхней части страницы – например, Диаграмму Фан – и нажмите на карточку любого человека, чтобы центрировать диаграмму на нем. См. [Семейное дерево](tree.md) для всех диаграмм и опций.

## Следующие шаги

- **Понять структуру.** См. [Как Gramps организует данные](data-model.md) для того, как люди, семьи, события, места и источники связаны друг с другом.
- **Добавьте больше деталей.** Откройте страницу человека – например, с помощью кнопки **Детали человека** на панели инструментов диаграммы – чтобы добавить дополнительные события, заметки, источники и многое другое. См. [Редактирование в виде дерева](tree-edit.md) для того, что можно сделать непосредственно в диаграмме.
- **Добавьте фотографии и документы.** См. [Добавить медиафайлы](media.md).
- **Пригласите свою семью.** Родственникам нужна своя учетная запись в вашем дереве; смотрите [Управление пользователями](../administration/users.md) и [Регистрация](registration.md).
