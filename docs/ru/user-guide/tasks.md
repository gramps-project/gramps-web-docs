# Использование встроенного управления задачами

Gramps Web содержит встроенный инструмент управления генеалогическими задачами. Он предназначен для того, чтобы исследователи могли планировать и расставлять приоритеты, а также документировать свои задачи. Именно поэтому задачи представлены как источники в базе данных Gramps. После завершения задачи связанный контент может служить источником, документирующим процесс исследования.

## Основы задач

Задачи имеют следующие свойства:

- Статус. Это может быть "Открыто", "В процессе", "Заблокировано" или "Завершено"
- Приоритет. Это может быть "Низкий", "Средний" или "Высокий"
- Теги. Метки являются обычными тегами Gramps для соответствующего источника. (Обратите внимание, что у всех задач дополнительно есть метка `ToDo`, чтобы идентифицировать их как задачи, но эта метка скрыта в списке задач, чтобы избежать загромождения.)
- Заголовок. Отображается в списке задач
- Описание. Поле с форматированием, которое можно использовать для описания проблемы, а также для документирования любого прогресса
- Медиа. Любые медиафайлы, прикрепленные к задаче

## Создание задачи

Поскольку задачи являются обычными объектами Gramps, их могут редактировать или создавать те же группы пользователей, которые могут редактировать или создавать другие объекты (такие как люди или события).

Чтобы создать задачу, нажмите кнопку + на странице списка задач. Введите хотя бы заголовок, а также, по желанию, приоритет, описание, вложения и теги. Статус всегда будет "Открыто" при создании.

## Список задач

Список задач сортируется по статусу – завершенные задачи внизу – и внутри каждого статуса по приоритету, начиная с самого высокого.

Нажмите на задачу, чтобы открыть ее. Пользователи с правами редактирования также могут нажать на значок статуса задачи, чтобы изменить его статус непосредственно в списке, например, чтобы отметить его как завершенное.

Кнопка **фильтр** над списком фильтрует задачи по тегу, с помощью выражения [GOQL](goql.md) или с помощью [расширенного фильтра](lists.md#advanced-filter).

## Редактирование задачи

Страница задачи не имеет отдельного "режима редактирования", как другие объекты Gramps:

- Нажмите на заголовок, чтобы отредактировать его. Нажмите Enter, нажмите ✓ или кликните в другом месте, чтобы сохранить; нажмите Escape или нажмите ✕, чтобы отменить.
- Изменения статуса и приоритета применяются немедленно.
- Чтобы отредактировать описание или вложения, нажмите кнопку редактирования рядом с заголовком раздела. Описание сохраняется с помощью кнопки "сохранить" под ним; редактирование вложений завершается **Готово**.
- Кнопка блокировки устанавливает, является ли задача приватной. Описание задачи получает такую же конфиденциальность.

Пользователи без прав редактирования видят статус и приоритет в виде текста, а разделы без содержимого скрыты.

Под заголовком редакторы видят две дополнительные кнопки: **Редактировать источник** открывает источник, который представляет задачу, где можно редактировать другие заметки, цитаты и атрибуты. **Удалить** удаляет задачу после подтверждения и возвращает к списку задач; сообщение, которое появляется, имеет кнопку отмены для восстановления задачи.

## Массовое изменение свойств задач

Пользователи с правами редактирования видят флажок в каждой строке списка задач. Выберите задачи и используйте **Установить приоритет** или **Установить статус** над списком, чтобы изменить все выбранные задачи сразу.

## Задачи в Gramps Desktop

При добавлении задач через Gramps Web как источники, так и заметки будут иметь прикрепленный тег `ToDo`, поэтому задачи появятся в настольном [Грамплете Заметок To Do](https://gramps-project.org/wiki/index.php/Addon:ToDoNotesGramplet), а также в [Отчете To Do](https://gramps-project.org/wiki/index.php/Addon:ToDoReport).

Чтобы добавить или отредактировать задачу в Gramps Desktop, используйте следующие рекомендации:

- Добавьте источник с тегом `ToDo` и заголовком задачи в качестве заголовка
- При желании добавьте заметку к источнику с тегом `ToDo`, типом "To Do" и описанием в качестве текста
- Добавьте атрибут "Статус" и установите его на "Открыто", "В процессе", "Заблокировано" или "Завершено"
- Добавьте атрибут "Приоритет" и установите его на 9 для низкого, 5 для среднего или 1 для высокого (эти неинтуитивные значения взяты из спецификации iCalendar)
