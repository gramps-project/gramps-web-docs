При первом входе в Gramps Web будет отображена форма Настроек (обозначенная как Настройки пользователя), в которой пользователю необходимо выбрать язык для интерфейса и [Домашнего человека](https://www.gramps-project.org/wiki/index.php/Gramps_Glossary#home_person). Выбор Домашнего человека также можно изменить на главной странице сайта.

Домашний человек для пользователя сайта Gramps Web не обязательно должен совпадать с тем человеком, которого владелец сайта выбрал в Gramps для настольных ПК – это личная настройка, которая может отличаться для каждого пользователя Gramps Web. Домашний человек используется для начального просмотра семейного дерева и является отправной точкой для большинства отчетов. Типичным выбором будет, если пользователь выберет себя в качестве Домашнего человека. При сотрудничестве с другим членом Дерева эти пользователи могут захотеть установить общего предка в качестве Домашнего человека. Это обеспечивает общую точку отсчета для дальних родственных связей.

Чтобы выбрать человека в качестве Домашнего человека, начните вводить Имя или Фамилию в текстовом поле, и появится выпадающий список с совпадениями.

Если дерево все еще пустое, выбирать некого. В этом случае на главной странице отображается карточка **Начать работу**, которая направляет редакторов через первые шаги: сначала добавление человека (или импорт файла семейного дерева), затем соединение людей, добавляя семью. Первый человек, которого вы создаете в пустом дереве, автоматически становится вашим Домашним человеком. См. [Начать новое дерево](start-tree.md) для пошагового руководства.

Настройки языка и Домашнего человека хранятся в локальном хранилище браузера, поэтому они сохранятся на данном устройстве.
