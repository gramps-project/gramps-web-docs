# Хромосомный браузер

Хромосомный браузер — это инструмент для визуализации ДНК-совпадений человека. Он показывает сегменты ДНК, общие с другими людьми в дереве, в виде цветных полос на хромосомах.

Вы можете найти его на вкладке &ldquo;Хромосомный браузер&rdquo; в представлении ДНК.

Для каждой хромосомы верхняя (светло-голубая) полоса представляет копию, унаследованную от отца, а нижняя (светло-красная) полоса — ту, что унаследована от матери. Общие сегменты отображаются в виде цветных полос поверх этих. Сегменты, сторона (отцовская или материнская), которых не известна, показаны в отдельной дорожке между двумя. Если сегменты нескольких совпадений перекрываются, они рисуются в отдельных, более тонких полосах, чтобы каждый сегмент оставался видимым.

Щелчок по имени совпадения в легенде показывает только общие сегменты этого человека.

## Группировка по общим предкам

Над легендой вы можете переключаться между раскраской сегментов по **Совпадениям** и по **Общим предкам**. При выборе общих предков совпадения, которые происходят от одних и тех же самых недавних общих предков с выбранным человеком, имеют одинаковый цвет и строку в легенде. Это позволяет быстро увидеть, какие части хромосом были унаследованы от какой пары предков — сегмент другого совпадения, который перекрывается с сегментами группы с той же стороны, вероятно, происходит от тех же предков, что помогает расположить новое, неизвестное совпадение.

Группы упорядочены по ближайшему родству сначала. Совпадения без известных общих предков сгруппированы под "Неизвестно". Совпадение, которое связано через несколько линий, группируется по ближайшей.

## Сохранение диаграммы

Чтобы сохранить диаграмму, нажмите кнопку загрузки рядом с селектором человека. Это загрузит файл SVG с белым фоном и легендой, включая общее количество общих центиморганов для каждого совпадения. Если в легенде выбрано совпадение или группа, только оно будет включено.
