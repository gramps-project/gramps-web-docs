# Хромосомный браузер

Хромосомный браузер — это инструмент для визуализации ДНК-соответствий человека. Он показывает сегменты ДНК, которые разделяются с другими людьми в дереве, в виде цветных полос на хромосомах.

Вы можете найти его на вкладке &ldquo;Хромосомный браузер&rdquo; в представлении ДНК.

Для каждой хромосомы верхняя (светло-голубая) полоса представляет собой копию, унаследованную от отца, а нижняя (светло-красная) полоса — унаследованную от матери. Общие сегменты отображаются в виде цветных полос поверх этих. Если сторона (папина или мамина) неизвестна, сегмент охватывает обе полосы и отображается с штриховыми линиями.

При нажатии на имя совпадения в легенде отображаются только общие сегменты этого человека.

Чтобы сохранить диаграмму, нажмите кнопку загрузки рядом с селектором человека. Это загрузит файл SVG с белым фоном и легендой, включая общее количество разделяемых центиморганов для каждого совпадения. Если в легенде выбрано совпадение, то включается только это совпадение.
