# Использование встроенного блога

Блог предназначен для представления историй о вашем исследовании семейной истории.

В базе данных Gramps записи блога представлены как источники с прикрепленной заметкой, содержащей текст блога и, при желании, медиафайлы для изображений записи блога. Gramps Web рассматривает каждый источник с тегом `Blog` как статью блога.

## Добавить запись в блог

Самый быстрый способ написать запись — это специальная форма **Новая запись блога** в Gramps Web. Откройте ее либо из синей кнопки **+** на странице блога, либо из меню **Добавить** (значок плюса) в верхней панели приложения, выбрав **Запись блога**.

Форма содержит поля для:

- **Заголовок** – заголовок записи (обязательное)
- **Автор** – кто это написал
- **Содержание** – редактор формата rich-text для самой записи
- **Медиа** – один или несколько медиаобъектов. Первый из них становится изображением превью, отображаемым над текстом; все они появляются в виде галереи ниже.
- **Теги** и переключатель **приватный**, как и для любого другого объекта

Сохранение формы создает основной источник, заметку и тег `Blog` для вас, как описано [ниже](#relation-between-blog-and-sources).

### Добавление записи вручную

Вы также можете создать запись, самостоятельно создавая основные объекты. Это единственный способ сделать это в Gramps Desktop ([синхронизирован](../administration/sync.md) с Gramps Web), и шаги одинаковы в обоих приложениях:

- Добавьте новый источник. Заголовок источника будет заголовком вашей записи блога, автором источника будет автор записи.
- При желании, свяжите источник с репозиторием, соответствующим вашему блогу в Gramps Web.
- Добавьте новую заметку к источнику. Напишите вашу запись блога и скопируйте текст в заметку.
- При желании, добавьте один или несколько медиафайлов к вашему источнику. Первый медиафайл будет взят в качестве изображения превью записи, отображаемого над текстом. Все медиафайлы будут показаны ниже текста в виде галереи.
- Добавьте метку `Blog` к источнику (создайте ее, если она не существует).

## Связь между блогом и источниками

Поскольку записи блога являются просто источниками, все статьи блога также появляются в списке источников и отображаются как источники в поиске. В представлении источника есть кнопка "показать в блоге", которая перенаправит вас на представление блога для этой записи блога. URL записи блога также содержит ID Gramps соответствующего источника, так что статья по адресу `yourdomain.com/blog/S0123` соответствует источнику по адресу `yourdomain.com/source/S0123`.

Внизу каждой записи блога есть кнопка "детали", которая перенаправит вас на представление источника.
