# Руководство пользователя

Этот раздел документирует функции, доступные пользователям Gramps Web.

!!! note "Не видите все функции?"
    Gramps Web использует систему разрешений на основе ролей. Некоторые функции – такие как редактирование данных, управление тегами или просмотр приватных записей – доступны только пользователям с достаточными правами. Вы можете проверить свою текущую роль в [Настройках пользователя](settings.md). Если вам нужен больший доступ, свяжитесь с владельцем вашего дерева или администратором. См. [Система пользователей](../install_setup/users.md) для описания всех ролей.

## Навигация по интерфейсу

### Основная навигация

Боковая панель (или меню гамбургера на мобильных устройствах) является основным способом перемещения между разделами:

- **Главная** – панель управления (см. ниже)
- **Блог** – истории семейной истории, написанные в виде блогов
- **Семейное дерево** – интерактивные графики дерева
- **Хронология** – хронологический обзор событий в дереве (требуется достаточно новая версия API Gramps Web)
- **Карта** – географический обзор мест в дереве
- **ДНК** – инструменты анализа совпадений ДНК
- **Списки** – просмотр всех объектов каждого типа: Люди, Семьи, События, Места, Источники, Цитаты, Репозитории, Заметки
- **Медиа** – просмотр всех медиафайлов (фото, документы и т. д.)
- **Ассистент** – AI-чат-ассистент (если включен администратором)
- **История** – недавно измененные объекты
- **Закладки** – ваши сохраненные закладки
- **Задачи** – исследовательские задачи
- **Отчеты** – создание отчетов
- **Экспорт** – экспорт семейного дерева
- **Версии** – полная история транзакций (видна участникам и выше)
- **Уведомления** – прошлые уведомления

!!! note
    Теги больше не управляются из боковой панели – управление тегами переместилось в [Настройки администрирования](../administration/settings.md#tags) (только для владельцев/администраторов). См. [Теги](tags.md) для информации о том, как используются теги.

### Верхняя панель приложения

Панель в верхней части каждой страницы содержит:

- **Добавить** (иконка плюса, видна участникам и выше) – открывает меню для создания нового объекта: Человек, Семья, Событие, Место, Источник, Цитата, Репозиторий, Заметка, Медиа-объект или Задача
- **Поиск** (лупа) – открывает страницу поиска
- **Иконка пользователя** – открывает меню настроек: Настройки пользователя, Администрирование (только для владельцев), Управление пользователями (только для владельцев), Информация о системе

## Главная страница (панель управления)

Панель управления отображается при первом входе в систему. Она имеет два столбца:

**Левый столбец:**

- **Карточка домашнего человека** – показывает имя, фото (если доступно) и ключевые факты о вашем выбранном домашнем человеке, с ссылкой на их полный профиль и быстрой навигацией к семейному дереву. Нажмите кнопку **Установить домашнего человека** на карточке, чтобы найти и выбрать другого человека.
- **Юбилеи** – предстоящие дни рождения и юбилеи из дерева, основанные на сегодняшней дате.
- **Недавно измененные** – короткий список недавно измененных объектов, полезный для отслеживания совместных правок.

**Правый столбец:**

- **Недавние записи блога** – последние записи из [блога](blog.md), если таковые имеются.
- **Статистика** – сводка по количеству объектов в дереве (количество людей, семей, событий и т. д.).

Пока дерево еще пустое, панель управления скрывает панели, которые не имеют ничего для отображения, и вместо этого показывает карточку **Начать работу** для пользователей с правами редактирования: сначала предлагается создать человека или импортировать файл семейного дерева, а как только люди существуют, соединить их, создав семью. Карточка исчезает, как только в дереве появляется семья.

Если администратор дерева настроил **заметку на главной странице** и/или **изображение на главной странице**, они отображаются prominently над основными столбцами. Изображение появляется рядом с текстом заметки, когда оба установлены. См. [Настройки администрирования](../administration/settings.md#customization) для информации о том, как это настроить.

!!! tip
    Если дерево пустое и у вас есть права редактирования, панель управления показывает подсказку "Начать работу" с кнопками для добавления вашего первого человека или импорта файла семейного дерева.

## Установка Gramps Web как приложения

Gramps Web является прогрессивным веб-приложением (PWA), что означает, что ваш браузер может установить его наряду с другими вашими приложениями, вместо того чтобы держать его в вкладке браузера. Затем оно получает свою собственную иконку и открывается в отдельном окне, без адресной строки и панелей инструментов браузера.

Как вы его установите, зависит от вашего браузера:

- **Android (Chrome)** – откройте меню и выберите "Установить приложение" или "Добавить на главный экран".
- **iOS/iPadOS (Safari)** – нажмите кнопку "Поделиться" и выберите "Добавить на главный экран".
- **Настольный ПК (Chrome, Edge)** – нажмите иконку установки в правом конце адресной строки или используйте пункт "Установить" в меню браузера.
- **Настольный ПК (Firefox, Safari)** – установка не поддерживается; используйте обычную вкладку или окно браузера.

Ничего не меняется в том, как работает Gramps Web, и никакие данные не хранятся иначе – это то же самое приложение, просто представлено как отдельное приложение.

!!! note
    Gramps Web все еще должен подключаться к вашему серверу, чтобы показать ваши данные, поэтому установленное приложение не позволяет вам просматривать ваше семейное дерево в оффлайн-режиме.
