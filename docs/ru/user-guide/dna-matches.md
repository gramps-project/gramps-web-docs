# Работа с ДНК совпадениями

ДНК совпадения – это сегменты ДНК, которые совпадают между двумя индивидуумами, определяемые наличием маркеров, так называемых SNP (акроним для однонуклеотидных полиморфизмов, произносится как «снипс»).

Чтобы получить эти данные, вам нужен доступ к ДНК-тесту, который загружен в базу данных совпадений, позволяющую просматривать данные о совпадениях сегментов ДНК (например, MyHeritage, Gedmatch, FamilytreeDNA). Gramps Web не выполняет само совпадение, так как у него есть доступ только к данным, которые вы загружаете.

## Ввод данных о ДНК совпадениях

Чтобы ввести данные о ДНК совпадениях, вам нужны [права на редактирование](../install_setup/users.md), так как данные хранятся в виде заметки в базе данных Gramps. Вид ДНК, доступный из главного меню, предоставляет удобный способ ввода этих данных в правильном формате.

Чтобы ввести новое совпадение, нажмите кнопку + в правом нижнем углу. В открывшемся диалоговом окне выберите двух индивидуумов. Обратите внимание, что «Первый человек» и «Второй человек» обрабатываются по-разному: совпадение хранится как ассоциация от первого ко второму человеку. Только первый человек будет доступен для просмотра совпадений ДНК и браузера хромосом. Обычно первый человек – это тот, чей ДНК-тест вам доступен, а второй человек – более дальний родственник.

Если второго человека нет в базе данных, вам нужно сначала создать его, используя кнопку «Создать человека» в правом верхнем углу пользовательского интерфейса. После того как вы создадите человека, вы можете вернуться к просмотру ДНК совпадений и выбрать вновь созданного человека.

Далее вставьте сырые данные в текстовое поле. Данные должны быть в виде таблицы совпадений, разделенной запятыми или табуляцией, обычно содержащей номер хромосомы, начальную и конечную позицию совпадения, количество SNP в совпадении и длину совпадения в единицах сантиморганов (cM). Вы также можете перетащить файл с данными о совпадениях в текстовое поле.

Минимальный пример такой таблицы:

```csv
Хромосома,Начальная позиция,Конечная позиция,Сантиморганы,SNPs
6,6358001,18115715,19.6,7424
7,150135758,154205894,10.9,2816
```

Если формат действителен, предварительный просмотр отображается ниже текстового поля в виде таблицы.

Наконец, нажмите кнопку «Сохранить», чтобы сохранить совпадение в базе данных.

## Просмотр данных о ДНК совпадениях

Вид ДНК совпадений имеет выпадающий список, который позволяет выбрать каждого человека в базе данных, у которого есть связанное ДНК совпадение. После выбора человека его совпадения перечисляются в таблице: имя совпадения, их родство с выбранным человеком, общая длина общего ДНК в сантиморганах (cM), количество общих сегментов и длина самого большого из этих сегментов.

Для совпадений, которые уже размещены в дереве, столбец родства показывает родство, зафиксированное в дереве (автоматически определенное из базы данных Gramps). Для совпадений, которые не связаны с выбранным человеком в дереве, показывается родство, оцененное по общему ДНК, помеченное «≈».

Нажатие на совпадение открывает его страницу с резюме общего ДНК, [оценкой родства](#relationship-estimate), диаграммой родства в дереве и списком сегментов. Каждый сегмент показывает, находится ли он по отцовской или материнской линии. Сторона может быть введена вручную (предоставив `P` для отцовской или `M` для материнской в столбце под названием `Сторона` в сырых данных) или определена автоматически от наиболее недавнего общего предка. Кнопка загрузки рядом с сегментами сохраняет их в виде CSV-файла в формате, который принимает диалог совпадений.

## Оценка родства

Общее ДНК не является доказательством конкретного родства: количество ДНК, которое делят два родственника, сильно варьируется, и разные родства пересекаются. Поэтому Gramps Web показывает диапазон возможных родств с их вероятностями, вычисленными на основе количества и длины общих сегментов (требуется Gramps Web API 3.26 или новее).

Родства группируются по их *степени*:

- **Родитель или ребенок** и **Полный брат или сестра** показываются отдельно.
- **Родственник 2 степени** включает сводных братьев и сестер, бабушек и дедушек, внуков, а также тетей, дядей, племянниц и племянников.
- **Родственник 3 степени** включает двоюродных братьев и сестер, прабабушек и прадедушек, двоюродных тетей и дядей, а также сводных тетей и дядей.
- Каждая следующая степень примерно на одно поколение дальше, например, двоюродные братья и сестры, разлученные один раз, – это степень 4, а двоюродные братья и сестры – степень 5. Степени 9 и выше группируются как «9+».

Родства с одинаковой степенью в среднем делят примерно одинаковое количество ДНК, поэтому только по ДНК их нельзя различить. Используйте возраст людей, чтобы решить между ними – 30-летний родственник 2 степени 60-летнего человека с большей вероятностью является племянницей, чем бабушкой.

Оценка наиболее надежна для близких родственников. Для дальних родств совпадения делят лишь несколько сегментов, и вероятности распределяются по нескольким степеням.

### Проверка дерева на соответствие ДНК

Если совпадение размещено в дереве, Gramps Web проверяет, соответствует ли общее ДНК зафиксированному там родству. Если ДНК очень маловероятно для этого родства, в таблице совпадений отображается значок предупреждения, а на странице совпадения – предупреждение. Число в скобках, например «1 : 500», сравнивает, насколько вероятно ДНК для зафиксированного родства с тем, насколько вероятно оно для наиболее вероятного родства.

Предупреждение – это причина для более тщательной проверки, а не доказательство ошибки. Общие причины:

- ошибка в дереве, такая как неверный родитель,
- неверно приписанное родство, например, неизвестное усыновление или другой биологический отец,
- неполные данные о совпадениях, например, если были скопированы только сегменты выше высокого порога из службы тестирования,
- родства через более чем одну линию, например, люди, связанные как по материнской, так и по отцовской линии («коллапс родословной»), которые делят больше ДНК, чем ожидалось.

Родства, которые не являются биологическими, такие как через усыновление, не проверяются.

## Редактирование совпадения

Чтобы отредактировать совпадение, откройте его страницу и нажмите кнопку редактирования или нажмите `e`. Обратите внимание, что вы можете изменить сырые данные, но не индивидуумов, связанных с совпадением – вам нужно удалить совпадение и создать новое, если вы хотите изменить индивидуумов.

## Приватные совпадения

Диалоги для добавления и редактирования совпадения имеют переключатель **Приватный**. Приватное совпадение, включая его сегменты, скрыто от пользователей, которые не могут просматривать приватные записи. Приватные совпадения помечены замком для всех остальных. См. [Приватные записи](privacy.md) для получения дополнительной информации о конфиденциальности.

## Работа с данными совпадений в Gramps Desktop

Данные о ДНК совпадениях хранятся в виде заметки в базе данных Gramps. Формат совместим с 
[Дополнением карты сегментов ДНК](https://gramps-project.org/wiki/index.php/Addon:DNASegmentMapGramplet),
доступным для Gramps Desktop. Его страница в вики содержит больше информации о том, как получить данные, как их интерпретировать и как ввести данные в Gramps.

!!! info
    Gramps Web API v2.8.0 ввел некоторые изменения для принятия более широкого диапазона сырых данных о совпадениях ДНК, которые еще не доступны в дополнении Gramps Desktop. В будущем дополнение Gramps Desktop будет обновлено для поддержки тех же форматов.
