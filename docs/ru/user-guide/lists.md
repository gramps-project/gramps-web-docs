# Списки

Каждый тип объекта в Gramps Web имеет представление списка: Люди, Семьи, События, Места, Источники, Цитации, Репозитории, Заметки и Медиа. Все они работают одинаково и используют одни и те же инструменты для сортировки, фильтрации и массового редактирования.

## Сортировка и постраничный просмотр

Нажмите заголовок столбца, чтобы отсортировать по этому столбцу; нажмите его снова, чтобы изменить порядок. Сортировка выполняется на сервере, поэтому она применяется ко всему списку, а не только к странице, которую вы просматриваете.

Длинные списки разбиваются на страницы. Используйте элементы управления постраничным просмотром внизу, чтобы перемещаться между ними.

На узких экранах таблица автоматически переключается на компактный макет, так что представления списков остаются удобными для использования на телефоне.

## Выбор столбцов

Нажмите значок шестеренки над списком, чтобы открыть диалог **Столбцы**. Установите или снимите флажок со столбца, чтобы показать или скрыть его. **Сброс** восстанавливает выбор по умолчанию для этого списка.

По крайней мере, один столбец должен оставаться видимым, поэтому последний оставшийся столбец нельзя снять с отметки.

Ваш выбор столбцов запоминается для каждого типа объекта и для каждого семейного дерева. Он хранится в вашем браузере, поэтому не виден другим пользователям – но он также не переносится в другой браузер или устройство.

## Фильтрация

Нажмите кнопку **фильтр**, чтобы открыть панель фильтрации. Она предлагает три способа фильтрации, которые можно комбинировать:

- **Готовые фильтры** в сворачиваемых секциях, которые зависят от типа объекта. Например, для людей вы можете фильтровать по году рождения, году смерти, различным свойствам человека, количеству ассоциаций, тегам и тому, является ли объект частным или публичным.
- **Расширенный фильтр** – конструктор условий для фильтров, которые не могут быть выражены готовыми, описан [ниже](#advanced-filter).
- **GQL** – текстовое поле для запроса на [Языке запросов Gramps](gql.md). Введите запрос и нажмите Enter или нажмите **Применить**. Если запрос недействителен, рамка поля становится красной. Запрос применяется поверх других фильтров.

Активные фильтры отображаются в виде чипов над списком. Удалите один фильтр, нажав кнопку очистки чипа, или используйте **Очистить все фильтры**, чтобы удалить их все сразу.

### Расширенный фильтр

Нажмите **Расширенный фильтр** внизу панели фильтрации, чтобы открыть конструктор условий. Его условия – это правила фильтрации, известные из Gramps Desktop, такие как "Люди с &lt;имя&gt;" или "Предки &lt;человека&gt;".

- Нажмите **Добавить условие**, чтобы выбрать правило. Правила сгруппированы по категориям и могут быть найдены по имени или описанию.
- Заполните параметры правила. Каждый параметр имеет соответствующий ввод, например, поле даты, селектор тегов или селектор объекта для человека или места.
- Выберите, как условия группы комбинируются: **Все условия**, **Любое условие** или – через меню рядом с ними – **Точно одно условие**.
- Нажмите **Добавить группу**, чтобы добавить группу условий внутри другой группы с собственным способом их комбинирования.
- Выберите **Не** для условия или группы, чтобы инвертировать его.

Нажмите **Применить**, чтобы отфильтровать список.

Готовые фильтры, которые активны, когда вы открываете конструктор, появляются там как условия. Если фильтр, который вы создаете, может быть выражен с помощью готовых фильтров, он отображается с ними после применения. В противном случае он отображается как один чип **Расширенный фильтр**, и панель фильтрации предлагает кнопку **Редактировать**, чтобы снова открыть конструктор.

!!! note
    Правила, которые ссылаются на пользовательские фильтры, сохраненные в Gramps Desktop, недоступны в конструкторе. Правила отображаются на вашем языке с Gramps Web API 3.24 или новее.

## Выбор объектов и массовые действия над ними

Пользователи с правами редактирования видят кнопку **Выбрать** рядом с кнопкой фильтра. Нажмите ее, чтобы войти в режим выбора, который добавляет флажок к каждой строке.

Установите флажки для объектов, которые вы хотите, и появится панель инструментов, показывающая, сколько объектов выбрано, вместе с выпадающим меню **Действие** и кнопкой **Применить**.

Флажок в заголовке таблицы выбирает все объекты на текущей странице. Если больше объектов соответствуют текущим фильтрам, панель инструментов затем предлагает **Выбрать все (N)**, что выбирает все N соответствующих объектов на всех страницах. Снятие флажка с строки, изменение страницы или фильтров или выход из режима выбора завершает этот выбор.

### Удалить

Выберите один или несколько объектов, выберите **Удалить** и нажмите **Применить**. Появится диалог подтверждения, который попросит вас подтвердить, предупреждая, что действие нельзя отменить.

Удаление более десяти объектов выполняется как фоновая задача. Его прогресс отображается рядом с кнопкой **Применить** и в [Уведомлениях](notifications.md), а список перезагружается, когда задача завершена.

!!! tip
    Удаления записываются в [историю изменений](revisions.md) так же, как и любые другие изменения, поэтому ошибочное массовое удаление можно отменить, отменив соответствующую транзакцию.

### Слить

Выберите **ровно два** объекта, выберите **Слить** и нажмите **Применить**. Появится диалог, в котором будет предложено выбрать, какой из двух объектов должен предоставить основные данные для объединенного объекта; нажмите тот, который вы хотите оставить основным. Данные другого объекта объединяются с ним, и ссылки обновляются.

Слияние доступно для людей, семей, событий, мест, источников и цитат. Оно недоступно для репозиториев, заметок и медиа объектов.

В представлении медиа выбор работает как в галерее, так и в виде списка: в режиме выбора нажатие на плитку или строку переключает ее состояние. **Удалить** – единственное действие, доступное для медиа.

Если вы выбираете действие без действительного выбора – например, слияние только с одним выбранным объектом – появится диалог, объясняющий, что требуется.
