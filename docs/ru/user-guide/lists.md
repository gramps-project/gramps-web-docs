# Списки

Каждый тип объекта в Gramps Web имеет представление списка: Люди, Семьи, События, Места, Источники, Цитаты, Репозитории, Заметки и Медиа. Все они работают одинаково и используют одни и те же инструменты для сортировки, фильтрации и массового редактирования.

## Сортировка и постраничный просмотр

Нажмите на заголовок столбца, чтобы отсортировать по этому столбцу; нажмите снова, чтобы изменить порядок. Сортировка выполняется на сервере, поэтому она применяется ко всему списку, а не только к странице, которую вы просматриваете.

Длинные списки разбиваются на страницы. Используйте элементы управления постраничным просмотром внизу, чтобы перемещаться между ними.

На узких экранах таблица автоматически переключается на компактный макет, так что представления списков остаются удобными для использования на телефоне.

## Выбор столбцов

Нажмите на значок шестеренки над списком, чтобы открыть диалог **Столбцы**. Установите или снимите галочку с столбца, чтобы показать или скрыть его. **Сброс** восстанавливает выбор по умолчанию для этого списка.

По крайней мере, один столбец должен оставаться видимым, поэтому последний оставшийся столбец нельзя снять с отметки.

Ваш выбор столбцов запоминается для каждого типа объекта и для каждого семейного дерева. Он хранится в вашем браузере, поэтому не виден другим пользователям – но он также не переносится в другой браузер или устройство.

## Фильтрация

Нажмите кнопку **фильтр**, чтобы открыть панель фильтрации. Она предлагает три способа фильтрации, которые можно комбинировать:

- **Готовые фильтры** в сворачивающихся секциях, которые зависят от типа объекта. Например, для людей вы можете фильтровать по году рождения, году смерти, различным свойствам человека, количеству ассоциаций, тегам и тому, является ли объект приватным или публичным.
- **Расширенный фильтр** – конструктор условий для фильтров, которые не могут быть выражены готовыми, описан [ниже](#advanced-filter).
- **GQL** – текстовое поле для запроса на [Языке запросов Gramps](gql.md). Введите запрос и нажмите Enter или нажмите **Применить**. Если запрос недействителен, рамка поля становится красной. Запрос применяется поверх других фильтров.

Активные фильтры отображаются в виде чипов над списком. Удалите один фильтр, нажав кнопку очистки чипа, или используйте **Очистить все фильтры**, чтобы удалить их все сразу.

### Расширенный фильтр

Нажмите **Расширенный фильтр** внизу панели фильтрации, чтобы открыть конструктор условий. Его условия – это правила фильтрации, известные из Gramps Desktop, такие как "Люди с &lt;имя&gt;" или "Предки &lt;человека&gt;".

- Нажмите **Добавить условие**, чтобы выбрать правило. Правила сгруппированы по категориям и могут быть найдены по имени или описанию.
- Заполните параметры правила. Каждый параметр имеет соответствующий ввод, например, поле даты, селектор тегов или селектор объекта для человека или места.
- Выберите, как комбинируются условия группы: **Все условия**, **Любое условие** или – через меню рядом с ними – **Точно одно условие**.
- Нажмите **Добавить группу**, чтобы добавить группу условий внутри другой группы с собственным способом их комбинирования.
- Выберите **Не** для условия или группы, чтобы инвертировать его.

Нажмите **Применить**, чтобы отфильтровать список.

Готовые фильтры, которые активны при открытии конструктора, появляются там как условия. Если фильтр, который вы создаете, может быть выражен с помощью готовых фильтров, он отображается с ними после применения. В противном случае он отображается как один чип **Расширенный фильтр**, и панель фильтрации предлагает кнопку **Редактировать**, чтобы снова открыть конструктор.

!!! note
    Правила, которые ссылаются на пользовательские фильтры, сохраненные в Gramps Desktop, недоступны в конструкторе. Правила отображаются на вашем языке с Gramps Web API 3.24 или новее.

## Выбор объектов и массовые действия

Пользователи с правами редактирования видят кнопку **Выбрать** рядом с кнопкой фильтра. Нажмите на нее, чтобы войти в режим выбора, который добавляет флажок к каждой строке.

Отметьте объекты, которые вам нужны, и появится панель инструментов, показывающая, сколько объектов выбрано, вместе с выпадающим меню **Действие** и кнопкой **Применить**.

### Удалить

Выберите один или несколько объектов, выберите **Удалить** и нажмите **Применить**. Появится диалог подтверждения, который попросит вас подтвердить действие, предупреждая, что его нельзя будет отменить.

!!! tip
    Удаления записываются в [историю изменений](revisions.md), как и любое другое изменение, поэтому ошибочное массовое удаление можно отменить, отменив соответствующую транзакцию.

### Объединить

Выберите **ровно два** объекта, выберите **Объединить** и нажмите **Применить**. Появится диалог, в котором будет предложено выбрать, какой из двух объектов должен предоставить основные данные для объединенного объекта; нажмите на тот, который вы хотите оставить основным. Данные другого объекта будут объединены с ним, и ссылки будут обновлены.

Объединение доступно для людей, семей, событий, мест, источников и цитат. Оно недоступно для репозиториев, заметок и медиа объектов.

Если вы выберете действие без действительного выбора – например, объединение с выбранным только одним объектом – появится диалог, объясняющий, что требуется.
