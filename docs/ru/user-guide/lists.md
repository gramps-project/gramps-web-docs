# Списки

Каждый тип объекта в Gramps Web имеет представление списка: Люди, Семьи, События, Места, Источники, Цитаты, Репозитории, Заметки и Медиа. Все они работают одинаково и используют одни и те же инструменты для сортировки, фильтрации и массового редактирования.

## Сортировка и постраничный просмотр

Нажмите на заголовок столбца, чтобы отсортировать по этому столбцу; нажмите снова, чтобы изменить порядок. Сортировка выполняется сервером, поэтому она применяется ко всему списку, а не только к странице, которую вы просматриваете.

Длинные списки разбиваются на страницы. Используйте элементы управления пагинацией внизу, чтобы перемещаться между ними.

На узких экранах таблица автоматически переключается на компактный макет, чтобы представления списков оставались удобными для использования на телефоне.

## Выбор столбцов

Нажмите на значок шестеренки над списком, чтобы открыть диалог **Столбцы**. Установите или снимите галочку со столбца, чтобы показать или скрыть его. **Сброс** восстанавливает выбор по умолчанию для этого списка.

По крайней мере один столбец должен оставаться видимым, поэтому последний оставшийся столбец нельзя снять с отметки.

Ваш выбор столбцов запоминается для каждого типа объекта и для каждого семейного дерева. Он хранится в вашем браузере, поэтому не виден другим пользователям – но он также не переносится на другой браузер или устройство.

## Фильтрация

Нажмите кнопку **фильтр**, чтобы открыть панель фильтров. Переключатель в верхней части панели переключает между двумя режимами:

- **простой** – набор готовых фильтров, который зависит от типа объекта. Например, для людей вы можете фильтровать по году рождения, году смерти, различным свойствам человека, количеству ассоциаций, тегам и тому, является ли объект приватным или публичным.
- **GQL** – одно текстовое поле для расширенного запроса на [Языке запросов Gramps](gql.md). Введите запрос и нажмите Enter или нажмите **Применить**. Если запрос недействителен, рамка поля становится красной.

Активные фильтры отображаются в виде чипов над списком. Удалите один фильтр, нажав кнопку очистки чипа, или используйте **Очистить все фильтры**, чтобы удалить их все сразу.

!!! note
    Эти два режима являются альтернативами, а не дополнительными: запрос GQL заменяет простые фильтры, а возврат к простому режиму отменяет запрос.

## Выбор объектов и массовые действия с ними

Пользователи с правами редактирования видят кнопку **Выбрать** рядом с кнопкой фильтра. Нажмите на нее, чтобы войти в режим выбора, который добавляет флажок к каждой строке.

Установите отметки для объектов, которые вы хотите выбрать, и появится панель инструментов, показывающая, сколько объектов выбрано, вместе с выпадающим меню **Действие** и кнопкой **Применить**.

### Удалить

Выберите один или несколько объектов, выберите **Удалить** и нажмите **Применить**. Появится диалог подтверждения, который попросит вас подтвердить действие, предупреждая, что его нельзя будет отменить.

!!! tip
    Удаления записываются в [истории изменений](revisions.md) так же, как и любое другое изменение, поэтому ошибочное массовое удаление можно отменить, отменив соответствующую транзакцию.

### Объединить

Выберите **ровно два** объекта, выберите **Объединить** и нажмите **Применить**. Появится диалог, в котором будет предложено указать, какой из двух объектов должен предоставить основные данные для объединенного объекта; нажмите на тот, который вы хотите оставить основным. Данные другого объекта будут объединены с ним, и ссылки будут обновлены.

Объединение доступно для людей, семей, событий, мест, источников и цитат. Оно недоступно для репозиториев, заметок и медиаобъектов.

Если вы выберете действие без действительного выбора – например, объединение с выбранным только одним объектом – появится диалог, объясняющий, что требуется.
