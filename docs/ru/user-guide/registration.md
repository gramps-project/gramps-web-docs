В установке с одним деревом любой может зарегистрировать новую учетную запись в экземпляре Gramps Web, но она должна быть вручную активирована владельцем сайта, прежде чем ее можно будет использовать для входа.

В установке с несколькими деревьями пользователи дополнительно требуют идентификатор дерева для регистрации; на практике это означает, что они могут зарегистрироваться, используя ссылку на регистрацию, предоставленную владельцем дерева.

## 1. Найдите форму регистрации

На форме входа на главной странице Gramps Web обычно есть ссылка "Зарегистрировать новую учетную запись".

Если эта ссылка отсутствует, либо регистрация отключена на этом сервере, либо это установка Gramps Web с несколькими деревьями. В любом случае свяжитесь с владельцем дерева, который может создать учетную запись для вас или отправить вам ссылку на регистрацию.

Если сервер поддерживает вход с помощью внешней учетной записи (например, Google, Microsoft или единого входа вашей организации), страница регистрации также предлагает эти варианты. Выбор одного из них создает вашу учетную запись без пароля и без подтверждения электронной почты, указанного ниже. Если сервер не назначает роли автоматически, учетная запись все равно должна быть активирована владельцем дерева (шаг 4).

Владелец дерева может найти и скопировать ссылку на регистрацию в разделе Настройки/Администрирование.

## 2. Отправить форму регистрации

Форма регистрации имеет четыре обязательных поля: имя пользователя, пароль, адрес электронной почты и полное имя. Когда все четыре поля будут заполнены, нажмите "отправить", чтобы начать процесс регистрации.

## 3. Подтвердите адрес электронной почты

После отправки формы на указанный адрес электронной почты будет отправлено автоматическое письмо с ссылкой для подтверждения электронной почты. Нажатие на нее откроет страницу подтверждения.

Если подтверждающее письмо не приходит (и вы проверили папку "Спам"), возможно, что электронная почта не была настроена правильно администратором сервера Gramps Web.

## 4. Активировать учетную запись

После подтверждения адреса электронной почты владелец дерева получит уведомление по электронной почте и сможет активировать новую учетную запись пользователя, перейдя в раздел "Администрирование пользователей" на странице настроек (доступно через значок пользователя в верхней панели приложения) и изменив роль пользователя с "отключена" на любую из [других ролей](../install_setup/users.md).

Обратите внимание, что новый пользователь *не* получит автоматическое уведомление о том, что его учетная запись была активирована, поэтому рекомендуется, чтобы администратор уведомил их лично.
