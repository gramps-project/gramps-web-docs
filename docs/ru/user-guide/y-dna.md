# Использование Gramps Web для анализа Y-ДНК

!!! note "Примечание"
    Эта функция требует версии Gramps Web API 3.3.0 или новее и версии Gramps Web frontend 25.9.0 или новее.

Просмотр Y-ДНК в Gramps Web может использовать необработанные данные о полиморфизме одиночных нуклеотидов (SNP) Y-хромосомы для определения наиболее вероятной гаплогруппы Y-ДНК человека и отображения производных предков в дереве человеческой Y-хромосомы вместе с оценками времени.

## Как получить и сохранить данные SNP Y-ДНК

Чтобы получить данные SNP Y-ДНК, вам необходимо пройти тест Y-ДНК через службу генетического тестирования. Результат представлен в виде набора мутаций (SNP), каждая из которых идентифицируется строкой (например, `R-BY44535`) и знаком `+` или `-`, указывающим, присутствует ли мутация или отсутствует. Gramps Web ожидает строку всех протестированных SNP в формате `SNP1+, SNP2-, SNP3+,...`, которая должна быть сохранена в атрибуте человека пользовательского типа `Y-ДНК` (чувствительно к регистру). Вы можете либо вручную создать этот атрибут в Gramps Web или Gramps Desktop, либо перейти в просмотр Y-ДНК в Gramps Web и нажать на синюю кнопку "Добавить", выбрать человека, к которому нужно добавить данные, и вставить строку SNP. В любом случае данные будут сохранены как атрибут человека в вашей базе данных Gramps.

[Смотрите ниже](#инструкции-по-получению-данных-snp-от-тестирующих-служб) инструкции о том, как получить данные SNP от различных тестирующих служб.

## Как это работает

Как только у человека есть атрибут `Y-ДНК`, содержащий данные SNP, Gramps Web будет использовать библиотеку Python с открытым исходным кодом [yclade](https://github.com/DavidMStraub/yclade) для определения наиболее вероятного положения человека на дереве человеческой Y-хромосомы. Дерево было создано проектом [YFull](https://www.yfull.com/) на основе десятков тысяч тестов Y-ДНК. Обратите внимание, что Gramps Web использует локальную копию дерева YFull, поэтому никакие данные не отправляются третьим лицам.

Дерево проходит от корня к листьям, и на каждом узле SNP, связанные с этим узлом, сравниваются с положительно и отрицательно протестированными SNP человека, и следует соответствующей ветви.

Конечный результат — это последовательность кладер от корня дерева (Y-хромосомный "Адам" [Y-chromosomal "Adam"](https://en.wikipedia.org/wiki/Y-chromosomal_Adam)) до наиболее производного клада, который соответствует данным SNP человека. Каждый клад имеет оценочный возраст, основанный на возрастах образцов в базе данных YFull, которые принадлежат этому кладу.

Поскольку Y-хромосомы наследуются от отца к сыну, эта последовательность соответствует отрывку патрилинейного предковедения человека.

## Как интерпретировать результаты

Самая важная информация — это наиболее вероятная гаплогруппа человека, показанная в верхней части страницы. Название связано с соответствующей страницей на сайте [YFull](https://www.yfull.com/), которая содержит дополнительную информацию, такую как страна происхождения протестированных образцов, принадлежащих к этой гаплогруппе.

В дереве патрилинейных предков, показанном в Gramps Web, коробка прямо над протестированным человеком является самым недавним общим предком (MRCA) всех протестированных образцов, принадлежащих к гаплогруппе человека. Дата, показанная для этого предка, — это его оценочная приблизительная дата рождения. Предок выше него — это предок, у которого впервые появилась мутация, определяющая эту гаплогруппу.

Из-за медленной скорости мутаций Y-хромосом MRCA может быть много сотен лет назад. Для редких гаплогрупп (т.е. гаплогрупп, для которых протестировано мало людей) это может быть даже тысячи лет.

Между MRCA и протестированным человеком диаграмма показывает отцовскую линию, насколько это задокументировано в вашем дереве: отец, его отец и так далее, начиная с самого старшего. Пунктирная линия над самым старым задокументированным предком обозначает поколения, которые не задокументированы, с оценкой их числа. Следуются только биологические отцы — линия останавливается на приемном отце или отчиме, так как они не передали Y-хромосому. Нажмите на человека в линии, чтобы открыть его страницу.

Иконка на каждом кладе открывает этот клад на сайте YFull.

## Частные данные Y-ДНК

Диалоги для добавления и редактирования данных Y-ДНК имеют переключатель **Частный**. Частные данные Y-ДНК скрыты от пользователей, которые не могут просматривать частные записи. См. [Частные записи](privacy.md).

## Инструкции по получению данных SNP от тестирующих служб

### [YSEQ](https://www.yseq.net/)

После входа в "Мой аккаунт" перейдите в "Мои результаты / Просмотр моих аллелей" и прокрутите страницу вниз. Текстовое поле "Список аллелей компактный" было добавлено специально для Gramps Web и находится в точно правильном формате для вставки в атрибут `Y-ДНК`.
