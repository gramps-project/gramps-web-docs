# Настройки пользователя

Настройки пользователя доступны через иконку пользователя в верхней панели приложения, затем **Настройки пользователя**. Страница организована в сворачиваемые секции. Изменения вступают в силу немедленно, если не указано иное.

!!! note
    Изменения в настройках пользователя касаются только вашей учетной записи. Настройки, которые влияют на всех пользователей дерева, управляются в [Настройках администрирования](../administration/settings.md).

## Учетная запись

Содержит информацию о вашем профиле, учетные данные и безопасность учетной записи.

### Информация о пользователе

Показывает ваше **имя пользователя** и текущую **роль пользователя** (например, Гость, Участник, Редактор). Эти данные доступны только для чтения.

### Изменить адрес электронной почты

Введите новый адрес электронной почты и нажмите **Отправить**, чтобы обновить адрес, связанный с вашей учетной записью. Адрес электронной почты используется для сброса пароля и (если настроено) уведомлений.

### Изменить пароль

Введите ваш текущий пароль и новый пароль, затем нажмите **Отправить**. Вы останетесь в системе на текущем устройстве, в то время как ваши сеансы на других устройствах и браузерах завершатся через 15 минут. Если вы забыли текущий пароль, используйте ссылку **Забыли пароль** на странице входа.

Этот раздел скрыт, если сервер позволяет вход только через внешнего провайдера (см. [OIDC аутентификация](../install_setup/oidc.md)).

### Связанные методы входа

Если ваш сервер предлагает единую аутентификацию (см. [OIDC аутентификация](../install_setup/oidc.md)), вы можете связать учетную запись из провайдера, такого как Google или вход вашей организации, с вашей учетной записью Gramps Web. Вы сможете войти через этого провайдера и попасть в свою существующую учетную запись с вашей ролью и вашими правками. Этот раздел появляется только при включенной единой аутентификации и поддержке связывания сервером (Gramps Web API 3.24 и выше).

Чтобы связать учетную запись, нажмите **Связать с** и имя провайдера, войдите в систему у провайдера, и вы вернетесь к своим настройкам. Если вы не входили в систему недавно, вам будет предложено сначала снова войти в систему.

Учетная запись провайдера может быть связана только с одной учетной записью Gramps Web. Если вы видите "Этот вход уже связан с другой учетной записью", значит, она связана в другом месте, например, с учетной записью, созданной при первом входе с этим провайдером. Администратор может удалить эту другую учетную запись, после чего вы сможете связать ее с вашей.

Чтобы отвязать учетную запись, нажмите **Отвязать**. Если это ваш последний связанный метод входа, вам также нужно ввести свой пароль, чтобы вы могли войти в систему позже. Если ваша учетная запись была создана через единую аутентификацию и вы никогда не устанавливали пароль, используйте **Забыли пароль** на странице входа, чтобы сначала установить его (это требует, чтобы сервер отправлял электронные письма). Если сервер позволяет вход только через провайдера, последнюю связанную учетную запись нельзя отвязать.

## Внешний вид

Управляет предпочтениями отображения, сохраненными на вашем устройстве.

### Язык

Выберите язык для интерфейса Gramps Web. Настройка языка сохраняется в локальном хранилище браузера и применяется только к текущему устройству.

### Темная тема

Выберите между:

- **Система** – следует предпочтению светлой/темной темы операционной системы (по умолчанию)
- **Светлая** – всегда использовать светлую тему
- **Темная** – всегда использовать темную тему

Настройка темы сохраняется в локальном хранилище браузера.

### Предпочтения семейного дерева

#### Вид семейного дерева по умолчанию

Устанавливает, какой тип диаграммы открывается по умолчанию, когда вы переходите на страницу [Семейное дерево](tree.md). Опции: Древо предков, Древо потомков, Часовая диаграмма, Диаграмма отношений и Фан-диаграмма.

Это предпочтение сохраняется в локальном хранилище браузера.

## Инструменты разработчика

### API токен

Копирует ваш текущий токен сеанса в буфер обмена. Токен может быть использован для аутентификации напрямую через REST API, например, в интерактивном Swagger UI, предоставляемом вашим экземпляром Gramps Web по адресу `/api/swagger-ui`.

Нажмите **Запустить Swagger**, чтобы открыть Swagger UI в новой вкладке с уже доступным вашим сеансом.

!!! note
    Токен сеанса имеет короткий срок действия. Скопируйте его сразу перед использованием в Swagger, так как он может истечь.
