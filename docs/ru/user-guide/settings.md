# Настройки пользователя

Настройки пользователя доступны через значок пользователя в верхней панели приложения, затем **Настройки пользователя**. Страница организована в сворачиваемые секции. Изменения вступают в силу немедленно, если не указано иное.

!!! note
    Изменения в настройках пользователя касаются только вашей учетной записи. Настройки, которые влияют на всех пользователей дерева, управляются в [Настройках администрирования](../administration/settings.md).

## Учетная запись

Содержит информацию о вашем профиле, учетные данные и безопасность учетной записи.

### Информация о пользователе

Показывает ваше **имя пользователя** и текущую **роль пользователя** (например, Гость, Участник, Редактор). Эти данные доступны только для чтения.

### Изменить электронную почту

Введите новый адрес электронной почты и нажмите **Отправить**, чтобы обновить адрес, связанный с вашей учетной записью. Адрес электронной почты используется для сброса пароля и (если настроено) уведомлений.

### Изменить пароль

Введите ваш текущий пароль и новый пароль, затем нажмите **Отправить**. Если вы забыли текущий пароль, используйте ссылку **Забыли пароль** на странице входа.

### Связанные методы входа

Если ваш сервер предлагает единый вход (см. [аутентификацию OIDC](../install_setup/oidc.md)), вы можете связать учетную запись провайдера, например Google или вход вашей организации, с вашей учетной записью Gramps Web. Затем вы можете войти с помощью этого провайдера и попасть в свою существующую учетную запись с вашей ролью и вашими правками. Этот раздел появляется только тогда, когда единый вход включен и сервер поддерживает связывание (Gramps Web API 3.24 и выше).

Чтобы связать учетную запись, нажмите **Связать с** и имя провайдера, войдите в систему у провайдера, и вы будете возвращены к своим настройкам. Если вы не входили в систему недавно, вам будет предложено сначала снова войти в систему.

Учетная запись провайдера может быть связана только с одной учетной записью Gramps Web. Если вы видите "Этот вход уже связан с другой учетной записью", это связано в другом месте, например, с учетной записью, которая была создана, когда вы впервые вошли с этим провайдером. Администратор может удалить ту другую учетную запись, после чего вы сможете связать ее с вашей.

Чтобы разъединить учетную запись, нажмите **Разъединить**. Если это ваш последний связанный метод входа, вам также нужно ввести свой пароль, чтобы вы все еще могли войти в систему после этого. Если ваша учетная запись была создана через единый вход и вы никогда не устанавливали пароль, используйте **Забыли пароль** на странице входа, чтобы сначала установить его (это требует, чтобы сервер отправлял электронные письма). Если сервер позволяет вход только через провайдера, последнюю связанную учетную запись нельзя разъединить.

## Внешний вид

Управляет предпочтениями отображения, сохраненными на вашем устройстве.

### Язык

Выберите язык для интерфейса Gramps Web. Настройка языка хранится в локальном хранилище браузера и применяется только к текущему устройству.

### Темная тема

Выберите между:

- **Системная** – следует предпочтению светлой/темной темы операционной системы (по умолчанию)
- **Светлая** – всегда использовать светлую тему
- **Темная** – всегда использовать темную тему

Настройка темы хранится в локальном хранилище браузера.

### Предпочтения семейного дерева

#### Вид семейного дерева по умолчанию

Устанавливает, какой тип диаграммы открывается по умолчанию, когда вы переходите на страницу [Семейное дерево](tree.md). Варианты: Древо предков, Древо потомков, Часовая диаграмма, Диаграмма отношений и Фан-диаграмма.

Это предпочтение хранится в локальном хранилище браузера.

## Инструменты разработчика

### Токен API

Копирует ваш текущий токен сессии в буфер обмена. Токен может быть использован для аутентификации напрямую через REST API, например, в интерактивном Swagger UI, предоставляемом вашим экземпляром Gramps Web по адресу `/api/swagger-ui`.

Нажмите **Запустить Swagger**, чтобы открыть Swagger UI в новой вкладке с вашей сессией, уже доступной.

!!! note
    Токен сессии имеет короткий срок действия. Скопируйте его сразу перед использованием в Swagger, так как он может истечь.
