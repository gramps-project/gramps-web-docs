# Impostazioni di Amministrazione

La pagina **Impostazioni > Amministrazione** è accessibile tramite l'icona utente nella barra superiore dell'app. È disponibile solo per gli utenti con il ruolo di Proprietario o Amministratore e fornisce strumenti per gestire il database dell'albero genealogico.

La pagina è organizzata in sezioni espandibili. Clicca su un'intestazione di sezione per espanderla. Questa pagina elenca le sezioni e i link a dove ciascuna di esse è descritta.

## Dati

- [Quote di utilizzo](import.md#usage-quotas){#usage-quotas} – utilizzo attuale rispetto ai limiti per persone e archiviazione media
- [Importa dati](import.md){#import-data} – carica un file dell'albero genealogico
- [Stato dei file multimediali](import-media.md#media-file-status){#media-file-status} – oggetti multimediali con checksum o file mancanti
- [Importa archivio multimediale](import-media.md){#import-media-archive} – carica un file ZIP per completare i file multimediali mancanti

## Indice di ricerca

- [Gestisci indice di ricerca](search-index.md){#manage-search-index} – controlla lo stato dell'indice e ricostruiscilo

## Impostazioni dell'albero

- [Nome dell'albero genealogico](customization.md#family-tree-name){#family-tree-name} – rinomina il database Gramps sottostante
- [Informazioni sul Ricercatore](customization.md#researcher-information){#researcher-information} – dettagli di contatto del ricercatore principale, incorporati nelle esportazioni
