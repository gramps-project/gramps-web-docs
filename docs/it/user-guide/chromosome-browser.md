# Browser dei Cromosomi

Il browser dei cromosomi è uno strumento per visualizzare i corrispondenze del DNA di una persona. Mostra i segmenti di DNA condivisi con altre persone nell'albero come barre colorate sui cromosomi.

Puoi trovarlo sotto la scheda &ldquo;Browser dei Cromosomi&rdquo; nella vista DNA.

Per ogni cromosoma, la barra superiore (azzurra chiaro) rappresenta la copia ereditata dal padre, la barra inferiore (rossa chiaro) quella ereditata dalla madre. I segmenti condivisi sono mostrati come barre colorate sopra di queste. Se il lato (paterno o materno) non è noto, il segmento si estende su entrambe le barre ed è mostrato con segni a tratteggio.

Cliccando sul nome di una corrispondenza nella legenda, vengono mostrati solo i segmenti condivisi di questa persona.

Per salvare il grafico, clicca sul pulsante di download accanto al selettore della persona. Viene scaricato un file SVG con uno sfondo bianco e la legenda, inclusi i centimorgani totali condivisi di ciascuna corrispondenza. Se una corrispondenza è selezionata nella legenda, solo quella corrispondenza è inclusa.
