# Hakemisto

**Hakemisto**-osio [Hallinta-asetuksissa](settings.md) näyttää koko tekstin hakemiston tilan ja antaa mahdollisuuden rakentaa se uudelleen.

## Hallitse hakemistoa

Gramps Web ylläpitää koko tekstin hakemistoa, joka päivitetään normaalisti automaattisesti aina, kun tiedot muuttuvat. Tilaindikaattori näyttää, kuinka monta objektia on tällä hetkellä indeksoitu verrattuna kokonaisten objektien määrään.

Napsauta **Päivitä hakemisto** -painiketta aloittaaksesi täydellisen uudelleenrakentamisen. Edistymisindikaattori näkyy, kun tehtävä suoritetaan taustalla. Tämä on harvoin tarpeen.

Jos puulla ei vielä ole hakemistoa, esimerkiksi palvelimen päivityksen jälkeen, joka muutti hakemiston formaattia, Gramps Web rakentaa sen taustalla ensimmäisen kerran, kun puu avataan. Kun sitä rakennetaan, osio näyttää "Hakemistoa rakennetaan." sen sijaan, että näyttäisi laskentatiedot, **Päivitä hakemisto** -painike on poistettu käytöstä, ja hakutulokset saattavat olla puutteellisia. Rakentaminen näkyy [Ilmoituksissa](../user-guide/notifications.md) "Päivitä hakemisto" -tehtävänä.
