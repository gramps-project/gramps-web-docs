# Aikajana

!!! info
    Aikajanakatselu vaatii riittävän uuden Gramps Web API -version. Jos palvelimesi on vanhempi, **Aikajana**-kohta on piilotettu sivupalkista.

**Aikajana** on sivupalkin kohta, joka näyttää kaikki tapahtumat perhepuussasi aikajärjestyksessä vaakasuoralla, zoomattavalla aikajanalla.

## Aikajanan selaaminen

- Vieritä, vedä tai nipistä siirtyäksesi ajassa; käytä zoomauspainikkeita (tai hiiren rullaa/nipistysliikettä) zoomataksesi sisään ja ulos.
- Kun zoomaat sisään, tapahtumien nimilaput ilmestyvät; napsauta tapahtumapistettä nähdäksesi sen tiedot (ja muiden samana päivänä tapahtuneiden tapahtumien tiedot).

## Suodatus

Käytä suodatin kenttää keskittyäksesi aikajanaan, joka liittyy yhteen **henkilöön** tai **paikkaan**:

- **Henkilö** – näyttää vain tapahtumat, jotka liittyvät kyseiseen henkilöön, mukaan lukien heidän perheidensä tapahtumat, kuten avioliitot. Vaihtoehto antaa sinun vaihtaa **Henkilö** (vain kyseisen yksilön tapahtumat), **Esivanhemmat** ja **Jälkeläiset** (kaikkien heidän esivanhempiensa/jälkeläistensä tapahtumat).
- **Paikka** – näyttää vain tapahtumat, jotka tapahtuivat siellä.

Tyhjennä suodatin, jotta voit palata täyteen aikajanaan.

## Hyppääminen aikajanaan

Tapahtuman tai paikan tietosivulla **Näytä aikajanalla** -painike avaa aikajanakatselun, joka on vieritetty ja zoomattu kyseisen tapahtuman päivämäärälle.
