# Kromosomiselain

Kromosomiselain on työkalu, jolla visualisoidaan henkilön DNA-yhteensopivuudet. Se näyttää DNA-segmentit, jotka ovat yhteisiä muiden ihmisten kanssa puussa värillisinä palkkeina kromosomeilla.

Voit löytää sen &ldquo;Kromosomiselain&rdquo; -välilehdeltä DNA-näkymässä.

Jokaiselle kromosomille ylempi (vaaleansininen) palkki edustaa isältä perittyä kopiota, alempi (vaaleanpunainen) palkki äidiltä perittyä kopiota. Yhteiset segmentit näkyvät värillisinä palkkeina näiden päällä. Jos puoli (isä tai äiti) ei ole tiedossa, segmentti kattaa molemmat palkit ja se näkyy viivamerkeillä.

Napsauttamalla yhteensopivuuden nimeä selitteessä näytetään vain tämän henkilön yhteiset segmentit.

Tallentaaksesi kaavion, napsauta latauspainiketta henkilön valitsimen vieressä. Se lataa SVG-tiedoston, jossa on valkoinen tausta ja selite, mukaan lukien jokaisen yhteensopivuuden kokonaisjaetut sentimorganit. Jos selitteessä on valittuna yhteensopivuus, vain se yhteensopivuus sisältyy.
