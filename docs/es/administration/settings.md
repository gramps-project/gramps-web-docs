# Configuración de Administración

La página de **Configuración > Administración** es accesible a través del ícono de usuario en la barra de aplicaciones superior. Solo está disponible para usuarios con el rol de Propietario o Administrador y proporciona herramientas para gestionar la base de datos del árbol genealógico.

La página está organizada en secciones colapsables. Haz clic en el encabezado de una sección para expandirla. Esta página enumera las secciones y enlaces a donde cada una de ellas está descrita.
