Al iniciar sesión en Gramps Web por primera vez, se mostrará un formulario de Preferencias (etiquetado como Configuración del Usuario) que requerirá que el usuario seleccione un idioma para la interfaz y una [Persona Principal](https://www.gramps-project.org/wiki/index.php/Gramps_Glossary#home_person). La selección de la Persona Principal también se puede cambiar desde la Página de Inicio del sitio web.

La Persona Principal para un usuario de un sitio web de Gramps Web no tiene que ser la misma persona que el propietario del sitio eligió en Gramps para Escritorios; es una configuración personal que puede ser diferente para cada usuario de Gramps Web. La persona principal se utiliza para la vista inicial del árbol genealógico y el punto de partida para la mayoría de los Informes. Una elección típica sería que un usuario se seleccione a sí mismo como Persona Principal. Al colaborar con otro miembro de un Árbol, esos usuarios podrían querer establecer al ancestro común como la Persona Principal. Esto asegura un punto de referencia común para las relaciones distantes.

Para seleccionar a una persona como Persona Principal, comienza a escribir un Nombre o Apellido en el campo de texto y aparecerá una lista desplegable con coincidencias.

Si el árbol aún está vacío, no hay nadie para elegir todavía. En este caso, la página de inicio muestra una tarjeta de **Comenzar** que guía a los editores a través de los primeros pasos: primero agregando una persona (o importando un archivo de árbol genealógico), luego conectando personas al agregar una familia. La primera persona que crees en un árbol vacío se convierte automáticamente en tu Persona Principal. Consulta [Iniciar un nuevo árbol](start-tree.md) para una guía paso a paso.

Las configuraciones de idioma y Persona Principal se almacenan en el almacenamiento local del navegador, por lo que persistirán en un dispositivo determinado. La Persona Principal se almacena por separado para cada árbol.
