# Gramps-Web-Administrationshandbuch

Unabhängig davon, ob du deine eigene Gramps-Web-Instanz eingerichtet oder dich für eine vorinstallierte Instanz angemeldet hast, besteht der nächste Schritt darin, deine Familiendatenbank zu füllen und zu verwalten.

Der Schwerpunkt dieses Abschnitts liegt auf administrativen Aufgaben, die von **Baumbesitzern** durchgeführt werden. Normalerweise gibt es für jede Familiendatenbank einen Baumbesitzer (als Baumbesitzer kannst du jedoch auch weitere Baumbesitzerkonten erstellen).

Dieser Abschnitt befasst sich ausschließlich mit Aktionen, die über die Weboberfläche ausgeführt werden können. Informationen zu Befehlszeilenwerkzeugen oder zur Serverkonfiguration findest du im vorherigen Abschnitt [Einrichtung](../install_setup/setup.md).
