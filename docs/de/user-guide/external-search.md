# Externe Suche

Mit Gramps Web kannst du direkt von der Detailseite einer Person aus nach Personen auf externen Genealogie-Websites suchen.


## Durchführen einer externen Suche

So suchst du nach einer Person auf externen Websites:

1. Öffne die Detailansicht einer Person.
2. Klicke auf die Schaltfläche für die externe Suche.
3. Es wird ein Pop-up mit Links zu verschiedenen Genealogie-Websites wie CompGen, FamilySearch und Ancestry angezeigt.
4. Wenn du auf einen Link klickst, wird die Suchergebnisseite der jeweiligen Website geöffnet. Sie ist bereits mit dem Namen, den Geburts- und Sterbeorten sowie weiteren relevanten Informationen der Person ausgefüllt.

## Anpassen der Optionen für die externe Suche

Du kannst festlegen, welche externen Such-Websites im Pop-up angezeigt werden.

1. Klicke im Pop-up für die externe Suche oben auf die Schaltfläche mit dem Zahnrad, um den Bearbeitungsmodus zu öffnen.
2. Wähle die Websites aus oder ab, die du anzeigen oder ausblenden möchtest.
3. Speichere deine Änderungen.

## Hinzufügen einer benutzerdefinierten Suchmaschine

Du kannst neue externe Such-Websites mit benutzerdefinierten Parametern hinzufügen.

1. Klicke im Pop-up für die externe Suche oben auf die Schaltfläche mit dem Zahnrad, um den Bearbeitungsmodus zu öffnen.
2. Klicke auf die Schaltfläche „+ Benutzerdefinierte Suchmaschine hinzufügen“.
3. Es wird ein Abschnitt mit den Feldern „Name“ und „Such-URL“ angezeigt. Gib den Namen der Website und die URL mit durchsuchbaren Parametern ein, z. B. `https://example.com/search?name={{name_given}}_{{name_surname}}&place={{birth_place}}`.
4. Klicke auf die Schaltfläche „Hinzufügen“, um die neue Suchmaschine in die Liste aufzunehmen.
5. Die neue Suchmaschine wird gespeichert und kann später angepasst werden.
