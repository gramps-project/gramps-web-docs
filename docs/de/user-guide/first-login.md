Wenn du dich zum ersten Mal bei Gramps Web anmeldest, wird ein Einstellungsformular (mit der Bezeichnung „Benutzereinstellungen“) angezeigt, in dem du eine Sprache für das Frontend und eine [Hauptperson](https://www.gramps-project.org/wiki/index.php/Gramps_Glossary#home_person) auswählen musst. Die Auswahl der Hauptperson kann auch über die Startseite der Website geändert werden.

Die Hauptperson eines Benutzers einer Gramps-Web-Website muss nicht dieselbe Person sein, die der Eigentümer der Website in Gramps für Desktops ausgewählt hat – es handelt sich um eine persönliche Einstellung, die für jeden Benutzer von Gramps Web unterschiedlich sein kann. Die Hauptperson wird für die anfängliche Ansicht des Stammbaums und als Ausgangspunkt für die meisten Berichte verwendet. Eine typische Wahl wäre, sich selbst als Hauptperson auszuwählen. Bei der Zusammenarbeit mit einem anderen Mitglied eines Stammbaums möchten diese Benutzer möglicherweise den gemeinsamen Vorfahren als Hauptperson festlegen. Dadurch wird ein gemeinsamer Bezugspunkt für die entfernten Verwandtschaftsbeziehungen geschaffen.

Um eine Person als Hauptperson auszuwählen, beginne im Textfeld mit der Eingabe eines Vor- oder Familiennamens. Daraufhin wird eine Dropdown-Liste mit Treffern angezeigt.

Wenn der Stammbaum noch leer ist, gibt es noch niemanden zur Auswahl. In diesem Fall zeigt die Startseite eine Karte **Loslegen**, die Bearbeiter durch die ersten Schritte führt: zunächst eine Person hinzufügen (oder eine Stammbaumdatei importieren) und anschließend Personen durch das Hinzufügen einer Familie miteinander verbinden. Die erste Person, die du in einem leeren Stammbaum erstellst, wird automatisch zu deiner Hauptperson. Eine schrittweise Anleitung findest du unter [Einen neuen Stammbaum starten](start-tree.md).

Die Einstellungen für Sprache und Hauptperson werden im lokalen Speicher des Browsers gespeichert und bleiben daher auf dem jeweiligen Gerät erhalten. Die Hauptperson wird für jeden Stammbaum separat gespeichert.
