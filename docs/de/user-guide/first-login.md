Beim ersten Anmelden bei Gramps Web wird ein Einstellungsformular (mit der Bezeichnung Benutzereinstellungen) angezeigt, das den Benutzer auffordert, eine Sprache für das Frontend auszuwählen und eine [Hauptperson](https://www.gramps-project.org/wiki/index.php/Gramps_Glossary#home_person) festzulegen. Die Auswahl der Hauptperson kann auch von der Startseite der Website aus geändert werden.

Die Hauptperson für einen Benutzer einer Gramps Web-Website muss nicht die gleiche Person sein, die der Eigentümer der Website in Gramps für Desktops ausgewählt hat – es handelt sich um eine persönliche Einstellung, die für jeden Benutzer von Gramps Web unterschiedlich sein kann. Die Hauptperson wird für die anfängliche Ansicht des Stammbaums und als Ausgangspunkt für die meisten Berichte verwendet. Eine typische Wahl wäre, dass ein Benutzer sich selbst als Hauptperson auswählt. Wenn man mit einem anderen Mitglied eines Baumes zusammenarbeitet, möchten diese Benutzer möglicherweise den gemeinsamen Vorfahren als Hauptperson festlegen. Dies gewährleistet einen gemeinsamen Bezugspunkt für die entfernten Beziehungen.

Um eine Person als Hauptperson auszuwählen, beginnen Sie, einen Vornamen oder Nachnamen im Textfeld einzugeben, und eine Dropdown-Liste mit Übereinstimmungen wird angezeigt.

Wenn der Baum noch leer ist, gibt es noch niemanden zur Auswahl. In diesem Fall zeigt die Startseite eine **Loslegen**-Karte an, die die Bearbeiter durch die ersten Schritte führt: zuerst eine Person hinzufügen (oder eine Stammbaumdatei importieren), dann Personen verbinden, indem eine Familie hinzugefügt wird. Die erste Person, die Sie in einem leeren Baum erstellen, wird automatisch Ihre Hauptperson.

Die Einstellungen für Sprache und Hauptperson werden im lokalen Speicher des Browsers gespeichert, sodass sie auf einem bestimmten Gerät bestehen bleiben.
