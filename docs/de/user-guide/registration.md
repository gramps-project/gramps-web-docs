In einer Installation mit einem einzelnen Stammbaum kann sich jede Person bei einer Gramps-Web-Instanz für ein neues Konto registrieren. Dieses muss jedoch von einem Seitenbesitzer manuell aktiviert werden, bevor es zum Anmelden verwendet werden kann.

In einer Installation mit mehreren Stammbäumen benötigen Benutzer zusätzlich die Baum-ID zur Registrierung. In der Praxis bedeutet dies, dass sie sich über einen vom Besitzer des Stammbaums freigegebenen Registrierungslink registrieren können.

## 1. Registrierungsformular finden

Im Anmeldeformular auf der Startseite von Gramps Web gibt es normalerweise einen Link „Neues Konto registrieren“.

Wenn dieser Link fehlt, ist die Registrierung auf diesem Server entweder deaktiviert oder es handelt sich um eine Installation von Gramps Web mit mehreren Stammbäumen. Wende dich in beiden Fällen an den Besitzer des Stammbaums. Dieser kann ein Konto für dich erstellen oder dir einen Registrierungslink senden.

Wenn der Server die Anmeldung mit einem externen Konto unterstützt, beispielsweise Google, Microsoft oder dem Single Sign-on deiner Organisation, werden diese Optionen ebenfalls auf der Registrierungsseite angeboten. Wenn du eine davon auswählst, wird dein Konto ohne Passwort und ohne die unten beschriebene E-Mail-Bestätigung erstellt. Sofern der Server Rollen nicht automatisch zuweist, muss das Konto weiterhin vom Besitzer des Stammbaums aktiviert werden (Schritt 4).

Der Besitzer des Stammbaums findet und kopiert den Registrierungslink unter Einstellungen/Administration.

## 2. Registrierungsformular absenden

Das Registrierungsformular enthält vier Pflichtfelder: Benutzername, Passwort, E-Mail-Adresse und vollständiger Name. Wenn alle vier Felder ausgefüllt sind, klicke auf „Absenden“, um den Registrierungsvorgang zu starten.


## 3. E-Mail-Adresse bestätigen

Nachdem das Formular abgesendet wurde, wird eine automatische E-Mail an die angegebene E-Mail-Adresse gesendet. Sie enthält einen Link zur Bestätigung der E-Mail-Adresse. Wenn du darauf klickst, wird eine Bestätigungsseite geöffnet.

Wenn die Bestätigungs-E-Mail nicht eintrifft (und du deinen Spam-Ordner überprüft hast), wurde die E-Mail möglicherweise vom Administrator des Gramps-Web-Servers nicht korrekt konfiguriert.

## 4. Konto aktivieren

Nachdem die E-Mail-Adresse bestätigt wurde, erhält der Besitzer des Stammbaums eine E-Mail-Benachrichtigung und kann das neue Benutzerkonto aktivieren. Dazu muss er im Einstellungsbereich „Benutzerverwaltung“ auf der Einstellungsseite (erreichbar über das Benutzersymbol in der oberen App-Leiste) die Benutzerrolle von „deaktiviert“ in eine der [anderen Rollen](../install_setup/users.md) ändern.

Beachte, dass der neue Benutzer keine automatische Benachrichtigung erhält, dass sein Konto aktiviert wurde. Daher ist es empfehlenswert, dass der Administrator ihn persönlich darüber informiert.
