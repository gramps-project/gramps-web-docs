Gramps Web ermöglicht das Etikettieren von Personen in Fotos, ähnlich wie Gramps Desktop, und verknüpft die Person mit dem Medienobjekt. Dies wird durch die automatische Gesichtserkennung vereinfacht.

Eine Region eines Bildes kann nicht nur mit einer Person, sondern auch mit einer Familie, einem Ereignis, einem Ort, einer Quelle oder einem Beleg verknüpft werden – zum Beispiel ein Gebäude auf einem Foto oder ein Beleg auf einer gescannten Seite. Ein Objekt kann mehrere Regionen im selben Bild haben, beispielsweise auf einer Albumseite mit mehr als einem Foto derselben Person.

## Verknüpfen einer Region

Gehe wie folgt vor, um eine Region eines Bildes mit einem Objekt zu verknüpfen:

- Öffne die Detailansicht des Medienobjekts, z. B. indem du in der Vollbildvorschau auf „Details anzeigen“ klickst.
- Klicke auf die blaue Bearbeitungsschaltfläche in der unteren rechten Ecke. Wenn du diese Schaltfläche nicht siehst, verfügt dein Benutzer nicht über Bearbeitungsberechtigungen.
- Auf dem Bild siehst du mit gestrichelten Linien umrandete Kästen, die erkannten Gesichtern entsprechen. Klicke auf einen Kasten, um ihn auszuwählen.
- Um stattdessen selbst eine Region zu zeichnen, klicke auf die

- Klicke auf die Schaltfläche „Verknüpfen“ und wähle eine vorhandene Person, Familie, ein Ereignis, einen Ort, eine Quelle oder einen Beleg aus.

Verknüpfte Regionen werden mit einem durchgezogenen Rahmen und einer Beschriftung mit dem Namen des verknüpften Objekts sowie dem Symbol seines Typs angezeigt. In der Vollbildansicht des Bildes öffnet ein Klick auf eine verknüpfte Region das verknüpfte Objekt.

## Bearbeiten einer Region

Klicke im Bearbeitungsmodus auf eine verknüpfte Region, um sie auszuwählen. Danach kannst du:

- sie durch Ziehen **verschieben** oder mit ihren vier Eckgriffen **in der Größe ändern**. Die Änderung wird gespeichert, sobald du die Maustaste loslässt oder deinen Finger hebst.
- sie mit der Schaltfläche „Verknüpfen“ mit einem **anderen Objekt** verknüpfen.

Drücke die Esc-Taste oder klicke auf die Schaltfläche „Auswahl aufheben“, um die Auswahl aufzuheben und den Zeichenmodus zu verlassen.

Regionen können auch mit der Tastatur verwendet werden: Drücke die Tabulatortaste, um zwischen ihnen zu wechseln, und die Eingabetaste oder die Leertaste, um im Bearbeitungsmodus eine Region auszuwählen oder in der Vollbildansicht das verknüpfte Objekt zu öffnen.
