Gramps Web ermöglicht das Taggen von Personen in Fotografien, ähnlich wie Gramps Desktop, und verknüpft die Person mit dem Medienobjekt. Dies wird durch automatisierte Gesichtserkennung vereinfacht.

Ein Bereich eines Bildes kann nicht nur mit einer Person, sondern auch mit einer Familie, einem Ereignis, einem Ort, einer Quelle oder einer Zitation verknüpft werden – beispielsweise ein Gebäude auf einem Foto oder eine Zitation auf einer gescannten Seite. Ein Objekt kann mehrere Bereiche im selben Bild haben, zum Beispiel auf einer Albumseite mit mehr als einem Foto der gleichen Person.

## Verknüpfen eines Bereichs

Um einen Bereich eines Bildes mit einem Objekt zu verknüpfen, befolgen Sie diese Schritte:

- Öffnen Sie die Detailansicht des Medienobjekts, z. B. indem Sie auf "Details anzeigen" in der Vollbildansicht klicken.
- Klicken Sie auf die blaue Schaltfläche "Bearbeiten" in der unteren rechten Ecke. Wenn Sie diese Schaltfläche nicht sehen, hat Ihr Benutzer keine Berechtigung zum Bearbeiten.
- Überlagert auf dem Bild sehen Sie Kästchen mit gestricheltem Rand, die den erkannten Gesichtern entsprechen. Klicken Sie auf ein Kästchen, um es auszuwählen.
- Um einen Bereich selbst zu zeichnen, klicken Sie auf die

- Klicken Sie auf die Schaltfläche "Verknüpfen" und wählen Sie eine vorhandene Person, Familie, ein Ereignis, einen Ort, eine Quelle oder eine Zitation aus.

Verknüpfte Bereiche werden mit einem durchgehenden Rand und einem Etikett mit dem Namen des verknüpften Objekts sowie dem Symbol seines Typs angezeigt. In der Vollbildansicht des Bildes öffnet ein Klick auf einen verknüpften Bereich das verknüpfte Objekt.

## Bearbeiten eines Bereichs

Im Bearbeitungsmodus klicken Sie auf einen verknüpften Bereich, um ihn auszuwählen. Dann können Sie:

- **verschieben** Sie ihn, indem Sie ihn ziehen, oder **ändern** Sie seine Größe mit den vier Ecken. Die Änderung wird gespeichert, wenn Sie die Maustaste loslassen oder Ihren Finger heben.
- verknüpfen Sie ihn mit einem **anderen Objekt** über die Schaltfläche "Verknüpfen".
- **löschen** Sie ihn mit der

Drücken Sie die Escape-Taste oder klicken Sie auf die Schaltfläche "Auswahl aufheben", um die Auswahl zu löschen und den Zeichenmodus zu verlassen.

Bereiche können auch mit der Tastatur verwendet werden: Drücken Sie Tab, um zwischen ihnen zu wechseln, und Enter oder Leertaste, um einen im Bearbeitungsmodus auszuwählen oder um das verknüpfte Objekt in der Vollbildansicht zu öffnen.
