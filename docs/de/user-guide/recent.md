# Zuletzt durchsuchte Objekte

**Verlauf** in der Seitenleiste öffnet die Seite „Zuletzt durchsuchte Objekte“, auf der die zuletzt in Gramps Web geöffneten Objekte aufgelistet werden, wobei das zuletzt angezeigte Objekt ganz oben steht. Es werden bis zu 20 Objekte gespeichert.

Dies ist nützlich, um schnell zu einer Person, Familie oder einem anderen Objekt zurückzukehren, das du während deiner Sitzung zuvor angesehen hast, ohne erneut danach suchen zu müssen.

Klicke auf einen beliebigen Eintrag, um zu diesem Objekt zurückzukehren. Verwende die Schaltfläche **Alle löschen**, um die Liste zurückzusetzen.

Der Verlauf wird im lokalen Speicher des Browsers gespeichert – er gilt nur für das aktuelle Gerät und den aktuellen Browser und wird nicht mit anderen Benutzern geteilt.
