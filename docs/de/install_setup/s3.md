# Hosten von Mediendateien auf S3

Anstatt die Mediendateien des Familienstammbaums auf demselben Server wie die Gramps-Datenbank zu hosten, können sie auch auf Amazon S3 oder einem anderen API-kompatiblen Objektspeicherdienst gehostet werden. Dadurch werden die Speicher- und Datenverkehrsanforderungen an den Gramps-Webserver erheblich reduziert.

## Anmeldedaten vorbereiten

Rufe in deinem AWS-Konto (oder dem Konto eines anderen Objektspeicherdienstes) eine *Access Key ID* und einen *Secret Access Key* ab (möglicherweise möchtest du zunächst einen separaten Benutzer mit einer Sicherheitsrichtlinie erstellen, die nur den Zugriff auf S3 erlaubt).

## Mediendateien hochladen

Um deine vorhandenen Mediendateien auf S3 hochzuladen, kannst du unter Linux eine lokale Gramps-Installation mit dem Addon „S3 Media Uploader“ verwenden, das du direkt über Gramps Desktop installieren kannst. Allerdings ist eine zusätzliche Konfiguration erforderlich.

Das Addon verwendet intern die Python-Bibliothek `boto3`. Du musst sie zunächst mit folgendem Befehl installieren:

```bash
python3 -m pip install boto3
```

Exportiere in der Befehlszeile die Access Key ID und den Secret Key in die entsprechenden Umgebungsvariablen:
```bash
export AWS_ACCESS_KEY_ID=my_access_key_id
export AWS_SECRET_ACCESS_KEY=my_secret_access_key
```

Jetzt kannst du den Uploader mit folgendem Befehl starten:

```bash
gramps -O "My Family Tree" -a tool \
    -p "name=s3uploader,bucket_name=my_bucket_name"
```

Ersetze dabei „My Family Tree“ durch den Namen deines Familienstammbaums und `my_bucket_name` durch den vollständigen Namen deines S3-Buckets. Du benötigst einen eigenen S3-Bucket für deine Gramps-Web-Instanz. Falls der Bucket noch nicht existiert, versucht das Addon „S3 Uploader“, ihn zu erstellen.

## Gramps Web konfigurieren

Um den neuen S3-Bucket als Medienquelle für Gramps Web zu verwenden, setze einfach die [Konfigurationsoption](configuration.md) `MEDIA_BASE_DIR` auf `s3://my_bucket_name`.

Bei Verwendung von [Docker Compose](deployment.md) ist es am einfachsten, alle Umgebungsvariablen zum Block `environment:` des Dienstes `grampsweb` hinzuzufügen:

```yaml
environment:
  AWS_ACCESS_KEY_ID: my_access_key_id
  AWS_SECRET_ACCESS_KEY: my_secret_access_key
  GRAMPSWEB_MEDIA_BASE_DIR: s3://my_bucket_name
  AWS_DEFAULT_REGION: eu-central-1
```

Beachte, dass nur die Gramps-Web-Konfigurationsoption das Präfix `GRAMPSWEB_` trägt; die Variablen `AWS_*` werden direkt von der zugrunde liegenden `boto3`-Bibliothek gelesen und müssen ohne Präfix bleiben.

Wenn du einen anderen S3-kompatiblen Objektspeicher als AWS verwenden möchtest (z. B. GCP oder für lokale Tests), setze die Umgebungsvariable `AWS_ENDPOINT_URL`.

## Mediendateien synchronisieren

Um Mediendateien zwischen einer lokalen Gramps-Installation und den in S3 gehosteten Gramps-Web-Mediendateien synchron zu halten, unterstützt das [Gramps Web Sync Addon](../administration/sync.md) die Dateisynchronisierung über die Web-API.
