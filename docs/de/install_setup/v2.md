# Gramps 5.2-Upgradeleitfaden

**Gramps 5.2** wurde am 23. Februar 2024 veröffentlicht. Da es im Vergleich zu Gramps 5.1 ein neues Datenbankschema für Familienstammbäume verwendet, sind beim Upgrade von Gramps Web für die Verwendung mit Gramps 5.2 zusätzliche Schritte erforderlich. Diese Seite beschreibt die notwendigen Schritte.


## Übersicht der Schritte


Dies ist eine Übersicht der für das Upgrade erforderlichen Schritte. 
Außerdem wird angezeigt, welche Schritte vom Administrator des Gramps-Web-Servers, vom Besitzer des Familienstammbaums ausgeführt werden und ob sie nur für Benutzer des [Sync-Add-ons](../administration/sync.md) erforderlich sind.

## Detaillierte Schritte

Dieser Abschnitt enthält weitere Einzelheiten zu einigen der oben genannten Schritte.

### Familienstammbaum sichern

Gehe in Gramps Web zur Seite „Export“ und wähle „Gramps XML (family tree)“ (die Standardoption) aus. Klicke auf „Generate“ und warte, bis der Download der .gramps-Datei beginnt.

Du kannst auch [auf die übliche Weise](https://www.gramps-project.org/wiki/index.php/How_to_make_a_backup) eine Sicherung in Gramps Desktop erstellen.

### Datenbankschema des Familienstammbaums aktualisieren

Wenn du nach dem Upgrade zum ersten Mal auf Gramps Web zugreifst, wird ein Bildschirm mit der folgenden Meldung angezeigt: 

> Der Familienstammbaum, den du zu laden versuchst, verwendet eine Schemaversion, die von dieser Version von Gramps Web nicht unterstützt wird. Daher kannst du diesen Familienstammbaum nicht laden, ohne sein Schema zu aktualisieren. Diese Aktion kann nicht rückgängig gemacht werden.

Du kannst jetzt auf die Schaltfläche „Upgrade Family Tree“ klicken. Daraufhin wird ein Fortschrittsbalken angezeigt, und der Vorgang sollte nicht länger als eine Minute dauern. Keine Sorge: Wenn du versehentlich dein Browserfenster schließt, wird die Konvertierung im Hintergrund fortgesetzt.

!!! warning
    Wenn du eine nicht standardmäßige Einrichtung *ohne* Hintergrundaufgabenwarteschlange verwendest, kann das Datenbank-Upgrade fehlschlagen und dein Familienstammbaum beschädigt werden. Du kannst vor der Aktualisierung von Gramps Web überprüfen, ob du eine Hintergrundaufgabenwarteschlange verwendest. Gehe dazu im Einstellungsbereich zum Abschnitt „System Information“ und stelle sicher, dass dort „task queue: true“ angezeigt wird.



### Gramps Desktop aktualisieren

Befolge die Installationsanweisungen für Gramps Desktop für dein Betriebssystem.

### Aktualisiertes Sync-Add-on installieren

Du kannst den in Gramps 5.2 enthaltenen [neuen Plugin-Manager](https://gramps-project.org/wiki/index.php/Addon:Plugin_Manager) verwenden – suche einfach nach Gramps Web Sync, klicke auf „install“ und starte Gramps neu.
