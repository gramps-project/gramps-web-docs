# Gramps-6.0-Upgrade-Leitfaden

Gramps 6.0 wurde am 19. März 2025 veröffentlicht. Da es im Vergleich zu Gramps 5.2 ein neues Datenbankschema für Familien-Stammbäume verwendet, sind beim Upgrade von Gramps Web für die Verwendung mit Gramps 6.0 zusätzliche Schritte erforderlich. Diese Seite beschreibt die notwendigen Schritte.

!!! info
    Zuletzt aktualisiert: 4. Mai 2025

## Detaillierte Schritte

Dieser Abschnitt enthält weitere Informationen zu einigen der oben genannten einzelnen Schritte.

### Deinen Familien-Stammbaum sichern

Gehe in Gramps Web zur Seite „Export“ und wähle „Gramps XML (Familienstammbaum)“ (die Standardoption) aus. Klicke auf „Generieren“ und warte, bis der Download der .gramps-Datei beginnt.

Du kannst auch in Gramps Desktop [auf die übliche Weise](https://www.gramps-project.org/wiki/index.php/How_to_make_a_backup) eine Sicherung erstellen.

### Das Datenbankschema des Familien-Stammbaums aktualisieren

Wenn du nach dem Upgrade zum ersten Mal auf Gramps Web zugreifst, wird dir ein Bildschirm mit der folgenden Meldung angezeigt: 

> Der Familien-Stammbaum, den du zu laden versuchst, verwendet eine Schemaversion, die von dieser Version von Gramps Web nicht unterstützt wird. Daher kannst du diesen Familien-Stammbaum nicht laden, ohne sein Schema zu aktualisieren. Diese Aktion kann nicht rückgängig gemacht werden.

Du kannst jetzt auf die Schaltfläche „Familien-Stammbaum aktualisieren“ klicken. Es wird ein Fortschrittsbalken angezeigt, und der Vorgang sollte nicht länger als eine Minute dauern. Keine Sorge: Wenn du versehentlich dein Browserfenster schließt, wird die Konvertierung im Hintergrund fortgesetzt.

!!! warning
    Wenn du eine nicht standardmäßige Einrichtung *ohne* Hintergrundaufgabenwarteschlange verwendest, kann das Datenbank-Upgrade fehlschlagen und dein Familien-Stammbaum beschädigt werden. Du kannst vor der Aktualisierung von Gramps Web überprüfen, ob du eine Hintergrundaufgabenwarteschlange verwendest, indem du in den Einstellungen zum Abschnitt „Systeminformationen“ gehst und sicherstellst, dass dort „task queue: true“ angezeigt wird.


### Gramps Desktop aktualisieren

Befolge die Installationsanweisungen für Gramps Desktop für dein Betriebssystem.

### Das aktualisierte Sync-Add-on installieren

Du kannst den Plugin-Manager in Gramps 6.0 verwenden, um das Gramps-Web-Sync-Add-on zu installieren. Suche nach Gramps Web Sync, klicke auf „Installieren“ und starte Gramps neu.
