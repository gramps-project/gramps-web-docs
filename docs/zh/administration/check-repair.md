# 检查和验证数据

**家谱处理**部分的[管理设置](settings.md)包含两个检查家谱的工具：一个用于检查数据库中的技术问题，另一个用于检查不合理的数据。

## 检查和修复数据库

该工具检查 Gramps 数据库中的内部不一致性，并修复可以修复的问题 – 类似于 Gramps 桌面版中的[检查和修复数据库工具](https://www.gramps-project.org/wiki/index.php/Gramps_5.2_Wiki_Manual_-_Tools#Check_and_Repair_Database)。

点击 **检查和修复**，并等待进度指示器完成。结果显示在按钮下方：

- 如果没有发现错误，将显示确认消息。
- 如果发现错误，将显示应用的修复摘要。

如果您遇到意外错误或行为，可能是由于数据库不一致性引起的，例如对象之间缺失关系，请运行此工具。

## 验证数据

虽然[检查和修复数据库](#check-and-repair-database)查找*技术*不一致性，但此工具查找*不合理*的数据 – 类似于 Gramps 桌面版中的[验证数据工具](https://gramps-project.org/wiki/index.php/Gramps_5.0_Wiki_Manual_-_Tools#Verify_the_Data)。它报告一些不可能的事情，但由于不太可能而值得再检查一遍，例如一位12岁的母亲或一位活到130岁的人。

在 **选项** 下，您可以调整测试使用的阈值 – 最大年龄、结婚或生育的最小和最大年龄、最大子女数等等 – 以及是否估算缺失或不准确的日期，以及是否报告无效日期，例如2月31日。

点击 **验证数据** 开始。检查作为后台任务运行，结果随后列在 **数据验证结果** 下。此工具不会更改任何内容：它只报告它所发现的内容。

!!! note
    发现并不证明存在错误。长寿和较大的年龄差距确实存在，因此将结果视为待检查事项的列表，而不是待修复事项的列表。
