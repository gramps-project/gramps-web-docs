# 为树的拥有者创建账户

在开始使用 Gramps Web 之前，您需要为树的拥有者创建一个账户。如果给定树没有用户账户，将显示一个表单来创建账户。该表单取决于服务器的设置是单树还是多树。

## 单树设置：创建管理员账户

在单树设置的服务器上，当尚未存在用户账户时，打开 Gramps Web 会显示一个创建管理员账户的表单。管理员用户将是（单个）树的拥有者和安装的管理员。该表单还允许设置电子邮件配置，以便进行电子邮件通知（例如，重置用户密码）。如果电子邮件配置已经通过配置文件或服务器上的环境变量添加，则可以将此部分留空。

密码必须输入两次；只有当两个输入匹配时，表单才能提交。

如果实例已经设置，打开表单的地址会显示一条消息，要求您使用现有账户登录。

## 多树设置：创建管理员账户

在多树设置中，如果在*任何树*中不存在用户，将显示相同的创建管理员账户的表单，即当服务器刚刚创建时。

## 多树设置：创建树拥有者账户

在多树设置中，每个用户都与单个树绑定。即使其他树中已经存在用户，如果*此树*尚不存在拥有者，则可以在 Web 界面中创建树拥有者。

然而，树拥有者创建表单不会自动显示在 Gramps Web 的主页上，该主页对所有树都是相同的。相反，可以通过访问 `https://my-gramps-instance/firstrun/my-tree-id` 来访问，其中 `https://my-gramps-instance` 是您 Gramps Web 安装的基本地址，`my-tree-id` 是您树的 ID。

网站管理员创建新树的可能工作流程是：

- 通过 REST API 创建树，获取新树的树 ID
- 与潜在的树拥有者共享带有适当树 ID 的拥有者创建表单的链接

树拥有者创建表单类似于上述描述的管理员创建表单，只是它不允许更改电子邮件配置（这仅允许管理员进行）。
