## 备份你的家谱

要创建家谱的备份，请在 Gramps Web 中打开导出页面，并选择 Gramps XML 格式。

点击“导出”将生成文件，并在准备好后开始下载。

请注意，如果你的 Gramps Web 用户没有权限查看私人记录，则导出将不是完整的备份，因为它将不包含任何私人记录。

此 Gramps XML 文件稍后可以用于通过 [从备份恢复](settings.md#restore-from-backup) 将树恢复到此确切状态。

## 与其他家谱程序的用户共享你的家谱

当以 Gramps XML 形式共享家谱数据不可行时，你也可以导出 GEDCOM 文件。请注意，这不适合作为 Gramps Web 树的备份。

## 备份你的媒体文件

要备份你的媒体文件，你可以在导出页面创建并下载所有媒体文件的 ZIP 压缩包。

请注意，特别是对于大型树，这可能是对服务器的昂贵操作，仅在绝对必要时进行。

定期备份媒体文件的更好选择是使用 [Gramps Web Sync 插件](sync.md)（它本身不是备份解决方案），并在本地计算机上创建增量备份。

在这两种情况下，如果你的 Gramps Web 用户没有权限查看私人记录，导出将不包含私人媒体对象的文件。

## 移动到不同的 Gramps Web 实例

Gramps Web 不会将你锁定在特定的提供商中，你可以随时移动到不同的 Gramps Web 实例，而不会丢失任何数据，也不需要直接访问任何服务器。

要实现完整迁移，请按照以下步骤操作（假设你拥有树的所有者权限）：

1. 转到导出页面并将你的树导出为 Gramps XML (`.gramps`) 文件。如果你使用 [Sync 插件](sync.md)，你也可以在 Gramps 桌面上生成导出。
2. 在导出页面，生成并下载媒体归档。如果你使用 [Sync 插件](sync.md)，你也可以简单地将本地 Gramps 媒体文件夹压缩为 ZIP。
3. 转到 设置 > 管理 > 管理用户，并点击“导出用户详细信息”按钮。它将下载一个 JSON 文件。
4. 在新的 Gramps Web 实例中，打开导入页面。导入在步骤 1 中导出的 `.gramps` 文件。
5. 在新的 Gramps Web 实例的导入页面，上传媒体归档（ZIP）。
6. 转到新的 Gramps Web 实例的 设置 > 管理 > 管理用户。点击“导入用户帐户”按钮，并上传在步骤 3 中下载的 JSON 文件。

请注意，虽然你的用户帐户将被迁移，但所有用户都需要通过使用“忘记密码”链接来设置新密码，因为密码以加密形式存储，无法导出。
