# 导出数据

导出页面允许您以多种格式下载家谱数据，以及所有媒体文件的归档。

## 将家谱导出为 Gramps XML

要获取家谱数据的副本，请在 Gramps Web 中打开导出页面并选择 Gramps XML 格式。点击 **生成** 以创建文件，文件准备好后点击 **下载**。对于大型家谱，生成文件可能需要一些时间；您可以在此期间离开页面，稍后从 [通知](../user-guide/notifications.md) 中的条目下载文件。

请注意，如果您的 Gramps Web 用户没有查看私人记录的权限，则导出将不包含任何私人记录。

## 备份您的家谱

有关家谱的完整备份，包括其设置和用户，请参见 [备份和恢复](backups.md)。Gramps XML 导出仅可作为家谱数据的备份，并可以通过 [从备份恢复](backups.md#restore-from-backup) 进行恢复。

## 与其他家谱程序的用户共享您的家谱

当以 Gramps XML 共享家谱数据不是一个选项时，您还可以导出 GEDCOM 文件。请注意，这不适合作为您 Gramps Web 家谱的备份。

## 备份您的媒体文件

要备份您的媒体文件，您可以在导出页面创建并下载所有媒体文件的 ZIP 归档。

请注意，特别是对于大型家谱，这可能是对服务器的一个昂贵操作，仅在绝对必要时进行。因此，可以创建的媒体归档数量是有限的（默认每小时一个）。如果达到限制，将显示错误消息。

定期备份媒体文件的更好选择是使用 [Gramps Web Sync 插件](sync.md)（本身并不是备份解决方案），并在您的本地计算机上创建增量备份。

在这两种情况下，如果您的 Gramps Web 用户没有查看私人记录的权限，则导出将不包含私人媒体对象的文件。

## 移动到不同的 Gramps Web 实例

Gramps Web 不会将您锁定在特定的提供商中，您可以随时迁移到不同的 Gramps Web 实例，而不会丢失任何数据，也无需直接访问任一服务器。

要实现完整迁移，请按照以下步骤操作（假设您具有树的所有者权限）：

1. 转到导出页面并将您的家谱导出为 Gramps XML (`.gramps`) 文件。如果您使用 [Sync 插件](sync.md)，您也可以在 Gramps 桌面中生成导出。
2. 在导出页面，生成并下载媒体归档。如果您使用 [Sync 插件](sync.md)，您也可以简单地将本地 Gramps 媒体文件夹压缩为 ZIP 文件。
3. 转到设置 > 管理 > 管理用户，点击“导出用户详细信息”按钮。它将下载一个 JSON 文件。
4. 在新的 Gramps Web 实例中，打开 [导入页面](import.md)。导入在步骤 1 中导出的 `.gramps` 文件。
5. 在新的 Gramps Web 实例的导入页面，上传媒体归档（ZIP）到 [导入媒体文件](import-media.md) 下。
6. 转到新的 Gramps Web 实例的设置 > 管理 > 管理用户。点击“导入用户帐户”按钮并上传在步骤 3 中下载的 JSON 文件。

请注意，虽然您的用户帐户将被迁移，但所有用户都需要通过使用“忘记密码”链接设置新密码，因为密码以加密形式存储，无法导出。
