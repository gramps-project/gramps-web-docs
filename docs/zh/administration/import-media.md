# 导入媒体文件

如果您已经[导入了家谱](import.md)并需要上传相应的媒体文件，请在[管理设置](settings.md)的“数据”部分使用**导入媒体文件**。它需要一个包含缺失媒体文件的ZIP文件。文件与您树中的媒体对象匹配有两种方式：

- **通过校验和。** 对于具有校验和的媒体对象——例如从Gramps Desktop导入的树——将使用与校验和匹配的文件，而不管其名称或ZIP文件中的文件夹结构如何。这仅在Gramps数据库中的校验和正确时有效，运行检查和修复工具可以确保这一点。
- **通过路径。** 没有校验和的媒体对象——在GEDCOM导入后通常是这种情况——通过其路径进行匹配：ZIP文件必须包含在媒体对象中存储的确切相对路径下的文件。

如果您在GEDCOM文件中存储的路径是绝对路径（例如 `C:\Users\...\photo.jpg`），则通过路径匹配将无法工作。在这种情况下，建议先将所有内容导入Gramps Desktop，它有更多选项将现有媒体文件与导入的树关联，然后按照[来自Gramps Desktop的说明](import.md#coming-from-gramps-desktop)迁移到Gramps Web。
