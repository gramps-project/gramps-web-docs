# 导入媒体文件

如果您已经[导入了家谱](import.md)并需要上传相应的媒体文件，请在[导入页面](import.md)上使用**导入媒体文件**，该选项位于家谱导入的下方。它需要一个包含缺失媒体文件的ZIP文件。只有当树中包含媒体对象时，才能进行上传，因为文件是与现有媒体对象匹配的——家谱文件仅引用其媒体文件，因此请先导入它。

文件通过以下两种方式之一与您树中的媒体对象匹配：

- **通过校验和。** 对于具有校验和的媒体对象——例如从Gramps桌面导入的树——将使用具有匹配校验和的文件，而不管其名称或ZIP文件中的文件夹结构。这仅在Gramps数据库中的校验和正确时有效，运行检查和修复工具可以确保这一点。
- **通过路径或文件名。** 对于没有校验和的媒体对象——通常在GEDCOM导入后出现——通过存储在媒体对象中的相对路径进行匹配。如果ZIP中没有文件具有该路径，则仅通过文件名进行匹配，忽略大小写（自Gramps Web API 3.26起）。这也适用于来自其他程序的绝对路径，例如`C:\Users\...\Family\grandpa.jpg`，因此您可以简单地将所有文件放入ZIP文件中。只有在文件名在ZIP文件中和仍然没有文件的媒体对象中是唯一时，才会使用该文件名。

上传后，结果会显示找到文件的媒体对象数量，并列出ZIP文件中没有文件的对象，附带其Gramps ID和存储路径。使用此列表查找缺失的文件，然后上传另一个仅包含这些文件的ZIP文件——已经在服务器上的文件不会受到影响。

如果多个媒体对象在不同文件夹中具有相同的文件名，则通过文件名匹配对它们不起作用。要么从ZIP文件中存储的路径重新创建文件夹结构，要么先将所有内容导入Gramps桌面，该软件有更多选项将现有媒体文件与导入的树关联，然后按照[来自Gramps桌面](import.md#coming-from-gramps-desktop)中描述的方式迁移到Gramps Web。

## 媒体文件状态

[管理设置](settings.md)的**数据**部分显示：

- 树中媒体对象的总数以及是否有缺少校验和的对象
- 与服务器上缺失的文件相关联的媒体对象数量

绿色的勾号表示一切正常。如果检测到问题，将显示受影响对象的链接。缺失的校验和通常发生在从包含媒体引用但不包含实际文件的格式（如GEDCOM）导入数据时。可以按照上述描述上传缺失的文件。
