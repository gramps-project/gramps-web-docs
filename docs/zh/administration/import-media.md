# 导入媒体文件

如果您已经[导入了家谱](import.md)并需要上传相应的媒体文件，请在[管理设置](settings.md)的“数据”部分使用**导入媒体文件**。它需要一个包含缺失媒体文件的ZIP文件。文件与您树中的媒体对象的匹配方式有两种：

- **按校验和。** 对于具有校验和的媒体对象——例如从Gramps Desktop导入的树——将使用具有匹配校验和的文件，而不管其名称或ZIP文件中的文件夹结构。这仅在Gramps数据库中的校验和正确时有效，运行检查和修复工具可以确保这一点。
- **按路径。** 对于没有校验和的媒体对象——通常在GEDCOM导入后出现——通过其路径进行匹配：ZIP文件必须包含在媒体对象中存储的确切相对路径下的文件。

如果您在GEDCOM文件中存储的路径是绝对路径（例如 `C:\Users\...\photo.jpg`），则按路径匹配将不起作用。在这种情况下，建议首先将所有内容导入Gramps Desktop，它有更多选项将现有媒体文件与导入的树关联，然后按照[来自Gramps Desktop](import.md#coming-from-gramps-desktop)的说明迁移到Gramps Web。

## 媒体文件状态

[管理设置](settings.md)的**数据**部分显示：

- 树中媒体对象的总数，以及是否有任何对象缺少校验和
- 与服务器上缺失的文件关联的媒体对象数量

绿色勾号表示一切正常。如果检测到问题，将显示受影响对象的链接。缺失的校验和通常发生在从包含媒体引用但不包含实际文件的格式（例如GEDCOM）导入数据时。缺失的文件可以按照上述说明上传。
