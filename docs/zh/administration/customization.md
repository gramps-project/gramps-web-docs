# 自定义树

树的拥有者和管理员可以为所有用户调整树的名称和外观，以及其主页。这些设置可以在[管理设置](settings.md)的**树设置**和**自定义**部分中找到。

## 家谱名称

!!! note
    重命名树仅在[多树设置](../install_setup/multi-tree.md)中有效，或在[服务器配置](../install_setup/configuration.md)中显式设置了`TREE_ID`时有效。在默认的单树安装中，如果未设置`TREE_ID`，则会引发错误。

这允许更改底层Gramps家谱数据库的名称。输入新名称并点击**重命名**以应用。

!!! tip
    如果您只想更改应用程序栏中显示的名称而不重命名数据库，请使用[应用标题](#app-title)设置。

## 研究者信息

设置主要研究者的姓名、地址和联系方式。这些信息会嵌入到导出中（例如GEDCOM文件）。

## 主题颜色

为Gramps Web界面设置自定义**主色**和**强调色**。这些颜色会应用于该树的所有用户，并在保存后立即生效。

使用颜色选择器选择颜色，然后点击**保存**。点击**重置**以恢复默认设置。

## 应用标题

为应用程序设置自定义标题。如果设置了此项，则会覆盖浏览器标题栏和顶部应用栏中的家谱名称。

输入标题并点击**保存**。留空以使用默认值（家谱名称）。

## 主页备注

选择一个Gramps **备注**对象以在仪表板主页上显示。备注内容会渲染在主仪表板列下方，并对所有有权访问该树的用户可见。

使用对象选择器搜索并选择一个备注，然后保存。点击**移除**以清除当前主页备注。

## 主页图片

选择一个Gramps **媒体**对象以在仪表板主页上显示为图片。当与主页备注结合使用时，图片会出现在备注文本旁边。如果没有备注，则只显示图片。

使用对象选择器搜索并选择一个媒体对象，然后保存。点击**移除**以清除当前主页图片。

## 导出/导入设置

树级设置（应用标题、主题颜色、主页备注/图片等）可以导出为JSON文件以备份或复制到另一个Gramps Web实例。

- 点击**导出设置**以下载当前设置为JSON文件。
- 点击**导入树设置**以上传先前导出的JSON文件并应用设置。
