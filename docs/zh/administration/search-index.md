# 搜索索引

**搜索索引**部分在[管理设置](settings.md)中显示全文搜索索引的状态，并允许您重建它。

## 管理搜索索引

Gramps Web 维护一个全文搜索索引，该索引通常在数据更改时自动更新。状态指示器显示当前已索引的对象数量与总对象数量的对比。

点击**更新搜索索引**以触发完全重建。在任务在后台运行时，会显示进度指示器。这种情况很少需要。

如果一个树尚未建立搜索索引，例如在更改了索引格式的服务器升级后，Gramps Web 会在第一次打开该树时在后台构建它。在构建过程中，该部分显示“搜索索引正在构建。”而不是计数，**更新搜索索引**被禁用，搜索结果可能不完整。构建过程会在[通知](../user-guide/notifications.md)中显示为“更新搜索索引”任务。
