在单树安装中，任何人都可以在 Gramps Web 实例上注册新账户，但在可以登录之前，需要由站点所有者手动启用。

在多树安装中，用户还需要树 ID 才能注册；实际上，这意味着他们可以使用树所有者共享的注册链接进行注册。

## 1. 找到注册表单

在 Gramps Web 的主页登录表单上，通常会有一个“注册新账户”的链接。

如果这个链接缺失，可能是该服务器上禁用了注册，或者这是一个多树安装的 Gramps Web。在这两种情况下，请联系树所有者，他们可以为您创建一个账户或发送注册链接。

如果服务器支持使用外部账户（如 Google、Microsoft 或您组织的单点登录）进行登录，注册页面也会提供这些选项。选择其中一个将创建一个没有密码的账户，并且不需要下面的电子邮件确认。除非服务器自动分配角色，否则账户仍需由树所有者启用（步骤 4）。

树所有者可以在设置/管理下找到并复制注册链接。

## 2. 提交注册表单

注册表单有四个必填字段：用户名、密码、电子邮件地址和全名。当所有四个字段都填写完毕后，点击“提交”以开始注册过程。

## 3. 确认电子邮件地址

表单提交后，将向提供的电子邮件地址发送一封自动电子邮件，包含电子邮件确认链接。点击该链接将打开确认页面。

如果确认电子邮件没有到达（并且您已检查过垃圾邮件文件夹），可能是 Gramps Web 服务器管理员未正确配置电子邮件。

## 4. 启用账户

在电子邮件地址确认后，树所有者将收到电子邮件通知，并可以通过访问设置页面中的“用户管理”部分（通过顶部应用栏中的用户图标访问）来启用新用户账户，并将用户角色从“禁用”更改为任何其他[角色](../install_setup/users.md)。

请注意，新用户将*不会*收到账户已启用的自动通知，因此建议管理员亲自通知他们。
