# 修订历史

修订历史视图显示了对家谱所做的所有编辑。

列表视图按“事务”对编辑进行分组。事务是一组对 Gramps 对象进行的一次或多次添加、删除或更改。例如，添加一个有两个现有人员作为父母的新家庭会生成一个事务，其中包含一个新增的家庭对象和两个修改过的人员对象（因为它们包含指向新家庭对象的链接）。

点击一个事务会打开事务详细视图。它包含按 Gramps 对象列出的单个添加、删除和更新的列表。

选择一个单独的更改会打开 Gramps 对象的原始 JSON 表示形式的视图，添加和删除分别以绿色和红色突出显示。差异上方的按钮会直接带您到该对象的页面。

## 单个对象的修订

要查看特定人员、家庭、事件或其他对象的历史，请打开其页面并切换到 **修订** 选项卡。它列出了对该对象所做的每个更改，最新的在前，包括更改类型（添加、更新或删除）、执行更改的用户以及时间。点击一个条目会打开它所属的事务，您可以检查差异或撤销它。

点击 **显示更多** 以加载较旧的条目；对于历史非常长的对象，仅显示最近的修订。对于在记录修订历史之前最后更改的对象，该选项卡仅显示最后更改的时间。

!!! note
    修订选项卡对成员及以上可见，并要求 Gramps Web API 版本 3.22 或更高版本。

## 撤销修订

在事务详细页面上，**撤销** 按钮允许您逆转该事务。点击它会检查是否可以干净地执行撤销。

**干净撤销** – 如果自事务以来没有任何受影响的对象被修改，则可以在没有风险的情况下进行撤销。会显示一个确认对话框，点击 **撤销** 会逆转该事务。

**需要强制** – 如果一个或多个受影响的对象被后续事务修改，则无法进行干净撤销。对话框会警告强制撤销可能导致数据不一致，因为依赖于相关对象的后续更改将保持不变，即使基础对象被还原。您可以选择取消或点击 **强制撤销** 继续进行。

在这两种情况下，撤销将作为后台任务运行，并显示进度指示器。
