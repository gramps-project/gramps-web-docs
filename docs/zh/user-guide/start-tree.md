# 开始一个新家谱

本页面将指导您在一个空的家谱中进行第一步：添加自己、添加父母，并查看家谱图中的结果。大约需要 15 分钟。

如果您已经在其他家谱程序或 Gramps Desktop 中有一个家谱，您无需手动重新输入 – 请参见 [导入数据](../administration/import.md)。

!!! note
    添加人员需要编辑者角色或更高权限。树的所有者始终拥有该权限。有关所有角色的信息，请参见 [用户系统](../install_setup/users.md)。

## 1. 创建地点

在 Gramps 中，一个地点只需创建一次，然后在每个发生事件时选择它 – 例如几个兄弟姐妹在同一城镇出生。这就是为什么在您可以将其选择为某人的出生地点之前，地点必须存在。

要创建您出生的地点：

1. 点击顶部应用栏中的 **+**（添加）按钮，然后选择 **地点**。
2. 输入地点的 **名称**，并可选地输入其 **类型**（例如城市或村庄）。
3. 可选地，点击 **在地图上选择** 以设置其坐标，以便该地点出现在 [地图](map.md) 上。
4. 点击 **添加**。

以相同的方式创建您父母的出生地点。如果您还不知道某个地点，可以跳过 – 您可以稍后添加。

## 2. 添加自己

返回主页。当树为空时，它会显示一个 **开始使用** 卡片。点击 **新建人员** 以打开新人员的表单：

- **姓名** – 您的名字和姓氏
- **性别**
- **出生日期** – 请参见下面的 [输入日期](#entering-dates)
- **出生地点** – 点击 **选择现有地点** 并搜索您创建的地点

将死亡字段留空，然后点击 **添加**。新人员的页面将打开。

在空树中创建的第一个人自动成为您的 **家庭成员**：家谱图的起始人。您可以随时在主页上选择不同的家庭成员。

### 输入日期

日期作为单独的年份、月份和日期字段输入。如果您只知道年份，请只填写年份。对于不确定的日期，请更改日期的类型 – 例如改为“约”或“之前” – 而不是猜测确切的日期。

## 3. 添加您的父母

1. 点击侧边栏中的 **家谱**。图表显示您作为家庭成员。
2. 点击右下角的铅笔按钮以切换到编辑模式。
3. 点击您卡片上的小 **+** 按钮。**添加家庭成员** 对话框将打开。
4. 在 **父亲** 旁边，点击 **+** 图标以创建新人员，按照之前的方式填写表单并保存。您的父亲将出现在图表中，并与您关联。
5. 对 **母亲** 重复上述步骤。

每个关系旁边的 **链接** 图标连接一个已经存在于您树中的人，而不是创建一个新的人。

以相同的方式，点击图表中任何卡片上的 **+** 以添加该人的父母、子女或配偶。每次更改都会立即保存。要退出编辑模式，请点击顶部应用栏中的关闭按钮。

## 4. 查看结果

图表现在显示您和您的父母。尝试页面顶部选项卡中的其他图表类型 – 例如扇形图 – 并点击任何人的卡片以将图表居中到他们身上。有关所有图表和选项，请参见 [家谱](tree.md)。

## 下一步

- **添加更多细节。** 打开一个人的页面 – 例如通过图表工具栏中的 **人员详情** 按钮 – 以添加进一步的事件、备注、来源等。有关可以直接在图表中完成的操作，请参见 [在树视图中编辑](tree-edit.md)。
- **添加照片和文档。** 请参见 [添加媒体文件](media.md)。
- **邀请您的家人。** 亲属需要在您的树上拥有自己的账户；请参见 [管理用户](../administration/users.md) 和 [注册](registration.md)。
