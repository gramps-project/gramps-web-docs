# 标签

标签是可以应用于 Gramps 数据库中任何对象的标签——人、家庭、事件、地点、来源、引用、存储库、笔记和媒体。它们对于分组和过滤对象非常有用。标签存储在 Gramps 家谱数据库中，并在所有用户之间共享；它们与在 Gramps Desktop 中创建的标签完全兼容。

## 管理标签

标签可以在 [管理设置](../administration/settings.md#tags) 的 **标签** 部分进行管理，该部分仅对拥有所有者或管理员角色的用户可用。它显示所有现有标签，并允许您：

- **创建** 新标签，使用 **新标签** 按钮
- **重命名** 标签，使用编辑（铅笔）图标
- **更改标签颜色**，使用颜色选择器
- **删除** 标签，使用删除图标

!!! note
    删除标签会将其从所有应用了该标签的对象中移除。

## 将标签应用于对象

在编辑模式下，可以在对象的详细信息页面上将标签应用于或从对象中移除标签。要一次性标记多个对象，请在列表中选择它们，并使用 **添加标签** 或 **移除标签** 操作，参见 [列表](lists.md#tags-and-privacy)。

标签显示在列表的 **标签** 列中，以及在搜索结果、书签和历史记录中。如果列表未显示该列，请在列选择器中启用它。

## 按标签过滤

所有 [对象列表页面](lists.md)（人、家庭、事件、地点、来源、引用、存储库、笔记、媒体）都包含标签过滤器。使用它仅显示应用了特定标签的对象。

## 特殊标签

在 Gramps Web 中，有两个标签具有特殊含义：

- **`Blog`** – 任何标记为 `Blog` 的来源被视为博客文章，并出现在 [博客](blog.md) 视图中
- **`ToDo`** – 任何标记为 `ToDo` 的笔记被视为研究任务，并出现在 [任务](tasks.md) 视图中

当您首次使用博客或任务功能时，这些标签会自动创建。重命名或删除它们将破坏相应的功能。
