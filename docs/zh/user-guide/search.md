# 搜索

搜索页面可以通过点击顶部应用栏中的放大镜图标，或按 `s` [键盘快捷键](shortcuts.md) 访问。

## 全文搜索

在搜索框中输入查询。结果会在您输入时显示，从第二个字符开始；按 Enter 键可搜索单个字符。Gramps Web 会在所有对象类型中进行搜索——人员、家庭、事件、地点、来源、引文、库、笔记和媒体——并返回按相关性排序的匹配结果。要清除搜索，请点击字段中的清除按钮或按 Escape 键。

每个结果显示对象类型、名称和一些细节，例如一个人的出生和死亡、一个家庭的婚姻、一个来源的作者或一条笔记的第一行。点击任何结果以打开相应的详细页面。

## 搜索语法

- **所有单词必须匹配。** `Müller Berlin` 查找包含这两个词的对象。
- **`or`** 查找包含任一单词的对象，例如 `Meyer or Maier`。`and` 也可以在单词之间输入，但没有区别。
- `or` 适用于直接相邻的单词：`Meyer or Maier Berlin` 意思是 "(Meyer or Maier) and Berlin"。不支持括号。
- **引号** 匹配一个短语，即按此顺序的单词：`"Johann Georg"`。
- **通配符：** 结尾的 `*` 匹配任何结尾，例如 `Mey*` 匹配 "Meyer"、"Meyers"、"Meyerhofer" 等。这也适用于短语：`"Johann Georg"*`。
- **最后一个单词是完整的。** 如果查询以字母或数字结尾，则会被视为以 `*` 结尾，因此 `Anna Smi` 已经可以找到 "Anna Smith"。要精确搜索最后一个单词，请在查询末尾加一个空格，或将该单词放在引号中。对象选择器和 [地图](map.md#search) 的搜索框也适用相同规则。
- `or` 和 `and` 在任何情况下都被识别。要搜索这些单词本身，请将其放在引号中。
- 单词不能被排除；没有 "not"。

## 搜索结果

- 重音符号不需要匹配：“Müller” 也会找到 “Muller”，而 “muller” 会找到 “Müller”。
- 家庭和事件也可以通过其人员的名字找到，例如 “Müller” 会找到所有名为 Müller 的人的家庭和事件。这些结果的排名低于直接匹配。
- 标准类型通过您界面语言中的名称找到，例如 “Taufe” 在德语界面中找到洗礼。
- 下划线分隔单词，因此 “microfilm” 找到名为 `scanned_microfilm.png` 的媒体文件。
- 无法查看私人记录的用户无法通过私人信息找到对象，例如通过私人成员的名称找到家庭。

## 按对象类型过滤

在搜索框下方，每个对象类型（人员、家庭、事件、地点等）的切换按钮让您可以将结果缩小到一个或多个特定类型。默认情况下会搜索所有类型。激活一个或多个切换按钮会将结果限制为仅这些类型。
