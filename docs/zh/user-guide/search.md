# 搜索

搜索页面可以通过点击顶部应用程序栏中的放大镜图标，或按 `s` [键盘快捷键](shortcuts.md) 访问。

## 全文搜索

在搜索字段中输入任何查询并按 Enter（或点击搜索按钮）。Gramps Web 会在所有对象类型中进行搜索——人、家庭、事件、地点、来源、引用、存储库、笔记和媒体——并返回按相关性排名的匹配结果。

结果显示对象类型、名称和简要摘要。点击任何结果以打开相应的详细页面。

## 搜索语法

- **所有单词必须匹配。** `Müller Berlin` 查找包含这两个词的对象。
- **`or`** 查找包含任一单词的对象，例如 `Meyer or Maier`。`and` 也可以在单词之间输入，但没有区别。
- `or` 适用于直接相邻的单词：`Meyer or Maier Berlin` 意味着“（Meyer 或 Maier）和 Berlin”。不支持括号。
- **引号** 匹配短语，即按此顺序的单词：`"Johann Georg"`。
- **通配符：** 结尾的 `*` 匹配任何结尾，例如 `Mey*` 匹配 "Meyer"、"Meyers"、"Meyerhofer" 等。这也适用于短语：`"Johann Georg"*`。
- `or` 和 `and` 在任何情况下都被识别。要搜索这些单词本身，请将其放在引号中。
- 单词不能被排除；没有“not”。

## 搜索结果

- 重音符号不需要匹配：“Müller” 也会找到 “Muller”，而 “muller” 会找到 “Müller”。
- 家庭和事件也可以通过其成员的名字找到，例如 “Müller” 会找到所有名为 Müller 的人的家庭和事件。这些结果的排名低于直接匹配。
- 标准类型通过您界面语言中的名称找到，例如 “Taufe” 会在德语界面中找到洗礼。
- 下划线分隔单词，因此 “microfilm” 会找到名为 `scanned_microfilm.png` 的媒体文件。
- 无法查看私人记录的用户不会通过私人信息找到对象，例如通过私人成员的名字找到家庭。

## 按对象类型过滤

在搜索字段下方，每个对象类型（人、家庭、事件、地点等）的切换按钮让您可以将结果缩小到一个或多个特定类型。默认情况下，搜索所有类型。激活一个或多个切换将结果限制为这些类型。
