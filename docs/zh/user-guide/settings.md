# 用户设置

用户设置可以通过应用程序顶部的用户图标访问，然后选择 **用户设置**。该页面组织为可折叠的部分。更改会立即生效，除非另有说明。

!!! note
    用户设置中的更改仅影响您自己的帐户。影响树中所有用户的设置在 [管理设置](../administration/settings.md) 中管理。

## 帐户

涵盖您的个人资料信息、凭据和帐户安全性。

### 用户信息

显示您的 **用户名** 和当前 **用户角色**（例如，访客、成员、编辑）。这些信息为只读。

### 更改电子邮件

输入新的电子邮件地址并点击 **提交** 以更新与您的帐户关联的地址。电子邮件地址用于密码重置和（如果配置）通知。

### 更改密码

输入您当前的密码和新密码，然后点击 **提交**。如果您忘记了当前密码，请在登录页面使用 **忘记密码** 链接。

### 关联的登录方式

如果您的服务器提供单点登录（请参见 [OIDC 认证](../install_setup/oidc.md)），您可以将来自提供者（如 Google 或您组织的登录）的帐户链接到您的 Gramps Web 帐户。然后，您可以使用该提供者登录，并进入您现有的帐户，保留您的角色和编辑。此部分仅在启用单点登录且服务器支持链接时显示（Gramps Web API 3.24 及更高版本）。

要链接帐户，请点击 **与** 和提供者的名称，登录提供者，然后您将返回到您的设置。如果您最近没有登录，系统会要求您先重新登录。

一个提供者帐户只能链接到一个 Gramps Web 帐户。如果您看到“此登录已链接到另一个帐户”，则它已在其他地方链接，例如在您首次使用该提供者登录时创建的帐户。管理员可以删除该其他帐户，之后您可以将其链接到您的帐户。

要取消链接帐户，请点击 **取消链接**。如果这是您最后一个链接的登录方式，您还需要输入密码，以便您之后仍然可以登录。如果您的帐户是通过单点登录创建的，并且您从未设置过密码，请在登录页面使用 **忘记密码** 先设置一个（这需要服务器发送电子邮件）。如果服务器仅允许通过提供者登录，则无法取消链接最后一个链接的帐户。

## 外观

控制保存在您设备上的显示偏好设置。

### 语言

选择 Gramps Web 界面的语言。语言设置存储在浏览器的本地存储中，仅适用于当前设备。

### 主题

选择以下选项之一：

- **系统** – 遵循操作系统的亮/暗主题偏好（默认）
- **浅色** – 始终使用浅色主题
- **深色** – 始终使用深色主题

主题设置存储在浏览器的本地存储中。

### 家谱偏好

#### 默认家谱视图

设置在您导航到 [家谱](tree.md) 页面时默认打开的图表类型。选项包括祖先树、后代树、沙漏图、关系图和扇形图。

此偏好设置存储在浏览器的本地存储中。

## 开发者工具

### API 令牌

将您当前的会话令牌复制到剪贴板。该令牌可用于直接对 REST API 进行身份验证，例如在您的 Gramps Web 实例提供的 `/api/swagger-ui` 中的交互式 Swagger UI。

点击 **启动 Swagger** 在新标签页中打开 Swagger UI，并且您的会话已可用。

!!! note
    会话令牌是短期有效的。在 Swagger 中使用之前，请立即复制它，因为它可能会过期。
