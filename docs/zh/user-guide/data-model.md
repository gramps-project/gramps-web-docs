# Gramps 如何组织数据

Gramps Web 将家谱存储为独立的对象——人、家庭、事件、地点、来源等——而不是作为图表，这些对象彼此相连。一旦你了解这些对象是如何组合在一起的，输入数据就变得可预测：你想要链接的任何内容必须首先存在。

Gramps Web 使用与 Gramps Desktop 相同的数据模型，因此本页上的所有内容适用于两者。

## 基础构件

| 对象 | 代表的内容 | 示例 |
|---|---|---|
| 人 | 个人 | 你，你的祖母 |
| 家庭 | 一对伴侣、他们的孩子，或两者 | 你的父母和他们的孩子 |
| 事件 | 发生的事情，具有日期和地点 | 出生、婚姻、人口普查、移民 |
| 地点 | 地理位置 | 一个村庄、一个教区、一个国家 |
| 来源 | 一份文件或信息的集合 | 一个教区登记册、一份人口普查、一部书 |
| 引用 | 来源中的特定参考 | 教区登记册第12页，第3条 |
| 存储库 | 存放来源的地方 | 一个档案馆、一个图书馆、一个网站 |
| 注释 | 自由文本 | 一份抄本、研究备注 |
| 媒体对象 | 一个文件 | 一张照片、一份扫描的证书 |

每种对象类型在 Gramps Web 中都有自己的列表，参见 [列表](lists.md)。

## 人与家庭

父母和孩子并不是直接相连，而是通过一个 **家庭**。一个家庭最多有两个伴侣和任意数量的孩子：

- 你的父母和你通过你作为孩子的家庭相连。
- 你的兄弟姐妹是同一个家庭的其他孩子。
- 你和你的配偶组成另一个家庭，在这个家庭中你是伴侣，和你的孩子一起。

一个人可以在一个家庭中是孩子，在多个家庭中是伴侣。每个孩子与每个父母之间有关系，例如出生、收养或继子女，每个家庭也有关系类型，例如已婚或民事结合。

这就是为什么“添加父母”到一个人意味着将此人作为孩子添加到一个家庭——这正是 [树状图](tree-edit.md) 为你一步完成的。

## 事件

出生、死亡或婚姻不是一个人的字段，而是一个独立的 **事件**，具有类型、日期、地点和描述。人们通过 **角色** 与事件相连：出生的那个人的角色是“主要”，而其他人可能作为证人与同一事件相连。

涉及一对伴侣的事件，例如婚姻，属于家庭而不是任何一方。一个事件也可以由几个人共享——例如，列出整个家庭的普查记录——而不是每个人都单独输入一次。

这影响了编辑。事件本身——其类型、日期、地点和描述——对所有与之相关的人都是相同的，因此从一个人的页面编辑共享事件会改变所有人的信息。编辑对话框因此首先列出其他参与者，只有在 **为所有人编辑** 后，字段才变为可编辑。属于一个人与事件链接的内容——角色、引用、注释和仅适用于该人的属性——在事件页面的 **参与者** 选项卡中以编辑模式进行编辑。在那里你也可以添加和移除参与者。例如，教父的角色和“以记号签名”的注释属于教父与洗礼的链接，而不是洗礼本身。

## 共享对象：地点和来源

地点、来源、引用、存储库、注释和媒体对象独立存在，任意数量的其他对象可以引用同一个对象。这有几个后果：

- **一次创建，多次选择。** 十个祖先出生的村庄是一个地点，在十个出生事件中被选择。如果你更正其名称或坐标，修正将适用于所有地方。
- **选择之前先创建。** Gramps Web 中的表单选择已经存在的地点和来源。首先使用顶部应用栏中的 **+**（添加）按钮创建新地点或来源。
- **地点是嵌套的。** 一个地点可以被更大的地点包围——一个村庄被一个县包围，县被一个国家包围——因此你不必为每个村庄重复整个层次结构。
- **来源和引用是分开的。** 一个来源是整个教区登记册；引用是支持某个事实的特定条目，包含其页面、日期和你的信心。许多引用可以指向同一个来源。

如果你不小心创建了同一个地点或来源两次，可以 [合并重复项](lists.md#merge)。

## 编辑对象页面

在来源、存储库或媒体对象的页面上，点击标题以编辑（对于媒体对象，编辑其描述）。按 Enter、点击 ✓ 或点击其他地方以保存；按 Escape 或点击 ✕ 以取消。

对象页面上的大多数列表保持你给定的顺序，例如事件、名称、属性、地址、引用或家庭的孩子。在编辑模式下，选择一行并使用上下按钮移动它，或将其拖动到新位置：使用鼠标，按住该行并移动；在触摸屏上，按住该行直到它被提起。拖动时按 Escape 以取消。画廊中的媒体可以以相同方式重新排序，参见 [个人资料照片](media.md#profile-pictures)。

## 家庭主页

家庭主页是家谱图表的起始点，也是报告的默认起始点。有关如何设置的内容，请参见 [首次登录](first-login.md)。

!!! note "与 Gramps Desktop 不同"
    在 Gramps Desktop 中，家庭主页存储在家谱数据库中，因此对于打开该数据库的每个人都是相同的。Gramps Web 不使用它。相反，家庭主页存储在你的浏览器中，每棵树是单独的：它不与其他用户共享，也不会随你转移到不同的浏览器或设备。在从 Gramps Desktop 导入树后，或者当你在另一台设备上使用 Gramps Web 时，你必须再次设置它。

## 推荐顺序

手动输入新家庭时，此顺序可以避免在表单之间来回跳转：

1. **地点和来源。** 创建所需的地点，并在记录来源时，创建你正在使用的来源。
2. **人。** 添加人及其出生和死亡日期和地点。在家谱图的编辑模式中，这样做是最快的，它会为你创建家庭——参见 [开始新树](start-tree.md) 和 [编辑家谱](tree-edit.md)。
3. **进一步的事件。** 打开一个家庭（例如从某个人的关系选项卡）以添加婚姻，并打开一个人的页面以添加其他事件。
4. **引用。** 在支持某个来源的人的来源引用选项卡、事件或其他对象上，添加新的引用，选择来源并输入页面。
5. **注释和媒体。** 附加抄本、照片和扫描——参见 [添加媒体文件](media.md)。

## 输入日期

日期作为单独的年、月、日字段输入，也可以使用日期选择器填写。省略你不知道的部分：仅年份也是有效日期。
不要猜测确切的日期，而是通过选择字段上方的日期类型来描述你实际知道的内容。提示在芯片下方解释所选类型：

| 你所知道的 | 类型 | 示例 |
|---|---|---|
| 确切日期或其部分 | 常规 | 1850年3月12日，或仅1850年 |
| 近似日期 | 大约 | 大约1850年 |
| 限制 | 之前、之后 | 1900年之前 |
| 日期在某个时期内 | 范围 | 1850年至1855年之间（“最早”和“最晚”字段） |
| 某事持续了一段时间 | 跨度 | 从1850年到1855年 |

对于跨度，两个日期中的任意一个（“从”和“到”）可以留空，因此“从1850年”或“到1855年”是只有一个日期的跨度。

**质量** 和 **日历** 字段在 **更多选项** 下，使用其中任何一个时会自动打开。质量记录你如何得出日期：“估计”表示经过推测，“计算”表示从其他信息推导出的日期，例如根据死亡年龄计算的出生年份。

!!! warning "关于大约和估计日期覆盖前后各50年"
    当 Gramps 比较日期时，它将“关于”类型的日期——以及任何质量为“估计”的日期——视为一个范围，从给定日期前50年到后50年。例如，过滤出生于1840年至1860年之间的人员列表时，也会找到“约1880年”出生的人，因为该日期被视为覆盖1830年至1930年。同样，“之前”和“之后”也被视为延伸至该日期前后各50年。

    这可能导致意外结果，因此仅在无法缩小日期时使用“关于”和“估计”。如果你知道更短的时间段，像“在1878年到1882年之间”的范围会更精确。

日历允许你输入原始记录中使用的日历中的日期，例如儒略历，而不是自己转换。
