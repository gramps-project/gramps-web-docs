# Gramps 如何组织数据

Gramps Web 将家谱存储为独立的对象——人、家庭、事件、地点、来源等——这些对象彼此关联。了解这些对象如何组合后，输入数据变得可预测：任何您想要链接的内容必须先存在。

Gramps Web 使用与 Gramps Desktop 相同的数据模型，因此本页面上的所有内容适用于两者。

## 基础构件

| 对象 | 代表的内容 | 示例 |
|---|---|---|
| 人 | 个人 | 你，你的祖母 |
| 家庭 | 一对伴侣，他们的孩子，或两者 | 你的父母和他们的孩子 |
| 事件 | 发生的事情，具有日期和地点 | 出生、婚姻、人口普查、移民 |
| 地点 | 地理位置 | 一个村庄、一个教区、一个国家 |
| 来源 | 一份文档或信息集合 | 一个教区登记册、一个人口普查、一部书 |
| 引用 | 来源中的特定参考 | 教区登记册的第12页，第3条 |
| 存储库 | 存放来源的地方 | 一个档案馆、一个图书馆、一个网站 |
| 注释 | 自由文本 | 一份抄本、研究备注 |
| 媒体对象 | 一个文件 | 一张照片、一份扫描证书 |

每种对象类型在 Gramps Web 中都有自己的列表，参见 [列表](lists.md)。

## 人与家庭

父母和孩子并不是直接相连，而是通过一个 **家庭** 连接。一个家庭最多有两个伴侣和任意数量的孩子：

- 你的父母和你通过你作为孩子的家庭相连。
- 你的兄弟姐妹是同一个家庭的其他孩子。
- 你和你的配偶组成另一个家庭，在这个家庭中你是一个伴侣，和你的孩子一起。

一个人可以在一个家庭中是孩子，在多个家庭中是伴侣。每个孩子与每位父母之间有关系，例如出生、收养或继子，而每个家庭有一种关系类型，例如已婚或民事结合。

这就是为什么“为一个人添加父母”意味着将该人作为孩子添加到一个家庭——这正是 [树形图](tree-edit.md) 为您一步完成的。

## 事件

出生、死亡或婚姻不是一个人的字段，而是一个独立的 **事件**，具有类型、日期、地点和描述。人们通过 **角色** 与事件相连：出生的人的角色是“主要”，而其他人可能作为证人与同一事件相连。

涉及一对伴侣的事件，例如婚姻，属于家庭而不是任一伴侣。一个事件也可以由几个人共享——例如，列出整个家庭的普查记录——而不是每个人都单独输入一次。

## 共享对象：地点和来源

地点、来源、引用、存储库、注释和媒体对象独立存在，任意数量的其他对象可以引用同一个对象。这有几个后果：

- **创建一次，多次选择。** 十个祖先出生的村庄是一个地点，在十个出生事件中被选择。如果您更正其名称或坐标，更正将在所有地方生效。
- **在选择之前创建。** Gramps Web 中的表单选择已经存在的地点和来源。首先使用顶部应用栏中的 **+**（添加）按钮创建一个新地点或来源。
- **地点是嵌套的。** 一个地点可以被更大的地点包围——一个县包围一个村庄，一个国家包围一个县——因此您不必为每个村庄重复整个层次结构。
- **来源和引用是分开的。** 一个来源是整个教区登记册；引用是支持一个事实的特定条目，包括其页码、日期和您的信心。许多引用可以指向同一个来源。

如果您不小心创建了相同的地点或来源两次，可以 [合并重复项](lists.md#merge)。

## 编辑对象页面

在来源、存储库或媒体对象的页面上，点击编辑模式下的标题以更改它（对于媒体对象，更改其描述）。按 Enter、点击 ✓ 或点击其他地方以保存；按 Escape 或点击 ✕ 以取消。

对象页面上的大多数列表保持您给定的顺序，例如事件、名称、属性、地址、引用或家庭的孩子。在编辑模式下，选择一行并使用上下按钮移动它，或将其拖动到新位置：使用鼠标，按住该行并移动；在触摸屏上，按住该行直到它被提起。拖动时按 Escape 以取消。画廊中的媒体可以以相同的方式重新排序，参见 [个人资料图片](media.md#profile-pictures)。

## 家庭主页

家庭主页是家谱图表的起始点，也是报告的默认起始点。有关如何设置的详细信息，请参见 [首次登录](first-login.md)。

!!! note "与 Gramps Desktop 不同"
    在 Gramps Desktop 中，家庭主页存储在家谱数据库中，因此对于打开该数据库的每个人都是相同的。Gramps Web 不使用它。相反，家庭主页存储在您的浏览器中，每个家谱单独存储：它不与其他用户共享，也不会随您转移到其他浏览器或设备。在从 Gramps Desktop 导入家谱后，或者当您在另一台设备上使用 Gramps Web 时，您必须再次设置它。

## 推荐的顺序

手动输入新家庭时，此顺序可以避免在表单之间来回跳转：

1. **地点和来源。** 创建所需的地点，并且如果记录来源，则创建您正在使用的来源。
2. **人。** 添加人及其出生和死亡日期和地点。这在家谱图的编辑模式中最快，该模式为您创建家庭——参见 [开始新家谱](start-tree.md) 和 [编辑家谱](tree-edit.md)。
3. **进一步的事件。** 打开一个家庭（例如从某个人的关系标签）以添加婚姻，并打开一个人的页面以添加其他事件。
4. **引用。** 在支持某个来源的个人、事件或其他对象的来源引用标签上，添加新的引用，选择来源，并输入页码。
5. **注释和媒体。** 附加抄本、照片和扫描——参见 [添加媒体文件](media.md)。

## 输入日期

日期作为单独的年、月、日字段输入，也可以使用日期选择器填写。省略您不知道的部分：仅年份也是有效日期。
与其猜测确切的日期，不如通过选择字段上方的类型来描述您实际知道的内容。字段上方的提示解释所选类型：

| 您所知道的 | 类型 | 示例 |
|---|---|---|
| 确切的日期或其部分 | 常规 | 1850年3月12日，或仅1850年 |
| 大约的日期 | 大约 | 大约1850年 |
| 限制 | 之前，之后 | 1900年之前 |
| 日期位于某个时期内 | 范围 | 1850年到1855年之间（“最早”和“最晚”字段） |
| 某事持续了一段时间 | 时段 | 从1850年到1855年 |

对于时段，两个日期中的任意一个（“从”和“到”）可以留空，因此“从1850年”或“到1855年”都是只有一个日期的时段。

**质量** 和 **日历** 字段位于 **更多选项** 下，当日期使用其中任何一个时会自动打开。质量记录您如何得出日期：“估计”表示经过推测，“计算”表示从其他信息得出的日期，例如根据去世时的年龄计算的出生年份。

!!! warning "大约和估计日期覆盖前后各50年"
    当 Gramps 比较日期时，它将“关于”类型的日期——以及任何具有“估计”质量的日期——视为一个范围，从给定日期前50年到后50年。例如，筛选出生在1840年至1860年之间的人员列表时，也会找到一个出生于“大约1880年”的人，因为该日期被视为覆盖1830年至1930年。以同样的方式，“之前”和“之后”被视为达到给定日期前后各50年。

    这可能会导致意外结果，因此仅在无法缩小日期范围时使用“大约”和“估计”。如果您知道更短的时间段，像“1878年至1882年之间”的范围会更精确。

日历允许您以原始记录中使用的日历输入日期，例如儒略历，而不是自己转换。
