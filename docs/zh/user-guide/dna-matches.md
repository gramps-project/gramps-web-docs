# 处理DNA匹配

DNA匹配是指两个个体之间同意的DNA片段，通过标记的存在来识别，这些标记被称为SNP（单核苷酸多态性，发音为“snips”）。

要获取这些数据，您需要访问已上传到匹配数据库的DNA测试，以便查看DNA片段匹配数据（例如MyHeritage、Gedmatch、FamilytreeDNA）。Gramps Web并不进行匹配，因为它只能访问您上传的数据。

## 输入DNA匹配数据

要输入DNA匹配数据，您需要[编辑权限](../install_setup/users.md)，因为数据作为注释存储在Gramps数据库中。可以从主菜单访问的DNA视图提供了一种方便的方式，以正确格式输入这些数据。

要输入新的匹配，单击右下角的 + 按钮。在打开的对话框中，选择两个个体。请注意，“第一个人”和“第二个人”的处理方式不同：匹配作为从第一个人到第二个人的关联存储。只有第一个人可以在DNA匹配视图和染色体浏览器中被选择。通常，第一个人是您可以访问其DNA测试的人，而第二个人是更远的亲属。

如果第二个人不在数据库中，您需要先使用用户界面右上角的“创建人员”按钮创建它。创建完该人员后，您可以返回DNA匹配视图并选择新创建的人。

接下来，将原始数据粘贴到文本字段中。数据应为逗号或制表符分隔的匹配表，通常包含染色体编号、匹配的起始和结束位置、匹配中的SNP数量以及以厘摩根（cM）为单位的匹配长度。您还可以将包含匹配数据的文件拖放到文本字段中。

这样表格的最小示例是：

```csv
Chromosome,Start Location,End Location,Centimorgans,SNPs
6,6358001,18115715,19.6,7424
7,150135758,154205894,10.9,2816
```

如果格式有效，文本字段下方将显示预览表格。

最后，单击“保存”按钮将匹配存储在数据库中。

## 查看DNA匹配数据

DNA匹配视图有一个下拉菜单，允许选择数据库中与DNA匹配相关的每个人。一旦选择了一个人，他们的匹配将以表格形式列出：匹配的名称、与所选人员的关系、共享DNA的总长度（以厘摩根cM为单位）、共享片段的数量以及这些片段中最长的长度。

对于已经放置在树中的匹配，关系列显示树中记录的关系（自动从Gramps数据库中确定）。对于与所选人员在树中没有关系的匹配，显示根据共享DNA估算的关系，并标记为“≈”。

单击匹配将打开其页面，页面上有共享DNA的摘要、[关系估算](#relationship-estimate)、树中关系的图表以及片段列表。每个片段显示它是来自父系还是母系。该侧可以手动输入（通过在原始数据中名为“Side”的列中提供`P`表示父系或`M`表示母系）或通过最近的共同祖先自动确定。片段旁边的下载按钮将其保存为CSV文件，格式与匹配对话框接受的格式相同。

## 关系估算

共享DNA并不能证明特定的关系：两个亲属共享的DNA量差异很大，不同的关系重叠。因此，Gramps Web显示了一系列可能的关系及其概率，这些概率是根据共享片段的数量和长度计算得出的（需要Gramps Web API 3.26或更新版本）。

关系按其*度*进行分组：

- **父母或子女**和**全兄弟姐妹**单独显示。
- **2度亲属**包括半兄弟姐妹、祖父母和孙子女，以及姑姑、叔叔、侄女和侄子。
- **3度亲属**包括表兄弟姐妹、曾祖父母、曾姑姑和曾叔叔，以及半姑姑和半叔叔。
- 每个进一步的度数大约相隔一代，例如，表兄弟姐妹一次移除是4度，表亲是5度。9度及以上的关系被归为“9+”。

同一度数的关系平均共享大约相同量的DNA，因此仅凭DNA无法区分它们。使用人们的年龄来决定它们之间的关系——一个30岁的2度亲属与一个60岁的人相比，更可能是侄女而不是祖父母。

对于近亲，估算最为可靠。对于远亲，匹配仅共享少量片段，概率分布在多个度数上。

### 检查树与DNA的匹配

如果匹配放置在树中，Gramps Web会检查共享DNA是否符合记录的关系。如果该关系的DNA非常不可能，则在匹配表中显示警告图标，并在匹配页面上显示警告。括号中的数字，例如“1 : 500”，比较记录的关系的DNA的可能性与最可能的关系的可能性。

警告是需要更仔细查看的理由，而不是错误的证明。常见原因包括：

- 树中的错误，例如错误的父母，
- 错误的亲子关系，例如未知的收养或不同的生物父亲，
- 不完整的匹配数据，例如如果仅从测试服务复制了高阈值以上的片段，
- 通过多个血缘关系的关系，例如通过母亲和父亲相关的人（“谱系崩溃”），共享的DNA比预期的要多。

非出生关系，例如通过收养的关系，不会被检查。

## 编辑匹配

要编辑匹配，请打开其页面并单击编辑按钮，或按`e`。请注意，您可以更改原始数据，但不能更改与匹配相关的个体——如果您想更改个体，您需要删除匹配并创建一个新的匹配。

## 私有匹配

添加和编辑匹配的对话框有一个**私有**开关。私有匹配及其片段对无法查看私有记录的用户隐藏。私有匹配对其他所有人标记为锁定。有关隐私的更多信息，请参见[私有记录](privacy.md)。

## 在Gramps桌面中处理匹配数据

DNA匹配数据作为注释存储在Gramps数据库中。该格式与
[DNA片段地图插件](https://gramps-project.org/wiki/index.php/Addon:DNASegmentMapGramplet)
兼容，适用于Gramps桌面。其维基页面包含有关如何获取数据、如何解释数据以及如何在Gramps中输入数据的更多详细信息。

!!! info
    Gramps Web API v2.8.0引入了一些更改，以接受更广泛的原始DNA匹配数据，这在Gramps桌面插件中尚不可用。Gramps桌面插件将在未来更新，以支持与之相同的格式。
