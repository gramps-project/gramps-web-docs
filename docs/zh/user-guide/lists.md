# 列表

Gramps Web 中的每种对象类型都有一个列表视图：人员、家庭、事件、地点、来源、引用、存储库、笔记和媒体。它们的工作方式相同，并共享相同的排序、过滤和批量编辑工具。

## 排序和分页

点击列标题按该列排序；再次点击以反转顺序。排序由服务器执行，因此适用于整个列表，而不仅仅是您正在查看的页面。

长列表被拆分为多个页面。使用底部的分页控件在它们之间移动。

在窄屏幕上，表格会自动切换到紧凑布局，因此列表视图在手机上仍然可用。

## 选择列

点击列表上方的齿轮图标以打开 **列** 对话框。勾选或取消勾选列以显示或隐藏它。**重置** 恢复该列表的默认选择。

至少必须保留一列可见，因此最后剩下的列无法取消勾选。

您的列选择会根据对象类型和家谱进行记忆。它存储在您的浏览器中，因此其他用户无法看到——但它也不会在不同的浏览器或设备间跟随您。

## 过滤

点击 **过滤** 按钮以打开过滤面板。面板顶部的药丸切换按钮在两种模式之间切换：

- **简单** – 一组依赖于对象类型的现成过滤器。例如，对于人员，您可以按出生年份、死亡年份、各种个人属性、关联数量、标签以及对象是私有还是公共进行过滤。
- **GQL** – 一个用于在 [Gramps 查询语言](gql.md) 中进行高级查询的单一文本字段。输入查询并按 Enter 或点击 **应用**。如果查询无效，字段的边框会变为红色。

活动过滤器显示为列表上方的芯片。通过点击芯片的清除按钮可以移除单个过滤器，或使用 **清除所有过滤器** 一次性移除所有过滤器。

!!! note
    这两种模式是替代关系，而不是叠加关系：GQL 查询会替代简单过滤器，切换回简单模式会丢弃查询。

## 选择对象并批量操作

具有编辑权限的用户会看到过滤按钮旁边的 **选择** 按钮。点击它以进入选择模式，这会在每一行添加一个复选框。

勾选您想要的对象，工具栏会显示所选对象的数量，并提供 **操作** 下拉菜单和 **应用** 按钮。

### 删除

选择一个或多个对象，选择 **删除**，然后点击 **应用**。确认对话框会询问您是否确认，警告该操作无法撤销。

!!! tip
    删除会像其他更改一样记录在 [修订历史](revisions.md) 中，因此错误的批量删除可以通过撤销相应的事务来恢复。

### 合并

选择 **恰好两个** 对象，选择 **合并**，然后点击 **应用**。对话框会询问两个对象中哪个应提供合并对象的主要数据；点击您希望保留为主要的那个。另一个对象的数据会合并到其中，并更新引用。

合并适用于人员、家庭、事件、地点、来源和引用。它不适用于存储库、笔记和媒体对象。

如果您选择了没有有效选择的操作——例如仅选择了一个对象的合并——对话框会解释所需的条件。
