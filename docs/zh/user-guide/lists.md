# 列表

Gramps Web 中的每种对象类型都有一个列表视图：人员、家庭、事件、地点、来源、引用、存储库、笔记和媒体。它们的工作方式相同，并共享相同的排序、过滤和批量编辑工具。

## 排序和分页

单击列标题以按该列排序；再次单击以反转顺序。排序由服务器执行，因此适用于整个列表，而不仅仅是您正在查看的页面。

长列表被拆分为多个页面。使用底部的分页控件在它们之间移动。

在窄屏幕上，表格会自动切换到紧凑布局，因此列表视图在手机上仍然可用。

## 选择列

单击列表上方的齿轮图标以打开 **列** 对话框。勾选或取消勾选某一列以显示或隐藏它。**重置** 将恢复该列表的默认选择。

至少必须保留一列可见，因此最后一列无法被取消勾选。

您的列选择会根据对象类型和家谱树进行记忆。它存储在您的浏览器中，因此对其他用户不可见——但它也不会跟随您到其他浏览器或设备。

## 过滤

单击 **过滤** 按钮以打开过滤面板。它提供三种过滤方式，可以组合使用：

- **现成的过滤器** 在可折叠的部分中，具体取决于对象类型。例如，对于人员，您可以按出生年份、死亡年份、各种个人属性、关联数量、标签以及对象是私有还是公共进行过滤。
- **高级过滤** - 一个条件构建器，用于现成的过滤器无法表达的过滤条件，详细描述见 [下文](#高级过滤)。
- **GQL** - 一个用于查询的文本字段，使用 [Gramps 查询语言](gql.md)。输入查询并按 Enter 或单击 **应用**。如果查询无效，字段的边框将变为红色。查询将在其他过滤器之上应用。

活动过滤器显示为列表上方的芯片。通过单击芯片的清除按钮删除单个过滤器，或使用 **清除所有过滤器** 一次性删除所有过滤器。

### 高级过滤

单击过滤面板底部的 **高级过滤** 以打开条件构建器。其条件是 Gramps Desktop 中已知的过滤规则，例如“具有 &lt;name&gt; 的人员”或“&lt;person&gt; 的祖先”。

- 单击 **添加条件** 以选择规则。规则按类别分组，并可以通过名称或描述进行搜索。
- 填写规则的参数。每个参数都有一个匹配的输入，例如日期字段、标签选择器或人员或地点的对象选择器。
- 选择如何组合一组条件：**所有条件**、**任一条件**，或通过旁边的菜单选择 **恰好一个条件**。
- 单击 **添加组** 在另一个组内添加一组条件，并具有自己的组合方式。
- 在条件或组上选择 **不** 以反转它。

单击 **应用** 以过滤列表。

当您打开构建器时，活动的现成过滤器作为条件显示在那里。如果您构建的过滤器可以用现成的过滤器表达，则在应用后与它们一起显示。否则，它将显示为单个 **高级过滤** 芯片，过滤面板提供 **编辑** 按钮以重新打开构建器。

!!! note
    引用 Gramps Desktop 中保存的自定义过滤器的规则在构建器中不可用。规则将以您的语言显示，使用 Gramps Web API 3.24 或更新版本。

## 选择对象并批量操作

具有编辑权限的用户在过滤按钮旁边看到一个 **选择** 按钮。单击它以进入选择模式，这会在每一行中添加一个复选框。

勾选您想要的对象，工具栏将显示已选择的数量，以及 **操作** 下拉菜单和 **应用** 按钮。

表格标题中的复选框选择当前页面上的所有对象。如果有更多对象符合当前过滤条件，工具栏将提供 **选择所有 (N)**，这将选择所有 N 个符合条件的对象。取消勾选一行、改变页面或过滤条件，或离开选择模式将结束此选择。

### 删除

选择一个或多个对象，选择 **删除**，然后单击 **应用**。确认对话框会询问您确认，警告该操作无法撤销。

删除超过十个对象将作为后台任务运行。其进度显示在 **应用** 按钮旁边和 [通知](notifications.md) 中，完成后列表会重新加载。

!!! tip
    删除记录在 [修订历史](revisions.md) 中，像其他任何更改一样，因此错误的批量删除可以通过撤销相应的事务来恢复。

### 合并

选择 **恰好两个** 对象，选择 **合并**，然后单击 **应用**。对话框会询问两个对象中哪个应该提供合并对象的主要数据；单击您希望保留为主要的那个。另一个对象的数据将合并到其中，并更新引用。

合并适用于人员、家庭、事件、地点、来源和引用。它不适用于存储库、笔记和媒体对象。

在媒体视图中，选择在画廊和列表布局中均可用：在选择模式下，单击一个图块或行会切换其状态。**删除** 是媒体的唯一可用操作。

如果您选择了一个没有有效选择的操作——例如仅选择了一个对象的合并——对话框会解释所需的内容。
