# 列表

Gramps Web 中的每种对象类型都有一个列表视图：人员、家庭、事件、地点、来源、引用、存储库、笔记和媒体。它们的工作方式相同，并共享相同的排序、过滤和批量编辑工具。

## 排序和分页

点击列标题可以按该列排序；再次点击可以反转顺序。排序由服务器执行，因此适用于整个列表，而不仅仅是您正在查看的页面。

长列表被拆分为多个页面。使用底部的分页控件在它们之间移动。

在窄屏幕上，表格会自动切换到紧凑布局，因此列表视图在手机上仍然可用。

## 选择列

点击列表上方工具栏右端的齿轮图标以打开 **列** 对话框。勾选或取消勾选某一列以显示或隐藏它。**重置** 恢复该列表的默认选择。

至少必须保留一列可见，因此最后一列无法被取消勾选。

除了默认列之外，每个列表还提供 **标签** 列，并且对于可以查看私人记录的用户，还有 **隐私** 列，显示每个私人对象的锁定图标。如果您之前更改过列表的列选择，则不会自动添加新列（如 **标签**）；请在对话框中勾选它们。

您的列选择会根据对象类型和家谱进行记忆。它存储在您的浏览器中，因此其他用户无法看到——但它也不会在不同的浏览器或设备上跟随您。

## 过滤

点击 **过滤** 按钮以打开过滤面板。它提供三种过滤方式，可以组合使用：

- **现成过滤器** 在可折叠的部分中，取决于对象类型。例如，对于人员，您可以按姓名、出生年份、死亡年份、各种个人属性、关联数量、标签以及对象是否为私人或公共进行过滤。家庭可以按父亲、母亲或子女的姓名进行过滤，来源可以按作者进行过滤，地点和存储库可以按其类型进行过滤。
- **高级过滤** - 用于现成过滤器无法表达的条件构建器，如下文所述 [高级过滤](#高级过滤)。
- **GOQL** - 用于在 [Gramps 对象查询语言](goql.md) 中输入表达式的文本字段，带有语法高亮。输入表达式并按 Enter 或点击 **应用**。如果表达式无效，该字段将标记为错误。表达式在其他过滤器之上应用。

活动过滤器以芯片的形式显示在工具栏下方的一行中。通过点击芯片的清除按钮可以移除单个过滤器，或使用 **清除所有过滤器** 一次性移除所有过滤器。

### 高级过滤

点击过滤面板底部的 **高级过滤** 以打开条件构建器。其条件是 Gramps Desktop 中已知的过滤规则，例如“具有 &lt;姓名&gt; 的人员”或 “&lt;人员&gt; 的祖先”。

- 点击 **添加条件** 以选择规则。规则按类别分组，并可以通过名称或描述进行搜索。
- 填写规则的参数。每个参数都有相应的输入，例如日期字段、标签选择器或人员或地点的对象选择器。
- 选择如何组合一组条件：**所有条件**、**任何条件**，或通过旁边的菜单选择 **恰好一个条件**。
- 点击 **添加组** 在另一个组内添加一组条件，并具有自己的组合方式。
- 在条件或组上选择 **不** 以反转它。

点击 **应用** 以过滤列表。

当您打开构建器时，现成的过滤器和活动的 GOQL 表达式会显示为条件。GOQL 表达式也可以作为自己的条件添加，例如与 **任何条件** 组合多个表达式。如果您构建的过滤器可以用现成的过滤器表达，则在应用后会与它们一起显示。否则，它将显示为单个 **高级过滤** 芯片，过滤面板提供 **编辑** 按钮以重新打开构建器。

!!! 注意
    引用 Gramps Desktop 中保存的自定义过滤器的规则在构建器中不可用。规则以您的语言显示，使用 Gramps Web API 3.24 或更新版本。

#### 保存的过滤器

要重用您构建的过滤器，请在条件构建器中点击 **保存** 并给它命名。使用现有名称保存将替换该过滤器。构建器中的 **保存的过滤器** 列出当前对象类型的已保存过滤器；选择一个将其加载到构建器中，您可以在点击 **应用** 之前进行更改。

保存的过滤器存储在您的浏览器中，按家谱和对象类型分类，因此其他用户或您的其他设备无法使用。

当树发生更改时，保存的过滤器可能会停止工作，例如如果它引用了一个已被删除的人（对象选择器将显示“未找到”）。在条件修复之前，该过滤器无法应用或保存。

## 选择对象并进行批量操作

具有编辑权限的用户会看到过滤按钮旁边的 **选择** 按钮。点击它以进入选择模式，这会在每一行添加一个复选框。

勾选您想要的对象，工具栏会显示已选择的数量，以及 **操作** 下拉菜单和 **应用** 按钮。

表头中的复选框选择当前页面上的所有对象。如果更多对象符合当前过滤条件，工具栏将提供 **全选 (N)**，这将选择所有 N 个匹配对象。取消勾选某一行、切换页面或过滤器，或离开选择模式将结束此选择。

### 删除

选择一个或多个对象，选择 **删除**，然后点击 **应用**。确认对话框会询问您确认，警告该操作无法撤销。

删除超过十个对象将作为后台任务运行。其进度会显示在 **应用** 按钮旁边和 [通知](notifications.md) 中，完成后列表会重新加载。

!!! 提示
    删除记录在 [修订历史](revisions.md) 中，像任何其他更改一样，因此错误的批量删除可以通过撤销相应的事务来恢复。

### 标签和隐私

操作 **添加标签**、**移除标签** 和 **隐私** 会同时更改所有选定对象（需要 Gramps Web API 3.26 或更新版本）：

- **添加标签** 添加现有标签或您在对话框中创建的新标签。
- **移除标签** 从具有该标签的选定对象中移除标签。
- **隐私** 将选定对象标记为私人或公共。这仅更改对象本身，而不更改其部分或它们链接的记录——请参见 [私人记录](privacy.md)。

与删除一样，编辑超过十个对象将作为后台任务运行。这些更改记录在 [修订历史](revisions.md) 中，作为一个事务，因此可以一起撤销。

### 合并

选择 **恰好两个** 对象，选择 **合并**，然后点击 **应用**。对话框会询问两个对象中哪个应提供合并对象的主要数据；点击您希望保留为主要的那个。另一个对象的数据将合并到其中，并更新引用。

合并适用于人员、家庭、事件、地点、来源和引用。它不适用于存储库、笔记和媒体对象。

在媒体视图中，选择在画廊和列表布局中均有效：在选择模式下，点击一个图块或行会切换它。媒体对象无法合并。

如果您选择了没有有效选择的操作——例如仅选择了一个对象的合并——对话框会解释所需的内容。
