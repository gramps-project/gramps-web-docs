Gramps Web 允许在照片中标记人物，类似于 Gramps Desktop，将人物与媒体对象关联。这通过自动人脸检测得以简化。

图像的一个区域不仅可以链接到一个人，还可以链接到一个家庭、事件、地点、来源或引用——例如照片中的一栋建筑，或扫描页面上的引用。一个对象可以在同一图像中有多个区域，例如在包含同一人物的多张照片的相册页面上。

## 链接区域

要将图像的一个区域链接到一个对象，请按照以下步骤操作：

- 打开媒体对象的详细视图，例如通过在全屏预览中点击“显示详细信息”。
- 点击右下角的蓝色编辑按钮。如果您看不到此按钮，您的用户没有编辑权限。
- 在图像上，您将看到与检测到的人脸对应的虚线边框的框。点击一个框以选择它。

链接的区域以实线边框和带有链接对象名称及其类型图标的标签显示。在图像的全屏视图中，点击链接区域会打开链接的对象。

## 编辑区域

在编辑模式下，点击一个链接区域以选择它。然后您可以：

- **移动**它，通过拖动来移动，或使用其四个角的手柄来**调整大小**。当您释放鼠标按钮或抬起手指时，变更将被保存。
- 使用“链接”按钮将其链接到**不同的对象**。

区域也可以使用键盘进行操作：按 Tab 在它们之间移动，按 Enter 或 Space 在编辑模式中选择一个，或在全屏视图中打开链接的对象。
