# 家谱

家谱页面可以从侧边栏访问，并显示以所选人物为中心的互动图表。页面顶部的标签提供五种图表类型。

## 选择起始人物

所有图表都从当前在树中选择的人物开始（在工具栏中显示）。当前居中的人物用阴影突出显示。使用 **家庭人物** 按钮跳回您的家庭人物，或使用 **返回** 按钮返回到之前查看的人物。点击任何图表中的人物卡片会将图表重新居中到该人物。

如果尚未设置家庭人物，页面会提供一个 **设置家庭人物** 按钮，以直接搜索并选择一个。如果树中尚未包含任何人物，具有编辑者角色或以上权限的用户会看到一个 **新建人物** 按钮——在空树中创建的第一个人物会自动成为您的家庭人物，因此图表会立即显示。

## 图表类型

### 祖先树

显示所选人物的祖先的谱系图。父母出现在左侧（或右侧，具体取决于布局），祖父母更远，依此类推。

### 后代树

显示所选人物的后代——子女、孙子女等。

### 沙漏图

在一个视图中结合所选人物上方的祖先和下方的后代。

### 关系图

显示两个人之间的关系路径。所选人物是一个端点；点击图表中的任何其他人物以设置第二个端点并显示它们之间的最短关系路径。

!!! note
    同一个人物可能在图中出现多次——例如，当某人结过多次婚并出现在路径上的多个家庭单元中时。这是故意的，而不是错误。

### 风扇图

一个圆形的谱系图。祖先从中心的所选人物向外辐射。

## 移动到亲属并扩展分支

在祖先树和风扇图中，所选人物有一个下拉按钮，打开他们子女的菜单。在后代树中，它打开他们父母的菜单。从菜单中选择一个人物会将图表居中到他们身上。

在祖先树、后代树和沙漏图中，图表边缘的人物如果没有显示其父母或子女，则在其分支继续的侧面有一个下拉按钮。点击它会在该分支上增加一代，而所选人物保持不变。这样，您可以例如查看所有祖父母，然后再向上追溯一条线。扩展的分支在您选择另一个人物或切换到不同图表时会重置。

## 导航控件

所有图表类型共享一个工具栏，包含以下按钮：

- **家庭人物** – 跳回您的家庭人物
- **返回** – 返回到之前居中的人物
- **人物详情** – 打开当前居中人物的完整个人资料页面
- **偏好设置** – 打开对特定图表显示选项进行调整的对话框（见下文）

所有图表支持 **平移**（点击并拖动）和 **缩放**（滚轮或捏合）。

## 图表偏好设置

**偏好设置** 对话框（工具栏中的齿轮图标）允许您根据图表类型调整以下选项：

- **最大祖先代数** – 显示多少代祖先
- **最大后代代数** – 显示多少代后代
- **最大分离度** – 对于关系图，搜索的最大路径长度
- **最大显示图像数量** – 限制图表中显示的个人资料照片数量以提高性能
- **姓名显示格式** – 控制人物卡片上姓名的显示方式

点击 **重置** 恢复默认设置，或点击 **关闭** 应用您的更改。

图表偏好设置存储在浏览器的本地存储中，因此在同一设备上的会话之间会保持。

## 默认图表类型

首次打开家谱页面时显示的图表类型可以在 [用户设置](settings.md) 中配置。您选择的默认设置适用于您所有的设备。

## 编辑树

具有编辑者角色或以上权限的用户可以直接从祖先树添加和链接人物。有关详细信息，请参见 [编辑家谱](tree-edit.md)。
