# 用户指南

本节文档记录了 Gramps Web 用户可用的功能。

!!! note "没有看到所有功能？"
    Gramps Web 使用基于角色的权限系统。一些功能——例如编辑数据、管理标签或查看私人记录——仅对具有足够权限的用户可用。您可以在 [用户设置](settings.md) 中检查您当前的角色。如果您需要更多访问权限，请联系您的树的所有者或管理员。有关所有角色的描述，请参见 [用户系统](../install_setup/users.md)。

## 导航界面

### 主要导航

侧边栏（或移动设备上的汉堡菜单）是在各个部分之间移动的主要方式：

- **首页** – 仪表板（见下文）
- **博客** – 以博客文章形式撰写的家族历史故事
- **家谱** – 交互式树状图
- **时间线** – 树中事件的时间顺序视图（需要足够新的 Gramps Web API 版本）
- **地图** – 树中地点的地理视图
- **DNA** – DNA 匹配分析工具
- **列表** – 浏览每种类型的所有对象：人物、家庭、事件、地点、来源、引用、库、笔记
- **媒体** – 浏览所有媒体文件（照片、文档等）
- **助手** – AI 聊天助手（如果管理员启用）
- **历史** – 最近更改的对象
- **书签** – 您保存的书签
- **任务** – 研究任务
- **报告** – 生成报告
- **导出** – 导出家谱
- **修订** – 完整的交易历史（对成员及以上可见）
- **通知** – 过去的通知

!!! note
    标签不再从侧边栏管理——标签管理已转移到 [管理设置](../administration/settings.md#tags)（仅限所有者/管理员）。有关标签的使用，请参见 [标签](tags.md)。

### 顶部应用栏

每个页面顶部的栏包含：

- **添加**（加号图标，仅对贡献者及以上可见） – 打开一个菜单以创建新对象：人物、家庭、事件、地点、来源、引用、库、笔记、媒体对象或任务
- **搜索**（放大镜） – 打开搜索页面
- **用户图标** – 打开设置菜单：用户设置、管理（仅限所有者）、管理用户（仅限所有者）、系统信息

## 首页（仪表板）

首次登录时显示仪表板。它有两列：

**左侧列：**

- **家庭成员卡** – 显示您选择的家庭成员的姓名、照片（如果有）和关键信息，并提供链接到其完整档案和快速导航到家谱。点击卡片上的 **设置家庭成员** 按钮以搜索并选择其他人。
- **周年纪念** – 基于今天日期的树中即将到来的生日和周年纪念。
- **最近更改** – 最近修改对象的简短列表，有助于跟踪协作编辑。

**右侧列：**

- **最近的博客文章** – 来自 [博客](blog.md) 的最新条目（如果存在）。
- **统计信息** – 树中对象计数的摘要（人物、家庭、事件等的数量）。

如果树的管理员配置了 **首页备注** 和/或 **首页图像**，这些将显著显示在主列上方。当两者都设置时，图像会出现在备注文本旁边。有关如何配置这些内容，请参见 [管理设置](../administration/settings.md#customization)。

!!! tip
    如果树是空的并且您具有编辑权限，仪表板将显示一个“开始使用”的提示，带有添加您的第一个人物或导入家谱文件的按钮。

## 将 Gramps Web 安装为应用

Gramps Web 是一个渐进式网络应用（PWA），这意味着您的浏览器可以将其安装在其他应用程序旁边，而不是将其保留在浏览器标签中。然后，它将获得自己的图标并在自己的窗口中打开，没有地址栏和浏览器工具栏。

安装方式取决于您的浏览器：

- **Android（Chrome）** – 打开菜单并选择“安装应用”或“添加到主屏幕”。
- **iOS/iPadOS（Safari）** – 点击分享按钮并选择“添加到主屏幕”。
- **桌面（Chrome、Edge）** – 点击地址栏右侧的安装图标，或使用浏览器菜单中的“安装”条目。
- **桌面（Firefox、Safari）** – 不支持安装；请使用普通的浏览器标签或窗口。

Gramps Web 的工作方式没有变化，数据的存储方式也没有不同——它是相同的应用程序，只是以独立应用的形式呈现。

!!! note
    Gramps Web 仍然需要访问您的服务器以显示您的数据，因此安装的应用程序无法让您离线浏览家谱。
