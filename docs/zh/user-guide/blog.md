# 使用内置博客

博客旨在展示关于您家族历史研究的故事。

在 Gramps 数据库中，博客文章被表示为带有附加注释的来源，注释中包含博客的文本，并可选地包含博客文章的图像媒体文件。Gramps Web 将每个带有标签 `Blog` 的来源视为博客文章。

## 添加博客文章

撰写文章的最快方法是在 Gramps Web 中使用专用的 **新博客文章** 表单。您可以通过博客页面上的蓝色 **+** 按钮或通过顶部应用程序栏中的 **添加** 菜单（加号图标）选择 **博客文章** 来打开它。

该表单包含以下字段：

- **标题** – 文章的标题（必填）
- **作者** – 撰写者
- **内容** – 文章本身的富文本编辑器
- **媒体** – 一个或多个媒体对象。第一个媒体文件将作为文本上方显示的预览图片；所有媒体文件将作为画廊显示在其下方。
- **标签** 和 **私有** 切换，与其他对象相同

保存表单会为您创建基础来源、注释和 `Blog` 标签，如 [下文所述](#relation-between-blog-and-sources)。

### 手动添加文章

您也可以通过自己构建基础对象来创建文章。这是 Gramps Desktop 中唯一的方式（与 Gramps Web [同步](../administration/sync.md)），两个应用程序中的步骤相同：

- 添加一个新来源。来源的标题将是您的博客文章的标题，来源的作者将是文章的作者。
- 可选地，将来源与对应于您的 Gramps Web 博客的存储库关联
- 向来源添加新注释。撰写您的博客文章并将文本复制到注释中。
- 可选地，向您的来源添加一个或多个媒体文件。第一个媒体文件将作为文本上方显示的文章预览图片。所有媒体文件将作为画廊显示在文本下方。
- 将标签 `Blog` 添加到来源（如果不存在，则创建它）

## 博客与来源之间的关系

由于博客文章只是来源，因此所有博客文章也会出现在来源列表中，并在搜索中显示为来源。在来源视图中，有一个“在博客中显示”的按钮，将带您到该博客文章的博客视图。博客文章的 URL 还包含相应来源的 Gramps ID，因此位于 `yourdomain.com/blog/S0123` 的文章对应于位于 `yourdomain.com/source/S0123` 的来源。

在每篇博客文章的底部，有一个“详细信息”按钮，将带您到来源视图。
