# 地图

地图页面以交互式标记的形式在地理地图上显示您家谱中的所有地点。您可以通过侧边栏访问它。

## 地点标记

只有在 Gramps 数据库中存储了 GPS 坐标的地点才会显示在地图上。没有坐标的地点将被静默省略。GPS 坐标可以在地点详细信息页面上设置（编辑地点并填写纬度和经度字段）。

!!! tip
    如果您的许多地点在地图上缺失，请打开地点详细信息页面，检查纬度和经度是否已设置。您可以直接从地点的编辑视图中添加或更正坐标。

每个有坐标的地点都显示为一个标记。点击标记会打开一个摘要卡片，显示地点名称及其关联的事件和人物。点击卡片中的地点名称以打开完整的地点详细信息页面。

## 搜索

地图左上角的搜索框允许您通过名称跳转到世界上的任何位置。这不会过滤树中的地点——它只是平移和缩放地图到搜索的位置。

## 时间滑块

页面底部的时间滑块根据其关联事件的年份过滤显示的地点标记：

- 拖动滑块选择年份。
- 仅显示与选定时间窗口内的事件相关联的地点。
- 使用此功能追踪您的祖先在历史特定时刻居住的位置。

## 地图图层

左下角的图层切换按钮（叠层图标）让您在两个底图之间进行选择：

### 基础地图

默认图层，由 [OpenFreeMap](https://openfreemap.org) 提供（轻模式的 Liberty 风格，暗模式的暗色风格）。这是一个现代通用地图，适合定位地点。

### 历史地图

将基础地图切换为 [OpenHistoricalMap](https://www.openhistoricalmap.org)（OHM），这是一个社区驱动的项目，绘制了世界在不同时间点的样子——可以将其视为 OpenStreetMap 的历史对应物。

当历史地图图层处于活动状态时，时间滑块还会过滤地图切片本身：OHM 以所选年份的样子渲染地图，因此显示历史边界、地点名称和特征，而不是现代的。这使得可以在一个视图中看到您祖先的位置以及当时的地理和政治背景。

!!! note
    OpenHistoricalMap 的覆盖范围因地区和时期而异。贡献稀少的区域或时代可能显示有限的历史细节。如果您注意到缺失或不准确的历史数据，请考虑 [为 OpenHistoricalMap 贡献](https://www.openhistoricalmap.org)——这是一个任何人都可以编辑的开放社区项目。

## 自定义地图叠加

除了内置的基础图层，您可以将任何扫描的历史地图图像——以 **媒体** 对象的形式存储在 Gramps 中——变成一个自定义叠加，定位在实时地图上。这对于您想要与现代或历史地理直接比较的旧城市规划、教区地图或财产地图的扫描非常有用。

### 地理参考图像

1. 打开扫描地图图像的媒体对象并切换到编辑模式。
2. 打开“地图”选项卡并点击 **编辑坐标**。这将打开一个地理参考对话框，显示图像和地图。
3. 点击 **选择地图上的一个点**，然后点击地图上应与图像上的一个点对应的位置。选择一个点后，图像首次被放置在地图上。
4. 使用 **缩放** 滑块调整图像大小，使用 **不透明度** 滑块在定位时查看底图。
5. 点击 **对齐图像**，然后再次点击地图以移动图像，使固定点精确对齐。
6. 重复缩放、不透明度和对齐步骤，直到图像与底层地理匹配，然后保存。

在后台，这会将图像的角坐标存储在媒体对象的 `map:bounds` 属性中。

### 在地图页面查看叠加

一旦媒体对象以这种方式进行了地理参考，它将自动作为可切换的图层在地图页面上可用。打开图层切换器（叠层图标，左下角）以独立于基础地图显示或隐藏每个叠加。叠加按媒体对象的标题列出。
