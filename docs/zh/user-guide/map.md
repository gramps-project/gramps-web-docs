# 地图

地图页面将您家谱中的所有地点显示为地理地图上的互动标记。可以从侧边栏访问。

## 地点标记

只有在 Gramps 数据库中存储了 GPS 坐标的地点才会显示在地图上。没有坐标的地点将被静默省略。可以在地点详细信息页面上设置 GPS 坐标（编辑地点并填写纬度和经度字段）。

!!! 提示
    如果您的许多地点在地图上缺失，请打开地点详细信息页面，检查是否设置了纬度和经度。您可以直接从地点的编辑视图中添加或更正坐标。

每个具有坐标的地点都显示为一个标记。单击标记会打开一个摘要卡片，显示地点名称及其关联的事件和人员。单击卡片中的地点名称以打开完整的地点详细信息页面。

## 搜索

地图左上角的搜索框在您输入时会进行搜索，并将结果分为三个标题：

- **地点** – 您家谱中的地点。选择一个地点会将地图平移到该地点并突出显示其标记。
- **人员** – 您家谱中的人员。选择一个人员会将地图切换到下面描述的人员视图 [下方](#following-a-person-across-the-map)。
- **外部** – 来自 [OpenStreetMap](https://www.openstreetmap.org/) 的位置，适用于世界任何地方。选择一个位置会简单地平移和缩放地图到该位置；它不会过滤或更改您家谱中的地点。

外部结果在为地点添加坐标时也很有用：您可以在这里查找位置，以查看它的位置，然后再输入其纬度和经度。

## 在地图上跟随一个人

选择一个人 – 从地图的搜索框中，或在某个人的详细信息页面上使用 **在地图中打开** 按钮 – 会显示与该人事件相关的地点，按时间顺序用线连接。每条线上的小箭头指示旅行方向，因此您可以在地图上跟随一个人的生活，从出生到死亡。

地点详细信息页面上的地点也有一个 **在地图中打开** 按钮，点击后会打开以该地点为中心的地图。

## 时间滑块

页面底部的时间滑块根据与其关联事件的年份过滤显示的地点标记：

- 拖动滑块以选择年份。
- 仅显示与选定时间窗口内的事件相关联的地点。
- 使用此功能追踪您的祖先在历史特定时刻居住的地方。

## 地图图层

图层切换按钮（堆叠图层图标，左下角）让您在两个基础地图之间进行选择。在它们下面，列出了您自己的地图图层，标记为“您的地图”（参见 [自定义地图叠加](#custom-map-overlays) 和 [地点的地图文件](#map-files-of-places)），以及“外部”下的 [Wikidata 建筑](#wikidata-buildings) 图层，每个图层都可以打开或关闭。

两个基础地图的标签以您在 Gramps Web 中选择的语言显示，当地图数据在该语言中有名称时，使用该语言，否则使用本地名称。

### 基础地图

默认图层，由 [OpenFreeMap](https://openfreemap.org) 提供（轻模式为 Liberty 风格，暗模式为暗色风格）。这是一个现代通用地图，适合定位地点。

### 历史地图

将基础地图切换为 [OpenHistoricalMap](https://www.openhistoricalmap.org)（OHM），这是一个社区驱动的项目，绘制了世界在不同时间点的样子 – 可以将其视为 OpenStreetMap 的历史对应物。

当历史地图图层处于活动状态时，时间滑块也会过滤地图瓦片本身：OHM 会渲染选定年份的地图，因此显示历史边界、地点名称和特征，而不是现代的。这使得可以在一个视图中同时看到您祖先的位置和当代的地理和政治背景。

!!! 注意
    OpenHistoricalMap 的覆盖范围因地区和时期而异。贡献稀少的地区或时代可能显示有限的历史细节。如果您注意到缺失或不准确的历史数据，请考虑 [为 OpenHistoricalMap 贡献](https://www.openhistoricalmap.org) – 这是一个任何人都可以编辑的开放社区项目。

## 自定义地图叠加

除了内置的基础图层，您还可以将任何扫描的历史地图图像 – 存储为 Gramps 的 **媒体** 对象 – 转换为位于实时地图上的自定义叠加。这对于旧城市规划、教区地图或财产地图的扫描非常有用，您可以直接与现代或历史地理进行比较。

### 地理参考图像

1. 打开扫描地图图像的媒体对象并切换到编辑模式。
2. 打开“地图”选项卡并单击 **编辑坐标**。这将打开一个地理参考对话框，显示图像和地图。
3. 单击 **在地图上选择一个点**，然后单击地图上图像上的一个点应该对应的位置。选择一个点后，图像将首次放置在地图上。
4. 使用 **缩放** 滑块调整图像大小，使用 **不透明度** 滑块在定位时查看基础地图。
5. 单击 **对齐图像**，然后再次单击地图以移动图像，使固定点精确对齐。
6. 重复缩放、不透明度和对齐步骤，直到图像与底层地理匹配，然后保存。

在后台，这将把图像的角坐标存储在媒体对象的 `map:bounds` 属性中。

### 在地图页面查看叠加

一旦媒体对象以这种方式进行了地理参考，它将自动作为可切换的图层在地图页面上可用。打开图层切换器（堆叠图层图标，左下角）以独立于基础地图显示或隐藏每个叠加。叠加按媒体对象的标题列出。

## 地点的地图文件

地点可以附加地图文件作为媒体对象 – 例如教区、地区或地产的边界，或路线。支持 KML (`.kml`)、GeoJSON (`.geojson`) 和 GPX (`.gpx`) 文件。

当您在地图上选择一个地点时，其地图文件会绘制在地图上，使用文件中存储的颜色（如果有的话）。这对于没有坐标的地点也有效：地图会缩放到文件覆盖的区域。当选择地点时，其文件会在图层切换器下的“您的地图”中列出，您可以关闭每个文件。

要将地图文件添加到地点，请像添加其他 [媒体文件](media.md) 一样将其添加到地点的图库中。

## Wikidata 建筑

“Wikidata 建筑”图层显示记录在 [Wikidata](https://www.wikidata.org/) 中的建筑，如教堂、农场或市镇房屋。默认情况下该图层处于关闭状态，可以在图层切换器的“外部”中打开。只有在地图缩放到足够近时，建筑才会显示。当时间滑块处于活动状态时，仅显示在选定时间存在的建筑。

单击建筑可以查看其来自 Wikidata 的详细信息，例如建造或拆除的时间、地址、居住者和所有者。

### 将建筑保存为地点

可以添加对象的用户在建筑的详细信息中看到一个 **保存为地点** 按钮。它会打开一个新地点的表单，预填建筑的名称（使用您的语言）、地点类型（农场为 `Farm`，否则为 `Building`）、其坐标和指向 Wikidata 项目的链接。完成表单，例如选择封闭地点，然后保存。

如果您家谱中的一个地点与建筑位于同一位置，则按钮会显示为 **打开已保存地点**，并显示该地点。

!!! 信息
    服务器管理员可以通过 [前端配置](../install_setup/frontend-config.md) 的 `mapWikidata` 选项删除 Wikidata 建筑图层。
