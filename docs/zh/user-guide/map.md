# 地图

地图页面将您家谱中的所有地点显示为地理地图上的互动标记。可以从侧边栏访问。

## 地点标记

只有在 Gramps 数据库中存储了 GPS 坐标的地点才会显示在地图上。没有坐标的地点会被静默省略。可以在地点详细信息页面上设置 GPS 坐标（编辑地点并填写纬度和经度字段）。

!!! tip
    如果您的许多地点在地图上缺失，请打开地点详细信息页面，检查纬度和经度是否已设置。您可以直接从地点的编辑视图中添加或更正坐标。

每个有坐标的地点都显示为一个标记。单击标记会打开一个摘要卡片，显示地点名称及其关联的事件和人员。单击卡片中的地点名称以打开完整的地点详细信息页面。

## 搜索

地图左上角的搜索框会在您输入时进行搜索，并将结果分为三个标题：

- **地点** – 您家谱中的地点。选择一个地点会将地图平移到该地点并突出显示其标记。
- **人员** – 您家谱中的人员。选择一个人员会将地图切换到[下面](#following-a-person-across-the-map)描述的人员视图。
- **外部** – 来自 [OpenStreetMap](https://www.openstreetmap.org/) 的位置，适用于全球任何地方。选择一个外部位置会简单地将地图平移和缩放到该位置；它不会过滤或更改您家谱中的地点。

外部结果在为地点添加坐标时也很有用：您可以在这里查找位置，以查看其在哪里，然后再输入其纬度和经度。

## 在地图上跟随一个人

选择一个人——从地图的搜索框中，或使用人员详细信息页面上的 **在地图中打开** 按钮——将显示与该人事件相关的地点，按时间顺序用线连接。每条线上的小箭头指示旅行方向，因此您可以在地图上跟随一个人的生活，从出生到死亡。

地点详细信息页面上的地点也有一个 **在地图中打开** 按钮，可以打开以该地点为中心的地图。

## 时间滑块

页面底部的时间滑块根据相关事件的年份过滤显示的地点标记：

- 拖动滑块选择一个年份。
- 仅显示与落在所选时间窗口内的事件相关的地点。
- 使用此功能追踪您的祖先在历史特定时期的居住地点。

## 地图图层

图层切换按钮（堆叠图层图标，左下角）让您在两个基础地图之间进行选择：

### 基础地图

默认图层，由 [OpenFreeMap](https://openfreemap.org) 提供支持（在亮模式下为 Liberty 风格，在暗模式下为暗色风格）。这是一个现代通用地图，适合定位地点。

### 历史地图

将基础地图切换到 [OpenHistoricalMap](https://www.openhistoricalmap.org)（OHM），这是一个社区驱动的项目，绘制了世界在不同时间点的样子——可以将其视为 OpenStreetMap 的历史对应物。

当历史地图图层处于活动状态时，时间滑块还会过滤地图图块本身：OHM 按照所选年份呈现地图，因此显示历史边界、地点名称和特征，而不是现代的。这使得可以在单一视图中同时看到您祖先的位置和当代的地理及政治背景。

!!! note
    OpenHistoricalMap 的覆盖范围因地区和时期而异。贡献稀少的地区或时代可能显示有限的历史细节。如果您注意到缺失或不准确的历史数据，请考虑[为 OpenHistoricalMap 贡献](https://www.openhistoricalmap.org)——这是一个任何人都可以编辑的开放社区项目。

## 自定义地图叠加

除了内置的基础图层外，您还可以将任何扫描的历史地图图像——作为 **媒体** 对象存储在 Gramps 中——转变为一个自定义叠加，定位在实时地图上。这对于旧城市规划图、教区地图或财产地图的扫描非常有用，您可以将其与现代或历史地理直接进行比较。

### 图像的地理参考

1. 打开扫描地图图像的媒体对象并切换到编辑模式。
2. 打开“地图”选项卡并单击 **编辑坐标**。这将打开一个地理参考对话框，图像与地图并排显示。
3. 单击 **在地图上选择一个点**，然后单击地图上图像上的一个点应对应的位置。选择一个点后，图像将首次放置在地图上。
4. 使用 **缩放** 滑块调整图像大小，使用 **不透明度** 滑块在定位时查看基础地图。
5. 单击 **对齐图像**，然后再次单击地图以移动图像，使固定点精确对齐。
6. 重复缩放、不透明度和对齐步骤，直到图像与底层地理匹配，然后保存。

在后台，这将把图像的角坐标存储在媒体对象的 `map:bounds` 属性中。

### 在地图页面查看叠加

一旦以这种方式对媒体对象进行了地理参考，它将自动作为可切换的图层在地图页面上可用。打开图层切换器（堆叠图层图标，左下角）以独立于基础地图显示或隐藏每个叠加。叠加按媒体对象的标题列出。
