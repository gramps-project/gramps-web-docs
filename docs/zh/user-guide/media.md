有两种方法可以添加新的媒体文件（图像、音频文件、视频文件或任何其他文件），并且可以在创建新对象时将现有媒体文件链接到新对象：

## 添加新的独立媒体文件

要添加独立媒体文件，请点击应用程序顶部工具栏中的 + 图标，然后选择“媒体对象”。

点击“选择文件”以从计算机中选择文件。在移动设备上，点击此按钮将给您直接用设备摄像头拍照的选项。

可选地，

- 在“标题”下输入媒体文件的描述
- 输入日期
- 将媒体文件设置为私有（这将使其仅对具有足够授权的用户可见）

点击“添加”以上传文件并创建媒体对象。

## 添加新的媒体文件并将其链接到另一个对象

在 Gramps 中，以下对象类型可以附加媒体对象：人、家庭、事件、地点、来源和引用。

在任何对象的详细视图中，点击右下角的蓝色编辑按钮（如果您看不到它，您的用户没有编辑权限）。点击“图库”选项卡，然后点击蓝色 + 按钮。

将打开一个对话框，提供与上一节中描述的相同字段。点击“保存”以上传文件、添加新的媒体对象并将其链接到查看的对象。

## 个人资料图片

一个人图库中的第一张图像用作他们的个人资料图片。在编辑模式下，它会标记为“个人资料图片”徽章。要使用不同的图像，请使用图库缩略图上的箭头按钮将其移动到第一位置，或将其拖动到那里：使用鼠标，按住缩略图并移动；在触摸屏上，按住并保持，直到它被提起。
如果一个人还没有媒体，编辑模式将显示 **添加个人资料图片** 占位符。点击它以上传新的媒体文件或选择现有的文件。

## 在创建对象时链接现有媒体文件

当您创建一个新的人、家庭、事件、地点、来源或引用时，表单中有一个“媒体”部分。在那里，您可以选择一个或多个现有媒体对象，这些对象在您保存时会链接到新对象。

当您与他们的出生和死亡事件一起创建一个人时，所选的媒体对象仅链接到此人，而不链接到事件。

## 浏览媒体

媒体视图以缩略图的画廊或列表形式显示媒体对象；该选择在您的浏览器中被记住。像其他 [列表视图](lists.md) 一样，它可以排序（包括按日期）、过滤，并用于批量选择和删除媒体。

点击画廊中的一个图块会在灯箱中打开媒体。使用箭头键、滑动或点击箭头按钮在过滤和排序的结果中逐页浏览。灯箱中的 **详细信息** 按钮打开媒体对象的页面。点击列表布局中的一行直接打开媒体对象的页面。

视频以缩略图和播放按钮显示。音频和视频文件可以在媒体对象页面、灯箱中、在 [博客文章](blog.md) 中以及嵌入笔记时播放。

## 文本识别（OCR）

如果服务器管理员启用了 OCR 支持，则在媒体对象的详细视图中，图像下方会出现“文本识别”按钮。

点击“文本识别”，选择图像中显示的文本的语言，然后点击“运行”。图像将使用 [Tesseract OCR](https://github.com/tesseract-ocr/tesseract) 进行处理，识别出的文本将显示在下方。

如果您的用户具有编辑权限，请点击“保存为笔记”以创建一个新的笔记（类型为“抄本”），其中包含识别的文本并将其链接到媒体对象。

!!! 提示
    OCR 的准确性在很大程度上取决于图像质量和所选语言。如果结果看起来不正确，请尝试不同的语言——例如，历史德文文档通常需要使用 Fraktur 变体，而不是普通德文。
