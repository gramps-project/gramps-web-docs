有两种方法可以添加新的媒体文件（图像、音频文件、视频文件或任何其他文件）：

## 添加新的独立媒体文件

要添加独立媒体文件，请点击应用程序顶部工具栏中的 + 图标，然后选择“媒体对象”。

点击“选择文件”以从计算机中选择文件。在移动设备上，点击此按钮将给您提供直接使用设备相机拍照的选项。

可选地，

- 在“标题”下输入媒体文件的描述
- 输入日期
- 将媒体文件设置为私有（这将使其仅对具有足够权限的用户可见）

点击“添加”以上传文件并创建媒体对象。

## 添加新的媒体文件并将其链接到另一个对象

Gramps 中以下对象类型可以附加媒体对象：人物、家庭、事件、地点、来源和引用。

在任何对象的详细视图中，点击右下角的蓝色编辑按钮（如果您看不到它，说明您的用户没有编辑权限）。点击“图库”选项卡，然后点击蓝色 + 按钮。

将打开一个对话框，提供与前一部分中描述的相同字段。点击“保存”以上传文件，添加新的媒体对象，并将其链接到所查看的对象。

## 文本识别 (OCR)

如果服务器管理员已启用 OCR 支持，则在媒体对象的详细视图中，图像下方会出现“文本识别”按钮。

点击“文本识别”，选择图像中显示的文本的语言，然后点击“运行”。该图像将使用 [Tesseract OCR](https://github.com/tesseract-ocr/tesseract) 进行处理，识别出的文本将显示在下方。

如果您的用户具有编辑权限，请点击“另存为备注”以创建一个包含识别文本的新备注（类型为“抄本”）并将其链接到媒体对象。

!!! 提示
    OCR 的准确性在很大程度上依赖于图像质量和所选语言。如果结果看起来不正确，请尝试不同的语言——例如，历史德文文档通常需要使用 Fraktur 变体而不是普通德文。
