# 使用内置任务管理

Gramps Web 包含一个内置的家谱任务管理工具。它旨在使研究人员能够规划和优先处理任务，同时记录他们的任务。这就是为什么任务在 Gramps 数据库中被表示为来源。在完成任务后，相关内容可以作为记录研究过程的来源。

## 任务基础

任务具有以下属性：

- 状态。可以是“打开”、“进行中”、“阻塞”或“完成”
- 优先级。可以是“低”、“中”或“高”
- 标签。标签是底层来源的普通 Gramps 标签。（请注意，所有任务还附加有 `ToDo` 标签以将其标识为任务，但该标签在任务列表中是隐藏的，以避免杂乱。）
- 标题。在任务列表中显示
- 描述。一个富文本字段，可以用来描述问题陈述，也可以记录任何进展
- 媒体。附加到任务的任何媒体文件

## 创建任务

由于任务是普通的 Gramps 对象，因此可以由能够编辑或创建其他对象（如人员或事件）的同一组用户进行编辑或创建。

要创建任务，请点击任务列表页面上的 + 按钮。输入至少一个标题，选填优先级、描述、附件和标签。创建时状态将始终为“打开”。

## 任务列表

默认情况下，任务列表按状态排序——已完成的任务排在最后——并在每个状态内按优先级排序，优先级最高的在前。过滤栏中的排序菜单还可以按优先级、标题或最后更改（最新的在前）进行排序。

点击任务以打开它。具有编辑权限的用户还可以直接在列表中点击任务的状态图标以更改其状态，例如将其标记为完成。

列表上方的 **过滤** 按钮可以根据标题、状态、优先级或标签过滤任务，使用 [GOQL](goql.md) 表达式，或使用 [高级过滤器](lists.md#advanced-filter)。勾选多个状态或优先级将显示具有任一状态的任务，例如所有打开和阻塞的任务。

## 编辑任务

任务页面没有像其他 Gramps 对象那样的单独“编辑模式”：

- 点击标题进行编辑。按 Enter、点击 ✓ 或点击其他地方以保存；按 Escape 或点击 ✕ 以取消。
- 状态和优先级的更改会立即应用。
- 要编辑描述或附件，请点击该部分标题旁边的编辑按钮。描述通过其下方的“保存”按钮保存；编辑附件以 **完成** 结束。
- 锁定按钮设置任务是否为私有。任务的描述将获得相同的隐私设置。

没有编辑权限的用户将状态和优先级视为文本，且没有内容的部分将被隐藏。

在标题下方，编辑者会看到两个按钮：**编辑来源** 打开表示任务的来源，可以编辑其其他注释、引用和属性。**删除** 在确认后删除任务并返回任务列表；出现的消息有一个撤销按钮以恢复任务。

## 批量更改任务属性

具有编辑权限的用户在任务列表的每一行上看到一个复选框。选择任务并使用列表上方的 **设置优先级** 或 **设置状态** 一次性更改所有选定任务。

## Gramps Desktop 中的任务

通过 Gramps Web 添加任务时，来源和注释将附加 `ToDo` 标签，因此任务将出现在桌面 [待办事项注释 Gramplet](https://gramps-project.org/wiki/index.php/Addon:ToDoNotesGramplet) 以及 [待办事项报告](https://gramps-project.org/wiki/index.php/Addon:ToDoReport) 中。

要在 Gramps Desktop 中添加或编辑任务，请使用以下指南：

- 添加一个带有 `ToDo` 标签的来源，并将任务标题作为标题
- 可选地，向来源添加一个带有 `ToDo` 标签的注释，类型为“待办事项”，描述为文本
- 添加一个属性“状态”，并将其设置为“打开”、“进行中”、“阻塞”或“完成”
- 添加一个属性“优先级”，并将其设置为 9（低）、5（中）或 1（高）（这些反直觉的值取自 iCalendar 规范）
