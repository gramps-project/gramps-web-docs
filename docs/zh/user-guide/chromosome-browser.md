# 染色体浏览器

染色体浏览器是一个可视化个人DNA匹配的工具。它以染色体上的彩色条形图显示与其他人共享的DNA片段。

您可以在DNA视图中的“染色体浏览器”选项卡下找到它。

对于每条染色体，上方（浅蓝色）条形代表从父亲继承的拷贝，下方（浅红色）条形代表从母亲继承的拷贝。共享的片段以彩色条形显示在这些条形的顶部。未知侧（父方或母方）的片段在两者之间的单独轨道中显示。当多个匹配的片段重叠时，它们会以单独的、更细的通道绘制，以便每个片段都保持可见。

点击图例中匹配的名称，仅显示该人的共享片段。

## 按共同祖先分组

在图例上方，您可以在按**匹配**和按**共同祖先**着色片段之间切换。通过共同祖先，与所选人有相同最近共同祖先的匹配将共享一种颜色和图例中的一行。这可以一目了然地显示染色体的哪些部分是从哪个祖先夫妇继承的——与同一侧组的其他匹配片段重叠的片段可能来自相同的祖先，这有助于确定一个新的、未知的匹配。

这些组按最近的亲属关系优先排序。没有已知共同祖先的匹配被归类为“未知”。通过多条线相关的匹配按最近的那条进行分组。

## 保存图表

要保存图表，请点击人员选择器旁边的下载按钮。它将下载一个带有白色背景和图例的SVG文件，包括每个匹配的总共享中心摩根值。如果在图例中选择了某个匹配或组，则仅包含该匹配或组。
