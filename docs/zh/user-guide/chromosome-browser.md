# 染色体浏览器

染色体浏览器是一个可视化个人DNA匹配的工具。它以染色体上的彩色条形图显示与其他人共享的DNA片段。

您可以在DNA视图中的“染色体浏览器”选项卡下找到它。

对于每条染色体，上方（浅蓝色）条形代表从父亲继承的拷贝，下方（浅红色）条形代表从母亲继承的拷贝。共享的片段显示为这些条形上方的彩色条形。如果未知是哪一方（父方或母方），则该片段跨越两个条形，并用斜线标记显示。

点击图例中匹配的名称，仅显示该人的共享片段。

要保存图表，请点击人员选择器旁边的下载按钮。它将下载一个带有白色背景和图例的SVG文件，包括每个匹配的总共享中心摩根。如果在图例中选择了一个匹配，则仅包含该匹配。
