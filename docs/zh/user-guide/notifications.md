# 通知

顶部应用栏中的铃铛打开通知。铃铛上的徽章显示未读通知的数量。菜单列出正在运行的任务和最新的通知；**显示全部** 打开完整的通知日志。在小屏幕上，铃铛直接打开日志。

通知内容包括：

- **其他用户的更改。** 当其他用户在您使用 Gramps Web 时更改树时，通知会显示是谁更改了什么，例如“编辑人员”或“12 次更改”。点击它可以在 [修订历史](revisions.md) 中打开更改。没有 Gramps Web 用户的更改，例如直接对与 Gramps Desktop 共享的数据库进行的更改，将以没有名称的方式显示。此功能仅对能够查看修订历史的用户（成员及以上）可用。
- **后台任务** – 例如导入和导出、生成报告、OCR 文本识别、数据库升级、删除或编辑多个对象以及搜索索引重建 – 显示其状态（例如待处理、已开始、进行中）并在完成或失败时通知您。
- **错误**，在您的会话期间发生的错误 – 失败的 API 请求、后台任务错误、保存失败或浏览器级错误。

完成的导出和媒体档案可以从其通知中下载，即使您已经离开 [导出页面](../administration/export.md)。

某些通知包含结构化细节，例如失败任务的错误消息。点击通知日志中的此类条目会打开一个对话框，其中包含错误数据的详细信息和一个 **复制 JSON** 按钮。这在报告错误时非常有用，因为 JSON 包含来自服务器的确切错误信息。

在通知日志中使用 **清除全部** 来消除所有通知。

更改整个树的任务，例如导入、恢复、删除所有对象或重建搜索索引，不能同时运行。如果您在另一个任务正在运行时启动一个任务，消息会提示该树上已经有另一个任务在运行，并显示正在运行的任务及其进度。

!!! note
    通知仅存储在内存中，并在您重新加载页面时清除。Gramps Web 仅在打开时检查其他用户的更改，因此在您离开期间所做的更改不会被报告；有关这些更改，请参见 [修订历史](revisions.md)。
