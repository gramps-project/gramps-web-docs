# 使用 AI 助手

在 Gramps Web 中的 **助手** 视图（如果在您的安装中启用）提供了一个 AI 助手，可以回答有关您的家谱的问题。

!!! warning
    与任何 AI 助手一样，答案可能是错误的。请使用答案中的链接检查其依据的记录。

## 工作原理

助手事先并不知道您的家谱。为了回答问题，一个大型语言模型会查找所需的记录，就像您自己会做的那样：

- 它使用 [全文搜索](search.md) 搜索家谱，
- 它按名称、日期、地点或子女数量等标准过滤人员、事件和家庭，
- 它找到某个人的祖先、后代和其他亲属，以及他们的关系，
- 它读取人员、家庭、事件、地点和备注的完整记录。

然后，它根据找到的记录进行回答，并提供相关链接。在它工作时，所使用的工具会显示出来，以便您可以跟随。需要更长时间的问题会在后台运行——您可以导航到其他地方，然后再回来。

助手只从您的家谱中回答问题，而不是从语言模型的一般知识中回答——即使是关于知名人物。如果家谱没有记录某些内容，它会说明这一点，并提到它找到的相关信息，例如在备注中。它只能看到您被允许看到的内容：对于无法查看的用户，私人记录的链接将以普通文本形式显示。

后续问题会保持同一对话中早期问题的上下文，因此您可以在询问某个人后问“他什么时候去世？”。

## 您可以询问的内容

- **关于人员的事实**：“玛丽·史密斯（Mary Smith）是什么时候出生的？”或“约翰·多（John Doe）的孩子叫什么名字？”
- **亲属关系**：“简·史密斯（Jane Smith）的祖父母是谁？”或“约翰·迈耶（Johann Meyer）的哪些后代移民到美国？”
- **带条件的搜索**：“谁在1850年后出生于伦敦？”、“列出1920年至1950年之间的婚姻”或“哪些夫妇有五个或更多孩子？”
- **地点**：“在巴黎发生了哪些事件？”或“谁出生于丹麦？”——较大地点内的地点也包括在内。
- **备注**：“关于迈耶家族的农场，备注中说了些什么？”

需要一次性查看整个家谱的问题，例如“最常见的名字是什么？”，效果较差，因为助手每次查找时只能看到有限数量的记录。

## 询问有关图像的问题

如果服务器管理员已启用此功能，提示中有一个按钮可以附加图像。您还可以粘贴图像或将图像文件拖放到提示中。最多可以附加四张图像到一个问题中，例如扫描的教堂记录，以询问“在此条目中提到的是谁，他们在我的家谱中吗？”

图像仅与它们附加到的问题一起发送。后续问题可以参考助手关于它们的回答，但不能直接引用图像本身，因此如果需要，请再次附加它们。如果您的家谱对 AI 使用有限制，每张图像的计算方式与额外的问题相同。

## 让助手更改您的家谱

如果服务器管理员已启用此功能，编辑者、所有者和管理员可以要求助手更改家谱，例如“在1802年5月3日为约翰·迈耶（Johann Meyer）添加洗礼”或“修正安娜·史密斯（Anna Smith）的出生年份，应该是1871年”。

助手从不自行更改任何内容。它会以 **建议更改** 卡片的形式回答，列出它将添加、编辑或删除的每条记录，旧值用删除线标出，新值用高亮显示。在您点击 **应用** 之前，什么都不会发生。更改将以一步完成，您可以像其他编辑一样撤销，从出现的消息或 [修订历史](revisions.md) 中撤销。

在应用建议之前，请仔细检查——特别是助手是否选择了正确的人，以及它是否没有添加一个已经在您家谱中以稍微不同名称存在的新记录（例如地点或来源）。如果建议不完全正确，请说明要更改的内容，助手会再次提出建议。

一旦建议被应用，同一对话中的较旧建议将无法再应用，因为它们是针对之前的家谱提出的。如果在此期间其中一条受影响的记录已被更改，情况也是如此。

## 提问技巧

- **命名人员。** 助手不知道您是谁或您的家庭成员是谁，因此与其问“我的祖母”，不如问“安娜·史密斯（Anna Smith，生于1950年）的祖母”。您也可以使用 Gramps ID，例如“ I0042 的孩子”。
- **具体** 当名称常见时：“1850年出生于波士顿的约翰·史密斯（John Smith）是什么时候结婚的？”比“约翰·史密斯（John Smith）是什么时候结婚的？”更好。
- **使用您的语言。** 您可以用自己的语言提问，并以同样的语言获得回答。
- **如果答案看起来不完整，请以不同方式再次提问**——例如，说明您感兴趣的地点或时间段。

!!! tip
    请与社区分享您对有效和无效事项的经验。
