Gramps Web allows tagging people in photographs, similar to Gramps Desktop, linking the person and the media object. This is simplified by automated face detection.

A region of an image can be linked not only to a person, but also to a family, event, place, source or citation – for example a building in a photo, or a citation on a scanned page. An object can have several regions in the same image, for instance on an album page with more than one photo of the same person.

## Linking a region

To link a region of an image to an object, follow these steps:

- Open the detail view of the media object, e.g. by clicking on "show details" in the full-screen preview.
- Click the blue edit button in the bottom-right corner. If you do not see this button, your user does not have edit permissions.
- Overlayed on the image, you will see boxes with dashed border corresponding to detected faces. Click on a box to select it.

## Editing a region

In edit mode, click a linked region to select it. Then you can:

- **move** it by dragging it, or **resize** it with its four corner handles. The change is saved when you release the mouse button or lift your finger.
- link it to a **different object** with the "Link" button.
