# Administration Settings

The **Settings > Administration** page is accessible via the user icon in the top app bar. It is only available to users with the Owner or Administrator role and provides tools for managing the family tree database.

The page is organized into collapsible sections. Click a section header to expand it. This page lists the sections and links to where each of them is described.

## Data

- [Usage quotas](import.md#usage-quotas){#usage-quotas} – current usage relative to the limits for people and media storage
- [Import data](import.md){#import-data} – upload a family tree file
- [Media file status](import-media.md#media-file-status){#media-file-status} – media objects with missing checksums or files
- [Import media archive](import-media.md){#import-media-archive} – upload a ZIP file to fill in missing media files

## Search index

- [Manage search index](search-index.md){#manage-search-index} – check the index status and rebuild it

## Tree settings

- [Family Tree name](customization.md#family-tree-name){#family-tree-name} – rename the underlying Gramps database
- [Researcher Information](customization.md#researcher-information){#researcher-information} – contact details of the primary researcher, embedded in exports

## Customization

- [Theme colors](customization.md#theme-colors){#theme-colors} – primary and accent color
- [App title](customization.md#app-title){#app-title} – title shown in the browser and the top app bar
- [Home page note](customization.md#home-page-note){#home-page-note} – a note shown on the home page
- [Home page image](customization.md#home-page-image){#home-page-image} – an image shown on the home page
- [Export/Import settings](customization.md#exportimport-settings){#exportimport-settings} – copy tree settings as a JSON file

## Family Tree Processing

- [Check and Repair Database](check-repair.md#check-and-repair-database){#check-and-repair-database} – find and fix database inconsistencies
- [Verify the Data](check-repair.md#verify-the-data){#verify-the-data} – find implausible data, such as unusual ages

## Tags

- [Manage tags](../user-guide/tags.md#managing-tags){#manage-tags} – create, rename, recolor, and delete tags

## Backups

- [Stored backups](backups.md#stored-backups){#stored-backups} – backups kept on the server
- [Restore from Backup](backups.md#restore-from-backup){#restore-from-backup} – replace the tree with a backup or a Gramps XML file

## Danger Zone

- [Delete all objects](import.md#delete-all-objects){#delete-all-objects} – clear the tree, or remove specific object types
