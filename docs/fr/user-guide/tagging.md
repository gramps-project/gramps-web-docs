Gramps Web permet de taguer des personnes sur des photographies, de manière similaire à Gramps Desktop, en liant la personne et l'objet média. Cela est simplifié par la détection automatique des visages.

Une région d'une image peut être liée non seulement à une personne, mais aussi à une famille, un événement, un lieu, une source ou une citation – par exemple, un bâtiment sur une photo, ou une citation sur une page numérisée. Un objet peut avoir plusieurs régions dans la même image, par exemple sur une page d'album avec plus d'une photo de la même personne.

## Lier une région

Pour lier une région d'une image à un objet, suivez ces étapes :

- Ouvrez la vue détaillée de l'objet média, par exemple en cliquant sur "afficher les détails" dans l'aperçu plein écran.
- Cliquez sur le bouton bleu d'édition dans le coin inférieur droit. Si vous ne voyez pas ce bouton, votre utilisateur n'a pas les permissions d'édition.
- Superposé à l'image, vous verrez des cases avec des bordures en pointillés correspondant aux visages détectés. Cliquez sur une case pour la sélectionner.
- Pour dessiner une région vous-même, cliquez sur le

Les régions liées sont affichées avec une bordure solide et une étiquette avec le nom de l'objet lié et l'icône de son type. Dans la vue plein écran de l'image, cliquer sur une région liée ouvre l'objet lié.

## Éditer une région

En mode édition, cliquez sur une région liée pour la sélectionner. Ensuite, vous pouvez :

- **déplacer** la région en la faisant glisser, ou **redimensionner** la région avec ses quatre poignées d'angle. Le changement est enregistré lorsque vous relâchez le bouton de la souris ou retirez votre doigt.
- la lier à un **autre objet** avec le bouton "Lier".

Les régions peuvent également être utilisées avec le clavier : appuyez sur Tab pour naviguer entre elles et sur Entrée ou Espace pour en sélectionner une en mode édition, ou pour ouvrir l'objet lié dans la vue plein écran.
