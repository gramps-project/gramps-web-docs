# Démarrer un nouvel arbre

Cette page vous guide à travers les premières étapes d'un arbre généalogique vide : vous ajouter, ajouter vos parents et voir le résultat dans le graphique de l'arbre généalogique. Cela prend environ 15 minutes.

Si vous avez déjà un arbre généalogique dans un autre programme de généalogie ou dans Gramps Desktop, vous n'avez pas besoin de le saisir à nouveau manuellement – consultez plutôt [Importer des données](../administration/import.md).

!!! note
    Ajouter des personnes nécessite le rôle d'Éditeur ou supérieur. Le propriétaire d'un arbre l'a toujours. Consultez [Système d'utilisateurs](../install_setup/users.md) pour tous les rôles.

## 1. Créer un lieu

Dans Gramps, un lieu est créé une fois et ensuite sélectionné pour chaque événement qui s'y est produit – par exemple, les naissances de plusieurs frères et sœurs dans la même ville. C'est pourquoi un lieu doit exister avant que vous puissiez le sélectionner comme lieu de naissance de quelqu'un.

Pour créer le lieu où vous êtes né :

1. Cliquez sur le bouton **+** (Ajouter) dans la barre d'application en haut et choisissez **Lieu**.
2. Entrez le **Nom** du lieu, et éventuellement son **Type** (comme ville ou village).
3. Optionnellement, cliquez sur **Choisir sur la carte** pour définir ses coordonnées, afin que le lieu apparaisse sur la [carte](map.md).
4. Cliquez sur **Ajouter**.

Créez les lieux de naissance de vos parents de la même manière. Si vous ne connaissez pas encore un lieu, passez-le – vous pourrez l'ajouter plus tard.

## 2. Ajoutez-vous

Retournez à la page d'accueil. Bien que l'arbre soit vide, il affiche une carte **Commencer**. Cliquez sur **Nouvelle Personne** pour ouvrir le formulaire pour une nouvelle personne :

- **Nom** – votre prénom et nom de famille
- **Genre**
- **Date de Naissance** – voir [Saisie des dates](#entering-dates) ci-dessous
- **Lieu de Naissance** – cliquez sur **Sélectionner un lieu existant** et recherchez le lieu que vous avez créé

Laissez les champs de décès vides et cliquez sur **Ajouter**. La page de la nouvelle personne s'ouvre.

La première personne créée dans un arbre vide devient automatiquement votre **Personne Domicile** : la personne à partir de laquelle le graphique de l'arbre généalogique commence. Vous pouvez choisir une autre Personne Domicile à tout moment sur la page d'accueil.

### Saisie des dates

Une date est saisie sous forme de champs séparés pour l'année, le mois et le jour. Si vous ne connaissez que l'année, remplissez uniquement l'année. Pour les dates incertaines, changez le type de la date – par exemple en "environ" ou "avant" – au lieu de deviner un jour exact.

## 3. Ajoutez vos parents

1. Cliquez sur **Arbre Généalogique** dans la barre latérale. Le graphique vous montre en tant que Personne Domicile.
2. Cliquez sur le bouton crayon dans le coin inférieur droit pour activer le mode édition.
3. Cliquez sur le petit bouton **+** sur votre carte. La boîte de dialogue **Ajouter un Membre de la Famille** s'ouvre.
4. À côté de **Père**, cliquez sur l'icône **+** pour créer une nouvelle personne, remplissez le formulaire comme précédemment, et enregistrez. Votre père apparaît dans le graphique, déjà lié à vous.
5. Répétez avec **Mère**.

L'icône **lien** à côté de chaque relation connecte une personne qui existe déjà dans votre arbre au lieu de créer une nouvelle.

De la même manière, cliquez sur le **+** sur n'importe quelle carte dans le graphique pour ajouter les parents, enfants ou conjoint de cette personne. Chaque changement est enregistré immédiatement. Pour quitter le mode édition, cliquez sur le bouton de fermeture dans la barre d'application en haut.

## 4. Voir le résultat

Le graphique vous montre maintenant avec vos parents. Essayez les autres types de graphiques dans les onglets en haut de la page – par exemple, le Graphique en éventail – et cliquez sur la carte de n'importe quelle personne pour centrer le graphique sur elle. Consultez [Arbre Généalogique](tree.md) pour tous les graphiques et options.

## Prochaines étapes

- **Ajouter plus de détails.** Ouvrez la page d'une personne – par exemple avec le bouton **Détails de la Personne** dans la barre d'outils du graphique – pour ajouter d'autres événements, notes, sources, et plus. Consultez [Édition dans la vue de l'arbre](tree-edit.md) pour ce qui peut être fait directement dans le graphique.
- **Ajouter des photos et des documents.** Consultez [Ajouter des fichiers multimédias](media.md).
- **Invitez votre famille.** Les proches ont besoin de leur propre compte sur votre arbre ; consultez [Gérer les utilisateurs](../administration/users.md) et [Inscription](registration.md).
