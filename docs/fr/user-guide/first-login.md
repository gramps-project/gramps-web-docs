Lors de la première connexion à Gramps Web, un formulaire de Préférences (intitulé Paramètres utilisateur) sera affiché, demandant à l'utilisateur de sélectionner une langue pour l'interface et une [Personne de référence](https://www.gramps-project.org/wiki/index.php/Gramps_Glossary#home_person). La sélection de la Personne de référence peut également être modifiée depuis la page d'accueil du site web.

La Personne de référence pour un utilisateur d'un site Gramps Web n'a pas besoin d'être la même que celle choisie par le propriétaire du site dans Gramps pour ordinateurs de bureau – c'est un paramètre personnel qui peut être différent pour chaque utilisateur de Gramps Web. La personne de référence est utilisée pour la vue initiale de l'arbre généalogique et le point de départ pour la plupart des rapports. Un choix typique serait qu'un utilisateur se sélectionne lui-même comme Personne de référence. Lorsqu'il collabore avec un autre membre d'un arbre, ces utilisateurs pourraient vouloir définir l'ancêtre commun comme Personne de référence. Cela garantit un point de référence commun pour les relations éloignées.

Pour sélectionner une personne comme Personne de référence, commencez à taper un Prénom ou un Nom de famille dans le champ de texte et une liste déroulante avec des correspondances apparaîtra.

Si l'arbre est encore vide, il n'y a personne à choisir pour le moment. Dans ce cas, la page d'accueil affiche une carte **Commencer** qui guide les éditeurs à travers les premières étapes : d'abord ajouter une personne (ou importer un fichier d'arbre généalogique), puis connecter des personnes en ajoutant une famille. La première personne que vous créez dans un arbre vide devient automatiquement votre Personne de référence. Voir [Démarrer un nouvel arbre](start-tree.md) pour un guide étape par étape.

Les paramètres de langue et de Personne de référence sont stockés dans le stockage local du navigateur, donc ils persisteront sur un appareil donné. La Personne de référence est stockée séparément pour chaque arbre.
