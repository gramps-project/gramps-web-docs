# Navigateur de chromosomes

Le navigateur de chromosomes est un outil pour visualiser les correspondances ADN d'une personne. Il montre les segments d'ADN partagés avec d'autres personnes dans l'arbre sous forme de barres colorées sur les chromosomes.

Vous pouvez le trouver sous l'onglet &ldquo;Navigateur de chromosomes&rdquo; dans la vue ADN.

Pour chaque chromosome, la barre supérieure (bleu clair) représente la copie héritée du père, la barre inférieure (rouge clair) celle héritée de la mère. Les segments partagés sont affichés sous forme de barres colorées au-dessus de celles-ci. Les segments dont le côté (paternel ou maternel) n'est pas connu sont affichés dans une piste séparée entre les deux. Lorsque les segments de plusieurs correspondances se chevauchent, ils sont dessinés dans des voies séparées et plus fines, de sorte que chaque segment reste visible.

En cliquant sur le nom d'une correspondance dans la légende, seuls les segments partagés de cette personne sont affichés.

## Regroupement par ancêtres communs

Au-dessus de la légende, vous pouvez basculer entre la coloration des segments par **Correspondances** et par **Ancêtres communs**. Avec les ancêtres communs, les correspondances qui descendent des mêmes ancêtres communs les plus récents avec la personne sélectionnée partagent une couleur et une ligne dans la légende. Cela montre d'un coup d'œil quelles parties des chromosomes ont été héritées de quel couple ancestral – un segment d'une autre correspondance qui chevauche ceux d'un groupe du même côté provient probablement des mêmes ancêtres, ce qui aide à situer une nouvelle correspondance inconnue.

Les groupes sont ordonnés par le lien le plus proche en premier. Les correspondances sans ancêtres communs connus sont regroupées sous "Inconnu". Une correspondance qui est liée par plusieurs lignées est regroupée par la plus proche.

## Sauvegarder le graphique

Pour sauvegarder le graphique, cliquez sur le bouton de téléchargement à côté du sélecteur de personne. Cela télécharge un fichier SVG avec un fond blanc et la légende, y compris le total des centimorgans partagés de chaque correspondance. Si une correspondance ou un groupe est sélectionné dans la légende, seul celui-ci est inclus.
