# Розгортання Gramps Web з Docker

Найзручніший варіант для розміщення Gramps Web на власному сервері (або віртуальному сервері) - це використання Docker Compose.

Ми припустимо, що Docker і Docker Compose вже встановлені у вашій системі. Ви можете використовувати Windows, Mac OS або Linux як хост-систему. Підтримувані архітектури включають не лише x86-64 (десктопні системи), але й ARM-системи, такі як Raspberry Pi, які можуть служити як недорогий, але потужний (достатньо) веб-сервер.

!!! note
    Вам не потрібно встановлювати Gramps на сервер, оскільки він міститься в образі docker.


## Крок 1: Налаштування Docker

Створіть новий файл на сервері з назвою `docker-compose.yml` і вставте наступний вміст: [docker-compose.yml](https://raw.githubusercontent.com/gramps-project/gramps-web-docs/main/examples/docker-compose-base/docker-compose.yml).

Це створить шість іменованих томів, щоб забезпечити збереження всіх відповідних даних при перезапуску контейнера.

Встановіть `GRAMPSWEB_BASE_URL` на адресу, за якою буде доступний Gramps Web, наприклад, `https://gramps.mydomain.com`. Це використовується для створення посилань в електронних листах, таких як скидання паролів. Щоб надсилати електронні листи, також додайте налаштування електронної пошти, описані в [налаштуванні](configuration.md).

!!! warning
    Вищезазначене зробить API доступним на порту 80 хост-машини **без захисту SSL/TLS**. Ви можете використовувати це для локального тестування, але не виставляйте це безпосередньо в інтернет, це абсолютно небезпечно!

## Крок 2: Захист доступу з SSL/TLS

Веб API **повинен** надаватися для публічного інтернету через HTTPS. Є кілька варіантів, наприклад:

- Використання хостингу Docker, який автоматично включає SSL/TLS
- Використання зворотного проксі-сервера Nginx з сертифікатом Let's Encrypt

Дивіться [Docker з Let's Encrypt](lets_encrypt.md) для налаштування першого варіанту.

Якщо ви плануєте використовувати Gramps Web лише у вашій локальній мережі, ви можете пропустити цей крок.

## Крок 3: Запустіть сервер

Запустіть

```
docker compose up -d
```

При першому запуску додаток відобразить майстра першого запуску, який дозволить вам

- Створити обліковий запис для користувача-адміністратора
- Імпортувати родинне дерево у форматі Gramps XML (`.gramps`)

## Крок 4: Завантаження медіафайлів

Є кілька варіантів для завантаження медіафайлів.

- Коли ви використовуєте файли, збережені на тому ж сервері, що й Gramps Web, ви можете змонтувати каталог у контейнер Docker замість використання іменованого тому, тобто `/home/server_user/gramps_media/:/app/media` замість `gramps_media:/app/media`, і завантажити свої медіафайли туди.
- Коли ви використовуєте медіафайли, [розміщені на S3](s3.md), ви можете використовувати додаток S3 Media Uploader
- Найзручніший варіант - це використання [Gramps Web Sync](../administration/sync.md).
