# Створіть обліковий запис для власника дерева

Перед тим, як почати використовувати Gramps Web, вам потрібно створити обліковий запис для власника дерева. Якщо для даного дерева не існує облікового запису користувача, буде показана форма для створення облікового запису. Форма залежить від налаштування сервера, яке може бути для одного дерева або для кількох дерев.

## Налаштування для одного дерева: створити обліковий запис адміністратора

На сервері з налаштуванням для одного дерева, коли обліковий запис користувача ще не існує, відкриття Gramps Web показує форму для створення облікового запису адміністратора. Адміністратор буде як власником (одного) дерева, так і адміністратором установки. Форма також дозволяє налаштувати конфігурацію електронної пошти, необхідну для сповіщень електронною поштою (наприклад, скидання пароля користувача). Якщо конфігурація електронної пошти вже була додана через файл конфігурації або змінні середовища на сервері, цю частину форми можна залишити порожньою.

Пароль потрібно ввести двічі; форму можна надіслати лише тоді, коли обидва введення співпадають.

Якщо екземпляр вже було налаштовано, відкриття адреси форми показує повідомлення з проханням увійти з існуючим обліковим записом.

## Налаштування для кількох дерев: створити обліковий запис адміністратора

У налаштуванні для кількох дерев та сама форма для створення облікового запису адміністратора буде показана, якщо не існує користувачів *в жодному дереві*, тобто коли сервер тільки що був створений.

## Налаштування для кількох дерев: створити обліковий запис власника дерева

У налаштуванні для кількох дерев кожен користувач прив'язаний до одного дерева. Навіть якщо користувачі вже існують в інших деревах, власника дерева можна створити в веб-інтерфейсі, якщо для *цього дерева* ще не існує власника.

Однак форма створення власника не буде відображатися автоматично на домашній сторінці Gramps Web, яка є однаковою для всіх дерев. Натомість до неї можна дістатися за адресою `https://my-gramps-instance/firstrun/my-tree-id`, де `https://my-gramps-instance` є базовою адресою вашої установки Gramps Web, а `my-tree-id` — це ID вашого дерева.

Можливий робочий процес для адміністратора сайту для створення нового дерева полягає в тому, щоб

- Створити дерево через REST API, отримавши ID нового дерева
- Поділитися посиланням на форму створення власника з відповідним ID дерева з потенційним власником дерева

Форма створення власника дерева аналогічна формі створення адміністратора, описаній вище, за винятком того, що не дозволяє змінювати конфігурацію електронної пошти (що дозволено лише для адміністраторів).
