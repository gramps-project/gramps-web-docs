# Експорт даних

Сторінка Експорту дозволяє завантажити дані родинного дерева в різних форматах, а також архів усіх медіафайлів.

## Експорт родинного дерева у форматі Gramps XML

Щоб отримати копію даних родинного дерева, відкрийте сторінку Експорту в Gramps Web і виберіть формат Gramps XML. Натисніть **Генерувати**, щоб створити файл, і **Завантажити**, коли він буде готовий. Для великого дерева створення файлу може зайняти деякий час; ви можете залишити сторінку в цей час і завантажити файл пізніше з його запису в [сповіщеннях](../user-guide/notifications.md).

Зверніть увагу, що якщо ваш користувач Gramps Web не має дозволу на перегляд приватних записів, експорт не міститиме жодних приватних записів.

## Резервне копіювання вашого родинного дерева

Для повних резервних копій дерева – включаючи його налаштування та користувачів – дивіться [Резервне копіювання та відновлення](backups.md). Експорт Gramps XML може слугувати резервною копією тільки даних родинного дерева і може бути відновлений через [Відновлення з резервної копії](backups.md#restore-from-backup).

## Поділіться своїм родинним деревом з користувачами інших генеалогічних програм

Коли обмін генеалогічними даними у форматі Gramps XML не є можливим, ви також можете експортувати файл GEDCOM. Зверніть увагу, що це не підходить як резервна копія вашого родинного дерева в Gramps Web.

## Резервне копіювання ваших медіафайлів

Щоб зробити резервну копію ваших медіафайлів, ви можете створити та завантажити ZIP-архів усіх медіафайлів на сторінці Експорту.

Зверніть увагу, що, особливо для великих дерев, це може бути витратною операцією для сервера і повинно виконуватися лише в разі крайньої необхідності. З цієї причини кількість медіаархівів, які можна створити, обмежена (за замовчуванням – один на годину). Якщо ви досягнете ліміту, з'явиться повідомлення про помилку.

Кращим варіантом для регулярного резервного копіювання ваших медіафайлів є використання [додатку Gramps Web Sync](sync.md) (який сам по собі не є рішенням для резервного копіювання) і створення інкрементних резервних копій на вашому локальному комп'ютері.

В обох випадках, якщо ваш користувач Gramps Web не має дозволу на перегляд приватних записів, експорт не міститиме файлів приватних медіаоб'єктів.

## Переміщення до іншої інстанції Gramps Web

Gramps Web не прив'язує вас до конкретного постачальника, і ви завжди можете переміститися до іншої інстанції Gramps Web без втрати даних і без прямого доступу до жодного з серверів.

Щоб досягти повної міграції, виконайте ці кроки (припускаючи, що у вас є права власника дерева):

1. Перейдіть на сторінку Експорту та експортуйте своє дерево у файл Gramps XML (`.gramps`). Якщо ви використовуєте [додаток Sync](sync.md), ви також можете згенерувати експорт у Gramps для настільних ПК.
2. На сторінці Експорту згенеруйте та завантажте медіаархів. Якщо ви використовуєте [додаток Sync](sync.md), ви також можете просто ZIP-архівувати свою локальну папку медіа Gramps.
3. Перейдіть до Налаштування > Адміністрування > Керування користувачами та натисніть кнопку "Експортувати деталі користувача". Це завантажить файл JSON.
4. У новій інстанції Gramps Web відкрийте [сторінку Імпорту](import.md). Імпортуйте файл `.gramps`, експортований на кроці 1.
5. На сторінці Імпорту нової інстанції Gramps Web завантажте медіаархів (ZIP) у розділі [Імпорт медіафайлів](import-media.md).
6. Перейдіть до Налаштування > Адміністрування > Керування користувачами нової інстанції Gramps Web. Натисніть кнопку "Імпортувати облікові записи користувачів" і завантажте файл JSON, завантажений на кроці 3.

Зверніть увагу, що, хоча ваші облікові записи користувачів будуть мігрувати, усім вашим користувачам потрібно буде встановити нові паролі, використовуючи посилання "забули пароль", оскільки паролі зберігаються в зашифрованій формі і не можуть бути експортовані.
