# Експорт даних

Сторінка Експорту дозволяє вам завантажити дані родинного дерева в різних форматах, а також архів усіх медіафайлів.

## Експортувати родинне дерево у форматі Gramps XML

Щоб отримати копію даних родинного дерева, відкрийте сторінку Експорту в Gramps Web і виберіть формат Gramps XML. Натискаючи "експортувати", ви згенеруєте файл, і завантаження розпочнеться, як тільки він буде готовий.

Зверніть увагу, що якщо ваш користувач Gramps Web не має дозволу на перегляд приватних записів, експорт не міститиме жодних приватних записів.

## Резервне копіювання вашого родинного дерева

Для повних резервних копій дерева – включаючи його налаштування та користувачів – дивіться [Резервне копіювання та відновлення](backups.md). Експорт Gramps XML може слугувати резервною копією лише даних родинного дерева і може бути відновлений через [Відновлення з резервної копії](backups.md#restore-from-backup).

## Поділіться своїм родинним деревом з користувачами інших генеалогічних програм

Коли обмін генеалогічними даними у форматі Gramps XML не є можливим, ви також можете експортувати файл GEDCOM. Зверніть увагу, що це не підходить як резервна копія вашого родинного дерева в Gramps Web.

## Резервне копіювання ваших медіафайлів

Щоб зробити резервну копію ваших медіафайлів, ви можете створити та завантажити ZIP-архів усіх медіафайлів на сторінці Експорту.

Зверніть увагу, що, особливо для великих дерев, це може бути затратною операцією для сервера і повинно виконуватись лише у разі крайньої необхідності. З цієї причини кількість медіаархівів, які можуть бути створені, обмежена (за замовчуванням – один на годину). Якщо ви досягнете межі, з'явиться повідомлення про помилку.

Кращим варіантом для регулярного резервного копіювання ваших медіафайлів є використання [додатку Gramps Web Sync](sync.md) (який сам по собі не є рішенням для резервного копіювання) та створення інкрементних резервних копій на вашому локальному комп'ютері.

В обох випадках, якщо ваш користувач Gramps Web не має дозволу на перегляд приватних записів, експорт не міститиме файлів приватних медіаоб'єктів.

## Переміщення на іншу інстанцію Gramps Web

Gramps Web не прив'язує вас до конкретного постачальника, і ви завжди можете переміститися на іншу інстанцію Gramps Web без втрати даних і без прямого доступу до будь-якого з серверів.

Щоб здійснити повну міграцію, виконайте ці кроки (припускаючи, що у вас є права власника дерева):

1. Перейдіть на сторінку Експорту та експортуйте своє дерево у форматі Gramps XML (`.gramps`). Якщо ви використовуєте [додаток Sync](sync.md), ви також можете згенерувати експорт у Gramps Desktop.
2. На сторінці Експорту згенеруйте та завантажте медіаархів. Якщо ви використовуєте [додаток Sync](sync.md), ви також можете просто ZIP-увати свою локальну папку медіа Gramps.
3. Перейдіть до Налаштування > Адміністрування > Керування користувачами та натисніть кнопку "Експортувати деталі користувача". Це завантажить файл JSON.
4. У новій інстанції Gramps Web відкрийте сторінку Імпорту. Імпортуйте файл `.gramps`, експортований на кроці 1.
5. На сторінці Імпорту нової інстанції Gramps Web завантажте медіаархів (ZIP).
6. Перейдіть до Налаштування > Адміністрування > Керування користувачами нової інстанції Gramps Web. Натисніть кнопку "Імпортувати облікові записи користувачів" і завантажте файл JSON, завантажений на кроці 3.

Зверніть увагу, що, хоча ваші облікові записи користувачів будуть мігрувати, усім вашим користувачам потрібно буде встановити нові паролі, використовуючи посилання "забули пароль", оскільки паролі зберігаються в зашифрованій формі і не можуть бути експортовані.
