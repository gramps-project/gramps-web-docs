## Резервне копіювання вашого родоводу

Власники дерев можуть створювати, завантажувати та відновлювати повні резервні копії дерева – включаючи його налаштування та користувачів – у розділі [Резервні копії](settings.md#backups) налаштувань адміністрації.

Альтернативно, щоб створити резервну копію лише даних родового дерева, відкрийте сторінку Експорту в Gramps Web і виберіть формат Gramps XML.

Натискання на "експортувати" згенерує файл і почне завантаження, як тільки він буде готовий.

Зверніть увагу, що якщо ваш користувач Gramps Web не має дозволу на перегляд приватних записів, експорт не буде повною резервною копією, оскільки не міститиме жодних приватних записів.

Цей файл Gramps XML можна пізніше використати для відновлення дерева до цього точного стану через [Відновлення з резервної копії](settings.md#restore-from-backup).

## Поділіться своїм родоводом з користувачами інших генеалогічних програм

Коли обмін генеалогічними даними у форматі Gramps XML не є варіантом, ви також можете експортувати файл GEDCOM. Зверніть увагу, що це не підходить як резервна копія вашого родового дерева Gramps Web.

## Резервне копіювання ваших медіафайлів

Щоб зробити резервну копію ваших медіафайлів, ви можете створити та завантажити ZIP-архів усіх медіафайлів на сторінці Експорту.

Зверніть увагу, що, особливо для великих дерев, це може бути витратною операцією для сервера і повинно виконуватися лише в разі крайньої необхідності. З цієї причини кількість медіаархівів, які можна створити, обмежена (за замовчуванням – один на годину). Якщо ви досягнете межі, повідомлення про помилку це покаже.

Кращим варіантом для регулярного резервного копіювання ваших медіафайлів є використання [додатку Gramps Web Sync](sync.md) (який сам по собі не є рішенням для резервного копіювання) і створення інкрементних резервних копій на вашому локальному комп'ютері.

В обох випадках, якщо ваш користувач Gramps Web не має дозволу на перегляд приватних записів, експорт не міститиме файлів приватних медіаоб'єктів.

## Переміщення до іншої інстанції Gramps Web

Gramps Web не прив'язує вас до конкретного постачальника, і ви завжди можете переміститися до іншої інстанції Gramps Web без втрати будь-яких даних і без прямого доступу до жодного з серверів.

Щоб здійснити повну міграцію, виконайте ці кроки (припускаючи, що у вас є права власника дерева):

1. Перейдіть на сторінку Експорту та експортуйте своє дерево як файл Gramps XML (`.gramps`). Якщо ви використовуєте [додаток Sync](sync.md), ви також можете згенерувати експорт у Gramps на настільному комп'ютері.
2. На сторінці Експорту згенеруйте та завантажте медіаархів. Якщо ви використовуєте [додаток Sync](sync.md), ви також можете просто ZIP-увати свою локальну папку медіа Gramps.
3. Перейдіть до Налаштування > Адміністрація > Керування користувачами та натисніть кнопку "Експортувати деталі користувача". Це завантажить файл JSON.
4. У новій інстанції Gramps Web відкрийте сторінку Імпорту. Імпортуйте файл `.gramps`, експортований на кроці 1.
5. На сторінці Імпорту нової інстанції Gramps Web завантажте медіаархів (ZIP).
6. Перейдіть до Налаштування > Адміністрація > Керування користувачами нової інстанції Gramps Web. Натисніть кнопку "Імпортувати облікові записи користувачів" і завантажте файл JSON, завантажений на кроці 3.

Зверніть увагу, що, хоча ваші облікові записи користувачів будуть мігрувати, усім вашим користувачам потрібно буде встановити нові паролі, використовуючи посилання "забули пароль", оскільки паролі зберігаються в зашифрованій формі і не можуть бути експортовані.
