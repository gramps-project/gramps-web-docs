# Імпорт медіафайлів

Якщо ви [імпортували родинне дерево](import.md) і потрібно завантажити відповідні медіафайли, використовуйте **Імпорт медіафайлів** на [сторінці імпорту](import.md), нижче імпорту родинного дерева. Очікується, що це буде ZIP-файл, що містить відсутні медіафайли. Завантаження можливе лише тоді, коли дерево містить медіаоб'єкти, оскільки файли співвідносяться з існуючими медіаоб'єктами – файл родинного дерева лише посилається на свої медіафайли, тому спочатку імпортуйте його.

Файли співвідносяться з медіаоб'єктами у вашому дереві одним із двох способів:

- **За контрольною сумою.** Для медіаоб'єктів, які мають контрольну суму – як це відбувається для дерев, імпортованих з Gramps Desktop – використовується файл з відповідною контрольною сумою, незалежно від його назви або структури папок у ZIP-файлі. Це працює лише якщо контрольні суми в базі даних Gramps правильні, що забезпечує запуск інструмента перевірки та ремонту.
- **За шляхом або назвою файлу.** Медійні об'єкти без контрольної суми – як це зазвичай буває після імпорту GEDCOM – співвідносяться за відносним шляхом, збереженим у медіаоб'єкті. Якщо жоден файл у ZIP не має цього шляху, вони співвідносяться лише за назвою файлу, ігноруючи регістр (з моменту Gramps Web API 3.26). Це також працює для абсолютних шляхів з інших програм, таких як `C:\Users\...\Family\grandpa.jpg`, тому ви можете просто помістити всі файли в ZIP-файл. Назва файлу використовується лише якщо вона є унікальною, як у ZIP-файлі, так і серед медіаоб'єктів, які ще не мають файлу.

Після завантаження результат вказує, для скількох медіаоб'єктів був знайдений файл, і перераховує ті, для яких у ZIP-файлі не було файлу, з їхнім Gramps ID та збереженим шляхом. Використовуйте цей список, щоб знайти відсутні файли, а потім завантажте ще один ZIP-файл лише з цими – файли, які вже є на сервері, не підлягають змінам.

Якщо кілька медіаоб'єктів мають однакову назву файлу в різних папках, співвідношення за назвою файлу не працює для них. Або відтворіть структуру папок з збережених шляхів у ZIP-файлі, або спочатку імпортуйте все в Gramps Desktop, який має більше можливостей для асоціації існуючих медіафайлів з імпортованим деревом, а потім перейдіть до Gramps Web, як описано в [Перехід з Gramps Desktop](import.md#coming-from-gramps-desktop).

## Статус медіафайлів

Розділ **Дані** в [Налаштуваннях адміністрації](settings.md) показує:

- Загальну кількість медіаоб'єктів у дереві та чи є відсутні контрольні суми
- Кількість медіаоб'єктів, для яких асоційований файл відсутній на сервері

Зелена галочка вказує на те, що все в порядку. Якщо виявлено проблеми, показуються посилання на постраждалі об'єкти. Відсутні контрольні суми зазвичай виникають, коли дані імпортуються з формату, такого як GEDCOM, який містить посилання на медіа, але не самі файли. Відсутні файли можна завантажити, як описано вище.
