# Імпорт медіафайлів

Якщо ви [імпортували родинне дерево](import.md) і потрібно завантажити відповідні медіафайли, використовуйте **Імпорт медіафайлів** у розділі Дані [Налаштувань адміністрації](settings.md). Очікується ZIP-файл, що містить відсутні медіафайли. Файли співвідносяться з медіаоб'єктами у вашому дереві одним із двох способів:

- **За контрольними сумами.** Для медіаоб'єктів, які мають контрольну суму – як це відбувається для дерев, імпортованих з Gramps Desktop – використовується файл з відповідною контрольною сумою, незалежно від його назви або структури папок у ZIP-файлі. Це працює лише якщо контрольні суми в базі даних Gramps правильні, що забезпечується запуском інструмента перевірки та виправлення.
- **За шляхом.** Медійні об'єкти без контрольної суми – як це зазвичай буває після імпорту GEDCOM – співвідносяться за їх шляхом: ZIP-файл повинен містити файл під точно таким же відносним шляхом, який зберігається в медіаоб'єкті.

Якщо шляхи, збережені у вашому файлі GEDCOM, є абсолютними (наприклад, `C:\Users\...\photo.jpg`), співвідношення за шляхом не спрацює. У цьому випадку рекомендується спочатку імпортувати все в Gramps Desktop, який має більше можливостей для асоціації існуючих медіафайлів з імпортованим деревом, а потім перейти до Gramps Web, як описано в [Перехід з Gramps Desktop](import.md#coming-from-gramps-desktop).

## Статус медіафайлів

Розділ **Дані** [Налаштувань адміністрації](settings.md) показує:

- Загальну кількість медіаоб'єктів у дереві та чи є серед них такі, що не мають контрольної суми
- Кількість медіаоб'єктів, файл яких відсутній на сервері

Зелена галочка вказує на те, що все в порядку. Якщо виявлено проблеми, показуються посилання на постраждалі об'єкти. Відсутні контрольні суми зазвичай виникають, коли дані імпортувалися з формату, такого як GEDCOM, який містить посилання на медіа, але не самі файли. Відсутні файли можна завантажити, як описано вище.
