# Імпорт медіа файлів

Якщо ви [імпортували родинне дерево](import.md) і потрібно завантажити відповідні медіа файли, використовуйте **Імпорт медіа файлів** у розділі Дані налаштувань [Адміністрування](settings.md). Очікується, що це буде ZIP файл, що містить відсутні медіа файли. Файли співвідносяться з медіа об'єктами у вашому дереві одним із двох способів:

- **За контрольною сумою.** Для медіа об'єктів, які мають контрольну суму – як це відбувається для дерев, імпортованих з Gramps Desktop – використовується файл з відповідною контрольною сумою, незалежно від його назви або структури папок у ZIP файлі. Це працює лише якщо контрольні суми в базі даних Gramps є правильними, що забезпечується запуском інструменту перевірки та ремонту.
- **За шляхом.** Медійні об'єкти без контрольної суми – як це зазвичай буває після імпорту GEDCOM – співвідносяться за їх шляхом: ZIP файл повинен містити файл під точно таким же відносним шляхом, який зберігається в медіа об'єкті.

Якщо шляхи, збережені у вашому GEDCOM файлі, є абсолютними (наприклад, `C:\Users\...\photo.jpg`), співвідношення за шляхом не спрацює. У цьому випадку рекомендується спочатку імпортувати все в Gramps Desktop, який має більше можливостей для асоціації існуючих медіа файлів з імпортованим деревом, а потім перейти до Gramps Web, як описано в [Перехід з Gramps Desktop](import.md#coming-from-gramps-desktop).
