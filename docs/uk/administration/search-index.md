# Індекс пошуку

Розділ **Індекс пошуку** в [Налаштуваннях адміністрації](settings.md) показує стан індексу повнотекстового пошуку та дозволяє вам відновити його.

## Керування індексом пошуку

Gramps Web підтримує індекс повнотекстового пошуку, який зазвичай оновлюється автоматично щоразу, коли дані змінюються. Індикатор статусу показує, скільки об'єктів наразі проіндексовано в порівнянні з загальною кількістю об'єктів.

Натисніть **Оновити індекс пошуку**, щоб запустити повне відновлення. Індикатор прогресу відображається під час виконання завдання у фоновому режимі. Це рідко потрібно.

Якщо у дерева ще немає індексу пошуку, наприклад, після оновлення сервера, яке змінило формат індексу, Gramps Web будує його у фоновому режимі під час першого відкриття дерева. Поки він будується, розділ показує "Індекс пошуку будується." замість кількостей, **Оновити індекс пошуку** вимкнено, а результати пошуку можуть бути неповними. Процес побудови відображається в [Сповіщеннях](../user-guide/notifications.md) як завдання "Оновити індекс пошуку".
