# Керування користувачами

Інтерфейс керування користувачами доступний через **Налаштування > Керувати користувачами** (іконка користувача у верхній панелі програми). Він доступний лише для користувачів з роллю Власник або Адміністратор.

## Ролі користувачів

Дивіться [Система користувачів](../install_setup/users.md) для повного опису доступних ролей користувачів та їхніх прав.

## Перегляд та фільтрація користувачів

Сторінка керування користувачами показує таблицю всіх зареєстрованих облікових записів користувачів з наступними стовпцями:

- **Ім'я користувача** – ім'я для входу
- **Повне ім'я** – відображуване ім'я
- **E-mail** – електронна адреса користувача
- **Роль** – призначена роль (Гість, Член, Учасник, Редактор, Власник або Адміністратор)
- **Джерело облікового запису** – або "Пароль" (локальний обліковий запис), або назва зовнішнього постачальника ідентичності (наприклад, при використанні OIDC)

Використовуйте поле пошуку та випадаючий список ролей у верхній частині таблиці для фільтрації списку. Натисніть кнопку скидання фільтрів, щоб скинути всі фільтри.

## Редагування користувача

Натисніть на іконку редагування (олівець) у будь-якому рядку, щоб відкрити діалог редагування. Ви можете змінити:

- Повне ім'я
- Електронну адресу
- Роль

Це основний спосіб **активувати новоствореного користувача**: змініть їхню роль з *вимкненої* на будь-яку активну роль (наприклад, Член або Редактор).

Електронні адреси не повинні бути унікальними (з версії Gramps Web API 3.22), тому кілька облікових записів можуть ділити одну й ту ж адресу.

Вимкнення користувача або зміна їхнього пароля завершує всі їхні сесії протягом 15 хвилин.

!!! note
    Власники не можуть редагувати, змінювати пароль або видаляти користувачів з вищою роллю, такими як адміністратор сайту. Користувачі з однаковою роллю, такі як два власники дерева, можуть керувати один одним.

## Додати користувача вручну

Натисніть на іконку **додати користувача** (особа-додати) над таблицею, щоб створити новий обліковий запис користувача без необхідності самостійної реєстрації. Заповніть ім'я користувача, повне ім'я, електронну адресу, пароль і роль у діалозі та натисніть **Зберегти**.

## Видалити користувача

Натисніть на іконку видалення (смітник) у будь-якому рядку та підтвердіть у діалозі. Цю дію не можна скасувати.

!!! note
    Щоб запобігти тому, щоб дерево залишилося без когось, хто може ним керувати, ви не можете знизити свою роль нижче Власника або видалити свій обліковий запис, якщо ви є єдиним Власником або Адміністратором дерева. Спочатку підвищте іншого користувача до Власника. Адміністратор все ще може змінити або видалити останнього власника дерева іншого користувача, оскільки вони можуть призначити нового.

## Експорт та імпорт облікових записів користувачів

Ці кнопки корисні при [міграції на інший екземпляр Gramps Web](export.md).

- **Експортувати деталі користувача** (іконка завантаження) – завантажує файл JSON, що містить всі облікові записи користувачів (без паролів, оскільки паролі зберігаються в зашифрованій формі).
- **Імпортувати облікові записи користувачів** (іконка група-додати) – завантажує раніше експортований файл JSON для створення облікових записів користувачів масово. Усі імпортовані користувачі повинні будуть встановити новий пароль через посилання "Забули пароль", оскільки паролі не можуть бути перенесені.

## Посилання для реєстрації (тільки для налаштування з кількома деревами)

У налаштуванні з кількома деревами посилання для реєстрації нових користувачів показується у верхній частині сторінки керування користувачами. Ви можете скопіювати це посилання та поділитися ним з людьми, яких хочете запросити зареєструвати обліковий запис на вашому дереві.

!!! note
    У налаштуванні з одним деревом є загальне посилання "Зареєструватися" на сторінці входу; посилання для реєстрації для кожного дерева потрібно лише в установках з кількома деревами.

## Дозволи на чат з ШІ

Якщо чат з ШІ було увімкнено на сервері, випадаючий список у верхній частині сторінки дозволяє вам контролювати, які ролі користувачів можуть використовувати функцію чату:

- Усі (включаючи гостей)
- Члени та вище
- Учасники та вище
- Редактори та вище
- Тільки власники та адміністратори
- Ніхто (вимкнути чат для всіх користувачів)
