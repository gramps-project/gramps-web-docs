# Налаштування дерева

Власники та адміністратори дерева можуть адаптувати назву та вигляд дерева, а також його домашню сторінку для всіх користувачів. Ці налаштування знаходяться в розділах **Налаштування дерева** та **Налаштування** в [Налаштуваннях адміністрації](settings.md).

## Назва родинного дерева

!!! note
    Зміна назви дерева працює лише в [налаштуванні з кількома деревами](../install_setup/multi-tree.md) або коли `TREE_ID` явно встановлено в [конфігурації сервера](../install_setup/configuration.md). У стандартній установці з одним деревом без встановленого `TREE_ID` це викличе помилку.

Це дозволяє змінити назву бази даних родинного дерева Gramps. Введіть нову назву та натисніть **Перейменувати**, щоб застосувати зміни.

!!! tip
    Якщо ви хочете змінити лише назву, що відображається в панелі програми, не перейменовуючи базу даних, скористайтеся налаштуванням [Назва програми](#app-title).

## Інформація про дослідника

Встановіть ім'я, адресу та контактні дані основного дослідника. Ця інформація вбудована в експорти (наприклад, файли GEDCOM).

## Кольори теми

Встановіть власний **основний колір** та **додатковий колір** для веб-інтерфейсу Gramps. Ці кольори застосовуються до всіх користувачів цього дерева і набирають чинності одразу після збереження.

Використовуйте вибір кольорів, щоб вибрати кольори, а потім натисніть **Зберегти**. Натисніть **Скинути**, щоб повернутися до значень за замовчуванням.

## Назва програми

Встановіть власну назву для програми. Якщо встановлено, це переважає назву родинного дерева в рядку заголовка браузера та в верхній панелі програми.

Введіть назву та натисніть **Зберегти**. Залиште порожнім, щоб використовувати значення за замовчуванням (назва родинного дерева).

## Примітка на домашній сторінці

Виберіть об'єкт **Примітка** Gramps для відображення на домашній сторінці панелі приладів. Вміст примітки відображається під основними стовпцями панелі приладів і є видимим для всіх користувачів, які мають доступ до дерева.

Використовуйте вибір об'єкта, щоб знайти та вибрати примітку, а потім збережіть. Натисніть **Видалити**, щоб очистити поточну примітку на домашній сторінці.

## Зображення на домашній сторінці

Виберіть об'єкт **Медіа** Gramps для відображення як зображення на домашній сторінці панелі приладів. У поєднанні з приміткою на домашній сторінці зображення з'являється поруч з текстом примітки. Без примітки відображається лише зображення.

Використовуйте вибір об'єкта, щоб знайти та вибрати медіа-об'єкт, а потім збережіть. Натисніть **Видалити**, щоб очистити поточне зображення на домашній сторінці.

## Налаштування експорту/імпорту

Налаштування на рівні дерева (назва програми, кольори теми, примітка/зображення на домашній сторінці тощо) можна експортувати як файл JSON для резервного копіювання або для копіювання в інший екземпляр Gramps Web.

- Натисніть **Експортувати налаштування**, щоб завантажити поточні налаштування як файл JSON.
- Натисніть **Імпортувати налаштування дерева**, щоб завантажити раніше експортований файл JSON і застосувати налаштування.
