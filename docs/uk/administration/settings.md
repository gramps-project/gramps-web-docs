# Налаштування адміністрації

Сторінка **Налаштування > Адміністрація** доступна через іконку користувача у верхній панелі програми. Вона доступна лише для користувачів з роллю Власника або Адміністратора та надає інструменти для управління базою даних родинного дерева.

Сторінка організована у згортані секції. Натисніть заголовок секції, щоб розгорнути її. Ця сторінка містить секції та посилання на те, де кожна з них описана.

## Дані

- [Квоти використання](import.md#usage-quotas){#usage-quotas} – поточне використання відносно лімітів для людей та зберігання медіа
- [Імпорт даних](import.md){#import-data} – завантажити файл родинного дерева
- [Статус медіафайлів](import-media.md#media-file-status){#media-file-status} – медіа об'єкти з відсутніми контрольними сумами або файлами
- [Імпорт медіа архіву](import-media.md){#import-media-archive} – завантажити ZIP файл для заповнення відсутніх медіафайлів
