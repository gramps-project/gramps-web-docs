# Налаштування адміністрації

Сторінка **Налаштування > Адміністрація** доступна через іконку користувача в верхній панелі програми. Вона доступна лише для користувачів з роллю Власника або Адміністратора та надає інструменти для управління базою даних родинного дерева.

Сторінка організована у згортані секції. Натисніть заголовок секції, щоб розгорнути її.

## Дані

Охоплює квоти використання, імпорт даних та управління медіафайлами.

### Квоти використання

На початку секції показується поточне використання відносно будь-яких налаштованих обмежень:

- **Люди** – кількість об'єктів осіб у дереві порівняно з налаштованим максимумом (∞ якщо без обмежень)
- **Сховище медіа** – загальний розмір завантажених медіафайлів порівняно з налаштованою квотою сховища (∞ якщо без обмежень)

Квоти встановлюються адміністратором сервера; див. [Конфігурація сервера](../install_setup/configuration.md) для деталей.

### Імпорт даних

Секція імпорту дозволяє завантажити файл родинного дерева або медіаархів. Див. [Імпорт даних](import.md) для повних інструкцій.

### Статус медіафайлів

Ця секція показує:

- Загальну кількість медіаоб'єктів у дереві та чи є якісь з них без контрольної суми
- Кількість медіаоб'єктів, файл яких відсутній на сервері

Зелена галочка вказує, що все в порядку. Якщо виявлено проблеми, показуються посилання на постраждалі об'єкти. Відсутні контрольні суми зазвичай виникають, коли дані імпортувалися з формату, такого як GEDCOM, який включає посилання на медіа, але не самі файли. Відсутні файли можна завантажити через функцію імпорту медіаархіву.

### Імпорт медіаархіву

Дозволяє завантажити ZIP-файл медіафайлів для заповнення відсутніх файлів. Див. [Імпорт даних](import.md) для повних інструкцій.

## Індекс пошуку

### Управління індексом пошуку

Gramps Web підтримує повнотекстовий індекс пошуку, який зазвичай автоматично оновлюється щоразу, коли дані змінюються. Індикатор статусу показує, скільки об'єктів наразі проіндексовано порівняно з загальною кількістю об'єктів.

Натисніть **Оновити індекс пошуку**, щоб запустити повну перебудову. Індикатор прогресу показується, поки завдання виконується у фоновому режимі. Це зазвичай потрібно лише після оновлення сервера.

### Семантичний індекс пошуку

!!! warning "Застаріло"
    Семантичний пошук застарів і буде видалено в Gramps Web API 3.25 разом з цією секцією. AI чат не потребує його, оскільки Gramps Web API 3.24.

Якщо на сервері увімкнено [семантичний (на базі AI) пошук](../install_setup/chat.md#semantic-search-deprecated), з'являється додаткова секція з двома діями:

- **Відновити семантичний індекс пошуку** – перебудовує весь семантичний індекс з нуля. Це ресурсомісткий процес і може зайняти багато часу.
- **Оновити семантичний індекс пошуку** – виконує інкрементне оновлення, додаючи лише об'єкти, які ще не були проіндексовані. Швидше, ніж повна перебудова.

## Налаштування дерева

### Назва родинного дерева

!!! note
    Зміна назви дерева працює лише в [налаштуванні з кількома деревами](../install_setup/multi-tree.md) або коли `TREE_ID` явно встановлено в [конфігурації сервера](../install_setup/configuration.md). У стандартній установці з одним деревом без встановленого `TREE_ID` це викличе помилку.

Це дозволяє змінити назву бази даних родинного дерева Gramps. Введіть нову назву та натисніть **Перейменувати**, щоб застосувати.

!!! tip
    Якщо ви хочете лише змінити назву, що відображається в панелі програми, не перейменовуючи базу даних, використовуйте налаштування [Назва програми](#app-title).

### Інформація про дослідника

Встановіть ім'я, адресу та контактні дані основного дослідника. Ця інформація вбудована в експорти (наприклад, файли GEDCOM).

## Налаштування

### Кольори теми

Встановіть власний **основний колір** та **акцентний колір** для інтерфейсу Gramps Web. Ці кольори застосовуються до всіх користувачів цього дерева та набирають чинності негайно після збереження.

Використовуйте вибір кольорів, щоб вибрати кольори, потім натисніть **Зберегти**. Натисніть **Скинути**, щоб повернутися до значень за замовчуванням.

### Назва програми

Встановіть власну назву для програми. Якщо встановлено, це замінює назву родинного дерева в заголовку браузера та верхній панелі програми.

Введіть назву та натисніть **Зберегти**. Залиште порожнім, щоб використовувати значення за замовчуванням (назву родинного дерева).

### Нотатка на домашній сторінці

Виберіть об'єкт **Нотатка** Gramps для відображення на домашній сторінці інформаційної панелі. Зміст нотатки відображається під основними стовпцями інформаційної панелі і видимий для всіх користувачів, які мають доступ до дерева.

Використовуйте вибір об'єктів, щоб шукати та вибрати нотатку, потім збережіть. Натисніть **Видалити**, щоб очистити поточну нотатку на домашній сторінці.

### Зображення на домашній сторінці

Виберіть об'єкт **Медіа** Gramps для відображення як зображення на домашній сторінці інформаційної панелі. У поєднанні з нотаткою на домашній сторінці зображення з'являється поруч із текстом нотатки. Без нотатки відображається лише зображення.

Використовуйте вибір об'єктів, щоб шукати та вибрати медіаоб'єкт, потім збережіть. Натисніть **Видалити**, щоб очистити поточне зображення на домашній сторінці.

### Налаштування експорту/імпорту

Налаштування на рівні дерева (назва програми, кольори теми, нотатка/зображення на домашній сторінці тощо) можуть бути експортовані як файл JSON для резервного копіювання або копіювання в інший екземпляр Gramps Web.

- Натисніть **Експортувати налаштування**, щоб завантажити поточні налаштування як файл JSON.
- Натисніть **Імпортувати налаштування дерева**, щоб завантажити раніше експортований файл JSON та застосувати налаштування.

## Обробка родинного дерева

### Перевірка та виправлення бази даних

Цей інструмент перевіряє базу даних Gramps на внутрішні несумісності та виправляє ті, які може – аналогічно до інструмента [Перевірка та виправлення бази даних](https://www.gramps-project.org/wiki/index.php/Gramps_5.2_Wiki_Manual_-_Tools#Check_and_Repair_Database) у Gramps Desktop.

Натисніть **Перевірити та виправити** і чекайте, поки індикатор прогресу завершить роботу. Результат показується під кнопкою:

- Якщо помилок не знайдено, відображається повідомлення про підтвердження.
- Якщо помилки знайдено, показується підсумок виправлень, які були застосовані.

Запустіть цей інструмент, якщо ви зіткнулися з несподіваними помилками або поведінкою, яка може бути викликана несумісностями в базі даних, такими як відсутні зв'язки між об'єктами.

### Перевірка даних

Поки [Перевірка та виправлення бази даних](#check-and-repair-database) шукає *технічні* несумісності, цей інструмент шукає *недостовірні* дані – аналогічно до інструмента [Перевірка даних](https://gramps-project.org/wiki/index.php/Gramps_5.0_Wiki_Manual_-_Tools#Verify_the_Data) у Gramps Desktop. Він повідомляє про речі, які не є неможливими, але є достатньо малоймовірними, щоб на них варто звернути увагу, такі як мати віком 12 років або особа, яка дожила до 130 років.

У розділі **Опції** ви можете налаштувати пороги, які використовують тести – максимальний вік, мінімальний і максимальний вік для одруження або народження дітей, максимальна кількість дітей тощо – а також чи оцінювати відсутні або неточні дати та чи повідомляти про недійсні дати, такі як 31 лютого.

Натисніть **Перевірити дані**, щоб почати. Перевірка виконується як фонове завдання, а результати потім перераховуються в розділі **Результати перевірки даних**. Цей інструмент нічого не змінює: він лише повідомляє про те, що знаходить.

!!! note
    Виявлення не є доказом помилки. Довге життя та великі вікові різниці дійсно трапляються, тому сприймайте результати як список речей, які потрібно перевірити, а не як список речей, які потрібно виправити.

## Теги

### Управління тегами

Створюйте, перейменовуйте, змінюйте кольори та видаляйте [теги](../user-guide/tags.md) для родинного дерева. Теги зберігаються в базі даних Gramps, спільні для всіх користувачів, і повністю сумісні з Gramps Desktop.

Натисніть **Новий тег**, щоб створити тег. Використовуйте елементи керування поряд з існуючим тегом, щоб перейменувати його (іконка олівця), змінити його колір (вибір кольору) або видалити його (іконка видалення).

!!! note
    Видалення тега видаляє його з усіх об'єктів, до яких він був застосований.

Див. [Теги](../user-guide/tags.md) для того, як теги використовуються в Gramps Web, включаючи спеціальні теги `Blog` та `ToDo`.

## Резервні копії

Резервна копія містить дані родинного дерева, включаючи приватні записи, налаштування дерева та користувачів дерева. Медіафайли не включені; див. [Резервне копіювання ваших медіафайлів](export.md#back-up-your-media-files).

### Збережені резервні копії

Якщо адміністратор сервера встановив директорію резервних копій (`BACKUP_DIR`, див. [Конфігурація сервера](../install_setup/configuration.md)), резервні копії можуть зберігатися на сервері. В іншому випадку секція показує сповіщення про те, що зберігання резервних копій не налаштовано, і доступно лише відновлення з завантаженого файлу.

Натисніть **Створити резервну копію...**, щоб створити резервну копію. Вона створюється як фонове завдання, а потім з'являється в списку збережених резервних копій, з її датою, кількістю людей та її розміром. Сервер зберігає лише найновіші резервні копії (п'ять за замовчуванням) і автоматично видаляє старі. Кількість резервних копій, які можна створити за день, також обмежена.

Для кожної збереженої резервної копії ви можете:

- **Завантажити** її як файл `.tar`, наприклад, щоб зберегти копію в іншому місці.
- **Відновити** її, як описано нижче.
- **Видалити** її після підтвердження.

Резервна копія, створена за допомогою новішої версії Gramps Web, ніж та, що працює на сервері, позначається значком попередження і не може бути відновлена.

### Відновлення з резервної копії

Відновлює дерево з збереженої резервної копії або з завантаженого файлу. Щоб відновити збережену резервну копію, натисніть кнопку відновлення поруч із нею. Щоб відновити з файлу, виберіть резервну копію Gramps Web (`.tar`) або файл Gramps XML (`.gramps`) і натисніть **Відновити**.

!!! danger
    Відновлення даних є руйнівною заміною, а не злиттям. Будь-який існуючий об'єкт, який не присутній у резервній копії, буде видалено.

Для резервної копії Gramps Web діалог показує, коли була зроблена резервна копія, для якого дерева і з якою версією, і дозволяє вибрати, які частини відновити:

- **Дані** – об'єкти родинного дерева
- **Налаштування дерева** – налаштування цієї сторінки, такі як кольори теми, назва програми та нотатка на домашній сторінці
- **Користувачі** – користувачі дерева

Натисніть **Попередній перегляд**, щоб побачити, що зміниться після відновлення. Файл Gramps XML містить лише дані, тому для такого файлу попередній перегляд починається відразу. Вам буде запропоновано повторно автентифікуватися, якщо ваша сесія недостатньо нова. Попередній перегляд виконується як фонове завдання і, після завершення, відкриває діалог, що підсумовує зміни за типом об'єкта (люди, сім'ї, події, місця, цитати, джерела, репозиторії, медіаоб'єкти, нотатки, теги), а також для налаштувань дерева та користувачів, якщо вибрано:

- **Додати** – об'єкти, присутні в резервній копії, але відсутні в поточному дереві
- **Оновити** – об'єкти, присутні в обох, які відрізняються
- **Видалити** – об'єкти в поточному дереві, які відсутні в резервній копії
- **Без змін** – об'єкти, які ідентичні в обох

Якщо якісь об'єкти будуть видалені, діалог попереджає, скільки. Перегляньте підсумок, а потім натисніть **Відновити**, щоб застосувати зміни, або **Скасувати**, щоб скасувати.

Після відновлення користувачі, які були додані з резервної копії, перераховуються. Вони отримують випадковий пароль, тому їм потрібно скинути свій пароль, перш ніж вони зможуть увійти. Користувачі, які вже існують на сервері, ніколи не змінюються. Медіаоб'єкти, файли яких відсутні на сервері, також перераховуються; завантажте їх через [Імпорт медіаархіву](#import-media-archive).

!!! note
    Відновлення даних відновлює лише дані об'єктів та посилання на медіа. Бінарні медіафайли самі по собі та метадані дерева (за замовчуванням особа, закладки, групи імен) не підлягають змінам.

!!! tip
    Використовуйте це, щоб повернути дерево до відомої хорошої резервної копії, наприклад, після невдалого імпорту або небажаного масового редагування.

## Зона небезпеки

!!! danger
    Дії в Зоні небезпеки є **незворотними**. Зробіть [резервну копію](#backups) перед продовженням.

### Видалити всі об'єкти

Видаляє об'єкти з родинного дерева. Натискання **Видалити** відкриває діалог, де ви можете вибрати, щоб видалити:

- **Всі об'єкти** – повністю очищає дерево
- **Конкретні типи об'єктів** – наприклад, лише події або лише медіаоб'єкти

Вам буде запропоновано повторно автентифікуватися (увійти знову), щоб підтвердити дію. Видалення виконується як фонове завдання, і показується індикатор прогресу.

!!! warning
    Видалення лише підмножини типів об'єктів (а не всіх об'єктів одночасно) може зайняти дуже багато часу для великих дерев, оскільки сервер повинен перевірити та оновити всі зв'язки між об'єктами.

!!! tip
    Використовуйте це, щоб почати з чистого аркуша перед імпортом нового дерева або щоб видалити конкретні типи об'єктів, які були імпортовані неправильно.
