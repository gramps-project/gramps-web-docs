# Резервне копіювання та відновлення

Власники дерев можуть створювати, завантажувати та відновлювати резервні копії дерева в розділі **Резервні копії** налаштувань [Адміністрації](settings.md).

Резервна копія містить дані родинного дерева, включаючи приватні записи, налаштування дерева та користувачів дерева. Медійні файли не включені; див. [Резервне копіювання ваших медійних файлів](export.md#back-up-your-media-files).

## Збережені резервні копії

Якщо адміністратор сервера налаштував директорію для резервних копій (`BACKUP_DIR`, див. [Конфігурація сервера](../install_setup/configuration.md)), резервні копії можуть зберігатися на сервері. В іншому випадку, розділ показує повідомлення про те, що зберігання резервних копій не налаштоване, і доступне лише відновлення з завантаженого файлу.

Натисніть **Створити резервну копію...**, щоб створити резервну копію. Вона створюється як фонове завдання, а потім з'являється в списку збережених резервних копій, з вказанням дати, кількості людей та розміру. Сервер зберігає лише найновіші резервні копії (п’ять за замовчуванням) і автоматично видаляє старі. Кількість резервних копій, які можна створити за день, також обмежена.

Для кожної збереженої резервної копії ви можете:

- **Завантажити** її у вигляді файлу `.tar`, наприклад, щоб зберегти копію в іншому місці.
- **Відновити** її, як описано нижче.
- **Видалити** її після підтвердження.

Резервна копія, створена з новішою версією Gramps Web, ніж та, що працює на сервері, позначається значком попередження і не може бути відновлена.

## Відновлення з резервної копії

Відновлює дерево з збереженої резервної копії або з завантаженого файлу. Щоб відновити збережену резервну копію, натисніть кнопку відновлення поруч із нею. Щоб відновити з файлу, виберіть резервну копію Gramps Web (`.tar`) або файл Gramps XML (`.gramps`) і натисніть **Відновити**.

!!! danger
    Відновлення даних є руйнівною заміною, а не злиттям. Будь-який існуючий об'єкт, який відсутній у резервній копії, буде видалено.

Для резервної копії Gramps Web з'являється діалогове вікно, яке показує, коли була зроблена резервна копія, для якого дерева та з якою версією, і дозволяє вибрати, які частини відновити:

- **Дані** – об'єкти родинного дерева
- **Налаштування дерева** – налаштування сторінки адміністрації, такі як кольори теми, назва програми та примітка на домашній сторінці
- **Користувачі** – користувачі дерева

Натисніть **Попередній перегляд**, щоб побачити, що зміниться після відновлення. Файл Gramps XML містить лише дані, тому для такого файлу попередній перегляд починається відразу. Вам буде запропоновано повторно автентифікуватися, якщо ваша сесія недостатньо свіжий. Попередній перегляд виконується як фонове завдання і, після завершення, відкриває діалогове вікно, яке підсумовує зміни за типом об'єкта (люди, сім'ї, події, місця, цитати, джерела, репозиторії, медійні об'єкти, примітки, теги) та для налаштувань дерева і користувачів, якщо вибрано:

- **Додати** – об'єкти, присутні в резервній копії, але відсутні в поточному дереві
- **Оновити** – об'єкти, присутні в обох, які відрізняються
- **Видалити** – об'єкти в поточному дереві, які відсутні в резервній копії
- **Без змін** – об'єкти, ідентичні в обох

Якщо якісь об'єкти будуть видалені, діалогове вікно попереджає, скільки. Перегляньте підсумок, а потім натисніть **Відновити**, щоб застосувати зміни, або **Скасувати**, щоб скасувати.

Після відновлення користувачі, які були додані з резервної копії, відображаються в списку. Вони отримують випадковий пароль, тому їм потрібно скинути свій пароль, перш ніж вони зможуть увійти. Користувачі, які вже існують на сервері, ніколи не змінюються. Медійні об'єкти, файли яких відсутні на сервері, також відображаються; завантажте їх через [Імпорт медійних файлів](import-media.md).

!!! note
    Відновлення даних відновлює лише дані об'єктів та посилання на медіа. Бінарні медійні файли самі по собі та метадані дерева (за замовчуванням особа, закладки, групи імен) не підлягають змінам.

!!! tip
    Використовуйте це, щоб повернути дерево до відомої хорошої резервної копії, наприклад, після невдалого імпорту або небажаного масового редагування.

## Gramps XML як резервна копія

Якщо зберігання резервних копій недоступне, або ви просто хочете зберегти копію даних родинного дерева, [експортуйте](export.md) дерево як Gramps XML. Такий файл також можна відновити через [Відновлення з резервної копії](#restore-from-backup).

Зверніть увагу, що якщо ваш користувач Gramps Web не має дозволу на перегляд приватних записів, експорт не буде повною резервною копією, оскільки не міститиме жодних приватних записів.
