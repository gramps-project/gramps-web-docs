# Пошук

Сторінка пошуку доступна, якщо натиснути на значок лупи у верхній панелі програми або натиснути `s` [гарячу клавішу](shortcuts.md).

## Повнотекстовий пошук

Введіть будь-який запит у поле пошуку та натисніть Enter (або натисніть кнопку пошуку). Gramps Web здійснює пошук серед усіх типів об'єктів – людей, сімей, подій, місць, джерел, цитат, репозиторіїв, нотаток та медіа – і повертає результати, що відповідають запиту, відсортовані за релевантністю.

Результати показують тип об'єкта, ім'я та короткий опис. Натисніть на будь-який результат, щоб відкрити відповідну сторінку деталей.

Знак `*` може використовуватися як підстановочний знак, наприклад, `Mey*` відповідає "Meyer", "Meyers", "Meyerhofer" тощо.

## Фільтрація за типом об'єкта

Під полем пошуку кнопки-перемикачі для кожного типу об'єкта (Люди, Сім'ї, Події, Місця, …) дозволяють звузити результати до одного або кількох конкретних типів. За замовчуванням здійснюється пошук по всіх типах. Активування одного або кількох перемикачів обмежує результати лише цими типами.

## Семантичний пошук

!!! warning "Застаріло"
    Семантичний пошук застарів і буде видалений у Gramps Web API 3.25. Повнотекстовий пошук, описаний вище, не підлягає змінам.

Якщо адміністратор сервера увімкнув [семантичний (на базі ШІ) пошук](../install_setup/chat.md#semantic-search-deprecated), у верхньому правому куті сторінки пошуку з'являється перемикач режиму з двома опціями:

- **Пошук** – стандартний повнотекстовий пошук (за замовчуванням)
- **Семантичний** – пошук на базі ШІ, який розуміє значення вашого запиту, а не просто збігається з точними словами

Семантичний пошук корисний для запитів на природній мові, таких як "фермер у Баварії в 19 столітті". Він вимагає заповнення семантичного індексу; див. [Налаштування адміністрації](../administration/settings.md) для того, як створити або оновити індекс.
