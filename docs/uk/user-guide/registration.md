У встановленні з одною деревом будь-хто може зареєструвати новий обліковий запис на екземплярі Gramps Web, але його потрібно буде активувати вручну власником сайту, перш ніж він зможе бути використаний для входу.

У встановленні з кількома деревами користувачам додатково потрібен ID дерева для реєстрації; на практиці це означає, що вони можуть зареєструватися, використовуючи посилання на реєстрацію, яке поділився власник дерева.

## 1. Знайти форму реєстрації

На формі входу на домашній сторінці Gramps Web зазвичай є посилання "Зареєструвати новий обліковий запис".

Якщо це посилання відсутнє, або реєстрація вимкнена на цьому сервері, або це встановлення Gramps Web з кількома деревами. У будь-якому випадку, зв'яжіться з власником дерева, який може створити обліковий запис для вас або надіслати вам посилання на реєстрацію.

Якщо сервер підтримує вхід з зовнішнім обліковим записом (таким як Google, Microsoft або єдиний вхід вашої організації), сторінка реєстрації також пропонує ці варіанти. Вибір одного з них створює ваш обліковий запис без пароля і без підтвердження електронної пошти нижче. Якщо сервер не призначає ролі автоматично, обліковий запис все ще потрібно активувати власнику дерева (крок 4).

Власник дерева може знайти та скопіювати посилання на реєстрацію в розділі Налаштування/Адміністрування.

## 2. Надіслати форму реєстрації

Форма реєстрації має чотири обов'язкові поля: ім'я користувача, пароль, електронну адресу та повне ім'я. Коли всі чотири поля заповнені, натисніть "надіслати", щоб розпочати процес реєстрації.

## 3. Підтвердити електронну адресу

Після того, як форма була надіслана, на вказану електронну адресу буде надіслано автоматизований електронний лист, що містить посилання для підтвердження електронної пошти. Натискання на нього відкриє сторінку підтвердження.

Якщо підтвердження електронної пошти не приходить (і ви перевірили папку Спам), можливо, електронна пошта не була налаштована правильно адміністратором сервера Gramps Web.

## 4. Активувати обліковий запис

Після підтвердження електронної адреси власник дерева отримає сповіщення електронною поштою і може активувати новий обліковий запис користувача, перейшовши в розділ "Адміністрування користувачів" на сторінці налаштувань (доступно через іконку користувача у верхній панелі програми) і змінивши роль користувача з "вимкнено" на будь-яку з [інших ролей](../install_setup/users.md).

Зверніть увагу, що новий користувач *не* отримає автоматизоване сповіщення про те, що їхній обліковий запис було активовано, тому рекомендується адміністратору особисто сповістити їх.
