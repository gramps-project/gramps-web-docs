# Хромосомний браузер

Хромосомний браузер — це інструмент для візуалізації ДНК-співпадінь людини. Він показує сегменти ДНК, які спільні з іншими людьми в дереві, у вигляді кольорових смуг на хромосомах.

Ви можете знайти його на вкладці &ldquo;Хромосомний браузер&rdquo; у перегляді ДНК.

Для кожної хромосоми верхня (світло-блакитна) смуга представляє копію, успадковану від батька, нижня (світло-червона) смуга — ту, що успадкована від матері. Спільні сегменти показані як кольорові смуги поверх цих. Якщо сторона (батьківська або материнська) не відома, сегмент охоплює обидві смуги і показується з рисками.

Клацнувши на ім'я співпадіння в легенді, показуються лише спільні сегменти цієї особи.

Щоб зберегти діаграму, натисніть кнопку завантаження поруч із селектором осіб. Це завантажить файл SVG з білим фоном і легендою, включаючи загальну кількість спільних центиморганів для кожного співпадіння. Якщо в легенді вибрано співпадіння, лише це співпадіння буде включено.
