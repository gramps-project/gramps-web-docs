# Списки

Кожен тип об'єкта в Gramps Web має вигляд списку: Люди, Сім'ї, Події, Місця, Джерела, Цитати, Репозиторії, Нотатки та Медіа. Вони всі працюють однаково і мають однакові інструменти для сортування, фільтрації та масового редагування.

## Сортування та пагінація

Клацніть заголовок стовпця, щоб відсортувати за цим стовпцем; клацніть ще раз, щоб змінити порядок. Сортування виконується сервером, тому воно застосовується до всього списку, а не лише до сторінки, яку ви переглядаєте.

Довгі списки розділені на сторінки. Використовуйте елементи керування пагінацією внизу, щоб переміщатися між ними.

На вузьких екранах таблиця автоматично переходить у компактний режим, тому вигляди списків залишаються зручними для використання на телефоні.

## Вибір стовпців

Клацніть значок шестерні над списком, щоб відкрити діалог **Стовпці**. Відмітьте або зніміть відмітку зі стовпця, щоб показати або приховати його. **Скинути** відновлює вибір за замовчуванням для цього списку.

Принаймні один стовпець повинен залишатися видимим, тому останній залишений стовпець не може бути знятий з відмітки.

Ваш вибір стовпців запам'ятовується для кожного типу об'єкта та для кожного родинного дерева. Він зберігається у вашому браузері, тому не видимий іншим користувачам – але також не переноситься на інший браузер або пристрій.

## Фільтрація

Клацніть кнопку **фільтр**, щоб відкрити панель фільтрації. Вона пропонує три способи фільтрації, які можна комбінувати:

- **Готові фільтри** в згортальних секціях, які залежать від типу об'єкта. Наприклад, для людей ви можете фільтрувати за роком народження, роком смерті, різними властивостями особи, кількістю асоціацій, тегами та тим, чи є об'єкт приватним чи публічним.
- **Розширений фільтр** – конструктор умов для фільтрів, які не можуть бути виражені готовими, описаними [нижче](#advanced-filter).
- **GQL** – текстове поле для запиту в [Мові запитів Gramps](gql.md). Введіть запит і натисніть Enter або клацніть **Застосувати**. Якщо запит недійсний, рамка поля стає червоною. Запит застосовується поверх інших фільтрів.

Активні фільтри відображаються у вигляді чіпсів над списком. Видаліть один фільтр, клацнувши кнопку очищення чіпса, або використовуйте **Очистити всі фільтри**, щоб видалити їх усі одразу.

### Розширений фільтр

Клацніть **Розширений фільтр** внизу панелі фільтрації, щоб відкрити конструктор умов. Його умови – це правила фільтрації, відомі з Gramps Desktop, такі як "Люди з &lt;ім'я&gt;" або "Предки &lt;особи&gt;".

- Клацніть **Додати умову**, щоб вибрати правило. Правила згруповані за категоріями і можуть бути знайдені за назвою або описом.
- Заповніть параметри правила. Кожен параметр має відповідний ввід, наприклад, поле дати, селектор тегів або селектор об'єкта для особи чи місця.
- Виберіть, як умови групи комбінуються: **Усі умови**, **Будь-яка умова** або – через меню поруч з ними – **Тільки одна умова**.
- Клацніть **Додати групу**, щоб додати групу умов всередині іншої групи, з власним способом їх комбінування.
- Виберіть **Не** для умови або групи, щоб інвертувати її.

Клацніть **Застосувати**, щоб відфільтрувати список.

Готові фільтри, які активні, коли ви відкриваєте конструктор, з'являються там як умови. Якщо фільтр, який ви створюєте, може бути виражений за допомогою готових фільтрів, він відображається з ними після застосування. В іншому випадку, він відображається як єдиний чіп **Розширений фільтр**, а панель фільтрації пропонує кнопку **Редагувати**, щоб знову відкрити конструктор.

!!! note
    Правила, які посилаються на користувацькі фільтри, збережені в Gramps Desktop, недоступні в конструкторі. Правила відображаються вашою мовою з Gramps Web API 3.24 або новішої версії.

## Вибір об'єктів і масові дії над ними

Користувачі з правами редагування бачать кнопку **Вибрати** поруч із кнопкою фільтрації. Клацніть її, щоб увійти в режим вибору, що додає прапорець до кожного рядка.

Відмітьте об'єкти, які вам потрібні, і з'являється панель інструментів, що показує, скільки об'єктів вибрано, разом з випадаючим меню **Дія** та кнопкою **Застосувати**.

### Видалити

Виберіть один або кілька об'єктів, виберіть **Видалити** і клацніть **Застосувати**. Діалог підтвердження запитує вас про підтвердження, попереджаючи, що дію не можна скасувати.

!!! tip
    Видалення записується в [історії змін](revisions.md) так само, як і будь-яка інша зміна, тому помилкове масове видалення можна скасувати, скасувавши відповідну транзакцію.

### Об'єднати

Виберіть **точно два** об'єкти, виберіть **Об'єднати** і клацніть **Застосувати**. Діалог запитує, який з двох повинен надати основні дані для об'єднаного об'єкта; клацніть той, який ви хочете зберегти як основний. Дані іншого об'єкта об'єднуються в нього, і посилання оновлюються.

Об'єднання доступне для людей, сімей, подій, місць, джерел і цитат. Воно недоступне для репозиторіїв, нотаток і медіа-об'єктів.

Якщо ви виберете дію без дійсного вибору – наприклад, об'єднання лише з одним вибраним об'єктом – діалог пояснить, що потрібно.
