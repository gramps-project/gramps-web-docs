# Списки

Кожен тип об'єкта в Gramps Web має вигляд списку: Люди, Сім'ї, Події, Місця, Джерела, Цитати, Репозиторії, Нотатки та Медіа. Вони всі працюють однаково і мають однакові інструменти для сортування, фільтрації та масового редагування.

## Сортування та пагінація

Натисніть заголовок стовпця, щоб відсортувати за цим стовпцем; натисніть його ще раз, щоб змінити порядок. Сортування виконується сервером, тому воно застосовується до всього списку, а не лише до сторінки, яку ви переглядаєте.

Довгі списки розділені на сторінки. Використовуйте елементи керування пагінацією внизу, щоб переміщатися між ними.

На вузьких екранах таблиця автоматично переключається на компактний вигляд, тому списки залишаються зручними для використання на телефоні.

## Вибір стовпців

Натисніть значок шестерні над списком, щоб відкрити діалог **Стовпці**. Позначте або зніміть позначку зі стовпця, щоб показати або приховати його. **Скинути** відновлює вибір за замовчуванням для цього списку.

Принаймні один стовпець має залишатися видимим, тому останній залишковий стовпець не може бути знятий.

Ваш вибір стовпців запам'ятовується для кожного типу об'єкта та для кожного родинного дерева. Він зберігається у вашому браузері, тому не видимий для інших користувачів – але він також не переноситься на інший браузер або пристрій.

## Фільтрація

Натисніть кнопку **фільтр**, щоб відкрити панель фільтрації. Вона пропонує три способи фільтрації, які можна комбінувати:

- **Готові фільтри** в згортаних секціях, які залежать від типу об'єкта. Наприклад, для людей ви можете фільтрувати за роком народження, роком смерті, різними властивостями особи, кількістю асоціацій, тегами та тим, чи є об'єкт приватним чи публічним.
- **Розширений фільтр** – конструктор умов для фільтрів, які не можуть бути виражені готовими, описаними [нижче](#advanced-filter).
- **GQL** – текстове поле для запиту в [Мові запитів Gramps](gql.md). Введіть запит і натисніть Enter або натисніть **Застосувати**. Якщо запит недійсний, рамка поля стає червоною. Запит застосовується поверх інших фільтрів.

Активні фільтри відображаються як чіпси над списком. Видаліть один фільтр, натиснувши кнопку очищення чіпса, або використовуйте **Очистити всі фільтри**, щоб видалити їх усі одразу.

### Розширений фільтр

Натисніть **Розширений фільтр** внизу панелі фільтрації, щоб відкрити конструктор умов. Його умови – це правила фільтрації, відомі з Gramps Desktop, такі як "Люди з &lt;ім'я&gt;" або "Предки &lt;особи&gt;".

- Натисніть **Додати умову**, щоб вибрати правило. Правила згруповані за категоріями та можуть бути знайдені за назвою або описом.
- Заповніть параметри правила. Кожен параметр має відповідний ввід, наприклад, поле дати, селектор тегів або селектор об'єкта для особи чи місця.
- Виберіть, як умови групи комбінуються: **Усі умови**, **Будь-яка умова** або – через меню поруч з ними – **Точно одна умова**.
- Натисніть **Додати групу**, щоб додати групу умов всередині іншої групи, з власним способом їх комбінування.
- Виберіть **Не** для умови або групи, щоб інвертувати її.

Натисніть **Застосувати**, щоб відфільтрувати список.

Готові фільтри, які активні, коли ви відкриваєте конструктор, з'являються там як умови. Якщо фільтр, який ви створюєте, може бути виражений за допомогою готових фільтрів, він показується з ними після застосування. В іншому випадку він показується як єдиний чіп **Розширений фільтр**, а панель фільтрації пропонує кнопку **Редагувати** для повторного відкриття конструктора.

!!! note
    Правила, які посилаються на користувацькі фільтри, збережені в Gramps Desktop, недоступні в конструкторі. Правила відображаються вашою мовою з Gramps Web API 3.24 або новішої версії.

## Вибір об'єктів та масові дії над ними

Користувачі з правами редагування бачать кнопку **Вибрати** поруч із кнопкою фільтра. Натисніть її, щоб увійти в режим вибору, який додає прапорець до кожного рядка.

Позначте об'єкти, які вам потрібні, і з'являється панель інструментів, що показує, скільки об'єктів вибрано, разом з випадаючим меню **Дія** та кнопкою **Застосувати**.

Прапорець у заголовку таблиці вибирає всі об'єкти на поточній сторінці. Якщо більше об'єктів відповідають поточним фільтрам, панель інструментів тоді пропонує **Вибрати всі (N)**, що вибирає всі N відповідні об'єкти на всіх сторінках. Зняття позначки з рядка, зміна сторінки або фільтрів або вихід з режиму вибору завершують це вибір.

### Видалити

Виберіть один або кілька об'єктів, виберіть **Видалити** і натисніть **Застосувати**. Діалог підтвердження запитує вас про підтвердження, попереджаючи, що дію не можна скасувати.

Видалення більше ніж десяти об'єктів виконується як фонове завдання. Його прогрес відображається поруч із кнопкою **Застосувати** та в [Сповіщеннях](notifications.md), а список перезавантажується, коли це завершено.

!!! tip
    Видалення записується в [історії змін](revisions.md) так само, як і будь-яка інша зміна, тому помилкове масове видалення можна скасувати, скасувавши відповідну транзакцію.

### Об'єднати

Виберіть **точно два** об'єкти, виберіть **Об'єднати** і натисніть **Застосувати**. Діалог запитує, який з двох має надати основні дані для об'єднаного об'єкта; натисніть той, який ви хочете зберегти як основний. Дані іншого об'єкта об'єднуються в нього, і посилання оновлюються.

Об'єднання доступне для людей, сімей, подій, місць, джерел і цитат. Воно недоступне для репозиторіїв, нотаток і медіа-об'єктів.

У вигляді медіа вибір працює як у галереї, так і в списковому вигляді: у режимі вибору натискання на плитку або рядок перемикає його. **Видалити** – єдина доступна дія для медіа.

Якщо ви виберете дію без дійсного вибору – наприклад, об'єднання лише з одним вибраним об'єктом – діалог пояснює, що потрібно.
