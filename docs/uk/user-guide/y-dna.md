# Використання Gramps Web для аналізу Y-ДНК

!!! note "Примітка"
    Ця функція вимагає версії Gramps Web API 3.3.0 або новішої та версії Gramps Web frontend 25.9.0 або новішої.

Вид Y-ДНК у Gramps Web може використовувати сирі дані про однонуклеотидні поліморфізми (SNP) Y-хромосоми для визначення найбільш ймовірної гаплогрупи Y-ДНК особи та відображення похідних предків у дереві Y-хромосоми людини разом із оцінками часу.

## Як отримати та зберегти дані SNP Y-ДНК

Щоб отримати дані SNP Y-ДНК, вам потрібно пройти тест Y-ДНК через службу генетичного тестування. Результат представлений як набір мутацій (SNP), кожна з яких ідентифікується рядком (наприклад, `R-BY44535`) та знаком `+` або `-`, що вказує на те, чи присутня мутація, чи відсутня. Gramps Web очікує рядок усіх протестованих SNP у форматі `SNP1+, SNP2-, SNP3+,...`, який потрібно зберегти в атрибуті особи з користувацьким типом `Y-DNA` (чутливість до регістру). Ви можете або вручну створити цей атрибут у Gramps Web або Gramps Desktop, або перейти до виду Y-ДНК у Gramps Web і натиснути синю кнопку "Додати", вибрати особу, до якої потрібно додати дані, і вставити рядок SNP. У будь-якому випадку дані будуть збережені як атрибут особи у вашій базі даних Gramps.

[Дивіться нижче](#instructions-for-obtaining-snp-data-from-testing-services) для отримання інструкцій про те, як отримати дані SNP з різних служб тестування.

## Як це працює

Якщо у особи є атрибут `Y-DNA`, що містить дані SNP, Gramps Web використовуватиме бібліотеку Python з відкритим вихідним кодом [yclade](https://github.com/DavidMStraub/yclade) для визначення найбільш ймовірної позиції особи в дереві Y-хромосоми людини. Дерево було створено проектом [YFull](https://www.yfull.com/) на основі десятків тисяч тестів Y-ДНК. Зверніть увагу, що Gramps Web використовує локальну копію дерева YFull, тому жодні дані не надсилаються третім особам.

Дерево проходиться від кореня до листя, і на кожному вузлі SNP, пов'язані з цим вузлом, порівнюються з позитивно та негативно протестованими SNP особи, і слідується відповідній гілці.

Кінцевий результат — це послідовність кладів від кореня дерева (Y-хромосомний "Адам" [Adam](https://en.wikipedia.org/wiki/Y-chromosomal_Adam)) до найбільш похідного кладу, що відповідає даним SNP особи. Кожен клад має оцінену вікову групу на основі віку зразків у базі даних YFull, які належать до цього кладу.

Оскільки Y-хромосоми успадковуються від батька до сина, ця послідовність відповідає витягу патрилінійного походження особи.

## Як інтерпретувати результати

Найважливішою інформацією є найбільш ймовірна гаплогрупа особи, яка відображається у верхній частині сторінки. Назва пов'язана з відповідною сторінкою на веб-сайті [YFull](https://www.yfull.com/), яка містить більше інформації, такої як країна походження протестованих зразків, що належать до цієї гаплогрупи.

У дереві патрилінійних предків, показаному в Gramps Web, коробка безпосередньо над протестованою особою є найближчим загальним предком (MRCA) усіх протестованих зразків, що належать до гаплогрупи особи. Дата, показана для цього предка, є його приблизною оцінкою дати народження. Предок над ним — це предок, де мутація, що визначає цю гаплогрупу, вперше з'явилася.

Через повільну швидкість мутацій Y-хромосом, MRCA може бути багато сотень років у минулому. Для рідкісних гаплогруп (тобто гаплогруп, для яких протестовано небагато людей), це може бути навіть тисячі років.

Між MRCA та протестованою особою графік показує батьківську лінію настільки далеко, наскільки це задокументовано у вашому дереві: батька, його батька і так далі, найстаршого спочатку. Пунктирна лінія над найстаршим задокументованим предком позначає покоління, які не задокументовані, з оцінкою їх кількості. Слідують лише біологічні батьки — лінія зупиняється на прийомному батькові або вітчиму, оскільки вони не передали Y-хромосому. Натисніть на особу в лінії, щоб відкрити їхню сторінку.

Іконка на кожному блоці кладу відкриває цей клад на веб-сайті YFull.

## Приватні дані Y-ДНК

Діалоги для додавання та редагування даних Y-ДНК мають перемикач **Приватний**. Приватні дані Y-ДНК приховані від користувачів, які не можуть переглядати приватні записи. Дивіться [Приватні записи](privacy.md).

## Інструкції для отримання даних SNP з тестувальних служб

### [YSEQ](https://www.yseq.net/)

Після входу в "Мій обліковий запис" перейдіть до "Мої результати / Переглянути мої алелі" і прокрутіть до нижньої частини сторінки. Текстове поле "Список алелів компактний" було додано спеціально для Gramps Web і має точно правильний формат для вставки в атрибут `Y-DNA`.
