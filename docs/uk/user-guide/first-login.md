Коли ви вперше входите в Gramps Web, з'явиться форма Налаштувань (позначена як Налаштування користувача), яка вимагатиме від користувача вибрати мову для інтерфейсу та [Домашню особу](https://www.gramps-project.org/wiki/index.php/Gramps_Glossary#home_person). Вибір Домашньої особи також можна змінити з Головної сторінки веб-сайту.

Домашня особа для користувача веб-сайту Gramps Web не обов'язково повинна бути тією ж особою, яку вибрав власник сайту в Gramps для настільних комп'ютерів – це особисте налаштування, яке може бути різним для кожного користувача Gramps Web. Домашня особа використовується для початкового перегляду родинного дерева та є відправною точкою для більшості звітів. Типовим вибором буде, якщо користувач вибере себе як Домашню особу. Коли ви співпрацюєте з іншим членом Дерева, ці користувачі можуть захотіти встановити спільного предка як Домашню особу. Це забезпечує спільну точку відліку для віддалених зв'язків.

Щоб вибрати особу як Домашню особу, почніть вводити Ім'я або Прізвище в текстовому полі, і з'явиться випадаючий список з відповідними варіантами.

Якщо дерево ще порожнє, вибрати нема кого. У цьому випадку головна сторінка показує картку **Почати** (Get started), яка проводить редакторів через перші кроки: спочатку додавання особи (або імпорт файлу родинного дерева), а потім з'єднання людей, додаючи родину. Перша особа, яку ви створите в порожньому дереві, автоматично стане вашою Домашньою особою. Дивіться [Почати нове дерево](start-tree.md) для покрокового керівництва.

Налаштування мови та Домашньої особи зберігаються в локальному сховищі браузера, тому вони зберігатимуться на даному пристрої. Домашня особа зберігається окремо для кожного дерева.
