# Використання вбудованого блогу

Блог призначений для представлення історій про дослідження вашої родинної історії.

У базі даних Gramps публікації блогу представлені як джерела з прикріпленою нотаткою, що містить текст блогу, а за бажанням, медіафайли для зображень публікації блогу. Gramps Web розглядає кожне джерело з тегом `Blog` як статтю блогу.

## Додати публікацію блогу

Найшвидший спосіб написати публікацію — це спеціальна форма **Нова публікація блогу** в Gramps Web. Відкрийте її або з блакитної кнопки **+** на сторінці блогу, або з меню **Додати** (іконка плюс) у верхній панелі додатку, вибравши **Публікація блогу**.

Форма має поля для:

- **Заголовок** – заголовок публікації (обов'язково)
- **Автор** – хто її написав
- **Зміст** – редактор збагаченого тексту для самої публікації
- **Медіа** – один або кілька медіаоб'єктів. Перший з них стає зображенням попереднього перегляду, що показується над текстом; всі вони з'являються як галерея під ним.
- **Теги** та перемикач **приватний**, як для будь-якого іншого об'єкта

Збереження форми створює основне джерело, нотатку та тег `Blog` для вас, як описано [нижче](#relation-between-blog-and-sources).

### Додавання публікації вручну

Ви також можете створити публікацію, самостійно створивши основні об'єкти. Це єдиний спосіб зробити це в Gramps Desktop ([синхронізовано](../administration/sync.md) з Gramps Web), і кроки однакові в обох додатках:

- Додайте нове джерело. Заголовок джерела буде заголовком вашої публікації блогу, автором джерела буде автор публікації.
- За бажанням, асоціюйте джерело з репозиторієм, що відповідає вашому блогу в Gramps Web.
- Додайте нову нотатку до джерела. Напишіть свою публікацію блогу та скопіюйте текст у нотатку.
- За бажанням, додайте один або кілька медіафайлів до вашого джерела. Перший медіафайл буде взято як зображення попереднього перегляду публікації, що показується над текстом. Усі медіафайли будуть показані під текстом як галерея.
- Додайте мітку `Blog` до джерела (створіть її, якщо вона не існує).

## Взаємозв'язок між блогом та джерелами

Оскільки публікації блогу є просто джерелами, всі статті блогу також з'являються у списку джерел і показуються як джерела в пошуках. У перегляді джерела є кнопка "показати в блозі", яка перенесе вас до перегляду блогу для цієї публікації. URL публікації блогу також містить ID Gramps відповідного джерела, тому стаття за адресою `yourdomain.com/blog/S0123` відповідає джерелу за адресою `yourdomain.com/source/S0123`.

Внизу кожної публікації блогу є кнопка "деталі", яка перенесе вас до перегляду джерела.
