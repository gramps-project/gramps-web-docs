# Посібник користувача

Цей розділ документує функції, доступні користувачам Gramps Web.

!!! note "Не бачите всіх функцій?"
    Gramps Web використовує систему дозволів на основі ролей. Деякі функції – такі як редагування даних, управління тегами або перегляд приватних записів – доступні лише користувачам з достатніми правами. Ви можете перевірити свою поточну роль у [Налаштуваннях користувача](settings.md). Якщо вам потрібен більший доступ, зверніться до власника вашого дерева або адміністратора. Дивіться [Система користувачів](../install_setup/users.md) для опису всіх ролей.

## Навігація по інтерфейсу

### Головна навігація

Бічна панель (або меню "гамбургер" на мобільних пристроях) є основним способом переміщення між розділами:

- **Головна** – інформаційна панель (див. нижче)
- **Блог** – історії родинної історії, написані у вигляді блог-постів
- **Сімейне дерево** – інтерактивні графіки дерева
- **Хронологія** – хронологічний перегляд подій у дереві (вимагає достатньо нової версії API Gramps Web)
- **Карта** – географічний перегляд місць у дереві
- **ДНК** – інструменти для аналізу збігів ДНК
- **Списки** – перегляд усіх об'єктів кожного типу: Люди, Сім'ї, Події, Місця, Джерела, Цитати, Репозиторії, Нотатки
- **Медіа** – перегляд усіх медіа-файлів (фото, документи тощо)
- **Асистент** – AI-чат асистент (якщо активовано адміністратором)
- **Історія** – нещодавно змінені об'єкти
- **Закладки** – ваші збережені закладки
- **Завдання** – дослідницькі завдання
- **Звіти** – генерувати звіти
- **Експорт** – експортувати сімейне дерево
- **Ревізії** – повна історія транзакцій (видима для учасників та вище)
- **Сповіщення** – минулі сповіщення

!!! note
    Теги більше не керуються з бічної панелі – управління тегами переміщено до [Налаштувань адміністрації](../administration/settings.md#tags) (тільки для власників/адміністраторів). Дивіться [Теги](tags.md) для інформації про використання тегів.

### Верхня панель додатку

Панель у верхній частині кожної сторінки містить:

- **Додати** (іконка плюс, видима для учасників та вище) – відкриває меню для створення нового об'єкта: Особа, Сім'я, Подія, Місце, Джерело, Цитата, Репозиторій, Нотатка, Медіа-об'єкт або Завдання
- **Пошук** (лупа) – відкриває сторінку пошуку
- **Іконка користувача** – відкриває меню налаштувань: Налаштування користувача, Адміністрування (тільки для власників), Управління користувачами (тільки для власників), Інформація про систему

## Головна сторінка (інформаційна панель)

Інформаційна панель відображається, коли ви вперше входите в систему. Вона має два стовпці:

**Лівий стовпець:**

- **Картка домашньої особи** – показує ім'я, фото (якщо доступно) та ключові факти про вашу обрану домашню особу, з посиланням на їх повний профіль та швидкою навігацією до сімейного дерева. Натисніть кнопку **Встановити домашню особу** на картці, щоб знайти та вибрати іншу особу.
- **Ювілеї** – майбутні дні народження та ювілеї з дерева, на основі сьогоднішньої дати.
- **Нещодавно змінені** – короткий список найостанніших змінених об'єктів, корисний для відстеження спільних редагувань.

**Правий стовпець:**

- **Нещодавні блог-пости** – останні записи з [блогу](blog.md), якщо такі є.
- **Статистика** – підсумок кількості об'єктів у дереві (кількість людей, сімей, подій тощо).

Поки дерево ще порожнє, інформаційна панель приховує панелі, які не мають нічого для показу, і замість цього відображає картку **Почати** для користувачів з правами редагування: спочатку пропонує створити особу або імпортувати файл сімейного дерева, а коли особи існують, з'єднати їх, створивши сім'ю. Картка зникає, як тільки дерево містить сім'ю.

Якщо адміністратор дерева налаштував **ноту на головній сторінці** та/або **зображення на головній сторінці**, вони відображаються помітно над основними стовпцями. Зображення з'являється поруч з текстом нотатки, коли обидва налаштовані. Дивіться [Налаштування адміністрації](../administration/customization.md) для інформації про налаштування цих елементів.

!!! tip
    Якщо дерево порожнє і у вас є права редагування, інформаційна панель показує запит "Почати" з кнопками для додавання вашої першої особи або імпорту файлу сімейного дерева.

## Встановлення Gramps Web як додатку

Gramps Web є прогресивним веб-додатком (PWA), що означає, що ваш браузер може встановити його поряд з іншими вашими додатками, замість того, щоб зберігати його у вкладці браузера. Він отримує власну іконку та відкривається у власному вікні, без адресного рядка та панелей інструментів браузера.

Як ви його встановите, залежить від вашого браузера:

- **Android (Chrome)** – відкрийте меню та виберіть "Встановити додаток" або "Додати на домашній екран".
- **iOS/iPadOS (Safari)** – натисніть кнопку спільного доступу та виберіть "Додати на домашній екран".
- **Настільний (Chrome, Edge)** – натисніть іконку встановлення в правому кінці адресного рядка або використайте пункт "Встановити" у меню браузера.
- **Настільний (Firefox, Safari)** – встановлення не підтримується; використовуйте звичайну вкладку або вікно браузера.

Нічого не змінюється в тому, як працює Gramps Web, і жодні дані не зберігаються інакше – це той же додаток, просто представлений як окремий додаток.

!!! note
    Gramps Web все ще потребує доступу до вашого сервера, щоб показати ваші дані, тому встановлений додаток не дозволяє переглядати ваше сімейне дерево офлайн.
