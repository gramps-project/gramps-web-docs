# Configurações de Administração

A página **Configurações > Administração** é acessível através do ícone do usuário na barra superior do aplicativo. Ela está disponível apenas para usuários com a função de Proprietário ou Administrador e fornece ferramentas para gerenciar o banco de dados da árvore genealógica.

A página está organizada em seções colapsáveis. Clique no cabeçalho de uma seção para expandi-la. Esta página lista as seções e links para onde cada uma delas é descrita.

- [Status do arquivo de mídia](import-media.md#media-file-status){#media-file-status} – objetos de mídia com somas de verificação ou arquivos ausentes
- [Importar arquivo de mídia](import-media.md){#import-media-archive} – fazer upload de um arquivo ZIP para preencher arquivos de mídia ausentes
