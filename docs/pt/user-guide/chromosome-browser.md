# Navegador de Cromossomos

O navegador de cromossomos é uma ferramenta para visualizar as correspondências de DNA de uma pessoa. Ele mostra os segmentos de DNA compartilhados com outras pessoas na árvore como barras coloridas nos cromossomos.

Você pode encontrá-lo na aba “Navegador de Cromossomos” na visualização de DNA.

Para cada cromossomo, a barra superior (azul claro) representa a cópia herdada do pai, a barra inferior (vermelho claro) a herdada da mãe. Os segmentos compartilhados são mostrados como barras coloridas em cima dessas. Se o lado (paternal ou maternal) não for conhecido, o segmento abrange ambas as barras e é mostrado com marcas de hachura.

Clicando no nome de uma correspondência na legenda, apenas os segmentos compartilhados dessa pessoa são exibidos.

Para salvar o gráfico, clique no botão de download ao lado do seletor de pessoas. Ele baixa um arquivo SVG com fundo branco e a legenda, incluindo o total de centimorgans compartilhados de cada correspondência. Se uma correspondência for selecionada na legenda, apenas essa correspondência é incluída.
